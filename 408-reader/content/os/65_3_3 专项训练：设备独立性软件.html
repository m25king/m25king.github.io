当进程提出 I/O 请求后，系统的设备分配程序可按以下步骤进行设备分配：


① 分配设备。首先根据 I/O 请求中的物理设备名 (一般进程是提供逻辑设备名，通过逻辑设备表映射成物理设备名)，查找系统设备表 SDT，从中找出该设备的设备控制表 DCT，再根据 DCT 中的设备状态字段获知该设备是否正忙。若忙，则将请求 I/O 的进程的 PCB 挂在设备队列上。否则，按照一定的算法（比如银行家算法等）计算本次设备分配的安全性。如果不会导致系统进入不安全状态（就是不会出现死锁），则将设备分配给请求进程。否则，仍将其 PCB 插入设备等待队列


② 分配控制器。在系统把设备分配给请求 I/O 的进程后，再到其 DCT 中找出与该设备连接的控制器的控制器控制表COCT，从 COCT 的状态字段中可知该控制器是否正忙。若忙，则将请求 I/O 进程的 PCB 挂在该控制器的等待队列上。否则，将该控制器分配给进程


③ 分配通道。在该 COCT 中又可找到与该控制器连接的通道的通道控制表 CHCT。根据 CHCT 内的状态信息可知该通道是否正忙。若忙，则将请求 I/O 的进程挂在该通道的等待队列上；否则，将该通道分配给进程


只有在设备、控制器和通道三者都分配成功时，这次的设备分配才算成功。然后，便可启动该 I/O 设备进行数据传送，本题选 A

在 Linux 系统中，一切设备都被视为文件，/dev 目录下的文件（如 /dev/sda）就是逻辑设备名。它是操作系统为用户提供的统一接口，用户程序通过这些文件名来访问硬件设备，无需关心底层物理细节，本题选 B

下列关于 Linux 主设备号和次设备号的说法中，错误的是：

A. 主设备号用于标识设备的类型，决定使用哪一个驱动程序
B. 次设备号用于标识同一类型下的不同设备实例（如不同的磁盘分区）
C. 同一主设备号下的次设备号必须是连续的，不能自定义
D. 主 / 次设备号存储在设备文件的 inode 中，而非文件本身

A 正确，主设备号是内核用来匹配设备驱动的关键标识，同一类设备（如所有 SATA 磁盘）共享同一个主设备号，对应同一个驱动程序


B 正确，次设备号用于区分同一驱动下的不同设备实例，例如/dev/sda1和/dev/sda2的主设备号相同，但次设备号不同，分别对应不同的磁盘分区


C 错误，次设备号由驱动程序定义，内核只要求它在该主设备号下唯一，并不要求连续。驱动程序可以根据需要自定义次设备号，例如使用 1、2、5 来标识不同的设备实例，本题选 C


D 正确，设备文件本身不包含数据，主 / 次设备号存储在文件的 inode 中，内核通过 inode 信息完成逻辑设备名到物理设备的映射

下列哪项不是设备独立性带来的优势？

A. 程序可在不同硬件配置的系统上移植
B. 更换物理设备时无需修改应用程序
C. 提高设备的传输速度
D. 系统可动态分配同类型设备，提高资源利用率

A 描述正确，因为程序不依赖具体的物理设备名，只要内核提供了相同的逻辑设备接口，程序就能在不同硬件上运行，可移植性大大提高


B 描述正确，更换物理设备后，内核只需更新逻辑设备名到新物理设备的映射，应用程序使用的逻辑设备名不变，因此无需修改代码


C 描述错误，设备的传输速度由硬件本身的性能、驱动程序和 I/O 调度算法决定，设备独立性只是改变了程序访问设备的方式，不会直接提升硬件的传输速度，本题选 C


D 描述正确，当一个逻辑设备名对应多个物理设备时，系统可以动态分配其中空闲的设备，避免进程因单个设备忙碌而阻塞，从而提高了设备资源的整体利用率

设备驱动程序管理的核心目标之一是统一管理系统资源，避免冲突。下列哪项不属于驱动程序需要管理的资源？

A. 内存
B. I/O 端口地址
C. 中断号
D. 进程优先级

设备驱动程序需要管理的资源，是指设备正常工作所必需的硬件或内核资源，而进程优先级属于进程调度的范畴，不由驱动程序管理，本题选 D


驱动程序运行在内核态，需要分配内核内存来存储设备状态、缓冲区等信息，属于驱动管理的资源


硬件设备通过 I/O 端口与 CPU 通信，驱动程序必须管理这些端口地址，避免多个设备冲突


设备通过中断通知 CPU 处理，驱动程序需要注册并管理中断号，确保中断处理正确

【20-30】对于具备设备独立性的系统，下列叙述中，错误的是 ( )。

A.可以使用文件名访问物理设备

C.需要建立逻辑设备与物理设备之间的映射关系
D.更换物理设备后必须修改访问该设备的应用程序
在 Linux 操作系统中，每一个设备都对应一个设备文件，我们完全可以使用这个设备文件来访问对应的设备，在这个设备文件对应的 inode 中记录着主设备号和次设备号，通过主设备号可以找到设备对应的驱动程序，然后将次设备号发送给驱动程序，然后驱动程序根据次设备号就可以确定和某一个具体的设备进行通信了

所以说，在操作系统中，我们可以通过文件名来访问物理设备，这也体现了设备独立性，因此 A 正确

这些设备文件的名称实际上就是逻辑设备名，因此，我们一般使用逻辑设备名来访问物理设备，选项 B 正确

既然要通过逻辑设备名来访问物理设备，那么系统必须建立从逻辑设备名到物理设备之间的映射，说白了就是内核需要通过逻辑设备名找到对应的物理设备，因此 C 正确


比如设备文件对应 inode 中的主设备号和次设备号就是一种逻辑设备到物理设备之间的映射（通过主次设备号可以找到某台具体的物理设备）


因为应用程序按逻辑设备名访问设备，再经驱动程序的处理来控制物理设备，若更换物理设备，可能只需更换驱动程序（当然，也可能不需要更换驱动程序），而无须修改应用程序，选项 D 错误，本题选 D
