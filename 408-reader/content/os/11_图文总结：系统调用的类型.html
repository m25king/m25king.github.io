系统调用 vs 过程调用

在 OS 中提供系统调用的目的是，使应用程序可以通过系统调用来间接调用 OS 中的相关过程，进而取得相应的服务。系统调用在本质上是应用程序请求 OS 内核完成某功能时的一种过程调用，但它是一种特殊的过程调用，它与一般的过程调用在下述几方面有着显著差别
① 运行在不同的系统状态。一般的过程调用，其调用程序和被调用程序运行在相同的状态 (内核态或用户态)；而系统调用与一般的过程调用的最大区别就在于，系统调用的调用程序运行在用户态，而被调用程序运行在内核态
② 状态的转换。由于一般的过程调用并不涉及系统状态的转换，因此可直接由调用过程转向被调用过程。但在运行系统调用时，由于调用过程和被调用过程工作处于不同的系统状态，因而不允许由调用过程直接转向被调用过程，需要通过软中断机制先由用户态转换为内核态，经内核分析后才能转向相应的系统调用处理子程序
③ 返回问题。在采用了抢占式 (剥夺) 调度方式的系统中，系统调用时，在被调用过程执行完成后，要对系统中所有要求运行的进程做优先级分析。当调用进程仍具有最高优先级时，才返回到调用进程继续执行；否则，将重新调度，以便让优先级最高的进程优先执行。此时，将把调用进程放入就绪队列
④ 嵌套调用。像一般的过程调用一样，系统调用也可以嵌套进行，即在一个被调用过程执行期间，还可以利用系统调用命令去调用另一个系统调用。当然，每个系统调用对嵌套调用的深度都有一定的限制，如最大深度为 6。但一般的过程调用对嵌套调用的深度则没有限制

如何理解【在一个被调用过程执行期间，还可以利用系统调用命令去调用另一个系统调用】呢？

很多时候，我们会把 int $0x80 或者 syscall 称为系统调用命令，但是，这里的系统调用命令不是 int $0x80 和 syscall，而是一个系统调用在内核中的接口函数，当内核指执行一个系统调用服务程序时，它是可以通过普通的函数调用来调用另一个系统调用在内核中的接口的，比如在内核中的系统调用函数 sys_write，可以调用另一个内核函数 kmalloc() 来申请一个缓冲区内存，而这个函数 kmalloc() 也是内核提供给用户的服务接口，这就是所谓的系统调用的嵌套调用，这种嵌套调用必然是发生在内核态的
我们还需要区分这两个概念：系统调用嵌套调用和系统调用嵌套。所谓系统调用嵌套调用就是一个系统调用程序在执行时，调用了内核中其他系统调用的接口函数，那么什么是系统调用嵌套呢？
我们知道中断嵌套（就是多重中断），是指 CPU 正在处理一个中断 / 系统调用时，又响应了更高优先级的其他中断，打断当前流程去处理新中断  ；而系统调用嵌套是不存在的，不可能会发生在内核执行一个系统调用时，另一个用户态发起的系统调用打断当前系统调用的执行，这是因为，当用户程序通过系统调用命令发起一次系统调用后，此时的 CPU 将会处于内核态，此时用户程序时挂住的，不可能再次发起一个系统调用，也就不会出现系统调用嵌套， 即用户态在一个系统调用返回前，不能再发起另一个系统调用

注意，在多重中断系统中，当用户通过系统调用命令发起一个系统调用时，内核执行系统调用服务程序之前，需要打开中断，这样在内核执行系统调用服务程序时就可以响应优先级更高的硬件中断（比如 I/O 完成中断、时钟中断等），从而形成中断嵌套；举个例子， 系统调用正在执行 sys_write 写磁盘，此时磁盘控制器发出 I/O 完成中断（优先级更高），CPU 会暂停 sys_write 的执行，先处理磁盘中断，处理完后再回到 sys_write 继续执行  

系统调用的类型

在每个操作系统中，通常有几十条甚至上百条系统调用，每一个系统调用都是一个能完成特定功能的子程序，我们学习操作系统主要就是学习这些系统调用的功能。操作系统提供的系统调用大致可分为六大类：① 文件和设备管理；② 内存管理；③ 进程控制；④ 信息维护；⑤ 通信；⑥ 保护。在本门课程中，主要也就是学习前 3 类的系统调用

应用程序可以通过系统调用创建 (create( )) 和删除 (delete( )) 文件。这两个系统调用需要文件名称，还可能需要文件的一些属性。一旦文件创建后，就会打开 (open ( )) 并使用它，也会读 (read( ))、写 (write( )) 或重定位 (lseek( )) (例如，重新回到文件开头，或直接跳到文件末尾)。最后，需要关闭 (close( )) 文件，表示不再使用它

内存管理类的系统调用的核心功能主要是：① 申请/释放进程虚拟内存；② 修改页表（比如修改内存权限等）；③ 控制页面置换；④ 实现多进程共享内存
在进程管理中，进程就是一个运行的程序，在一个计算机系统上，可以运行很多个进程，而操作系统必须具备管理这些进程的功能，也就是说操作系统需要具备控制所有进程的能力。就是因为操作系统具有管理进程的能力，所以操作系统给应用程序提供了以下几个系统调用：
  • 创建进程
  • 终止进程
  • 暂停或恢复进程
  • 修改进程属性
  • ...
