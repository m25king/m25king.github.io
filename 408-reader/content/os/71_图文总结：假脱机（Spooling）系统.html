通过假脱机技术就可以将一台物理 I/O 设备虚拟为多台逻辑 I/O 设备，这样就可以允许多个用户共享一台物理 I/O 设备，接下来我们先来看什么假脱机系统，然后再来看假脱机系统是如何提高 I/O 设备的利用率的

什么是假脱机（Spooling）系统

大家还记得吗？我们在第一章的时候，就学习过什么是脱机输入输出方式，就是下面的图
这种脱机输入输出方式，利用专门的外围机，将卡片上的数据传送到磁带机上，然后将磁带机放到主机上作为输入，主机可以直接从磁带上读出数据，然后进行计算处理，计算处理后的结果写到磁带中，然后在外围机的控制下，将磁带上的数据输出打印出来，在这里，输入和输出是在外围机的控制下进行的，是和主机脱机的，因此称为脱机输入输出方式
现代的计算机硬件性能已经非常好了，现代的磁盘的速度比上面这种磁带的速度要快很多很多，计算机的处理器和 I/O 设备都集成在一台计算机中，上图使用人工做的事情，实际上也可以使用一道程序来代替，上图的一个输入动作，可以使用一个输入程序来自动完成，另一个输出动作，也可以使用一个输出程序来完成
比如现在计算机中（看下图），有两个低速的 I/O 设备（磁带 A 和磁带 B）和一个高速的磁盘设备，现在需要处理的数据都放在磁带 A 中，而且数据量还挺大的，那么要处理磁带 A 中的数据，不能全部加载到内存，因为内存可能不够，但是，如果直接处理磁带 A 中的数据又很慢，因为磁带的访问速度又特别慢，此时，我们可以写一个输入程序 A，让它负责将低速设备（磁带 A）上的数据，通过一个输入缓冲区，再传送到高速的磁盘设备中，这里的输入程序 A 模拟了前面脱机输入时的外围控制机的功能
接下来，处理程序就可以从磁盘中将数据拿出来进行处理，处理完的数据，还是写到磁盘中；然后再用一个输出程序 B，将磁盘中的结果数据，通过输出缓冲区，一点一点的输出到另一个低速设备（磁带 B）中，这里模拟了前面的脱机输出时的外围控制机的功能
这样的话，便可以在主机的直接控制下，实现以前的脱机输入输出功能，因为现代的操作系统支持多道程序并行执行，上面两个输入输出程序实现的外围操作和处理程序，在同一台机器上运行，这里的输入输出没有脱离主机，我们将这种在联机情况下实现的同时外围操作的技术称为 SPOOLing 技术，或者称为假脱机技术

假脱机（Spooling）系统的工作原理

在假脱机系统中，首先会在磁盘上开辟两个存储区域，分别称为输入井和输出井（看下图），输入井模拟脱机输入时的磁盘，用于收容低速 I/O 设备输入的数据，输出井模拟脱机输出时的磁盘，用于收容用户程序的输出数据；然后再内存中开辟两个缓冲区（输入缓冲区和输出缓冲区），用于缓和 CPU 和磁盘之间速度不匹配的矛盾，输入缓冲区用于暂存由输入设备传送的数据，之后再传送到输入井。输出缓冲区用于暂存从输出井传送的数据，之后再传送到输出设备
输入进程，用于模拟脱机输入时的外围控制机，将用户要求的数据从输入设备传送到输入缓冲区，再存放到输入井；输出进程，用于模拟脱机输出时的外围控制机，将输出井中的数据经过输出缓冲区输出至输出设备上
上图还有一个井管理程序，用于控制正在运行的程序（上图进程 A）与磁盘井之间信息的交换，当程序（上图进程 A）执行过程中向某台设备发出启动输入或输出操作请求时，由井管理进程控制从输入井读取信息或将信息输出至输出井，当然这里读写磁盘，需要缓冲区（上图的输入缓冲区 2 和输出缓冲区 2）
在上面的输入井和输出井中，数据一般以文件的形式组织管理，我们把这些文件称为井文件，一个文件仅存放某一个进程的输入 (或者输出) 数据，所有进程的数据输入 (或输出) 文件链接成为一个输入 (或输出) 队列，比如上图中的进程 1 的输入存放在一个井文件中，进程 1 的输出同样存放在一个井文件中

假脱机打印机系统

我们知道打印机输入独占设备，当一个进程使用打印机时，一定要等这个进程全部打印完，才可以开始打印其他进程的数据，但是使用假脱机技术将打印机改造成一台可以供多个进程共享的设备，从而提高设备的利用率
因为打印机是输出设备，所以在假脱机系统中就不需要输入设备和输入井（看下图），只需要用到下面的输出这条线即可，在这里的话，输出设备就是打印机，那么输出程序可以称为打印程序
现在运行的程序 A（进程 A），需要打印数据，首先生成一份需要打印的文档，文档通过井管理程序，经过输出缓冲区 2，传送到输出井中，然后打印进程会在内存中维护一个打印请求（上图左边的 A），我们假设这个时候打印机正在工作，那么这个程序 A 的打印请求，就先放在内存中的打印请求等待队列中，这个时候程序 A 就可以去做其他的事情了，因为你要打印的数据被保存到了输出井，打印请求也送到了打印程序管理的打印请求等待队列中，所以程序 A 就不用管了，用心去做其他的事情
假设现在程序 B（进程 B）也要打印数据，生成一个数据文档，通过井管理程序，传送到输出井，然后再内存中生成一个打印进程 B 数据的请求，挂在内存中打印请求等待队列的队尾，此时，进程 B 就可以去做其他的事情了；假设现在程序 C 也要打印数据，生成一个数据文档，通过井管理程序，传送到输出井，然后再内存中生成一个打印进程 C 数据的请求，挂在内存中打印请求等待队列的队尾，此时，进程 C 就可以去做其他的事情
你看，有了这个输出井和打印进程，进程只要提交打印请求，生成好打印的数据即可，然后进程就可以去做其他的事情，接下来，就是打印进程的事情了，当它知道打印机空闲时，就会从待打印队列中，拿到队头的那个请求，然后，将其对应数据，从输出井中，读出来，送到打印中进行打印，打印完了进程 A 的数据，再来打印进程 B 的数据
打印机打印的同时，进程 A、B、C 都在做其他的事情，这就相当于，多个进程共享这台打印机一样，进程只要把要打印的数据生成好，然后提交请求，就可以认为打印成功了，好像每一个进程都独自占用一台打印机似的，这样就将一台独占的打印机设备，变成了共享的设备

假脱机系统的特点

（1）提高了 I/O 速度。这里对数据所执行的 I/O 操作，已从对低速 I/O 设备执行的 I/O 操作演变为对磁盘缓冲区中的数据进行的存取操作，如同脱机输入/脱机输出一样，提高了 I/O 速度，缓和了 CPU 与低速 I/O 设备之间速度不匹配的矛盾
（2）将独占设备改造为共享设备。在假脱机打印机系统中，实际上并没有为任何进程分配设备，而只是在磁盘缓冲区中为进程分配了一个空闲盘块和建立了一张 I/O 请求表。这样，便把独占设备改造成了共享设备
（3）实现了虚拟设备功能。宏观上，虽然多个进程在同时使用一台独占设备，但对于每个进程而言，它们都会认为自己独占了一个设备。当然，该设备只是逻辑上的设备（即虚拟设备）。假脱机打印机系统实现了将独占设备变换为若干台对应的逻辑设备的功能
