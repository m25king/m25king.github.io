什么是缓冲区？

我们来看一个实际生活中的例子，比如在快递行业中，快递员送快递的速度很快，可能 1 个小时内就可以送 100 个包裹，而收件人取件的速度是很慢的，每个人在不同时间取，不会集中在 1 个小时内，这个时候，如果快递员等收件人当场取件的话，效率太低
所以出现了快递驿站，快递员先把所有的快递都临时存放在驿站，然后收件人可以在自己方便的时间来取快递，这里的快递驿站就解决了送快递速度快，但是取件慢的矛盾，可以提高效率，这个快递驿站就起到了缓冲的作用，这个快递驿站就是一个缓冲区
在计算机系统中，缓冲也是无处不在，我们知道 CPU 和 I/O 设备之间的速度也是不一致的，CPU 的运算速率远远高于 I/O 设备的速率，如果 CPU 不断的给打印机发送数据，但是打印机的速度跟不上，那么必然会丢失数据，有很多数据打印不到，如果要打印所有数据（不丢失）的话，那么 CPU 发送一个数据，然后等待打印机打印完一个字符，再发一个，这个又使得 CPU 的工作效率很低
所以呢，为了缓和 CPU 和 I/O 设备间速度不匹配的矛盾，可以在内存中开辟一个缓冲区（这个缓冲区由 I/O 系统的独立性软件来管理），CPU 先将应用程序需要打印的数据，拷贝到这个缓冲区中，然后，将缓冲区中的数据一个拿到打印机打印，打印机打印的同时，CPU 可以去做其他的事情，打印完后，再从缓冲区拿出一个数据，打印，这样，可以提高 CPU 的工作效率，可以提高 CPU 和 I/O 设备之间的并行性，当这个打印机在打印的时候，CPU 可以去做其他的事情
在现代操作系统中，几乎所有的 I/O 设备在与处理机交换数据时都用了缓冲区。缓冲区其实就是一个存储区域，它可以由专门的硬件寄存器组成，但由于硬件寄存器的成本较高，容量也较小，一般仅用在对速度要求非常高的场合，比如上图设备控制器中用的数据缓冲区，就是硬件寄存器，这种数据寄存器实际上就是一个缓冲区，它很快，但是容量有限，因为成本很高，在一般情况下，更多的是利用内存作为缓冲区（即某一块内存区域）

缓冲区的 4 个作用

从上面我们可以看出缓冲区 2 个作用：
  • ① 缓和 CPU 和 I/O 设备间速度不匹配的矛盾
  • ② 提高 CPU 和 I/O 设备之间的并行性
缓冲区的第 ③ 个作用是减少对 CPU 的中断频率，比如现在使用 DMA 读取磁盘 4KB 的数据，如果缓冲区是 1KB 的话，那么需要 4 次 DMA 传输，也就需要 4 次中断；如果缓冲区是 4KB 的话，那么一次 DMA 就可以传输 4KB 数据，这样的话，只需要 1 次中断了
缓冲区的第 ④ 个作用是解决数据粒度不匹配问题，比如在网络通信中，下图左边机器上的 TCP/IP 协议，每次给右边机器发送 100 字节的数据，但是右边计算机的应用程序每次想要的是 400 字节的数据
那么右边机器的网络通信软件就需要一个 400B 的缓冲，左边机器发送的 100B 数据都放在右边机器的缓冲区中，等待将 4 个 100B 的数据都收到了，然后转换为 400B 的数据，让应用程序读取
因此，缓冲区可用于解决在生产者和消费者之间交换的数据粒度 (数据单元大小) 不匹配的问题。如果生产者所生产的数据粒度比消费者消费的数据粒度小时，生产者可以一连生产好几个数据单元的数据，当其总和已达到消费者进程所要求的数据单元大小时，消费者便可以从缓冲区取出消费；当然，如果生产者所生产的数据粒度比消费者消费的数据粒度大时，生产者每次生产的数据消费者可以分几次从缓冲区中取出消费

缓冲和缓存的区别

缓存（cache）是保存数据副本的高速内存区域。现代计算机系统中有多种类型的缓存，如 CPU 缓存、磁盘缓存、光驱缓存等。访问缓存副本比访问其原版更加有效。例如，正在运行进程的指令保存在磁盘上，缓存在物理内存上，并被再次复制到了 CPU 的二级缓存和一级缓存中
CPU 缓存先于内存同 CPU 交换数据，速率很快，故也称为高速缓存。它主要是为了缓和 CPU 运行速率与内存读/写速率不匹配的矛盾。其工作原理是：当 CPU 要读取一个数据时，首先从 CPU 缓存中进行查找，找到就立即读取并将其送给 CPU 处理；若没有找到，则从速率相对较慢的内存中读取并将其送给 CPU 处理，同时把这个数据所在的数据块调入缓存中，这可以使得以后对整块数据的读取都从缓存中进行，而不必再调用内存。正是这样的读取机制使 CPU 读取缓存的命中率变得非常高（大多数 CPU 可达 90% 左右），这大大节省了 CPU 直接读取内存的时间，也使CPU读取数据时基本无须等待
缓存和缓冲的区别：缓冲可以保存数据项的唯一的现有版本；而根据定义，缓存只提供一个位于其他地方的数据项的更快存储副本
缓存和缓冲的功能不同，但是有时一个内存区域可以用于两个目的。例如，为了保留复制语义和有效调度磁盘I/O，OS 会采用内存中的缓冲区来保存磁盘数据。这些缓冲区也用作缓存，以便提高文件的 I/O 效率；这些文件可被多个程序共享，或者快速地写入和重读。当内核收到文件 I/O 请求时，内核首先会访问缓冲区缓存，以便查看文件区域是否已经在内存中可用。如果是，则可以避免或延迟物理磁盘 I/O。此外，磁盘写入在数秒内会累积到缓冲区缓存中，以汇集大量传输，进而实现允许高效写入调度
