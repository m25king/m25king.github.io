这里的缺页异常处理时间 φ 和修改率有关系，可用的空页框或被替换的页未被修改，则处理一个缺页中断需要 1ms；如果被替换的页已被修改，则处理一个缺页中断需要 10ms，然后题目说 60% 的替换页被修改过，那么缺页异常处理时间 φ = 60% * 10ms + 40% * 1ms = 6.4ms

这里不考虑命中率（其实就是不考虑快表，也就是假设没有快表的情况），仅考虑缺页率，访问内存时间 t = 1μs，假设缺页率是 f，那么访问内存的有效时间 EAT = t + f * (φ + t) + (1 - f) * t = 1μs + f * (6.4ms + 1μs) + (1 - f) * 1μs = 1μs + f * 6.4ms + 1μs = 3μs

因此，缺页率 f = 1μs/6.4ms = 1/6400，本题选 D

【14-28】下列措施中，能加快虚实地址转换的是（ ）
I：增大块表 (TLB) 容量
II：让页表常驻内存
III：增大交换区 (swap)

A.仅 I
B.仅 II
C.仅 I，II
D.仅 II，III
虚实地址转换是指虚拟地址和物理地址的转换

首先看第 I 项：增大块表（TLB）容量，TLB 容量越大，能缓存的页表项越多，TLB 命中率越高（减少访问内存查页表的次数），从而加快虚实地址转换。该措施有效

再看第 II 项：让页表常驻内存，对于页表，我觉得 "常驻内存" 应该是它最基本的要求，所以说我觉得这一项不会加快虚实地址转换，但是标准答案给出的是这一项可以加快虚实地址转换，那么，我们只能这样来解释了：

正常情况下，页表是常驻内存的，但是当内存资源紧张的时候，操作系统可能会将不常用的页表页框换出到磁盘（类似进程数据的换出），这样，有些页表就会存储在磁盘中了，当要访问在磁盘中的页表数据时，就需要读写磁盘了，这样就会使得虚实地址转换变慢

这样考虑的，那么，让页表常驻内存的话，就可以加快虚实地址转换了

最后，再来看第 III 项：增大交换区 (swap)，交换区是硬盘上的区域，用于在内存不足时临时存放进程数据（页面置换换出的页面数据），与虚实地址转换的速度无关

所以，I 和 II 可以加快虚实地址转换，本题选 C

【24-16】对于页式虚拟存储管理系统，下列关于存储器层次结构的叙述中，错误的是 ( )。

A.Cache-主存层次的交换单位为主存块，主存-外存层次的交换单位为页
B.Cache-主存层次替换算法由硬件实现，主存-外存层次替换算法由软件实现
C.Cache-主存层次可采用回写法写策略，主存-外存层次通常采用回写法写策略
D.Cache-主存层次可采用直接映射方式，主存-外存层次通常采用直接映射方式

CPU 高速缓存和主存之间是通过主存块来交换数据的，而主存和磁盘之间是通过虚拟页来交换数据的（盘块大小 = 页框大小 = 虚拟页大小），也就是说 CPU 高速缓存缓存的是主存块，而主存缓存的是虚拟页数据，因此 A 正确


CPU 高速缓存一般由 SRAM 组成，主存一般由 DRAM 组成，DRAM 比 SRAM 要慢大约 10 倍，而磁盘要比 DRAM 慢大约 100000 多倍


因此，主存中的不命中比起 CPU 高速缓存中的不命中要昂贵得多，这是因为主存缓存不命中要由磁盘来服务（如果虚拟页不在主存中的话，则要去读写磁盘），而 CPU 高速缓存不命中通常是由基于 DRAM 的主存来服务的（如果 CPU 高速缓存不命中，则去主存中读写数据）


那么主存作为磁盘缓存的组织结构完全是由巨大的不命中开销驱动的


因为不命中的话，开销就很大（需要读写磁盘），所以虚拟页往往很大，通常是 4KB～2MB


由于大的不命中处罚（需要读写磁盘），所以主存缓存是全相联映射（这样的话，命中率是最高的）的，即任何虚拟页都可以放置在任何的物理页中，而 CPU 高速缓存支持直接映射、组相联映射、全相联映射三种方式（主要是因为 CPU 高速缓存未命中的话，是读写主存，这个相对磁盘快很多很多，所以不命中的处罚不大），因此 D 错误，本题选 D


不命中时的替换策略也很重要，因为替换错了虚拟页的处罚也非常之高。因此，与 CPU 高速缓存相比，操作系统对主存缓存使用了更复杂精密的替换算法 (比如，我们前面讨论的各种置换算法)，这些置换算法一般都是软件实现的，而 CPU 高速缓存中的替换算法一般采用硬件实现，所以选项 B 正确
