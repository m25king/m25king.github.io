操作系统的安装

OS 是程序，也就是一堆的指令和数据组成，那么 OS 事先保存在哪里呢？这个要看 OS 的类型，有些系统，比如手机、平板等，一般将整个 OS 保存在 ROM 中，所有形式的 ROM 都是固件，因为它的特性介于硬件和软件之间，通常，固件存在的问题是：执行代码比在 RAM 中慢。有些系统将 OS 保存在固件中，而要执行时将其复制到 RAM 中，以便执行更快，固件的最后一个问题是相对较贵，所以通常只有少量可用；对大型 OS（包括大多数通用 OS，比如 Windows、Mac OS 和 UNIX 等），其 OS 一般是存放在磁盘上
在一个磁盘出厂之前，需要先对它进行格式化，比如将磁盘中的每个盘面划分磁道、扇区，每个扇区也都需要按照固定的格式进行格式化，然后数据就是保存到这里的每个扇区中，这种格式化称为物理格式化，或者称为低级格式化，磁盘进行了物理格式化之后，才可以装配到计算机中使用
我们在计算机中安装操作系统之前，都是需要先给磁盘分区，一个文件系统管理一个磁盘分区的数据块，也就是说内核对磁盘的管理，是以磁盘分区为单位的，我们将一个固定容量大小的磁盘，分成若干个区，比如你手上的 Windows 电脑，可能分为 C 盘、D 盘、E 盘，对吧，每个盘其实就是一个分区
假设，我们将磁盘分成了 4 个分区（看下图），为了管理这些分区，在磁盘第一个分区前，保存了一个分区表，这个分区表记录了每个分区的起始和结束磁盘地址，也就是说，记录了每个分区的大小，根据他就可以找到每个分区的起始位置和结束位置，在所有的分区中，一定会有一个活动的分区，在分区表中需要标记出这个活动的分区，比如下面第二个分区是活动分区，分区表的前面就是磁盘的 0 号扇区，也就是第一个扇区，称为主引导记录，保存了引导程序，用来引导计算机的
分完区之后，接下来就可以安装操作系统，我们知道操作系统本质上就是一堆指令和数据，对吧，而且这些指令和数据是存放在文件中的，而一开始的时候，也就是裸的计算机上，根本就没有文件系统，对吧，那就更别说有文件了，所以说，在安装操作系统之前，还需要先创建一个文件系统，一个文件系统管理一个磁盘分区的数据块
接下来在活动分区（上图的磁盘分区 2）创建一个文件系统，文件系统将这个磁盘分区看成连续的盘块，然后需要在这个盘块中保存一些元数据。首先，在每个分区中的第一个扇区保存着分区引导程序，所以这个块，我们称为分区引导块；然后，还有一个超级块，用于存储文件系统全局的元数据；然后就是空闲空间管理的相关元数据了，比如索引位图、数据位图等数据；接下来还要存放 inode 的盘块也就是 inode 表，在这个 inode 表中，我们首先要分配一个 inode 来存储文件系统根目录（/）的元数据；剩下的盘块（数据区）就是存放文件或者目录的数据，这样的话，就创建好了一个文件系统了，这个过程称为磁盘的逻辑格式化，其实就是在磁盘分区上建立一个文件系统，磁盘的逻辑格式化也称为高级格式化
接下来就是安装操作系统了，我们可以将操作系统的指令和数据，以文件的形式存放在磁盘分区 2 中的数据区，比如在 Windows 操作系统中，一般 C 盘就是那个活动分区，操作系统一般都是安装存储在 C 盘中，所以说，操作系统的安装过程是这样的：① 首先磁盘进行物理格式化，这个一般在磁盘出厂之前厂商会帮你做好；② 然后我们对磁盘进行分区；③ 然后对活动分区的磁盘进行逻辑格式化（高级格式化），其实就是在这个分区上建一个文件系统；④ 最后将操作系统安装存放在这个文件系统中
注意，每个磁盘分区的第一个块都可以是分区引导块，都是可以存放分区引导程序的，你可以在每个分区都安装存放操作系统的指令和数据，也就是说在一台计算机中可以安装多个操作系统

操作系统的启动

在计算机启动时，硬件如何知道 OS 在哪里，或者说如何加载 OS 呢？加载 OS 以启动计算机的过程，称为系统引导。大多数计算机系统都有一小块代码，称之为引导程序或引导加载程序，这段代码能够定位 OS，并加载 OS 到内存以开始执行，对于大型 OS 来说，一般分两步来加载 OS：一个简单计算机引导程序（BIOS 程序）从磁盘上调入一个更复杂的操作系统引导程序（Bootloader 程序），而后者再加载 OS
BIOS（Basic I/O System）程序主要提供开机支持工作，固定在主板的 ROM 区域（其地址空间是 0xFFF00000 ~ 0xFFFFFFFF，看下图是 X86 架构下计算机）；Bootloader 程序则一般存放在磁盘活动分区的第一个扇区中（就是前面图中的分区引导程序）：
我们在计组中多次说过，一台计算机的主存空间一般包括 ROM 区和 DRAM 区，ROM 区主要存放系统数据，而 DRAM 区主要存放用户数据的，而 BIOS 程序是不变的系统代码，所以存放在 ROM 区中，在上图 X86 架构的计算机中，系统 ROM 区的起始物理地址是 0xFFF00000，BIOS 的起始物理地址是 0xFFFFE05B（不用记）
当你按下计算机启动开机按钮，CPU 会收到一个重置事件，此时 CPU 中的 PC 被设置为第一个要执行指令的主存地址 0xFFFFFFF0，在这个地址上只有一条无条件跳转指令 jmp 0xFFFFE05B，CPU 加载这条指令到指令寄存器中，执行这条指令，CPU 将 PC 的值设置为 0xFFFFE05B，就是跳转执行 BIOS 中的第一条指令，CPU 执行 BIOS 代码程序主要是做以下几件事：
① 配置基础中断，在主存的低端（看上图）建立一个中断向量表，填入键盘、显卡、时钟、磁盘、异常错误等中断服务程序入口，如果硬件出问题（比如硬件报错、定时中断、键盘按下）时，CPU 能正确跳转到对应处理函数， 而且 BIOS 自检过程中需要用到：屏幕打印、键盘检测、硬件报错蜂鸣，全都依赖中断
② 完成核心硬件的自检，就是看看 CPU、内存（DRAM）、主板芯片组、总线、缓存、键盘、显卡等关键硬件是否正常，有无短路、故障  
③ 初始化硬件控制器， 给显卡、南桥、硬盘控制器、串口、外设等最基础初始化，让硬件能正常响应读写  
③ 建立基础内存环境， DRAM 无初始化不可用，BIOS 配置内存时序、主存控制器，让内存条可以正常工作
⑤ 寻找并加载 Bootloader 程序，以上完成自检后，就读取磁盘第一个扇区的 MBR 到内存，CPU 执行主引导程序，MBR 找到标记为活动/可引导的活动分区，如果有多个分区都安装了操作系统，那么需要给用户提供操作系统选择菜单，让用户选择需要启动的操作系统，然后读取操作系统所在磁盘分区的第一个扇区的分区引导程序（即 Bootloader 程序），Bootloader 程序负责加载该磁盘分区中的内核的指令和数据到内存，这样就启动了操作系统，CPU 开始执行内核程序

操作系统的初始化

操作系统启动完，接下来要完成 OS 初始化的工作，主要是做以下几件事情（下面的内容主要是串一串 OS 学习的内容）：
① 硬件底层初始化， 接管 BIOS 遗留的硬件资源，重新管理 CPU、内存、磁盘、网卡、显示器等设备
② 内存管理系统初始化，建立页表、分页机制、虚拟内存体系，划分内核空间/用户空间，初始化空闲内存链表、内存分配算法，统一管理全部主存
③ 中断和异常机制重构，在 CPU 执行 BIOS 自检的时候，已经创建了一张中断向量表，这个表比较简陋，在 OS 初始化的时候， 废弃之前的简陋中断向量表 ，初始化完整的中断向量表，完善时钟、IO、错误、外设中断处理，支撑多任务与设备响应  
④ 进程/线程管理初始化， 建立进程控制块 PCB 链表、调度队列，初始化进程调度算法、时间片、就绪 / 阻塞队列，创建 0 号 / 1 号内核初始进程，为多任务并发做准备
⑤ 文件系统和设备管理初始化， 加载磁盘文件系统（NTFS/Ext4 等），挂载根文件系统，统一管理块设备、字符设备，建立设备驱动模型
⑥ 系统环境搭建，以及进入用户态， 初始化系统时钟、权限、网络、日志等基础服务，创建第一个用户进程（如 init / systemd 进程），最终从内核态过渡到用户态，启动桌面 / 终端，等待用户操作
