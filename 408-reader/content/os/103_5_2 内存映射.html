下列关于 Linux 进程虚拟地址空间的叙述中，错误的是（）

A.每个进程拥有独立私有虚拟地址空间，由内核通过 mm_struct 管理
B. 函数栈的虚拟地址在进程运行时动态分配，属于用户态虚拟区域
C.malloc 分配的内存来自运行时堆，堆区域虚拟地址由编译器编译时分配
D. 只读代码段（.text）的虚拟地址由编译器在编译阶段分配

A 选项：Linux 每个进程都有独立私有的虚拟地址空间，内核通过 mm_struct 结构体来管理该进程的虚拟地址空间，该描述正确


B 选项：函数栈（栈区）是进程运行过程中动态分配虚拟地址（函数调用时栈帧伸缩），属于用户态虚拟区域，该描述正确


C 选项：malloc 从堆中分配内存，堆的虚拟地址不是编译器编译时分配：编译期只会预留堆的地址范围，堆的具体虚拟地址分配、扩容是在进程运行时由操作系统动态完成的，所以这个叙述错误，本题选 C


D 选项：只读代码段.text的虚拟地址（链接后的地址）由编译器、链接器在编译链接阶段确定分配，该描述正确

内存映射（mmap）的核心作用是（）

A. 直接修改物理内存的地址分配规则
B. 将进程一段虚拟地址空间与磁盘文件 / 内核匿名对象建立关联
C. 绕过 MMU 地址翻译直接访问磁盘数据
D. 提升 CPU 缓存的命中率
mmap 的核心功能就是把进程的一段虚拟地址空间，和磁盘文件、内核匿名对象（比如匿名映射）建立映射关联，进程访问这段虚拟地址就相当于操作对应的文件 / 内核对象，本题选 B

32 位 Linux 系统中，进程用户态虚拟地址空间范围通常是 0~0xC0000000，内核占用高地址空间，其根本目的是（）

A. 增大单个进程可用虚拟内存总量
B. 区分用户态与内核态地址，实现权限隔离
C. 简化页表分级设计
D. 让堆和栈能向相反方向自由扩张

A 选项：32 位系统总虚拟地址固定为 4GB，划分后单个进程用户可用是 3GB，并没有增大总虚拟内存量，A 错误


B 选项：把虚拟地址划分为用户态低地址和内核态高地址，最根本的目的是区分两类地址、设置不同访问权限，用户态程序无法直接访问内核地址，实现权限隔离、保护内核安全，B 正确


C 选项：页表分级设计是硬件和内存管理的通用优化手段，和用户 / 内核地址划分没有根本因果关系，C 错误


D 选项：堆和栈反向扩张是用户空间内部的布局设计，而且是由于历史原因导致的，不是划分用户 / 内核地址的根本目的

匿名映射（MAP_ANON）缺页处理和普通文件映射最大区别是（）

A. 不需要分配物理页框
B. 无需从磁盘读取数据，直接把页框初始化为全 0
C. 不会产生缺页异常
D. 页表不需要维护有效位

A 选项：匿名映射缺页时依然需要分配物理页框，只是不需要从磁盘加载文件数据，所以 A 错误


B 选项：普通文件映射缺页时，需要从磁盘读取对应文件的内容来填充物理页；而匿名映射没有关联文件，缺页时直接分配物理页并初始化为全 0，无需磁盘 IO，这是二者最大的区别，B 正确


C 选项：匿名映射首次访问未分配物理页的虚拟地址时，同样会触发缺页异常，C 错误


D 选项：两种映射的页表都需要维护有效位来标记虚拟页是否绑定物理页，D 错误

mmap 参数设置 MAP_SHARED 普通文件映射，两个进程映射同一文件同一区域，进程 1 修改映射内存后，进程 2 访问该区域会（）

A. 看不到修改，各自拥有独立物理页副本
B. 能立刻看到修改，物理内存仅保留一份文件数据副本
C. 触发段错误异常
D. 需要重新 mmap 才能同步数据

MAP_SHARED 是共享文件映射，多个进程映射同一文件的同一区域时，物理内存里只留存一份文件数据副本，一个进程对映射内存的修改会直接反映到物理页上，其他进程能立刻看到修改，后续内核也会适时把修改写回文件


A 选项：这是 MAP_PRIVATE（私有映射）的特点，会写时复制产生独立副本，错误

B 选项：符合MAP_SHARED共享映射的机制，正确

C 选项：合法的共享内存访问不会触发段错误，错误

D 选项：共享映射无需重新 mmap 就能直接看到修改，错误

动态共享库（.so）采用 MAP_SHARED 内存映射的优势是（）

A. 每个进程独享一份库代码物理内存，隔离性更强
B. 物理内存中仅保留一份库代码，多进程共享节省内存
C. 编译阶段就能把库代码嵌入可执行文件
D. 库函数调用不需要经过 MMU 地址翻译

A 选项：MAP_SHARED 是共享映射，多个进程共享同一份物理库代码，不是独享副本，隔离性弱，该选项错误


B 选项：采用 MAP_SHARED 映射动态共享库时，物理内存里只保留一份库的代码段，所有使用该库的进程都可以共享这部分内存，能节省内存开销，这是它的核心优势，该选项正确


C 选项：动态共享库的库代码是运行时通过映射加载进进程地址空间的，编译阶段不会把库代码嵌入可执行文件，这是静态库的特点，该选项错误


D 选项：程序访问库函数依然要依靠 MMU 完成虚拟地址到物理地址的翻译，不可能绕过 MMU，该选项错误

同一文件 MAP_PRIVATE 映射到两个进程，进程 1 修改映射内容，磁盘上原文件会（）

A. 同步更新修改内容
B. 完全不会被修改
C. 下次进程 2 访问时自动更新

MAP_PRIVATE 是私有文件映射，采用写时复制（COW）机制：进程 1 对映射内容修改时，只会生成专属的物理页副本，修改不会同步到磁盘上的原文件，也不会影响其他进程的映射视图，本题选 B

MAP_PRIVATE 私有文件映射的写时复制（COW）发生在（）

A. mmap 调用创建映射时就复制所有页面
B. 首次对映射区域执行写操作时分配私有物理页副本
C. 进程 fork 时才会复制所有页面
D. 文件修改时自动复制页面

A 选项：mmap创建MAP_PRIVATE映射时不会提前复制所有页面，初始会和页缓存共享页面，A 错误


B 选项：私有映射的 COW 机制是首次对映射区域执行写操作时触发缺页异常，内核分配私有物理页副本，后续修改只作用于这个私有副本，不会影响原文件和其他进程，B 正确

D 选项：私有映射修改不会同步回文件，文件本身修改也不会触发页面复制，D 错误

内存映射文件是一种允许进程将文件内容直接映射到其虚拟地址空间的技术。下列关于内存映射文件的叙述中，错误的是 ( )

A.进程访问内存映射文件区域就像访问普通内存一样，无需显式的 read() 或 write() 系统调用
B.多个不同进程可以将同一个文件映射到它们各自的虚拟地址空间中，从而实现对该文件内的高效共享
C.当一个进程修改其内存映射文件区域时，所做的修改会立即写回磁盘上的原始文件
D.内存映射文件区域的读写操作可能会引发缺页中断，操作系统会负责将文件内容从磁盘按需调入物理内存

A 正确，一旦文件被映射到进程的虚拟地址空间，进程就可以像访问普通内存数组一样，通过指针和内存访问指令 (如 MOV) 来直接读写文件内容，而不需要调用传统的 read() 或 write() 系统调用


B 正确，内存映射文件是实现进程间共享数据 (特别是大文件) 的一种高效方式。多个进程可以将同一个文件映射到它们各自的地址空间。如果映射是共享的，那么一个进程对映射区域的修改对其他共享该映射的进程是可见的 (取决于映射类型和同步机制)


C 错误，当进程退出、关闭文件映射或者显示的调用 fflush() 系统调用时，所有的被改动页面才会被写回磁盘文件，并非修改后立即写回，本题选 C


D 正确，内存映射文件利用了操作系统的请求分页机制。当进程首次访问映射区域中的某个页面，而该页面尚未加载到物理内存时，会发生缺页中断。操作系统会响应该中断，从磁盘文件中读取相应的页面内容到物理内存，并更新页表，然后进程才能继续执行。这种按需调入的方式使得可以映射远大于物理内存的文件

以下关于内存映射文件的说法中正确有 ( )

I 一般的 I/O 操作中，从磁盘调入的文件会先写入内核的页高速缓存，然后再从页高速缓存复制到用户进程的缓冲区。而内存映射文件避免这次从内核空间到用户空间的额外数据复制，从而提高 I/O 效率

II 内存映射文件实现了从进程对应磁盘文件到其虚拟内存空间中某部分的映射

III 内存映射文件能为不同进程提供一个高带宽的通信通道

IV 进程通过系统调用将文件映射到其虚拟内存空间的一部分，并将这一文件全部调入到物理内存

A.仅 I、II
B.I、II、III
C.I、II、IV
D.I、II、III、IV

I 正确，传统的 I/O 操作 (如 read()) 会将文件数据从磁盘读入内核的页高速缓存，然后再从页高速缓存复制到用户进程的缓冲区。内存映射文件通过将文件内容直接映射到进程的虚拟地址空间，可以避免这次从内核空间到用户空间的额外数据复制，从而提高 I/O 效率


II 正确，内存映射（mmap）的核心就是把磁盘文件的内容映射到进程的虚拟内存地址空间


III 正确，使用MAP_SHARED的内存映射，多个进程可映射同一文件，通过共享的内存区域实现高效高带宽通信


IV 错误，内存映射是按需调页的，只有进程访问对应虚拟页时才会把页面载入物理内存，不会在映射时就把整个文件一次性全部调入物理内存
