假设计算机某个磁盘只有一个磁盘分区，该磁盘共有 100 个柱面，每个柱面有 20 个磁道，每个磁道分成 8 个扇区，操作系统将一个扇区看成一个盘块，每个盘块大小是 1KB，该磁盘分区上的文件系统采用位示图法管理空闲盘块，位示图如下所示：
请回答下面的问题：
（1）试给出位示图中位置 (i，j) 与对应盘块所在的物理位置（柱面号，磁头号，扇区号）之间的计算公式。假定柱面号、磁头号、扇区号和盘块号都从 0 开始编号
（2）现在要为文件分配 2 个盘块，试具体说明分配过程
（3）若要释放磁盘 300 号盘块，则应如何处理？


（1）位示图中的每个位置（i, j）对应着一个盘块，因为位示图每一行 16 个位，即每行表示 16 个盘块，所以盘块号 b = i × 16 + j



柱面是所有盘面上到主轴中心的距离相等的磁道的集合，上图中柱面 k 就是 6 个 6 号磁道的集合，6 个面表示有 6 个磁头


采用柱面优先分配盘块，就是先分配 0 号柱面的盘块，再分配 1 号柱面的盘块，接着分配 2 号柱面的盘块...，每个柱面的盘块数 = 每个柱面的磁道数（或者说磁头数）× 每个磁道的扇区数 = 20 × 8 = 160，所以盘块号 b 对应的柱面号 = ⌊b / 160⌋（向下取整），比如盘块号 3 的盘块位于 0 号柱面，盘块号 180 的盘块位于 1 号柱面


盘块号 b 所在的柱面号是 ⌊b / 160⌋，那么在这个柱面上的第一个盘块到盘块号 b 的盘块之间的盘块数是 b % 160（包括该柱面的第一个盘块和盘块号 b 的盘块），而在这个柱面上，每个磁道包含了 8 个盘块，所以盘块号 b 所在的磁道是 ⌊(b % 160) / 8⌋（向下取整），这个就是盘块号 b 所在的磁头号


因为每个磁道有 8 个扇区，那么盘块号 b 的盘块所在的扇区号是 b % 8，比如 3 号盘块所在扇区号是 3 % 8 = 3，也就是位于 0 号柱面的 0 号磁头的 3 号扇区；再比如 15 号盘块所在的扇区号是 15 % 8 = 7，也就是位于 0 号柱面的 1 号磁头对应磁道上的 7 号扇区，在 0 号柱面的 0 号磁头对应的磁道上有 8 个扇区，再加上 0 号柱面的 1 号磁头对应的磁道上的 8 个扇区，就是 15 号盘块


所以说，位置（i, j）对应盘块的物理地址是（柱面号 = ⌊b / 160⌋，磁头号 = ⌊(b % 160) / 8⌋，扇区号 = b % 8）

（2）现在要为文件分配 2 个盘块，步骤是这样的：


① 扫描位示图，找到值为 0 的位，扫描下面位示图 0 行和 1 行全是 1，即没有空闲盘块；再扫描 2 行，找到（i = 2，j = 3）的位是 0，对应盘块是空闲的，其对应的盘块号 b = 2 * 16 + 3 = 35，将 35 号盘块分配给文件；再扫描 3 行，找到（i = 3，j = 6）的位是 0，对应盘块是空闲的，其对应的盘块号 b = 3 * 16 + 6 = 54，将 54 号盘块分配给文件



② 标记已分配的盘块，将上面位示图中的（i = 2，j = 3）和（i = 3，j = 6）的位都修改为 1


③ 记录分配的盘块号，将盘块号 35 、54 记录到文件的 FCB 中，完成分配


（3）若要释放磁盘 300 号盘块，需要这样处理：


① 计算 300 号盘块对应的二进制位的行号 i 和列号 j，i = ⌊300 / 16⌋ = 18，j = 300 % 16 = 12，即对应位图中的 (18, 12) 对应的位


② 将位示图中对应的位修改为 0，把 (18, 12) 位的值由 1 改为 0，表示该盘块已释放，标记为空闲
