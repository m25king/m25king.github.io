什么是操作系统？

操作系统（Operating System、简称 OS）是管理计算机硬件的程序，而且当计算机加电启动后，这个程序一直在运行
既然是程序，那么 OS 就是由很多的指令和数据组成，这些指令和数据事先是存储在磁盘中的文件里，比如你现在用的 Windows OS 安装在 C 盘中，那么 Windows OS 所有的指令和数据一般都是存放在 C 盘文件中
当计算机加电启动时，磁盘中 OS 的指令和数据，会被加载到主存中，然后将 CPU 中的 PC 设置为操作系统中某条指令的内存地址，然后开始执行 OS 中的指令，当 CPU 执行了一系列 OS 中的初始化指令后，你就可以看到操作系统提供的界面，从而通过界面和计算机进行交互

操作系统的作用

我们作为用户，要使用计算机的硬件帮我们完成计算任务，如果我们直接操作计算机硬件的话，那么太麻烦了，不方便，所以，在用户和计算机硬件之间，加入一层操作系统（看下图），操作系统通过 CPU 管理、内存管理以及设备管理等功能，高效的管理整个计算机硬件资源，这 3 个管理程序就构成了操作系统的内核
  • 对于 CPU，操作系统将其执行的时间划分成一个个时间片，这些时间片就是 CPU 的一个个资源，如何管理这些时间片，那就是操作系统中 CPU 调度程序需要完成的
  • 对于内存，操作系统将内存抽象成字节数组来完成对内存这种硬件资源的管理
  • 对于 I/O 设备，在操作系统中也会存在一张线性表，用于管理一台计算机中所有的 I/O 设备
可以看到，操作系统的第一个作用是：对下，高效管理计算机硬件资源，操作系统管理好了这些硬件资源后，就可以向上提供简单方便的服务接口，比如，用户可以通过图形界面来操作计算机硬件，当然，图形界面需要通过内核，才可以访问计算机硬件
比如，我们进入到 D 盘的  408 目录中，打开一个文件，其实就是在访问 I/O 设备中的磁盘这个硬件，我们之所以不用自己动手去物理的打开磁盘，是因为中间的这一层操作系统，帮我们去访问磁盘，然后把你需要的数据，展示给你看
用户除了通过图形界面来使用计算机外，还可以使用命令接口来使用计算机，比如你电脑上的 CMD（看下图），这是一个命令解释程序
使用这个 CMD 命令解释窗口，可以代替鼠标的功能，鼠标能干什么，这个命令解释窗口也可以干什么
相对于操作系统中的内核，我们将这种提供给用户操作计算机的窗口，称为外壳，也就是 shell，下图包括了图形化 shell，这个是命令行 shell，可以看到，操作系统的第二个作用是：对上，给用户提供方便的服务接口
用户的需求是千变万化的，很多时候，并不能通过命令接口和界面来完成我们的需求，这时，我们可能需要通过开发系统程序、或者应用程序来指导计算机来完成特定的任务，比如编译器、数据库等就是系统程序，比如文本编辑器、PPT、Excel等，这些都是应用程序，你自己写含有 main 函数的程序，也是一个应用程序，而这些系统程序或者应用程序，如果要访问计算机硬件的话，也需要通过操作系统在内核中提供了程序接口
所谓的程序接口，其实就是操作系统提供的系统调用
本门操作系统课程，就是学习操作系统中的内核，主要包括 CPU 管理、内存管理、设备管理和程序接口等

几个关键抽象概念

从上面我们知道了操作系统的两个基本功能：① 对下，高效管理计算机硬件资源；② 对上，给用户提供方便的服务接口。而操作系统是通过几个基本的抽象概念（文件、虚拟内存、进程）来实现这两个功能的（看下图），对于指令集架构，它提供了对实际处理器硬件的抽象，使用这个抽象，机器代码程序表现得好像运行在一个一次只执行一条指令的处理器上，实际上，我们在学习计算机组成原理时，就知道处理器底层的硬件远比抽象描述的要复杂精细，不过有了指令集架构，我们程序员就不用去管处理器到底多复杂
所谓进程就是操作系统对一个正在运行的程序的一种抽象，一个运行的程序就是一个进程，而一个运行的程序，需要处理器执行指令，需要主存存储指令和数据，在程序执行的过程中，可能还需要访问 I/O 设备，所以，我们可以这样说，进程是对处理器、主存和 I/O 设备的抽象表示。在一个系统上，可以同时运行多个进程，而每个进程都好像在独占的使用计算机硬件，实际上并不是这样的，实际上是多个进程共享的使用计算机硬件，这个主要通过操作系统中的进程上下文切换功能来实现的
接下来是虚拟内存，它是对主存和磁盘 I/O 设备的抽象表示，我们知道，每个程序都包含指令和数据，这些指令和数据一开始是存储在磁盘文件中，当这个程序运行的时候，就会将需要执行的指令和数据加载到主存中，而不需要的指令和数据仍然存储在磁盘文件中，虚拟内存的基本思想就是：把一个运行程序的虚拟内存的内容存储在磁盘上，然后用主存作为磁盘的高速缓存。一个运行程序的虚拟内存的内容包括下图这些内容
虚拟内存就为每一个运行的程序提供了一个假象，就好像，每个运行的程序都是独占地使用整个主存，每个进程看到的内存都是一致的，称为虚拟地址空间。虚拟地址空间最上面的区域是保留给操作系统中的代码和数据的，这对所有进程来说都是一样的，地址空间的底部区域存放用户不同进程自己的代码和数据
接下来是文件，文件就是字节序列，仅此而已。每个 I/O 设备，包括磁盘、键盘、显示器，甚至网络，都可以看成是文件，系统中的所有输入输出都是通过一小组系统调用读写文件来实现的。文件向应用程序提供了一个统一的视图，来看待系统中可能含有的所有各式各样的 I/O 设备。例如，处理磁盘文件内容的应用程序员可以非常幸福，因为它们无须了解具体的磁盘技术。更进一步的说，同一个程序可以在使用不同磁盘技术的不同系统上运行

最后就是虚拟机，它提供对整个计算机的抽象，包括操作系统、处理器和程序，你只有学完了整个操作系统，才可以理解什么是虚拟机，虚拟机的作用是啥
可以看到，虚拟机依赖进程、进程依赖虚拟内存、虚拟内存则依赖文件，那么我们学习的时候，当然是先学习没有依赖的文件，学完文件，再学习虚拟内存，然后再去学习进程，最后再去学习虚拟机，这个学习顺序才是比较合理的学习顺序，所以，我们的课程章节的安排顺序就是这样的：
先学习文件相关的文件系统、I/O 管理等，然后在学习虚拟内存相关的内存管理，接下来再学习进程相关的内容，最后我们再学习虚拟机相关的内容。按照这个顺序学习，是可以降低学习曲线的
