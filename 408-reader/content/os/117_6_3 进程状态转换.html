一般情况下，分时系统中处于 (   ) 的进程最多

A.执行状态
B.就绪状态
C.阻塞状态
D.终止状态

分时系统允许多个用户同时通过自己的终端以交互方式使用一台计算机，共享系统资源。分时系统通常将 CPU 的工作时间划分成若干个时间片，轮流为就绪队列中的进程服务。当某个进程获得时间片而进入执行状态时，就绪队列中的其他进程就会处于就绪状态，等待时间片的到来。因此在一般情况下，分时系统中处于就绪状态的进程最多

在单处理机系统中，关于进程的叙述，正确的是 (   )。

A.一个处于就绪状态的进程一旦分配了 CPU，即进入运行状态
B.只能有一个进程处于就绪状态
C.一个进程可以同时处于就绪状态和阻塞状态
D.最多只有一个进程能处于运行状态

对于 A（一个处于就绪状态的进程一旦分配了 CPU，即进入运行状态），过于绝对，进程从就绪拿到 CPU，进入运行态的前提是CPU 当前空闲，若采用抢占式调度，存在特殊边界场景：刚分配 CPU、还未正式运行时，来了更高优先级中断 / 进程，会立刻剥夺 CPU，该进程不会真正进入稳定运行状态，因此 A 描述不够严谨，错误


B 选项：单处理机系统中可以有多个进程同时处于就绪状态，等待 CPU 调度，所以 “只能有一个” 错误


C 选项：一个进程同一时刻只能处于一种状态，不可能同时处于就绪和阻塞状态，错误


D 选项：单处理机（单核 CPU）同一时间只能运行一个进程，所以最多只有一个进程处于运行状态，正确

已经获得除 (   ) 以外的运行所需所有资源的进程处于就绪状态。

A.存储器
B.打印机
C.CPU
D.磁盘空间

进程的就绪状态定义：进程已经获取了除 CPU 之外运行需要的其他所有资源，只等待调度程序分配 CPU 时间片，就能投入运行

  • 存储器、打印机、磁盘空间这类设备 / 存储空间，就绪态进程一般已经提前申请分配到位；

  • 只有 CPU 是就绪进程最后等待分配的资源。

所以这道题选 C


当一个进程 (   ) 时，称其处于阻塞状态。

A.等待进入内存
B.等待协作进程的一个消息
C.等待一个时间片
D.等待 CPU 调度

就绪态：等待CPU 调度 / 时间片（C、D 属于就绪态的场景）


阻塞态（等待态）：主动等待某类外部事件，比如 I/O 完成、其他进程的消息、资源释放等，此时就算 CPU 空闲也无法运行，等待协作进程的消息，是进程主动等待外部事件，处于阻塞状态，本题选 B


A：等待进入内存，属于挂起相关的状态，不是典型阻塞态的常规场景

II 就绪态→阻塞态

III 阻塞态→执行态

IV 阻塞态→就绪态

A.I、IV
B.II
C.II、III

CPU 状态变化中可能直接发生的有：① 就绪态→执行态，如进程获得时间片。② 阻塞态→就绪态，如进程获得一直等待的除 CPU 以外的资源。③ 执行态→就绪态，如 CPU 时间片用完。④ 执行态→阻塞态，如请求磁盘数据

在实时系统中，当内存资源无法满足执行紧迫任务的需求时，OS 可能会将正在运行的进程的状态变为 (   ) 状态。

A.活动就绪
B.静止就绪
C.活动阻塞
D.静止阻塞

当系统中的工作负担比较重时，为了满足执行紧迫任务的需求，OS 会将暂时不紧迫的正在运行的进程挂起，使其处于静止就绪状态

以下关于挂起进程的叙述，正确的有 (   )

I 挂起进程不能立即执行

II 挂起进程一定在等待某一事件或某一资源

III 挂起进程可以自己改变进程状态

IV 挂起进程可能提高 CPU 利用率

V 挂起某进程可以缩短该进程的执行时间

A.I、III
B.II、IV
C.I、IV
D.III、VI

挂起是指某种原因使进程由执行状态变为静止状态，或者让处于就绪状态的进程暂不接受调度


被挂起的进程不能立即执行（I 正确），其可能存在某些问题，如父进程希望挂起某个子进程以协调各子进程，或者负荷需要调节等，而不一定是在等待某一事件或资源（II 错误）


挂起进程需要激活原语才能改变其状态（III 错误）；系统工作负荷重时，可把一些不重要的进程挂起，以保证系统正常运行，提高 CPU 利用率（IV 正确）；进程执行时间是由其本身所完成的功能决定的，与是否被挂起无关（V 错误）

关于进程的状态和状态转换，以下哪一种说法是正确的 ( )

A.进程由创建而产生，由调度而执行，因得不到资源而挂起，以及由撤销而消亡
B.新进程的创建必然引起进程的调度
C.进程在运行期间，不断地从一个状态转换到另一个状态，它可以多次处于就绪状态和执行状态，也可多次处于阻塞状态，但可能排在不同的阻塞队列
D.正在执行的进程，若时间片用完，会进入阻塞状态

A 错误，进程因得不到资源 (如等待 I/O 操作完成、等待信号量等) 而进入的通常是阻塞态，而不是挂起态。挂起态通常是由于终端用户请求、父进程请求、系统负荷调节或操作系统自身需要等原因，将进程置于静止状态


B 错误，新进程创建完成后，会进入就绪态并被放入就绪队列。此时是否立即引起进程调度取决于调度策略。在非抢占式调度中，当前运行的进程会继续执行直到主动放弃 CPU 或结束。在抢占式调度中，如果新创建的进程的优先级高于当前运行的进程，则可能会引起调度。因此，新进程的创建不必然引起进程调度


D 错误，当正在执行的进程时间片用完后，它会从执行态转换为就绪态，并被放入就绪队列的末尾，等待下一次调度。它不会进入阻塞态，因为时间片用完并不意味着它在等待某个外部事件

【12-28】若一个用户进程通过 read 系统调用读取一个磁盘文件中的数据，则下列关于此过程的叙述中，正确的是（ ）
I：若该文件的数据不在内存中，则该进程进入睡眠等待状态
II：请求 read 系统调用会导致 CPU 从用户态切换到核心态
III：read 系统调用的参数应包含文件的名称

A.仅 I，II
B.仅 I，III
C.仅 II，III
D.I，II 和 III
对于 I，如果文件的数据不在内存中，用户进程会产生缺页异常，执行缺页异常处理程序，缺页异常处理程序会根据虚拟页对应的盘块号，发起磁盘 I/O 去磁盘读取对应盘块数据到页框中，因为磁盘准备数据需要时间，所以当数据没有读到页框中的话，进程就需要阻塞，进入等待状态，进程被插入到读磁盘等待队列中

当 DMA 传输完一个盘块的数据，会发出一个 DMA 结束中断信号，CPU 去执行 DMA 结束中断处理程序，在 DMA 结束中断处理程序中，会执行 wakup 原语唤醒进程（将进程从读磁盘等待队列移出，将进程状态修改为就绪，将进程插入就绪队列）

因此 I 是正确的

对于 II，read 系统调用通过陷入将 CPU 从用户态切换到核心态，从而获取操作系统提供的服务，所以 II 正确

对于 III，要读一个文件首先要用 open 系统调用打开该文件。open 中的参数包含文件的路径名与文件名，而 read 只需要使用 open 返回的文件描述符，并不使用文件名作为参数

read 要求用户提供三个输入参数：① 文件描述符 fd；② buf 缓冲区首址；③ 传送的字节数 n。read 的功能是试图从 fd 所指示的文件中读入 n 个字节的数据，并将它们送至由指针 buf 所指示的缓冲区中

所以 III 是错误的

因此，本题 I 和 II 是正确的，所以选 A
