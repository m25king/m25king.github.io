一次从磁盘将数据传送到缓冲区的时间为 T1，这个时间是 DMA 传输数据的时间，而 CPU 处理一次数据的时间为 T2，所以说这个 T1 和 T2 是可以并行的，为了计算总时间，我们需要考虑 T1 和 T2 的大小关系，看下图：


如果 T1>T2（看上图 a），即 CPU 处理数据比数据传送快，此时除了第一次可视为 I/O 连续输入，磁盘将数据传送到缓冲区，与缓冲区中的数据传送到用户区及 CPU 处理数据，两者可视为并行执行，那么花费时间主要取决于磁盘将数据传送到缓冲区所用的时间，前 n-1 次所花的时间共为 (n-1) * T1，而最后一次的时间 T1 完成后，还要花时间从缓冲区传送到用户区，且 CPU 还要处理，即要加上时间 T2，读入并处理所用的总时间为 n * T1+T2

如果 T1>T2（看上图 b），即 CPU 处理数据比数据传送慢，那么磁盘将数据传送到缓冲区，再传送到用户区进行处理，除了第一次需要花的时间 T1+T2，剩余数据可视为 CPU 进行连续处理，共花费时间 (n-1) * T2，读入并处理所用的总时间为 T1 + nT2

综上所述，总时间为 (n-1) * max(T1，T2) + T1 + T2

当你按下键盘字符时，这个字符对应的按键扫描码首先暂存在键盘控制器的数据缓冲寄存器中

然后键盘控制器给 CPU 发送中断信号，CPU 执行完当前指令，就会响应这个中断，然后执行键盘中断处理程序

键盘中断处理程序读取键盘控制器中的数据缓冲寄存器中的按键扫描码，注意，此时需要经过 CPU 的寄存器，也就是将字符对应的按键扫描码，从控制器中的寄存器中，传送到 CPU 的某个通用寄存器


然后中断处理程序根据按键扫描码，确定用户按下的是哪个按键，并将其转换为相应的字符，然后存入内核中的键盘缓冲区，然后中断处理程序结束


所以键盘中断服务例程执行结束时，所输入数据的存放位置是内核缓冲区，本题选 C

之后，操作系统或应用程序可以从内核缓冲区中读取用户输入的数据到用户缓冲区，然后进行处理
