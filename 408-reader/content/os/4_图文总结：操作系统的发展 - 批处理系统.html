本文主要是看下操作系统发展的这 4 个阶段：
  • 阶段一：单道批处理系统
  • 阶段二：多道批处理系统
  • 阶段三：分时系统
  • 阶段四：实时系统
在这里，我们需要搞明白什么是批处理系统、什么是分时系统以及什么是实时系统

批处理系统

什么是作业？

在批处理系统中，有个很重要的概念，就是作业 (job)，它表示一个或者一组程序；但是作业是一个比程序更为广泛的概念，它不仅包含了通常的程序和数据，而且还应配有一份作业说明书，系统根据该说明书来对程序的运行进行控制，比如，下面就是一个典型的作业结构
一开始是张 $JOB 卡片，它标识出所需的最大运行时间、需要多大的内存、作业的类型以及编写这个程序员的名字等等信息；接着是 $FORTRAN 卡片，通知操作系统从系统磁带上装入 FORTRAN 语言编译器，对后面的 FORTRAN 源程序进行编译；然后是 $LOAD 卡片，通知操作系统装入编译好的目标程序；接着是 $RUN 卡片，告诉操作系统运行该程序并使用随后的数据；最后 $END 卡片标识作业结束。早期的作业，都是写在这种卡片中

单道批处理系统

在批处理系统中，是以作业为基本单位从外存调入内存的。在早期的批处理系统中，程序员首先收集要执行的多个作业，然后用一台相对便宜的计算机，如 IBM 1401 计算机，将它们读到磁带上（看下图），这种 IBM 1401计算机适用于读卡片、复制磁带和输出打印，但不适用于数值运算，需要运算的话，需要另外用较昂贵的计算机，如 IBM 7094 来完成真正的计算
所以，另外一个程序员，会将存储了多个作业的输入磁带，放到 7094 计算机进行执行计算（看上图），然后计算的输出也是存储到输出磁带中，当这一批作业执行完后，再将输出磁带中的计算结果通过 1401 计算机输出打印出来；当一批作业完全结束后，操作员取下输入和输出磁带，将输入磁带换成下一批作业，并把输出磁带拿到一台 1401 机器上进行打印
这种批处理方式，也称为脱机输入输出方式（Off-Line I/O），所谓脱机就是脱离主机，上图中，中间的是主机，左右链表的都是外围机，输入输出是在外围机上完成的，脱离了主机
在主机上，为了实现连续处理一批中所有的作业，需要配置一个监督程序（看上图），一开始 CPU 执行监督程序（看下图），监督程序首先判断输入磁带中，是否还有下一个要处理的作业，如果没有，那么就停止监督程序
如果有的话，就将下一个作业的源程序编译为可执行的目标程序，然后再将目标程序转入到内存中，接下来就把运行控制权交给该作业，CPU 执行这个作业的目标程序，当这个作业执行完，再将运行控制权还给监督程序，监督程序再将第二个作业调入内存
计算机系统就这样自动地一个作业紧接一个作业地进行处理，直至磁带上的所有作业全部完成，这样便形成了早期的批处理系统，虽然系统对作业的处理是成批进行的，但在内存中始终只保持一道作业，故称为单道批处理系统，上面的监督程序就是早期的操作系统
单道批处理系统最主要的缺点是，系统中的资源得不到充分的利用，这是因为在内存中仅有一道程序，每逢该程序在运行中发出 I/O 请求后，CPU 便处于等待状态，必须在其 I/O 完成后才继续运行，来看下图是单道批处理系统程序运行情况
假设用户程序发出 I/O 请求，比如要将数据输出到输出磁带中，然后由监督程序来启动 I/O，为什么是监督程序来启动 I/O，前面我们讲过，用户程序都是通过操作系统来操作硬件的，这里的监督程序就相当于操作系统，接下来，进行 I/O 操作，这段时间 CPU 没有执行任何的指令，而且 I/O 设备一般都是低速设备，这样 CPU 空转的时间就比较长，更使 CPU 的利用率显著降低，浪费了 CPU 资源
每个作业对内存的要求都不同，有些比较大的作业，需要的内存就比较多，而有些作业比较小，需要的内存就比较少，为了使得计算机可以处理所有的作业，那么内存的大小就应该以最大作业要求的内存大小为准，我们假设最大作业需要的内存就是 3MB，那么，我们的内存肯定要大于这个 3MB，因为内存中还需要存储监督程序
我们假设内存时 4MB，然后 1MB 用于存储监督程序，其他 3MB 用于存储用户程序，由于单道批处理系统，内存中只存放一道程序，而且实际上 80% 以上的作业都属于中小型，不需要太多内存，因此在单道程序环境下，也必定造成内存的浪费，内存利用率很低，所以说，单道批处理系统最主要的缺点是，系统中的资源（不管是 CPU 资源还是内存资源）得不到充分的利用

多道批处理系统

为了进一步提高计算机的资源利用率，后来引入了多道批处理系统，当然，计算机硬件也在飞快的发展，I/O 和主机直接通过总线连接在一起（看下图）：
多个作业都是事先存储在磁盘中，操作系统事先加载到内存，现在 CPU 开始执行操作系统程序，在操作系统中的有一个作业调度程序，按照一定的算法，从磁盘中选择若干个作业，调入内存中，此时内存中，同时存储多道程序， 这些程序共享计算机的 CPU
这样的话，当作业 1 运行时，需要执行 I/O 操作，此时操作系统切换其他的作业，让 CPU 来执行其他作业的指令，这样的话，在 I/O 操作的同时，CPU 也不空闲，不仅提高了内存的利用率，也提高了 CPU 的利用率
注意：如果某个作业在运行时，不需要执行 I/O 操作的话，那么在批处理系统中，这个作业会一直运行下去，直到这个作业运行结束
多道批处理系统的优缺点如下：
（1）资源利用率高。引入多道批处理能使多道程序交替运行，以保持 CPU 处于忙碌状态；在内存中装入多道程序可提高内存的利用率；此外还可以提高 I/O 设备的利用率（有些作业可能使用磁盘、有些作业可能使用打印机，使得 I/O 设备都在忙）
（2）系统吞吐量大。能提高系统吞吐量的主要原因可归结为：
  • ① CPU 和其它资源保持 "忙碌" 状态
  • ② 仅当作业完成时或运行不下去时才进行切换，系统开销小
（3）平均周转时间长。由于作业要排队依次进行处理，因而作业的周转时间较长，通常需几个小时，甚至几天才可以执行完（比如一个小作业，本来几秒钟就可以完成的，但是因为现在内存中已经有多道程序了，导致没有内存，所以这个小作业就要等，导致这个小作业的周转时间很长）
所谓周转时间是指作业提交到作业执行完的这段时间
（4）无交互能力。用户一旦把作业提交给系统后，直至作业完成，用户都不能与自己的作业进行交互，修改和调试程序极不方便
