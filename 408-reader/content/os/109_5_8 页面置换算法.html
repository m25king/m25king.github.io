关于 (进程) 页表的页表项，基本分页存储管理方式和请求分页存储管理方式均须设立的字段为 (   )

A.状态位
B.访问字段
C.修改位
D.物理块号

A 状态位：基本分页的页面一定常驻内存，不需要标记是否在内存的状态位；只有请求分页需要状态位（有效位）判断页面是否调入内存，因此不是两者都必须设立


B 访问字段：用于页面置换算法统计访问情况，仅请求分页（需要页面置换）会用到，基本分页无换页机制，不需要该字段


C 修改位：标记页面是否被修改、换出是否要写回外存，同样只有请求分页需要页面换出管理才需要，基本分页页面不换出，无需此字段


D 物理块号：基本分页和请求分页都要完成虚拟地址到物理地址的转换，都需要通过页表项里的物理块号拼接出最终物理地址，是两者均必须设立的字段，本题选 D

虚拟分页存储管理中有页表若干项，当内存中某一页面被淘汰时，可能根据下列哪项来决定是否将该页面写回外存？(   )

A."是否在内存中" 标志
B.外存地址
C."修改" 标志
D."访问" 标志

修改标志（脏位）：如果页面被修改过（修改位 = 1），淘汰时必须把新数据写回外存；若未被修改（修改位 = 0），外存中已有该页面的完整副本，就不需要写回，以此减少 I/O 开销。因此，使用“修改”标志来标志该页在调人内存后是否被修改过，从而决定是否将该页写回外存。本题选 C


A：“是否在内存中” 标志只用来判断页面是否驻留内存，和是否写回外存无关

B：外存地址是页面在外存的存放位置，不决定要不要写回

D：“访问” 标志用于页面置换算法筛选淘汰页面，不控制写回操作

在请求分页存储管理中，缺页率与进程所分得的内存页面数、（ ）、进程页面流的走向等因素有关

A.页表的位置
B.页面置换算法
C.外存管理算法
D.进程调度算法

在请求分页系统中，缺页率的影响因素主要有：

  • 进程分配到的内存物理页面数；

  • 页面置换算法：内存装满后，选用不同置换算法淘汰页面，会产生截然不同的缺页次数，直接影响缺页率；

  • 进程自身的页面访问序列（页面流走向）


A：页表位置只影响地址转换的快慢，不改变缺页次数

C：外存管理算法负责外存空间分配调度，和缺页率无直接关联

D：进程调度算法决定 CPU 在不同进程间的切换时机，不直接影响页面缺页情况

下列页面替换算法中，平均缺页率从大到小的顺序一般是()

① 最佳替换 OPT

② 先进先出 FIFO

③ 最近最少使用 LRU

A.③②①
B.②③①
C.②①③
D.①②③

最佳置换 OPT：理论最优，每次淘汰未来最久不使用的页面，平均缺页率最小


LRU（最近最少使用）：淘汰过去最久没被访问的页面，性能接近 OPT，缺页率低于 FIFO


FIFO（先进先出）：按页面调入顺序淘汰，会出现 Belady 异常（分配页框变多缺页率反而上升），平均缺页率最高


从大到小排序：FIFO（②）> LRU（③）> OPT（①）

A.可以为每个物理页框设置一个移位寄存器，并周期性地右移，访问时将最高位置 1，具有最小寄存器值的页面即为最近最久未使用页
B.可以利用一个特殊的硬件栈来维护当前在内存中页面的访问顺序，栈顶始终是最新访问的页面，栈底则是最近最久未使用的页面
C.操作系统可以通过在页表项中增加一个 "访问位"，并周期性地清零该位，结合一个替换指针
循环扫描来近似实现 LRU 算法
D.为了精确实现 LRU，最简单且开销最小的方法是为每个页表项设置一个时间戳寄存器，记录该页最后一次被访问的精确系统时间

A 正确，这是一种实现 LRU 算法的硬件方法。每次访问页面时，对应页框的寄存器特定位 (如最高位) 被置1。定时信号会周期性地将所有寄存器的内容右移。这样，长时间未被访问的页面，其寄存器中的 1 会逐渐右移出去，使得其数值变小。数值最小的寄存器对应的页面就是最近较长时间未使用的页面


B 正确，硬件栈是实现 LRU 算法的一种有效方式。每当一个页面被访问时，就将其页面号从栈中取出 (如果已存在) 并压入栈顶。这样，栈顶总是最近被访问的页面，而栈底则是最近最久未被访问的页面。当需要淘汰页面时，选择栈底的页面即可


C 正确，这描述的是 Clock (时钟) 置换算法，它是 LRU 算法的一种常用近似实现。通过访问位来记录页面近期是否被访问，并通过循环扫描和清除访问位的方式来选择淘汰页面，其开销比精确 LRU 小


D 错误，虽然为每个页表项设置时间戳并在每次访存时更新可以精确记录页面的最后访问时间，从而找到最近最久未使用的页面，但这种方法的开销非常大

  • 硬件开销：为每个页表项增加一个足够宽的时间戳寄存器会增加硬件成本

  • 时间开销：每次内存访问都需要更新对应页面的时间戳，这会增加内存访问的延迟。当需要淘汰页面时，还需要遍历所有页表项来比较时间戳，以找到最小(即最久未被访问)的那个，这个搜索过程本身也会有相当大的开销，尤其是在页表很大的情况下

页面置换算法 LRU-K 是 LRU 算法的变种，K 代表最近使用的次数，LRU 可以认为是 LRU-1。下面介绍 LRU-2 算法，LRU-2 算法需要维护两个队列 (历史访问队列，缓存队列)，需要访问某一页时，先查找缓存队列：

① 如果该页在缓存队列中，则可以直接访问，并且将该页重新放在缓存队列队尾位置

② 如果该页未在缓存队列中但是在历史访问队列中，则将该页从历史访问队列移出并加入缓存队列中

③ 如果该页未在缓存队列且未在历史访问队列中，则该页放人历史访问队列并访问该页

【16-26】某系统采用改进型 CLOCK 置换算法，页表项中字段 A 为访问位，M 为修改位。A=0 表示页最近没有被访问，A=1 表示页最近被访问过。M=0 表示页没有被修改过，M=1 表示页被修改过。按 (A,M) 所有可能的取值，将页分为四类： (0,0), (1,0), (0,1) 和 (1,1)，则该算法淘汰页的次序为（ ）

A.(0,0),(0,1),(1,0),(1,1)
B.(0,0),(1,0),(0,1),(1,1)
C.(0,0),(0,1),(1,1),(1,0)
D.(0,0),(1,1),(0,1),(1,0)

改进型 Clock 算法的执行过程可分成以下四步：


第一步：从查找指针所指示的当前位置开始，扫描循环队列，寻找 A=0 且 M=0 的第一类页面，将所遇到的第一个页面作为所选中的淘汰页。在第一次扫描期间不改变访问位 A


第二步：如果第一步失败，即查找一轮后未遇到第一类页面，则开始第二轮扫描，寻找 A=0 且 M=1 的第二类页面，将所遇到的第一个这类页面作为淘汰页。在第二轮扫描期间，将所有扫描过的页面的访问位都置 0


第三步：如果第二步也失败，亦即未找到第二类页面，则将指针返回到开始的位置，此时所有的访问位都是 0。然后重复第一步，即寻找 A=0 且 M=0 的第一类页面（它本质上是第一步中的第三类页面，即在第一步时，这个页面的 A = 1，M = 0，因为在第二步的时候 A 设置为 0 了）


第四步：如果仍失败，必要时再重复第二步，寻找 A=0 且 M=1 的第二类页面（本质上是第一步中的第四类页面，即在第一步时，这个页面的 A = 1，M = 1，因为在第二步的时候 A 设置为 0 了），此时就一定能找到被淘汰的页


综上，改进型 CLOCK 算法淘汰页的次序为：(0,0) → (0,1) → (1,0) → (1,1)，本题选 A

也就是说，现在没有空闲的页框分配给 2 号虚拟页了，此时，需要进行页面置换，按照改进型 Clock 置换算法选择一个页面（从 3 号页面和 4 号页面中选择）作为淘汰页，将其对应的数据换出到磁盘块中，然后将对应的页框分配给 2 号页面


我们在【页面置换：Clock 置换算法】这个视频的 10:22 这里讲解了由访问位 A 和修改位 M 可以组合成下面四种类型的页面：

  • 1 类 (A=0，M=0)：表示该页最近既未被访问，又未被修改，是最佳淘汰页

  • 2 类 (A=0，M=1)：表示该页最近未被访问，但已被修改，并不是很好的淘汰页

  • 3 类 (A=1，M=0)：表示最近已被访问，但未被修改，该页有可能再被访问

  • 4 类 (A=1，M=1)：表示最近已被访问且被修改，该页可能再被访问


改进型 Clock 算法的执行过程可分成以下四步：


第一步：从查找指针所指示的当前位置开始，扫描循环队列，寻找 A=0 且 M=0 的第一类页面，将所遇到的第一个页面作为所选中的淘汰页。在第一次扫描期间不改变访问位 A


第二步：如果第一步失败，即查找一轮后未遇到第一类页面，则开始第二轮扫描，寻找 A=0 且 M=1 的第二类页面，将所遇到的第一个这类页面作为淘汰页。在第二轮扫描期间，将所有扫描过的页面的访问位都置 0


第三步：如果第二步也失败，亦即未找到第二类页面，则将指针返回到开始的位置，此时所有的访问位都是 0。然后重复第一步，即寻找 A=0 且 M=0 的第一类页面（执行第二步之前是第三类页面，执行第二步之后就变成了第一类页面）


第四步：如果第三步也失败，再重复第二步，寻找 A=0 且 M=1 的第二类页面（执行第二步之前是第四类页面，执行第二步之后就变成了第二类页面），此时就一定能找到被淘汰的页


就是说，先淘汰 1 类 (A=0，M=0) 页面，再淘汰 2 类 (A=0，M=1) 页面，再淘汰 3 类 (A=1，M=0) 页面，最后再淘汰 4 类 (A=1，M=1) 页面

  • 页号为 4 的页面的访问位 A = 1，修改为 M = 1，属于第 4 类页面
