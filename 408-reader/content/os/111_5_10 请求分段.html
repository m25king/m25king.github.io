一个分段存储管理系统中，地址长度为 32 位，其中段号占 8 位，则系统段数上限为 ( )，最大段长是 ( )

A.2^8;2^32
B.2^8;2^24
C.2^24;2^8
D.2^24;2^32

分段存储管理的逻辑地址分为段号和位移量两部分，段号决定了段数上限，段内位移的最大值就是最大段长。地址长度为 32 位，段号占 8 位，因此系统内最多有 2^8 个段；位移量占32-8=24 位，因此最大段长为 2^24B

下列关于分段存储管理系统数据共享相关概念的叙述中，错误的是 ( )

A.共享代码段 (如公共库函数) 通常是可重入代码 (纯代码)，在执行过程中不会被修改，因此
多个进程可以同时安全地执行它
B.当多个进程共享一个数据段时，为了保证数据的一致性，操作系统通常需要提供同步互斥机制，如信号量或管程
C.系统为所有共享段建立一个共享段表，其中记录了每个共享段的物理位置、长度以及当前共享该段的进程数量 (共享计数)
D.为了实现共享，共享段在不同进程的段表中所对应的段号必须相同，但段内地址可以不同

A 正确，可重入代码 (纯代码) 的一个重要特性是其在执行期间自身不发生改变，任何可能改变的部分 (如局部变量、返回地址) 都存储在每个进程私有的栈空间或其他私有数据区。这使得多个进程可以同时执行同一份代码副本而不会相互干扰，是实现代码段共享的基础


B 正确，如果多个进程共享一个可读写的数据段，那么它们对该数据段的并发访问可能会导致数据不一致的问题 (例如，竞争条件)。因此，操作系统需要提供同步互斥机制 (如信号量、互斥锁、管程等)，让进程能够协调对共享数据的访问，以保证数据完整性和一致性


C 正确，为了有效管理共享段，操作系统通常会维护一个系统级的共享段表。该表记录了每个共享段的物理信息 (如在内存中的起始地址、段的长度) 以及一个共享计数(或链接计数),用于表示当前有多少个进程正在共享该段。当共享计数为0时，该段所占用的内存才能被回收


D 错误，在分段存储管理中，每个进程拥有自己独立的段表，段号是进程逻辑地址空间的一部分。当多个进程共享同一个物理段时，这个共享段在它们各自的段表中所对应的段号可以是不同的。例如，进程 A 可能将共享库段映射为其 3 号段，而进程 B 可能将其映射为其 5 号段。重要的是它们段表中的相应表项都指向物理内存中同一个共享段的起始地址和具有相同的段长。段内地址 (偏移量) 是相对于段起始而言的，对于同一个共享段内的同一逻辑位置，其段内地址是相同的

【16-28】某进程的段表内容如下所示。

当访问段号为 2、段内地址为 400 的逻辑地址时，进行地址转换的结果是（）

A.段缺失异常
B.得到内存地址4400
C.越权异常
D.越界异常
分段系统的逻辑地址到物理地址之间的地址变换过程如下：


① 拿到逻辑地址的段号和段表寄存器中的段表长度比较，如果大于等于段表长度，那么越界异常，很明显这里段号 2 小于段表长度 3，所以没有越界

② 然后将段表寄存器中的段表基地址 + 段号 * 段表项长度，得到段号 2 对应的段表项的物理地址，根据物理地址拿到对应的段表项，这里是拿到段号为 2 的段表项

③ 然后查看段表项的状态（其实就是段表中的有效位或者说存在位）为在内存中，也就是说段表项有效，不会发生段缺失异常，因此 A 错误

④ 查看段号为 2 的段表项的权限有读写权限，所以不会发生越权异常，因此 C 错误

⑤ 接下来将段内偏移 400 和 2 号段表项的段长比较，这里段内偏移 400 大于 2 号段的段长 300，因此发生越界异常，所以 D 正确，本题选 D

⑥ 如果上面一步没有发生越界异常的话，那么就可以将 2 号段表项中的内存起始地址 4000 加上段内偏移 400，得到真正的物理地址 4400，虽然选项 B 是 4400，但是不能选，因为地址转换时，在第五步的时候就越界了

【19-28】在分段存储管理系统中，用共享段表描述所有被共享的段。若进程 P1 和 P2 共享段 S，下列叙述中，错误的是（ ）

A.在物理内存中仅保存一份段 S 的内容
B.段 S 在 P1 和 P2 中应该具有相同的段号
C.P1 和 P2 共享段 S 在共享段表中的段表项
D.P1 和 P2 都不再使用段 S 时才回收段 S 所占的内存空间
下图是进程 P1 和 P2 共享段 S：


很明显，在物理内存中，只存储了一份段 S 的内容，因此 A 正确

从上面也可以看出，进程 P1 使用段号 1，而进程 P2 使用的是段号 2，来共享段 S，所以说对于一个共享段，在不同的进程中可以具有不同的段号，每个进程可用自己进程的段号去访问该共享段，所以 B 错误，本题选 B
