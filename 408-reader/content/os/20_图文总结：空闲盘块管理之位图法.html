再来看最后一个实现磁盘分配表的方法，就是位图法。位图本质上就是一个二进制数组，在位图法中，使用一个二进制位来表示一个盘块是否空闲，二进制 0 表示空闲，1 表示已分配，当然，也可以规定 1 表示空闲，0 表示已分配，假设磁盘有 16 个磁盘块，需要存储 16 个二进制位的位图来表示哪些盘块已经分配，哪些盘块是空闲的
第一个二进制位是 1，表示 0 号盘块已经分配，第二个二进制位是 0，表示 1 号盘块是空闲的，每次分配时，在位图中找到第一个二进制位 0，将其对应的盘块号分配即可，使用位操作在位图中查找第一个二进制 0 是非常高效的；如果要释放 2 号磁盘块，只需要将位图中对应的位修改为 0 即可，这种回收的效率也高。比如现在要分配连续的 4 个盘块，那么在位图中查找 4 个连续的 0 即可，然后将对应的盘块号分配，修改位图中对应的 4 个位为 1，这种使用位操作查找 n 个连续的 0 也是很快的
位图这种方法所需的空间较少，每块只用 1 个二进制位来标识，在文件系统挂载的时候，这个位图加载到内存的话，上面的位图只需要 16 个位（2B）就可以表示 16 个盘块的使用情况，占用内存很少，如果磁盘盘块的数量是 2^16 个，那么需要 2^16 个位的位图，其占用内存大小是 2^16 / 2^3 B = 2^13 / 2^10 KB = 8KB
来看一个问题：假设现在有一个磁盘分区，其容量大小是 1 GB，每个盘块大小是 1KB，那么需要多少个盘块来存储位图呢？首先该磁盘分区的盘块总数是 1 GB/1KB = 1024 * 1024 个，那么位图的大小是 128KB，而一个盘块是 1KB，那么需要 128 个盘块来存储位图
在上图，假设在磁盘分区中，使用 100 ~ 227 号这 128 个磁盘块存储位图，那么现在要释放 8195 号磁盘块，那么要修改的位图中的二进制位于哪一个盘块中的第几个二进制位呢？
首先，每个盘块是 1KB，可以存放二进制位数是 8192 位，然后将盘块号 8195 除以一个盘块能存放的二进制位数 8192，商是 1，余数是 3，那么需要修改的二进制位位于 100 + 1 = 101 号磁盘块中的第 3 个二进制位
