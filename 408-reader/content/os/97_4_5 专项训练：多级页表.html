假定一个分页虚拟存储系统的虚拟地址为 40 位，物理地址为 36 位，页大小为 16KB，按字节编址。若页表中有有效位、访问权限位、修改位、使用位，共占 4 位，外存地址不在页表中，则该存储系统中每个进程的页表大小为多少？如果按计算出来的实际大小构建页表，则会出现什么问题？

下列哪种手段不是操作系统减少页表内存占用的方案（）

A. 缩减页表项控制字段位数
B. 增大页面尺寸减少总虚拟页数
C. 多级页表仅存储有效页对应的页表项
D. 允许二级页表离散不连续存放

因为一个页表占用内存大小 = 页表项数量 * 一个页表项占用内存大小，所以内核可以通过下面三种方法来减少页表占用内存：

  1. 减少一个页表项占用内存大小

  2. 减少页表项数量

  3. 减少无效页表项的存储



A 选项：缩减页表项控制字段位数，能降低单个页表项的字节大小，整体减少页表内存占用，是可行优化方案


B 选项：增大页面尺寸，虚拟地址空间划分出的总虚拟页数会减少，页表项总数随之变少，页表总内存占用下降，是主流方案（大页机制）


C 选项：多级页表只给有效使用的页分配对应的下层页表、存储有效页表项，不用为整个虚拟地址空间预分配完整连续页表，大幅节省内存，是多级页表的核心优化思路


D 选项：允许二级页表离散不连续存放，只是改变了下层页表的存储布局（不需要整片连续内存放完整页表），解决的是页表本身内存分配连续性，不会减少页表整体的内存占用量，不属于减少页表内存占用的方案，本题选 D

32 位虚拟地址、页表项 4B 时，页面大小从 4KB 提升至 8KB，单层页表内存占用变化为（）

A. 从 4MB 变为 8MB
B.从 4MB 变为 2MB
C. 保持 4MB 不变
D. 从 4MB 变为 1MB

页面大小为 4KB 使，页表项数 = 总页数 = 虚拟地址空间大小 ÷ 页面大小 = 2^32B ÷ 4KB = 2^20，每个页表项大小是 4B，所以页表总大小 = 总页数 × 页表项大小 = 2^20 * 4B = 4MB


页面大小增大为 8KB 使，页表项数 = 总页数 = 虚拟地址空间大小 ÷ 页面大小 = 2^32B ÷ 8KB = 2^19，每个页表项大小是 4B，所以页表总大小 = 总页数 × 页表项大小 = 2^19 * 4B = 2MB


因此，页表内存从 4MB 变为 2MB，本题选 B

采用二级页表的分页系统中，一级页表页表项中的内容是 ( )。

A.用于二级页表索引的页号
B.对应二级页表所在的页框号
C.页目录号
D.程序文件所在的页框号

二级页表把分页拆成两级：一级页表（页目录表）和二级页表：

  • 虚拟地址的高位作为一级页号，去索引一级页表；

  • 一级页表的每一个表项，存放的是对应二级页表所在物理内存的页框号（二级页表本身是存放在一个物理页框里的）；本题选 B

  • 再用虚拟地址的中间位作为二级页号，索引这个二级页表，最终得到数据页的页框号

两级页表中，页目录项有效位为 0 （即无效）时代表（）

A. 对应的二级页表已经被换入内存
B. 该段虚拟地址区间未分配，不存在对应的二级页表
C. 二级页表可以直接复用其他进程的
D. 对应数据页已经驻留在物理内存
两级页表结构里，页目录项的有效位（存在位 P）用来标记对应的二级页表的状态：
  • 有效位为 1：对应的二级页表已经分配并驻留在物理内存中；
  • 有效位为 0：代表这段虚拟地址区间的虚拟地址都没有分配，不存在对应的二级页表，访问时会触发缺页异常

本题选 B


与单级页表相比，多级页表的主要优势在于：

A.显著加快了逻辑地址到物理地址的转换过程。
B.能够减少程序运行过程中发生缺页中断的频率
C.允许将页表离散地存放在内存中，避免了需要大块连续内存空间存放整个页表的问题
D.减少了每个页表项所占用的字节数，从而压缩了页表的整体大小。

A：多级页表地址转换需要多次内存访问，反而会减慢逻辑地址到物理地址的转换速度，A 错误


B：多级页表不会减少缺页中断的发生频率，缺页次数由程序的内存访问局部性决定，和页表分级无关，B 错误


C：单级页表需要一整块连续的物理内存来存放完整页表；多级页表可以把各级页表分散离散存放在不同内存块，只需要给用到的下级页表分配内存，解决了大页表需要连续大块内存的难题，这是多级页表最核心的优势，C 正确


D：只要页表的功能相同的话，那么多级页表的每个页表项位数和单级基本一致，并不会减少单个页表项的字节数，D 错误

最坏情况是 TLB 全部不命中，无快表缓存，依次访问 PGD→PUD→PMD→PTE（4 次访存），最后访问数据内存（第 5 次），TLB 全未命中时共 5 次

在一台以字节为单位寻址的 64 位计算机系统中，地址线宽为 64 位，实际使用的虚拟地址空间大小是 256TB。若采用虚拟页式存储管理，每页的大小为 8KB，页表表项长为 8B，采用多级页表进行管理，则多级页表的级次最小是 ( )

A.3
B.4
C.5
D.6

第 ① 步：计算有效虚拟地址位数，因为实际虚拟地址空间是 256TB = 2^48B，所以有效虚拟地址位数是 48 位


第 ② 步：计算页内偏移位数，因为页面大小是 8KB = 2^13B，所以虚拟地址的低 13 位是页内偏移，剩余用于多级页表分级索引的总位数是 48 - 13 = 35


第 ③ 步：计算每级页表能占用的索引位数，因为页表项大小是 8B，一个页大小是 8KB，因此一个页表可以存放的最多的页表项是 8KB / 8B = 1K = 2^10，那么每一级页表的索引占 10 位


第 ④ 步：求最小级数，把 35 位的虚拟地址拆分到每级最多 10 位的页表索引，⌈35 / 10⌉ = 4，所以多级页表的最小级数是 4，本题选 B，看下图：



题目中说 "地址线宽 64 位" 只是硬件描述，不参与任何计算，是出题人设置的干扰信息，不需要使用


64 位地址线：理论能访问 2^64 Byte 物理内存，但现代 64 位 CPU 不会真的全部启用 64 根地址线（x86-64 硬件仅支持最多 48 位物理地址），硬件会截断高位


x86-64 架构：地址线硬件 64 根，但虚拟地址仅 48 位、物理地址最多 48 位


地址线宽是硬件上限，虚拟地址位数是指令集架构（ISA）规定的， 物理地址位数是系统实际使用的有效位数，三者可以互不相等

系统按字节编址，采用分页式存储管理方式管理内存，逻辑地址结构为：{ 页目录号、页号、页内偏移量 }。假设逻辑地址空间大小为 64MB，页面大小为 1KB，页表项大小为 2B。问该系统的页目录表中至少需要包含多少个页表项 ( )

A.32
B.128

一个页面可放置页表项数 = 页面大小 / 页表项大小 = 1KB / 2B = 512，逻辑地址空间页数 = 虚拟地址空间大小 / 页面大小 = 64MB / 1KB = 64K


每个虚拟页对应一个页表项，所以总共有 64K 个页表项，保存这些页表项需要的页框数 = 页表项总数 / 一个页框保存的页表项数 = 64K / 512 = 128，也就是说，需要 128 个二级页表来保存所有的页表项，因此页目录表中应有 128 个表项
