在单级页表系统，在一个指令周期中，执行指令 lw $5, 1200($sp) 最多访问（ ）次主存

A.2
B.3
C.4
D.5
lw 是 加载字指令，功能是计算有效虚拟地址 EA = ($sp) + 1200，从主存 EA 处读出一个字，写入寄存器 $5，一个完整指令周期包含两个必然的主存访问：
  • 取指阶段：根据 PC 的值，从指令主存取出这条 lw 指令（第 1 次访存）
  • 访存阶段：根据算出的有效地址，从数据主存读取要加载的数据（第 2 次访存）

不管是取指令还是取数据，CPU 都是使用虚拟地址，需要经过地址转换成物理地址，而在地址转换的过程中，可能还需要访问主存中的页表，下图是 CPU 从主存中取一个指令或者取一个数据的过程：

CPU 首先给出一个虚拟地址（可以是指令的虚拟地址，也可以是一个操作数的虚拟地址），先来看如果 TLB 命中的话，分两种情况：

  • Cache 命中的话，那么 CPU 不需要访问内存

  • Cache 未命中的话，则需要访问 1 次内存

就是说，在 TLB 命中的情况下，最多只需要访问 1 次内存


再来看如果 TLB 未命中的话，MMU 拿到对应页表项（PTE）的物理地址 PTEA 去访问 Cache，此时要分 2 种情况：

  • Cache 未命中的话，那么 CPU 需要去内存拿到对应的页表项，也就是需要访问 1 次内存

  • Cache 命中的话，不需要访问内存，直接从 Cache 中拿到页表项

拿到页表项后，就可以拿到指令或者数据的物理地址，然后就可以去拿数据，此时也要分 2 中情况：

  • Cache 未命中，需要访存 1 次，从内存中拿到指令或数据

  • Cache 命中，不需要访存，直接从 Cache 中拿到指令或者数据

就是说，在 TLB 未命中的情况下，最多只需要访问 2 次内存（一次拿页表项，一次拿指令或者数据）


因此，CPU 拿一个指令或者一个数据时，最多最多访问 2 次内存，那么一个指令周期中，执行  lw $5, 1200($sp)  最多需要访问 4 次内存，本题选 C

首先 xaddr 送到 MMU 的翻译组件，翻译组件根据虚拟页号从 TLB 中查找对应页表项，假设命中，直接返回页表项 PTE，根据 PTE 中的页帧号和虚拟地址中的页面偏移构建物理地址，发给 Cache，假设命中，将结果数据从处理器送到高速缓存，因为 Cache 采用直接策略，所以，修改 Cache 行后，立马将物理地址和数据发给内存，将结果数据写到物理地址的位置

A.程序计数器 (PC) 的内容
B.通用寄存器的内容

处理外部中断时，分为两个阶段，分别是中断响应和中断处理如下图：



中断响应由 CPU 内部的硬件完成，也就是中断隐指令完成，会保存程序计数器 (PC) 的内容，因此 A 错误

【23-25】某系统采用页式存储管理，用位图管理空闲页框。若页大小为 4KB，物理内存大小为 16GB，则位图所占空间的大小是 ( )。

A.128B
B.128KB
C.512KB
D.4MB

物理内存大小为 16GB，每页大小为 4KB，因此物理内存总共包含的页框数为 (16GB)/(4KB)= 2^34 / 2^12 = 2^22


位图需要管理每个页框的空闲状态，因此位图的位数应该等于物理内存中页框的数量。每个位表示一个页框的空闲状态，所以位图所占空间大小应为  (位图所占位数) / 8 = (2^22) / 8 = 2^19B = 512KB，因此，位图所占空间的大小为 512KB，选项 C 为正确答案

【24-17】某计算机按字节编址，采用页式虚拟存储管理方式，虚拟地址为 32 位，主存地址为 30 位，页大小为 1KB。若 TLB 共有 32 个表项，采用 4 路组相联映射方式，则 TLB 表项中标记字段的位数至少是 ( )。

B.18
C.19
D.20
页大小是 1KB = 2^10B，因此页内偏移是 10 位，那么虚拟页号占的位数 = 虚拟地址位数 - 页内偏移位数 = 32 - 10 = 22

对于 TLB，是使用虚拟页号来查找的，而 TLB 是四路组相联的，意思是说每一组可以存储 4 个页表项，因为 TLB 总共有 32 个页表项，所以 TLB 总共有 32 / 4 = 8 组 = 2^3 组

那么采用虚拟页号的低 3 位作为 TLB 组索引，虚拟页号剩下的 22 - 3 = 19 位作为 TLB 标记位，因此，本题选 C
