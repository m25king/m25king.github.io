以下是有关段式存储管理的叙述，其中错误的是 (   )。

A.段是逻辑结构上相对独立的程序块，因此段是可变长的
B.按程序中实际的段来分配主存，所以分配后的存储块是可变长的
C.每个段表项必须记录对应段在主存的起始位置和段的长度
D.分段方式对低级语言程序员和编译器来说是透明的

A：段依据程序逻辑结构划分（如代码段、数据段），不同逻辑模块长度不同，段是可变长的，该叙述正确


B：段本身长度不固定，按程序实际段分配内存，分配得到的内存块长度和对应段一致，也是可变长的，该叙述正确


C：段表项必须记录段在主存的起始基址、段长度，用于地址转换和越界检查，该叙述正确


D：分页对程序员和编译器透明；而分段是面向程序逻辑结构的，低级语言程序员、编译器需要感知段的划分（比如按段名编写代码、划分代码 / 数据段），分段方式对它们不透明，该叙述错误

在分段管理中，(   )。

A.以段为单位进行分配，每个段都是一个连续存储区
B.段与段之间必定不连续
C.段与段之间必定连续
D.每个段都是等长的

A：分段管理是以段为单位分配内存，每个段内部占用一段连续的存储空间，这个描述是正确的


B：段与段之间不一定不连续，内存空闲情况允许的情况下，相邻段可以连续存放，“必定不连续” 的说法错误


C：段与段之间没有必须连续的要求，分段是按逻辑段独立分配，段间可以存在空闲缝隙，“必定连续” 的说法错误


D：分段依据程序逻辑模块划分，不同逻辑段的功能、代码 / 数据量不同，段的长度各不相等，不是等长的，该说法错误

在分段存储管理系统中，碎片处理问题可采用 (   ) 进行解决。

A.拼接技术（紧凑技术）
B.SPOOLing技术
C.覆盖技术
D.对换技术

A 拼接技术（紧凑技术）：可以把内存中分散的小空闲碎片移动合并成大的连续空闲区，是解决分段外部碎片的常用办法，本题选 A


B SPOOLing 技术：主要用于将独占设备改造为虚拟共享设备，解决设备利用率问题，和内存碎片无关


C 覆盖技术：是同一程序内部不同模块交替占用内存的技术，用来缩减程序内存占用，不处理碎片


D 对换技术：是把内存中暂时不用的进程换出到外存、再把需要的进程换入内存，主要缓解内存容量不足，不是专门处理碎片的手段

采用（ ）不会产生内部碎片

A.分页存储管理
B.分段存储管理
C.随机存储管理
D.段页式存储管理

A 分页存储管理：页面大小固定，最后一个页面大概率未占满，会产生内部碎片


B 分段存储管理：段按程序逻辑模块划分，分配内存时给每个段分配和段长度完全一致的连续空间，不会产生内部碎片，只会产生外部碎片，本题选 B


C 随机存储管理：没有统一的规整分配规则，容易出现各类碎片，通常会产生内部碎片


D 段页式存储管理：先分段再分页，分页环节会产生内部碎片

在内存管理中，内存利用率高且保护和共享容易的是 ( ) 方式。

A.分区存储管理
B.分页存储管理
C.分段存储管理
D.段页式存储管理

分区存储管理：容易产生外部碎片，内存利用率低，分段之间共享、保护的实现难度较大


分页存储管理：内存利用率较高，但页面没有逻辑意义，难以基于逻辑模块实现细致的保护与共享


分段存储管理：段依据程序逻辑模块划分，保护和共享很方便，但会产生外部碎片，内存利用率不如分页高


段页式存储管理：先按逻辑分段实现便捷的保护与共享，再对段分页来减少碎片、提升内存利用率，同时兼具分段和分页的优势，内存利用率高，保护和共享也容易实现


分页存储管理方式的优点是能很好地解决内存的外部碎片问题，内存利用率高；分段存储管理方式的优点是便于实现、分段可共享、便于保护、可动态链接等；段页式存储管理方式结合了上述两种管理方式的优点，本题选 D

下列关于分页和分段的描述中，正确的是 ( )

A.分页系统中，页面在物理内存中只能从页面大小的整数倍地址开始存放
B.页是信息的物理单位，页长由用户决定
C.分段主要目的是提高主存利用率
D.段是信息的逻辑单位，段长由系统决定

A 选项：分页系统中，页面大小由系统确定，物理内存的页框尺寸和页面一致，页框的起始地址一定是页面大小的整数倍，所以页面只能从页面大小的整数倍地址开始存放，该描述正确


B 选项：页是信息的物理单位，但页面大小是操作系统（系统）决定的，不是用户决定，错误


C 选项：分段的主要目的是满足程序逻辑模块化的需求、方便段的共享与保护；提升主存利用率是分页的优势，不是分段的主要目的，错误


D 选项：段是信息的逻辑单位，但段长是用户 / 程序员按逻辑模块划分决定的，不是系统决定，错误

A.用户的地址空间是分页管理，物理内存是分段管理
B.用户的地址空间是分段管理，物理内存是分页管理

段页式存储管理的机制：

  • 用户地址空间：先按程序逻辑分段，每个逻辑段再进行分页

  • 物理内存：划分为固定大小的页框，以页为单位分配内存，也就是物理内存是分页管理


A：用户地址是分段再分页，不是单纯分页，物理内存也不是分段，错误


B：用户地址空间先做逻辑分段，每个段内部分页；物理内存按页框分页管理，正确，本题选 B

A.一维、一维、二维
B.一维、二维、二维
C.一维、二维、一维
D.二维、一维、一维

分页存储管理：用户逻辑地址只有页号 + 页内偏移，整体是连续的一维地址空间，属于一维，访问内存时，不需要明确指令页号和页内偏移


分段存储管理：地址由段号 + 段内偏移组成，段是独立逻辑模块，地址需要两个维度定位，属于二维，在访问内存时，需要明确指明段号和段内偏移


段页式存储管理：地址由段号 + 页号 + 页内偏移，先分段再分页，依然需要段号和段内页号两层逻辑划分，属于二维

下列叙述中，正确的有 ( ) 

I 页式管理系统中，整个操作系统中只有一张页表

II 段式管理系统中，每个进程都有一张段表

III 段页式管理系统中，每个进程都有一张段表和一张页表

IV 段页式管理系统中，每个进程都有一张段表，整个操作系统中只有一张页表

A.仅 I、II
B.仅 II
C.仅 II、III
D.仅 I、IV
I 错误。在页式管理系统中，每个进程都有自己独立的页表。页表用于将进程的逻辑地址空间映射到物理内存地址空间。如果整个操作系统只有一张页表，那么不同进程的相同逻辑地址就会映射到相同的物理地址，无法实现进程地址空间的隔离

II 正确。在段式管理系统中，每个进程的逻辑地址空间由若干个段组成，每个段都有其独立的属性 (如基址、长度、权限等)。为了管理这些段并将段的逻辑地址映射到物理地址，操作系统会为每个进程建立一张段表

III、IV 均错误。在段页式管理系统中，先将进程的逻辑地址空间分成若干个段，然后再将每个段分成若干个页。因此，每个进程会有一张段表，段表中的每个表项对应一个段，并指向该段的页表。这意味着每个进程的每个段都有一个对应的页表，所以一个进程可能会有多张页表，而不是整个进程只有一张页表，更不是整个操作系统只有一张页表

在段页式存储系统中，为了获取一条指令或数据，必须三次访问内存：
  • 第一次访问内存中的段表，从中取得页表地址
  • 第二次访问内存中的页表，从中取得该页所在的物理块号并将该块号与页内地址一起形成指令或数据的物理地址
  • 第三次访问是根据第二次访问所得的地址，真正取出指令或数据(但这是在访问地址正确的情况下)

A.2^8 B

B.2^16 B

C.2^24 B

分段存储管理的逻辑地址分为段号和段内偏移两部分，段内偏移的最大值就是最大段长


地址长度为 32 位，段号占 8 位，则段内偏移量占 32 - 8 = 24 位，故最大段长为 2^24 B，选 C
