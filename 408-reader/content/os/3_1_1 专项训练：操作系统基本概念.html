BIOS 在执行引导前，会进行 POST（加电自检），检测 CPU、内存、主板等关键硬件，并识别已连接的外设，B 正确

引导程序（如 bootloader）并不会一次性把整个操作系统加载到内存，它只负责加载操作系统的内核到内存，然后由内核完成后续的初始化和系统加载。操作系统的大部分组件（如驱动、服务、用户程序）是在内核启动后，按需加载的，因此全部加载的描述错误，本题选 C

【13-29】计算机开机后，操作系统最终被加载到（ ）

A.BIOS
B.ROM
C.EPROM
D.RAM

计算机启动后，主板有电了，CPU 也开始执行指令


第一步：CPU 执行主板上 ROM 区域的 BIOS 的指令，其作用是：自检和加载磁盘中的 Bootloader 程序到内存


第二步：CPU 开始执行存放在内存中的 Bootloader 指令


第三步：Bootloader 程序将 OS 程序和数据加载到内存


第四步：CPU 跳到 OS 程序指令在内存中的位置，执行 OS 程序


第五步：开始操作系统的初始化工作，再创建各种各样的应用程序，至此计算机启动完毕


从上可以看出，操作系统最终被加载到内存中，而内存一般由 DRAM 和 SRAM 组成，因此本题选 D

【22-24】下列选项中，需要在操作系统进行初始化过程中创建的是 ( )。

A.中断向量表
B.文件系统的根目录
C.硬盘分区表
D.文件系统的索引结点表
在操作系统启动的时候，需要读写磁盘文件，也就是说需要发生磁盘 I/O，而磁盘 I/O 会产生中断（当读完一个盘块，会给 CPU 发生中断，表示 I/O 完成，如果采用 DMA 方式的话，也会产生中断），既然产生中断，就需要查询中断向量表，找到对应中断服务程序的内存地址，因此在操作系统启动初始化的时候，必须要先初始化中断向量表，因此，本题选 A

文件系统的根目录和索引结点都是在创建文件系统的时候创建的，而文件系统要么在安装操作系统之前在活动分区上创建一个文件系统，要么在操作系统启动后，我们人工使用 mkfs 来创建文件系统，并且使用 mount 来挂载文件系统，所以说 B 和 D 不可能是在操作系统初始化的时候创建的

磁盘分区要么在安装操作系统之前来做，要么在操作系统启动后来做，所以磁盘分区表也不可能是在操作系统初始化时创建的，因此 C 也是错误

在 X86-64 系统中，有 256 种异常/中断，每一种异常/中断都有自己对应的类型号（从 0 开始），如下图：



而每一种异常/中断都有自己对应的异常/中断处理程序，这些程序都是事先存储在内存中，所以每个处理程序都有对应的内存基地址，而中断向量表就是保存的每一种中断/异常处理程序的内存地址
