提高单机资源利用率的关键技术是 ( )。

A.脱机技术
B.虚拟技术
C.交换技术
D.多道程序设计技术
多道程序设计技术是提高单机资源利用率的核心技术，原理是：当一个程序因等待 I/O 操作（比如读写磁盘）而暂停时，操作系统会调度另一个程序使用 CPU，让 CPU 和 I/O 设备始终处于忙碌状态，避免资源闲置，从而大幅提升 CPU 和系统整体资源的利用率，本题选 D

A 脱机技术：主要用于早期的批处理系统，目的是缓解 CPU 与 I/O 设备的速度矛盾，但不是提高单机资源利用率的关键技术，A 错误


B 虚拟技术：是操作系统的一种资源抽象技术（如虚拟内存），它的核心目标是扩展资源的逻辑容量，而不是直接提高单机资源的利用率，B 错误


C 交换技术：是内存管理的一种策略，用于在内存不足时将进程换入 / 换出内存，属于多道程序设计的辅助技术，不是核心关键，C 错误


实际上虚拟技术与交换技术以多道程序设计技术为前提的，就是说，操作系统通过虚拟技术和交换技术来实现多道程序设计技术

批处理系统分为单道批处理和多道批处理。单道批处理确实不能并发执行，但多道批处理系统的核心就是支持并发执行，I 错误

多道程序设计的核心是宏观上并发、微观上交替执行。在单 CPU 系统中，同一时刻只有一个进程能真正占用 CPU 执行，多个进程是交替使用 CPU 的，并不是每一个时刻都有多个进程在执行，II 错误

多道程序的切换依赖中断机制（如 I/O 中断、时钟中断）：当一个进程发起 I/O 操作时，硬件会触发中断，让操作系统调度另一个进程运行。如果没有中断功能，CPU 就无法主动切换进程，多道程序设计也就无法实现，III 正确

如何理解当一个进程发起 I/O 操作时，硬件会触发中断？

首先，进程调用系统调用（比如 read()/write()）请求读写磁盘 / 网卡，此时会陷入内核态，由操作系统接管；操作系统把 I/O 指令发送给设备控制器，然后主动将发起请求的进程阻塞，调度其他就绪进程占用 CPU 运行，避免 CPU 空转；当设备（比如磁盘）完成数据读写后，会通过硬件中断信号通知 CPU："我干完了！数据已经在内存里了！"；CPU 收到中断后，暂停当前正在运行的进程，进入中断处理程序，把完成 I/O 的进程从阻塞队列唤醒，放回就绪队列，等待 CPU 调度

程序道数过多会导致频繁的进程切换（上下文切换开销），反而会降低系统效率。系统效率会随着道数增加先上升、后下降，存在一个最优的道数，并不是越多越好，IV 错误

分时系统中，当时间片固定时，用户数越多，每个用户分到的时间片就越少，响应时间就相应变长

分时系统的响应时间公式是：响应时间 ≈ 用户数 × 时间片，用户数越多 → 一轮循环需要的总时间越长 → 每个用户需要等待的时间越长 → 响应时间越长

响应时间是衡量分时操作系统性能的重要指标，下列选项中，能够改善响应时间的是 ( )

A.允许用户修改系统时间
B.加大时间片
C.允许中断嵌套
D.采用抢占式优先级调度
A.允许用户修改系统时间：这仅改变系统时钟的设置，与进程调度和响应时间无关，不会改善响应时间

B.加大时间片：响应时间 ≈ 用户数 × 时间片。加大时间片会直接让响应时间变长，反而会恶化交互体验

C.允许中断嵌套：中断嵌套允许高优先级中断在处理低优先级中断时被响应，这可以减少中断延迟，从而间接改善系统对 I/O 事件的响应。但中断嵌套主要影响中断处理效率，对进程级的响应时间改善不如调度策略直接

D.采用抢占式优先级调度：这种调度方式允许高优先级进程抢占当前运行的低优先级进程，从而确保高优先级进程 (如交互式用户进程) 能够及时获得 CPU 时间，直接减少响应时间。在分时系统中，这是改善响应时间的有效方法。本题选 D

Ⅵ 股票交易系统：对交易的时间确定性、低延迟有严格要求，部分高频交易场景会使用实时操作系统来保障处理速度与时间精度，属于典型的实时应用场景

因此，本题选 D

实时系统的核心是必须在截止时间内完成处理，工业控制、航空航天、医疗设备等场景的硬实时系统，若超时会导致严重后果；而股票交易等软实时场景，超时会影响交易公平性或收益，但不会造成物理损坏

考试中判断是否需要实时系统，看两点就行：
  1. 超时会不会导致严重后果？（如设备损坏、安全事故）
  2. 有没有严格的时间截止约束？（如必须在 1ms 内响应）
满足其中一点，才是实时系统的典型应用

计算机开机后，首先执行的是 BIOS 固件（存放在 ROM 中），这是引导流程的第一步，A 正确

BIOS 在执行引导前，会进行 POST（加电自检），检测 CPU、内存、主板等关键硬件，并识别已连接的外设，B 正确

引导程序（如 bootloader）并不会一次性把整个操作系统加载到内存，它只负责加载操作系统的内核到内存，然后由内核完成后续的初始化和系统加载。操作系统的大部分组件（如驱动、服务、用户程序）是在内核启动后，按需加载的，因此全部加载的描述错误，本题选 C

双系统场景下，引导程序会显示系统选择菜单，告诉用户该机器安装了两个操作系统，用户交互可以自己选定想要启动的操作系统，D 正确

【16-23】下列关于批处理系统的叙述中，正确的是（ ）
I：批处理系统允许多个用户与计算机直接交互
II：批处理系统分为单道批处理系统和多道批处理系统
III：中断技术使得多道批处理系统的 I/O 设备可与 CPU 并行工作

A.仅 II，III
B.仅 II
C.仅 I，II
D.仅 I，III
批处理系统中，作业执行时用户无法干预其运行，只能通过事先编制作业控制说明书来间接干预，缺少交互能力，也因此才发展出分时系统，I 错误

批处理系统按发展历程又分为单道批处理系统、多道批处理系统，II 正确

多道程序设计技术允许同时把多个程序放入内存，并允许它们交替在 CPU 中运行，它们共享系统中的各种硬、软件资源，当一道程序因 I/O 请求而暂停运行时，CPU 便立即转去运行另一道程序，即多道批处理系统的 I/O 设备可与 CPU 并行工作，这都是借助于中断技术实现的，III 正确

【17-28】与单道程序系统相比，多道程序系统的优点是（ ）
I：CPU 利用率高
II：系统开销小
III：系统吞吐量大
IV：I/O 设备利用率高

A.仅 I，III
B.仅 I，IV
C.仅 II，III
D.仅 I，III，IV

多道程序系统的优缺点如下：


（1）资源利用率高。引入多道程序能使多道程序交替运行，以保持 CPU 处于忙碌状态；在内存中装入多道程序可提高内存的利用率；此外还可以提高 I/O 设备的利用率（有些作业可能使用磁盘、有些作业可能使用打印机，使得 I/O 设备都在忙）

所以 I、IV 描述正确

（2）系统吞吐量大。由于 CPU 和 I/O 设备能并行工作（多个程序交替使用资源），单位时间内系统能处理的程序数量更多，吞吐量显著提升


所以 III 描述正确


（3）系统开销大：多道程序系统需要进行程序切换、内存管理、进程调度等操作，这些都会增加系统的管理开销，相比单道程序系统，其系统开销更大


注意，这道题目问的是多道程序系统，而不是多道批处理系统，如果是多道批处理系统的话，仅当作业完成时或运行不下去时才进行切换，系统开销比较小，但是多道程序系统的话，可能每隔一个 CPU 时间片就会切换一道程序，这个系统开销大


因此 II 描述错误，所以本题选 D
