I SSTF（最短寻道时间优先）算法：每次选择离当前磁头位置最近的请求。它不限制磁头的运动方向，只要哪个请求更近，就可以随时改变方向去访问，I 正确


II SCAN（扫描 / 电梯）算法：磁头会按一个固定方向移动，直到到达磁盘端点，再反向移动。在到达端点前，不能改变方向

【12-32】下列选项中，不能改善磁盘设备 I/O 性能的是（ ）

A.重排 I/O 请求次序
B.在一个磁盘上设置多个分区
C.预读和滞后写

磁盘 I/O 性能的核心瓶颈是硬件速度和数据读写效率，所以要改善磁盘设备 I/O 性能，就需要从这两个方面入手

对于 A，重排 I/O 请求次序也就是进行 I/O 调度，I/O 调度的目的就是为了减少磁盘 I/O 的平均寻道时间，寻道时间减少，就可以提高数据读写效率，因此可以提升磁盘 I/O 性能

对于 B，分区（如 Windows 的 C 盘、D 盘，Linux 的 /、/home 等）是对磁盘物理存储空间的逻辑划分，其作用是便于文件系统的管理，除了使得文件系统管理的盘块不会太多之外，还可以使得每个分区单独格式化、重装系统不影响其他分区数据

但是分区不会改变磁盘的物理结构：
  • 机械硬盘（HDD）的磁头、盘片转速，固态硬盘（SSD）的闪存颗粒、控制器等硬件性能不变
  • 而且所有分区共享磁盘的读写通道（所有分区使和同一个控制器连接）

因此分区不会优化硬件速度和数据读写效率这两点，所以，分区不能提升磁盘 I/O 性能，本题选 B

对于 C，缓冲区结合预读和滞后写技术对于具有重复性及阵发性的 I/O 进程改善磁盘 I/O 性能很有帮助。对于 D，优化文件物理块的分布可以减少寻找时间与延迟时间，从而提高磁盘性能。请复习：图文总结：如何提高磁盘 I/O 的速度？

【15-28】在系统内存中设置磁盘缓冲区的主要目的是（ ）

A.减少磁盘 I/O 次数
B.减少平均寻道时间
C.提高磁盘数据可靠性
D.实现设备无关性
我们在单缓冲区和双缓冲区中学习了缓冲区的四个作用：
  • ① 缓和 CPU 和 I/O 设备间速度不匹配的矛盾 
  • ② 提高 CPU 和 I/O 设备之间的并行性
  • ③ 减少对 CPU 的中断频率
  • ④ 解决数据粒度不匹配问题

不管是哪一个作用，都是用到了缓冲区的核心功能：暂存数据

对于磁盘缓冲区：
  • 当进程写入数据时，先写到缓冲区，缓冲区积累零散数据，达到阈值后一次性写入磁盘（避免频繁小量写入）
  • 当进程读取数据时，基于局部性原理可以预读相邻盘块的数据，然后一起放到磁盘缓冲区，后续访问直接从缓冲区获取

这两种机制直接减少了磁盘 I/O 的实际次数，是缓冲区的主要目的，因此本题选 A

寻道时间是机械硬盘移动磁头到目标磁道的物理耗时，由硬件结构决定。缓冲区是内存中的逻辑区域，无法影响磁盘的物理运动（如磁头移动），因此不能减少寻道时间，所以 B 错误

数据可靠性依赖冗余（如 RAID）、校验（如 CRC）等。缓冲区的数据是临时存储（断电可能丢失），不仅不能提升可靠性，甚至需要 "同步机制"（如 fsync，就是将缓冲区中的数据同步到磁盘中）才能避免数据丢失，因此与可靠性无关，对于什么是 RAID，可以学习视频：RAID（磁盘阵列）【了解即可】

题目说了，最外侧是 0 号磁道，也就是最小的磁道号在最外侧，然后，题目又说当前磁头位于第 58 号磁道并从外侧向内侧移动，也就是从磁道号增加的方向移动


所以，先按照磁道号升序的顺序，调度访问大于等于 58 号磁道的磁道，也就是调度访问 130、180、199 这 3 个磁道，移动的磁道数是 (130 - 58) + (180 - 130) + (199 - 180) = 199 - 58  = 141


注意：其实直接将最大的磁道号减去当前磁头所在磁道号即可，这样可以节省时间


接下来反向移动磁头，按照磁道号降序的顺序，调度访问小于 58 号磁道的磁道，也就是调度访问 42、15，移动的磁道数等于 199 减去最小的磁道号 15 ，也就是 199 - 15 = 184


因此磁头移过的磁道数是：(199 - 58) + (199 - 15) = 325，本题选 C


从这里你得学会，在 SCAN 调度算法中，如果移动方向是磁道号增加的方向的话，计算移动磁道数 = (最大磁道号 - 磁头当前磁头号) + (最大磁道号 - 最小磁道号)

【24-32】某磁盘的磁道数为 400 (磁道号为 0~399)，采用循环扫描算法 (CSCAN) 进行磁盘调度，完成对 200 号磁道的请求后，磁头向磁道号减小的方向移动。若还有 7 个磁盘请求，对应的磁道号分别为 300,120,110,0,160,210,399，则完成上述磁盘访问请求后磁头移动的距离是 ( )。

A.599
B.619
C.788
D.799
注意，看清题目，这里是采用循环扫描算法（CSCAN ），本题说，完成对 200 号磁道的请求后，磁头向磁道号减小的方向移动

那么，在 CSCAN 中，磁头在磁盘上仅仅在磁道号减少的方向上，会调度访问沿途遇到的所有磁盘请求。当磁头到达这个方向上的最后一个请求磁道号后，也就是请求的最小的磁道号，它会快速回到磁盘上待访问请求的最大磁道号的磁道上，在这个返回期间不处理任何请求，然后再次开始向磁盘号增加的方向扫描并调度新的请求

本题中，磁盘完成对 200 号磁道的请求后，磁头向磁道号减小的方向移动到 0 号磁道，处理了请求 160、120、110 和 0，期间移动了 200 个磁道（200 - 0 = 200）


随后，磁头从 0 号磁道快速移动到 399 号磁道，不处理任何请求，期间移动了 399 个磁道


最后，磁头从 399 号磁道移动到 210 号磁道，处理了请求 399、300 和 210，期间移动了 189 个磁道（399 - 210 = 189）


因此整个过程共移动了 200 + 399 + 189 = 788 个磁道，本题选 C
