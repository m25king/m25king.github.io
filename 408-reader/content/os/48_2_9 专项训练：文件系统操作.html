A.数据存储
B.数据保护

下列关于文件系统的说法，正确的是 ( )

A.文件系统可使用的容量大小一定等于其所在的磁盘空间大小
B.文件系统中单个文件的大小只受其所在磁盘空间大小的限制
C.一个文件系统只能将数据存放在一个磁盘上
D.文件系统可以管理的文件数量受限于该文件系统的文件控制块数量

A 错误：文件系统会占用一部分磁盘空间来存储元数据（如超级块、inode 表、位示图等），因此可使用的容量小于磁盘的总空间


B 错误：单个文件的大小不仅受磁盘空间限制，还受文件系统自身的限制，比如块大小、索引节点的结构等，比如在索引分配中，索引结点的直接块、一级间接块、二级 / 三级间接块的数量和位数，决定了能寻址的最大数据块数量，块大小和索引节点的地址结构共同决定文件上限


C 错误：现代文件系统支持跨磁盘存储，例如 LVM、RAID 等技术，一个文件系统的数据可以分布在多个磁盘上


D 正确：文件控制块（如 inode）的数量在文件系统创建时就已确定，每个文件都需要一个文件控制块来管理元数据，因此可管理的文件数量受限于文件控制块的总数

下列关于文件系统和虚拟文件系统 (VFS) 的说法中正确的是 ( )

A.每种操作系统都有自己专有的文件系统，不同操作系统之间文件系统完全不兼容
B.VFS 不能同时支持多种文件系统
C.通过 VFS，应用程序可以不关心底层使用的是哪种文件系统
D.文件系统挂载是一个不可逆的操作，一旦挂载无法卸载
A 错误：很多文件系统是跨操作系统兼容的，比如 FAT32、exFAT 可以在 Windows、macOS、Linux 上读写，ext4 也能在 Windows 上通过工具访问，并非 “完全不兼容”

B 错误：VFS（虚拟文件系统）的核心设计目标之一，就是同时支持多种不同的文件系统（如 ext4、NTFS、FAT32 等），为上层应用提供统一接口

C 正确：VFS 对应用层屏蔽了底层文件系统的差异，应用程序只需调用统一的系统调用（如 open、read、write），无需关心底层具体是哪种文件系统

D 错误：文件系统的挂载是可逆操作，可以通过 umount（Linux）或卸载卷（Windows）安全卸载，并非不可逆

关于虚拟文件系统 (VFS)，以下描述中不正确的是()

A.VFS 为不同的文件系统提供一个抽象层
B.VFS 允许用户在不同类型的文件系统中进行无缝切换
C.所有操作系统都使用相同的 VFS 实现
D.VFS 允许系统调用如 open 和 read 与特定文件系统无关

A 正确：VFS 的核心作用就是为不同文件系统（ext4、NTFS、FAT32 等）提供统一的抽象层，屏蔽底层差异


B 正确：VFS 让用户可以在不同文件系统之间无缝切换，比如你可以同时访问 ext4 的系统盘和 FAT32 的 U 盘，操作体验是一致的


C 错误：不同操作系统的 VFS 实现是不同的，比如 Linux 的 VFS、Windows 的 IFS（Installable File System）、macOS 的 VFS，它们的接口和内部结构都不一样，并不是 “所有操作系统都使用相同的 VFS 实现


D 正确：VFS 为应用程序提供了统一的系统调用（如 open、read、write），这些调用与底层具体的文件系统无关


FS 是操作系统内核级的设计，每个系统都会根据自身架构实现自己的 VFS 层。比如：

  • Linux 的 VFS 定义了 struct file、struct inode 等核心数据结构；

  • Windows 则通过 IFS 模型来实现类似的功能，接口和逻辑和 Linux 完全不同

虚拟文件系统 VFS 中的对象类型不包括()。

A.超级块(superblock)对象
B.索引节点(inode)对象
C.数据(data)对象
D.文件(fle)对象
Linux VFS（虚拟文件系统）的核心对象类型，主要包含以下四类：
  1. 超级块（superblock）对象：描述整个文件系统的全局信息（如块大小、inode 总数等），对应选项 A
  2. 索引节点（inode）对象：描述单个文件的元数据（如文件大小、权限、数据块指针等），对应选项 B
  3. 目录项（dentry）对象：描述文件的目录项，用于路径解析和缓存。
  4. 文件（file）对象：描述进程打开的文件实例，记录文件的当前状态（如文件指针位置、访问模式等），对应选项 D

选项 C 的数据（data）对象，并不是 VFS 定义的标准对象类型。文件的实际数据存储在磁盘的数据块中，由 inode 对象通过指针来管理，而不是作为 VFS 的独立对象存在，本题选 C

在计算机操作系统中，对于文件挂载的过程和相关概念，哪个选项的描述是正确的? ( )

A.文件挂载是将一个文件复制到另一个目录中，并将其与目录树中的挂载点关联，使其可访问和操作
B.文件挂载是将一个目录连接到另一个目录，使其成为目录树的一部分，并与外部文件系统关联
C.文件挂载是将一个文件系统连接到计算机的硬件设备，使文件系统中的文件和目录可供访问
D.文件挂载是将一个文件压缩并加密后存储在磁盘上，并与特定的解密工具关联，以便访问和操作

A 错误：挂载不是复制文件，它不会移动或复制任何数据，只是把外部文件系统 “接入” 到当前目录树中


B 正确：文件挂载的核心定义，就是将外部文件系统的根目录，连接到当前文件系统目录树中的一个节点（挂载点），让外部文件系统成为系统目录树的一部分


C 错误：挂载的过程不是把文件系统连接到硬件设备，而是将文件系统连接到操作系统的目录树。硬件设备本身是文件系统的载体，挂载是让操作系统识别并访问这个载体上的文件系统，确切的说文件系统的创建（比如通过 mkfs 命令）是文件系统连接到硬件设备


D 错误：挂载和文件的压缩、加密没有任何关系，这是无关的操作

某 Unix 系统中，多个单独设备上的多个文件系统被挂载到一个统一的文件系统中。假设某光盘文件系统中包含一个路径名为 /usr/bin/vim 的文件，且光盘被挂载到 /media/disk 处，则整个文件系统中这个文件的路径名是 ( )。

A./usr/bin/vim
B./media/vim
C./media/usr/bin/vim
D./media/disk/usr/bin/vim
文件挂载的核心逻辑是：将外部文件系统的根目录，挂载到系统目录树的一个挂载点上

光盘自身的文件系统中，文件路径是 /usr/bin/vim（光盘的根目录下的路径）

光盘被挂载到 /media/disk 这个挂载点上，意味着光盘的根目录会被 “接入” 到 /media/disk 目录下

因此，在整个系统中访问这个文件的路径，就是 挂载点路径 + 光盘内的文件路径，即 /media/disk/usr/bin/vim，本题选 D

【22-24】下列选项中，需要在操作系统进行初始化过程中创建的是 ( )。

A.中断向量表
B.文件系统的根目录
C.硬盘分区表
D.文件系统的索引结点表
在操作系统启动的时候，需要读写磁盘文件，也就是说需要发生磁盘 I/O，而磁盘 I/O 会产生中断（当读完一个盘块，会给 CPU 发生中断，表示 I/O 完成，如果采用 DMA 方式的话，也会产生中断），既然产生中断，就需要查询中断向量表，找到对应中断服务程序的内存地址，因此在操作系统启动初始化的时候，必须要先初始化中断向量表，因此，本题选 A

文件系统的根目录和索引结点都是在创建文件系统的时候创建的，而文件系统要么在安装操作系统之前在活动分区上创建一个文件系统，要么在操作系统启动后，我们人工使用 mkfs 来创建文件系统，并且使用 mount 来挂载文件系统，所以说 B 和 D 不可能是在操作系统初始化的时候创建的

磁盘分区要么在安装操作系统之前来做，要么在操作系统启动后来做，所以磁盘分区表也不可能是在操作系统初始化时创建的，因此 C 也是错误
