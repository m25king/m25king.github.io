进程和程序的本质区别在于(   )。

A.前者分时使用 CPU，或者独占 CPU
B.前者存储在内存，后者存储在外存
C.前者具有异步性，后者具有可再现性
D.前者可以并发执行，后者不能并发执行

A 选项：进程会分时 / 独占 CPU，但这不是二者本质区别，程序被调度执行成为进程后才会使用 CPU，静态程序本身不占用 CPU，A 错误


B 选项：程序平时存放在外存，运行时对应的进程会把代码加载到内存，但这只是运行时的存储状态变化，不是本质区别，B 错误


C 选项：异步性是进程的特征、可再现性是程序顺序执行的特征，但这是由动态 / 静态属性衍生的特点，不是本质区别本身，C 错误


D 选项：进程是程序的一次动态执行过程，可以并发执行；程序是静态的指令代码集合，本身不能并发执行，这是二者的核心本质区别之一（底层根源是进程动态、程序静态，并发能力是最直观的本质差异表现），本题选 D

在采用页式虚拟存储管理的操作系统中，当发生进程切换时，为了确保新调度的进程能够正确地在其独立的地址空间中运行，操作系统必须更新处理器的某些关键寄存器。下列哪些寄存器的内容一定需要根据新进程的 PCB 进行更新？

I 指向当前页表基址的寄存器

II 通用数据寄存器

III 程序计数器

IV 栈顶指针寄存器

A.仅 I、III
B.仅 II、IV
C.仅 I、III、IV
D.I、II、III、IV

对于 I（指向当前页表基址的寄存器），每个进程有独立的页表，页表基址存放在该进程的 PCB 中。进程切换时，必须从新进程 PCB 取出页表基址更新这个寄存器，才能让新进程使用自己的地址空间，需要更新


对于 II（通用数据寄存器），通用数据寄存器存放进程运行的临时数据，进程切换时会把旧进程的通用寄存器值保存到旧 PCB，再从新 PCB 恢复新进程的通用寄存器值，需要更新。


对于 III（程序计数器），程序计数器指示 CPU 下一条要执行的指令的地址。进程切换时，当前进程的 PC 值（即下一条要执行的指令地址）必须被保存到其 PCB 中。然后，将新调度进程在其上次被换下时保存的 PC 值加载到 CPU 的指令指针寄存器中，以便新进程能从正确的位置继续执行


对于 IV（栈顶指针寄存器），每个进程都有自己的用户栈和内核栈，栈顶指针寄存器 (如 RSP、SP) 指向当前栈的栈顶。进程切换时，当前进程的栈顶指针必须被保存，并且新进程的栈顶指针必须被恢复。这确保了新进程在执行时能够正确使用其自身的栈空间进行函数调用、局部变量存储等操作


因此本题选 D

下列关于中断响应与进程切换的上下文切换区别的叙述中，错误的是 ( )。

A.中断响应保存和恢复上下文是分开进行的，而进程切换的上下文保存与恢复是连续进行的
B.中断响应可能发生特权级切换，进程切换全程在内核态下进行
C.中断响应不涉及地址空间切换，进程切换涉及地址空间切换
D.中断响应维护的上下文一定是用户上下文，进程切换维护的一定是内核态下的上下文

A 选项：中断响应时，进入中断会先保存现场，中断处理结束后才恢复现场，保存和恢复是分开的；进程切换在调度时连续完成旧进程现场保存、新进程现场恢复，该描述正确


B 选项：中断可能从用户态切换到内核态（特权级切换）；进程切换全程在内核态的调度流程中完成，该描述正确


C 选项：中断是在当前进程的地址空间内处理，不切换地址空间；进程切换需要切换页表、刷新 TLB，完成地址空间切换，该描述正确


D 选项：当 CPU 处于用户态时，可能发生中断，此时中断响应维护的上下文是用户上下文，因此中断响应维护的上下文有可能是用户上下文，当然，也可能是内核上下文，而进程切换维护的一定是内核态下的上下文。D 错误，本题选 D

以下关于进程切换的说法中，正确的是 ( )

A.进程切换发生在用户态，从一个进程的运行态切换到另一个进程的运行态
B.中断/异常 (系统调用) 的发生是进程切换的前提
C.P0 进程切换为 P1 进程的过程中，操作系统需要保存的信息有 P0 进程的断点，现场，堆栈中的数据，进程级打开文件表，P0 进程的页表基址等信息
D.中断响应与进程切换保存和恢复上下文都是连续进行的

A 错误，进程切换全程发生在内核态，当进程从用户态切换到内核态 (如通过系统调用、中断或异常)，操作系统才会执行进程调度；切换过程中，CPU 的控制权完全交给内核，因此切换操作必须在内核态完成


B 正确，进程切换的触发时机通常是中断 / 异常（时钟中断、系统调用异常等）使 CPU 进入内核态，操作系统获得调度机会，中断 / 异常是进程切换发生的必要前提


C 错误，进程切换保存的是CPU 寄存器现场、页表基址这类硬件上下文信息；进程打开文件表、堆栈中的数据属于进程 PCB 里长期维护的信息，不会在每次进程切换时重复保存堆栈全部数据、文件表内容


D 错误，中断响应是先保存中断现场，中断处理结束后才恢复现场，保存和恢复不是连续进行；进程切换的上下文保存与恢复是连续完成的，二者不一样

下列关于 PCB 的组织方式的说法中，错误的是 ( )

A.线性方式将所有 PCB 存放在一个连续的内存区域 (如数组) 中，其优点是实现简单，但在需要频繁插入和删除 PCB 时效率较低
B.链接方式通过指针将 PCB 连接起来，可以方便地根据进程状态 (如就绪、阻塞) 将 PCB 组织成不同的队列，适用于进程状态频繁变化的系统
C.索引方式为所有 PCB 建立一个统一的索引表，通过进程 ID 直接计算索引即可快速定位 PCB，因此查找任何 PCB 的效率都非常高且固定
D.链接方式相比线性方式，在创建和撤销进程时，对 PCB 的插入和删除操作通常更灵活高效，因为不需要移动大量数据
