【12-43】（10 分）假定某计算机的 CPU 主频为 80MHz，CPI 为 4，平均每条指令访存 1.5 次，主存与 Cache 之间交换的块大小为 16B，Cache 的命中率为 99%，存储器总线宽度为 32 位。请回答下列问题。

1) 该计算机的 MIPS 数是多少？平均每秒 Cache 缺失的次数是多少？在不考虑 DMA 传送的情况下，主存带宽至少达到多少才能满足 CPU 的访存要求？

2) 假定在 Cache 缺失的情况下访问主存时，存在 0.0005% 的缺页率，则 CPU 平均每秒产生多少次缺页异常？若页面大小为 4KB，每次缺页都需要访问磁盘，访问磁盘时 DMA 传送采用周期挪用方式，磁盘 I/O 接口的数据缓冲寄存器为 32 位，则磁盘 I/O 接口平均每秒发出的 DMA 请求次数至少是多少？

3) CPU 和 DMA 控制器同时要求使用存储器总线时，哪个优先级更高？为什么？

4) 为了提高性能，主存采用四体低位交叉存储模式，工作时每 1/4 个存储周期启动一个体。若每个体的存储周期为 50ns，则该主存能提供的最大带宽是多少？

（1）MIPS 的含义是每秒执行多少百万条指令，因为 CPU 主频是 80MHz，意思就是说 1 秒钟有 80M 个时钟周期，CPI 为 4 表示执行一条指令需要 4 个时钟周期，那么 1 秒之内可以执行的指令数 = 80M / 4 = 20M，因为 1M = 10^6 = 百万，所以  1 秒中执行 20 个百万条指令，因此 MIPS = 20


公式：MIPS = CPU 主频 / (CPI * 10^6)


这里要是忘了，请复习视频：计算机系统的三个性能评估方式


因为一条指令平均访存 1.5 次，又 1 秒中执行 20M 条指令，所以 1 秒钟访存的次数是 20M * 1.5 = 30M 次，Cache 的命中率是 99%，说明 Cache 的缺失率是 1%，所以平均每秒 Cache 的缺失次数 = 每秒访存次数 * 缺失率 = 30M * 1% = 0.3M


因为 Cache 和主存之间交换的块大小是 16B，也就是说，每次 Cache 缺失，就要从主存中读取 16B 的数据，而平均每秒 Cache 的缺失次数是 0.3M，因此平均每秒需要从主存传输 16B * 0.3M = 4.8MB 的数据，也就是说主存至少每秒要传输 4.8MB 的数据，所以主存的带宽至少是 4.8MB/s


注意：主存带宽表示单位时间内存储器存取的数据量，这里的 M 表示 10^6


大家有没有发现，这一问题目说了一句话：在不考虑 DMA 传送的情况下，为什么要这么规定呢？

这是因为，当 DMA 将磁盘中的数据传输到物理内存中的话，会使得物理内存中的数据和 Cache 中的数据不一致，这个时候就会将 Cache 中的数据失效掉，从而会影响 Cache 的命中率，所以，题目为了方便计算，就忽略了 DMA 的传送了

CPU 可以访问内存，并且 CPU 和内存之间还有一个 Cache

DMA 控制器可以直接访问内存，但是 DMA 访问内存时不会经过 Cache

问题是，如果  DMA 控制器往内存写数据，这样是的 CPU Cache 中的数据和内存数据不一致了，该如何解决呢？

DMA 写（设备→内存）后：执行 Cache Invalidate（无效化），让 CPU 后续读时从内存加载新数据，而非用缓存旧值

DMA 读（内存→设备）前：执行 Cache Flush/Clean（回写），把 CPU 缓存脏数据刷到内存，避免 DMA 读旧值


（2）从上面可以知道平均每秒 Cache 的缺失次数是 0.3M，也就是说 CPU 平均每秒真正访存 0.3M，因为缺页率是 0.0005%，那么 CPU 平均每秒产生的缺页次数是 0.3M * 0.0005% = 1.5

我们先来思考一个问题：如果某个单体存储器的存储字长是 32 位，存储周期为 200ns，然后存储器总线的数据总线的宽度是 32 位，总线传输周期为 50ns，那么这个单体存储器的带宽是多少呢？


存储器的存取带宽与存储周期密切相关，表示单位时间内存储器存取的数据量，单位可以是字/秒、字节/秒或者位/秒（即 bps）

这个单体存储器，它的存储周期是 200ns，每个存储周期可读出一个存储字，那么 1s 内可以读出 1s / 200ns = (1000 * 10^6ns) / 200ns = 5M 个字，每个字是 32 位，那么它的带宽就是 5M * 32 位 / s = 160M bps

一定要注意的是：存储器的带宽是存储器内部的性能指标，和存储器总线没有任何关系，所以只需要看 1 个存储周期能读出多少位的数据即可，这里的 "读出" 是指从主存接收到地址开始，到准备好数据，将数据放到 DRAM 芯片的缓冲器中（不包括将数据传输到 CPU，因为这部分属于存储的外部了，所以不能算）
