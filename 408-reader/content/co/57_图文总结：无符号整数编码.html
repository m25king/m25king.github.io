无符号数的编码

当一个编码的所有二进制位都用来表示数值，而没有符号位时，该编码表示的就是无符号整数

按照上面的无符号编号的定义，那么一个 n 位的无符号编码能表示的整数的范围是 0 ~ 2^n - 1，即无符号编码只能表示非负整数（即 0 和正整数）
在计算机系统中，一般使用无符号整数进行地址运算，或者用来表示指针
无符号整数编码具有唯一性，即：一个长度为 n 的无符号编码（即长度为 n 的二进制串）都可以表示为 0 ~ 2^n - 1 之间的一个唯一的整数，反过来，在 0 ~ 2^n - 1 之间的每一个整数都可以编码为一个唯一的长度为 n 的无符号编码
比如，长度为 4 的一个无符号编码 1011，只能表示 11 这个整数，而整数 11 只能编码成长度为 4 的无符号编码 1011

C 语言中的无符号整数

在 C 语言中，有 4 种基本数据类型是无符号整数编码的：

无符号字符类型（unsigned char），被编码成 8 位的无符号编码，能表示的整数范围是 0 ~ 2^8 - 1 （即 0 ~ 255）；无符号短整型（unsigned short），被编码成 2 字节；无符号整型（unsigned int），被编码成 4 字节
而无符号长整型（unsigned long），有可能被编码成 4 字节，也有可能被编码成 8 字节，这个取决于你的程序被编译器编译成 32 位程序，还是 64 位程序；如果是 32 位程序其长度是 4 字节，64 位程序的话，其长度是 8 字节，如下表：

为什么要区分 32 位程序和 64 位程序呢？这个和计算机的发展有关系
每台机器都有一个机器字长，机器字长就是这台机器的 CPU 一次性可以计算处理多少位的数据，一般而言，CPU 中通用寄存器可以存储多少位的数据，那么这台机器的机器字长就是多少位
如果机器字长是 32 位的，那么这台机器就是 32 位机器，如果机器字长是 64 位的，那么这台机器就是 64 位机器；32 位机器一次性可以计算处理 32 位，也就是 4 字节数据，而 64 位机器，一次性可以计算处理 64 位，也就是 8 字节的数据
如果你的程序要运行在 32 位机器上，你就需要将它编译成 32 位程序，如果你的机器是 64 位机器的话，那么你的程序可以编译成 32 位程序，也可以编译成 64 位程序，都可以
但是 32 位机器上是不能执行 64 位机器的，现在的机器一般都是 64 位机器
