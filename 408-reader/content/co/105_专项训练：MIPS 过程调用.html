以下哪种类型的指令执行后不一定会改变程序执行顺序（ ）

A.无条件跳转指令
B.调用指令 (jal)
C.条件跳转指令
D.过程返回指令
A 无条件跳转指令：执行后必然会修改程序计数器（PC）的值，强制跳转到目标地址，100% 改变程序执行顺序

B 过程调用指令（jal）：执行时会将返回地址存入寄存器，同时修改 PC 跳转到子程序入口，必然改变执行顺序


C 条件跳转指令：执行后是否改变顺序，取决于条件是否满足。例如 beq $2, $0, label，如果 $2 寄存器的值不等于 0 的，程序会继续按顺序执行下一条指令，不一定改变执行顺序，本题选 C


D 过程返回指令：执行时会从栈中恢复返回地址并写入 PC，跳回调用点，必然改变执行顺序

下列关于转移指令（就是分支指令）和过程调用指令的叙述中，错误的是 ( )

A.转移指令必须给出转移分支的目标地址，而过程调用指令不需要
B.子程序执行结束时，需要返回到过程调用指令的下一条指令执行，而转移指令不一定。
C.转移指令不需要保存返回地址，过程调用指令必须需要保存返回地址。
D.转移指令可以按条件进行转移，但是过程调用指令必须无条件转移到目标地址

无论是转移指令（分支指令）还是调用指令，都必须明确给出目标地址，才能让 CPU 知道要跳转到哪里执行。调用指令的目标地址就是子程序的入口地址，不存在 "不需要给出目标地址" 的情况，因此 A 错误，本题选 A


调用指令用于过程调用，过程执行完后，必须通过返回指令回到调用指令的下一条指令继续执行；而普通转移指令（如条件跳转、无条件跳转）仅用于改变执行流程，没有 “必须返回” 的要求，B 正确


转移指令只是单纯改变程序计数器（PC），不需要保存返回地址；调用指令必须保存当前指令的下一条地址（返回地址），才能在子程序执行完后正确返回，C 正确


转移指令分为无条件转移和条件转移（如 if 分支），可以按条件跳转；而调用指令必须无条件跳转到子程序入口，不存在 “条件调用” 的情况，D 正确

以下有关过程调用指令的叙述中，错误的是 (   )。

A.与高级语言源程序中的过程调用相对应，一次过程调用对应一条调用指令
B.指令执行时必须保留返回地址，调用指令随后一条指令的地址是返回地址
C.嵌套调用时返回地址通常保存在栈中，非嵌套调用时可保存在特定寄存器中
D.指令执行时将无条件跳转到目标地址处，跳转目标地址无须在指令中明显给出

高级语言中的一次过程 / 函数调用，在编译后会对应一条机器级的过程调用指令（如 MIPS 的 jal、x86 的 call），是 一 一 对应的关系，A 正确


调用指令执行时，必须将下一条指令的地址（返回地址）保存下来，这样子程序执行完后才能正确回到调用点继续执行。B 正确


嵌套调用时，返回地址需要按 "后进先出" 的顺序保存，因此通常存在栈中；非嵌套调用（如简单的单层调用），可以直接存在专用寄存器（比如 MIPS 中的 $31 寄存器）中，无需入栈，C 正确


过程调用指令执行时，必须明确给出跳转的目标地址（即被调用过程的第一条指令的内存地址），CPU 才能知道要跳转到哪里执行，D 错误，本题选 D

假设 P 为调用过程，Q 为被调用过程，以下是 C 语言程序中过程调用所涉及的操作：

① 过程 Q 保存 P 的现场，并为非静态局部变量分配空间
② 过程 P 将实参存放到 Q 能访问到的地方
③ 过程 P 将返回地址存放到特定处，并转跳到 Q 执行
④ 过程 Q 取出返回地址，并转跳回到过程 P 执行
⑤ 过程 Q 恢复 P 的现场，并释放局部变量所占空间
⑥ 执行过程 Q 的函数体

过程调用的正确执行步骤是 ( )。

A.②→③→④→①→⑤→⑥
B.②→③→①→④→⑥→⑤
C.②→③→①→⑥→⑤→④
D.②→③→①→⑤→⑥→④

假定过程 P 调用过程 Q，则过程调用的执行步骤如下：

  1. P 将入口参数放到 Q 能访问到的地方

  2. P 将返回地址存到特定的地方（嵌套调用就放在栈内存，非嵌套调用就放在 $31 寄存器），然后将控制转移到 Q

  3. Q 为 P 保存现场（比如存放在 $16 这种保存寄存器中的数据，如果 Q 要用 $16 寄存器的话，就需要先将 $16 寄存器的数据保存到当前栈帧），并为自己的局部变量分配空间

  4. 执行过程 Q，并将返回结果放到 P 能访问到的地方

  5. Q 恢复 P 的现场（比如将栈内存中数据恢复到 $16 寄存器），并释放局部变量所占空间

  6. Q 取出返回地址，将控制转移到 P

因此，过程调用的步骤是 ②→③→①→⑥→⑤→④，本题选 C
