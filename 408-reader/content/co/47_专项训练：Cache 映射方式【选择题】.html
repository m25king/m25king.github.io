命中率高且电路实现简单的 Cache 与内存映射方式的是 ( )。

A.全相联映射
B.直接映射
C.组相联映射
D.哈希映射
A 全相联映射：虽然命中率最高，但需要比较 Cache 中所有行的标记，电路实现非常复杂，不符合 "电路实现简单" 的要求

B 直接映射：电路实现最简单，但每个主存块只能映射到唯一的 Cache 行，冲突缺失多，命中率最低，不符合 "命中率高" 的要求

C 组相联映射：将 Cache 分为若干组，每组包含若干行，主存块映射到固定组后，可在组内任意行存放。它兼顾了全相联的高命中率和直接映射的简单实现，是最符合题意的选项


D 哈希映射：并非 Cache 与内存的标准映射方式，属于干扰项

八路组相联 Cache 的每组有 8 行，而 Cache 共有 64 块（行），所以 Cache 组数 = 64 / 8 = 8，因为组号 y 的位数 = log2(8) = 3

因为每块是 64 字节，按字编址，一个字对应一个地址，每个字是 4B，那么一个主存块中包含 64B / 4B = 16 个字，也就是是有 16 个地址，因此块内地址 z 的位数 = log2(16) = 4


主存共有 8192 块，每块 64 个字节，所以，主存容量大小 = 8192 * 64B = 2^19B，按字编址，每个字 4B，因此，主存地址数量是 2^19B / 4B = 2^17B，所以，主存地址的位数 m = 17


主存地址的标记 x 的位数 = m - (y + z) = 17 - (3 + 4) = 10

②增加Cache块偏移量需要的位数

Cache访问时间是固定的，不会因为映射方式而改变，①错误；由于块大小不变，因此块偏移量所需位数不变，②错误；相联度为每组内的路数，相联度提高则组数减少，即组号所需位数减少，从而③正确。

主存地址空间是 28 位，按字节编址，有效容量为 128KB 的 Cache，每块 16B，采用 8 路组相联。字节地址为 1234567H 的单元调入该 Cache，则其 Tag 应为 ( )。

A.1234H
B.2468H
C.048DH
D.12345H

Cache 有效容量是 128KB，意思是 Cache 的数据区容量是 128KB，每块 16B，因此 Cache 总行数 = 128KB / 16B = 2^13


Cache 采用 8 路组相联，即每组有 8 行，所以 Cache 总组数 = 2^13 / 8 = 1024，那么组索引的位数 s = log2(1024) = 10

主存块大小为 16B，按字节编址，所以块内地址位数 b = log2(16) = 4

那么标记 Tag 位的位数 t = 主存地址位数 - (s + b) = 28 - (10 + 4) = 14，那么主存地址的高 14 位就是标记 Tag 位


字节地址为 1234567H 的二进制位是 0001 0010 0011 01000101 0110 0111（注意，主存地址位数是 26 位），红色划线部分就是 Tag，对应十六机制是 048DH，本题选 C

对于 n - 路组相联映射 Cache，在保持 n 及主存和 Cache 总容量不变的前提下，将主存块大小和 Cache 块大小都增加一倍，则下列描述中正确的是 ( )。

A.字块内地址的位数增加 1 位，主存 tag 字段的位数增加 1 位
B.字块内地址的位数增加 1 位，主存 tag 字段的位数不变
C.字块内地址的位数减少 1 位，主存 tag 字段的位数增加 1 位
D.字块内地址的位数增加 1 倍，主存 tag 字段的位数减少一半

组相联映射的主存地址结构为：tag 标记 + Cache 组索引 + 字块内地址


假设原来的主存块大小和 Cache 块大小都是 a，那么块内地址的位数 = log2(a)，现在主存块大小和 Cache 块大小都增加一倍，也就是 2a，那么块内地址的位数 = log2(2a) = log2(2) + log2(a) = 1 + log2(a)，所以字块内地址的位数增加 1 位


因为 Cache 总容量不变，但是块大小增加一倍，那么 Cache 总行数必定减少一倍，因为每组还是 n 行不变，那么 Cache 组数必定减少一倍，假设之前 Cache 组数是 b，那么现在组数就是 b/2，这样组索引的位数 = log2(b/2) = log2(b) - log2(2) = log2(b) - 1，即组索引的位数减少了 1 位


因为主存的容量不变，所以主存地址的位数也是不变的，假设主存地址位数为 m


那么，当主存块大小和 Cache 块大小都增加一倍后，标记 Tag 位的位数 = m - (块内地址位数 + 组索引位数) = m - (1 + log2(a) +  log2(b) - 1) = m - (log2(a) + log2(b))，即标记位的位数不变


因此，字块内地址的位数增加 1 位，但是标记位的位数不变，本题选 B

【2009 第 14 题】某计算机的 Cache 共有 16 块，采用 2 路组相联映射方式 (即每组 2 块)。每个主存块大小为 32B，按字节编址。主存 129 号单元所在主存块应装入到的 Cache 组号是（ ）

A.0
B.1
C.4
D.6

首先搞清楚几个概念：题目规定的是按字节编址，那么一个存储单元就是一个字节，主存 129 号单元意思就是地址为 129 的字节；然后主存块大小是 32B，因此一个主存块包含 32 个单元

由于 Cache 共有 16 块，也就是有 16 个缓存行，采用 2 路组相联，也就是每组 2 块，因此共分为 16 / 2 = 8 组，组号为 0,1, 2, …，7


主存按字节编址，那么主存 129 号单元的地址就是 129 = 128 + 1 = 1000 0000B + 1B = 1000 0001B（一般题目都会给一个很好转换二进制的数字的）

因为采用的是 2 路组相联，因此地址被分成 3 个字段，如下图：


主存块大小是 32B，所以块内地址位数 b = 5 (2^5 = 32)，因此地址 1000 0001 的低 5 位 0 0001 即 1 是块内地址

因为有 8 组，因此 Cache 组号位数 c = 3（2^3 = 8），因此地址 1000 0001 中低 5 位前面的 3 位 100 是 Cache 组号，即 4，因此选 C

剩下的标记位数 t 是多少，不用管，因为这个题目不需要计算，题目也没有告诉你地址位数 m 是多少，所以，你也无法计算标记到底多少位



另解，对于一个地址，除了低位的块内地址，剩下的就是主存块号，所以这一题，我们也可以先求出 129 号单元所在的主存块，即 129 / 32 = 4，即 129 号单元位于 4 号主存块（注意，主存块号是从 0 开始的），因为 Cache 组号是在主存块号的低 3 位，所以直接将主存块号与组数取模就可以得到 Cache 组号，即 4 % 8 = 4，所以 4 号主存块映射到 Cache 的 4 号组，选 C


比如 15 的二进制是 0000 1111，要取低 3 位的话，直接将 15 % (2^3) = 7，对应 1111 的低三位 111B = 7

对于 Cache 中的比较器的个数，取决于一个组内的 Cache 行数量
  • 如果是直接映射方式的话，相当于一个 Cache 行就是一个组，也就是说，一个组内只有一个 Cache 行，所以只需要 1 个比较器就可以
  • 如果是组相连映射的话，每组多少个 Cache 行，就有多少个比较器
  • 如果是全相连映射的话，相当于只有一个组，那么有多少 Cache 行，就有多少比较器

比较器比较的是主存地址中的标记和 Cache 行的标记，要求 Cache 中比较器的位数，其实就是要求标记 tag 的位数，在组相联映射中，主存地址被划分成以下 3 个字段：
因为主存块大小是 64B，按字节编址，因此块内地址位数 b = 6（因为 2^6 = 64）

因为 Cache 数据区容量为 32KB，一个 Cache 行数据区容量等于主存块大小，也就是 64B，所以 Cache 的总行数是 32KB / 64B = 512 行，Cache 采用 8 路组相联，就是说每组内有 8 行，所以 Cache 总共有 512 / 8 = 2^9/2^3 = 2^6，因此 Cache 组号位数 c = 6

最后，求出标记 tag 的位数 t = m - b - c = 32 - 6 - 6 = 20 位，所以比较器的位数就是 20 位，所以选 A
