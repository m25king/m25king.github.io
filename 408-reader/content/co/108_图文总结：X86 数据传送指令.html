push 和 pop

我们知道当程序执行时，都会有对应的栈内存，而栈内存则是由一个一个栈帧组成，在 X86-64 指令系统中，栈内存也是由高地址往低地址增长的，栈顶元素的地址则存放在 rsp 寄存器（栈指针寄存器）中
指令 push S 就是将寄存器 S 中的一个四字数据压入栈内存中，指令 pop D 就是弹出栈顶的四字数据，传送到寄存器 D 中，看下图：

执行 push rax 时，会做这两件事：
  • 首先将栈指针寄存器（rsp）的值减去 8，所以 rsp 寄存器的值从之前的 0x108 变为 0x100
  • 然后将寄存器 rax 中的四字（8 字节）的数据（即 0x123）复制到栈顶元素中
接下来执行 pop rdx 时，会做这两件事：
  • 首先将将栈顶的四字（8 字节）的元素（即 0x123）复制到 rdx 寄存器中，所以 rdx 中的值就是 0x123
  • 然后将栈指针寄存器（rsp）的值加上 8，此时 rsp 寄存器中的值从之前 0x100 变为 0x108
push 和 pop 这两个指令也称为堆栈操作指令，它们只有一个地址码，就是寄存器名称，根据寄存器名称可以定位对应的寄存器，从而拿到寄存器中的操作数，这是寄存器寻址，堆栈操作指令还有隐含寻址，它们的另一个操作数隐含为栈顶元素，指令中无须明显指出操作数地址，有的时候我们也称为堆栈寻址

mov 指令

指令 mov D, S 作用是把数据从源位置 S 复制到目的位置 D，看下图：

上图中的第二条指令 mov rbp rsp 的源位置和目的位置都是寄存器，将寄存器 rsp 中的值复制到寄存器 rbp 中，即在寄存器之间复制数据
接下来的四条指令都是将立即数复制到主存中，比如第三条指令 mov BYTE PTR [rbp-25], 102，就是将一个字节的数据 102 复制到主存地址为 R[rbp] - 25 的存储单元，其中寄存器 rbp 中存储了当前栈帧的第一个存储单元的内存地址，BYTE PTR 表示这条 mov 指令复制的是一个字节数据（因为变量 d 是 char 类型，占 1 字节），这条指令的第一个操作数就是基址寻址（rbp 是基址寄存器，-25 是内存偏移量）
第四条指令 mov WORD PTR [rbp-2], 10，WORD PTR 表示传送的是一个字的数据，因为变量 b 是 short 类型，占 2 个字节，用 1 个字表示，这条 mov 指令将 10 传送到内存地址为 R[rbp] - 2 的存储单元中
第五条指令 mov DWORD PTR [rbp-8], 1000，DWORD PTR 表示传送的是双字的数据，因为变量 a 是 int 类型，占 4 个字节，用双字表示，这条 mov 指令将 1000 传送到内存地址为 R[rbp] - 8 的存储单元中
第六条指令 mov QWORD PTR [rbp-16], 3000000，QWORD PTR 表示传送的是四字的数据，因为变量 c 是 long 类型，占 8 个字节，用四字表示，这条 mov 指令将 3000000 传送到内存地址为 R[rbp] - 16 的存储单元中
接下来第八条指令 mov QWORD PTR [rbp-24], rax，将寄存器 rax 的一个四字数据复制到主存地址为 R[rbp] - 24 的主存位置，这个是将寄存器数据复制到主存；再看第九条指令 mov eax, 0 将立即数 0 复制到 eax 寄存器中，这个是将立即数复制到寄存器
可以看到，根据源地址和目的地址的类型不同组合，mov 指令可以产生五种组合：
  1. 寄存器 → 寄存器：mov rbp rsp
  2. 立即数 → 寄存器：mov eax, 0
  3. 立即数 → 主存：mov BYTE PTR [rbp-25], 102
  4. 寄存器 → 主存：mov QWORD PTR [rbp-24], rax
  5. 实际上还有一个是主存 → 寄存器：mov rax, WORD PTR [rbp - 12]
x86-64 加了一条限制，传送指令 mov 的两个地址码，不能都指向内存位置，将一个值从一个内存位置复制到另一个内存位置需要两条指令，第一条指令将源数据加载到寄存器，第二条将该寄存器值写入目的位置

我们知道指针本质上就是内存地址，上图 int 类型的指针 xp 本质上就是一个 64 位（8 字节，四字）的内存地址，所以指针 xp 存储在 64 位的 rdi 寄存器中，而 int 类型的 y 占 4 字节（双字），所以存储在 32 位的 esi 寄存器中
第一条指令 mov eax, DWORD PTR [rdi] 将 rdi 中的内存地址所对应的内存中的双字复制到 eax 中，其实就是将指针 xp 指向的内存单元中的 int 类型值复制到变量 x 中，然后第二条指令 mov DWORD PTR [rdi], esi,   将 esi 中的值 y 复制到 rdi 中的内存地址所对应的内存单元中，也就是将 y 的值复制到指针 xp 指向的内存单元，最后返回，结果 x 放在 eax 寄存器中
这里的两个 mov 指令中的地址码 [rdi] 表示这个操作数位于寄存器中的内存地址对应的内存单元中，这种寻址方式称为寄存器间接寻址，即地址码是一个寄存器编号，该寄存器中存放的是操作数的有效地址
从上面可以看到，就单单一个 mov 指令，其操作数就支持很多种的寻址方式，可以是立即数寻址、寄存器直接寻址、寄存器间接寻址、基址寻址，所以说对于 x86 这种复杂指令集支持的寻址方式也是特别的多，每条指令也比较复杂，这也是复杂指令集的一个特点

lea 指令

lea 是 load effective address 的缩写，用于加载有效内存地址指令，指令 lea D, S 将有效内存地址 S 复制到目的位置 D，看下图：

上面的指令 lea rax, [rbp - 25] 就是将变量 d 的内存地址 R[rbp] - 25（使用 &d 得到的）复制到 rax 寄存器，就相当于 rax 中的数据表示指针 p，再次说明，C 指针本质上就是内存地址
再来看一个 C 函数（作用是交换数组 v 的两个元素 v[k] 和 v[k + 1] 的值），数组 v 的首地址存放在寄存器 rdi 中（在 X86-64 系统中，内存地址是 64 位的），参数 k 因为是 int 类型（32 位），所以暂存在 32 位 esi 寄存器：

第 ① 条指令 movsx rsi, esi 将 32 位 esi 寄存器中的 k 符号扩展到 64 位，结果放在 rsi 寄存器中，之所以要将变量 k 进行符号扩展，是因为接下来要用它和 64 位的数组基地址 v 来运算，计算下标 k 对应元素的内存地址
第 ② 条指令 lea rdx, [rdi + rsi * 4]，首先计算 v[k] 的内存地址 = 数组 v 的首地址 + k * 4 = rdi + rsi * 4，然后将 v[k] 的内存地址放到 rdx；第 ③ 条指令 mov ecx, DWORD PTR [rdx] 去主存中加载 rdx 中的内存地址的数据到 ecx 寄存器中，因为数组元素类型是 int，所以 mov 传送的是一个字的数据，所以放在 32 位的 ecx 寄存器中，那么变量 temp 对应着 ecx 寄存器
第 ④ 条指令通过 lea 指令将 v[k + 1] 的内存地址放到 rax 中，然后第 ⑤ 条指令将内存中的 v[k + 1] 复制到 esi 寄存器中；第 ⑥ 条指令将 esi 中的 v[k + 1] 的值复制到内存地址为 R[rdx]（其实就是 v[k] 的内存地址）的主存位置，第 ⑦ 条指令将 exc 中的 temp（即 v[k] 的值）复制到内存地址为 R[rax]（其实就是 v[k + 1] 的内存地址）的主存位置，这样就完成了 v[k] 和 v[k + 1] 的交换了
