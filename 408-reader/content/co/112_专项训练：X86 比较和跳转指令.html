下列有关标志寄存器的叙述中，错误的是(   )。

A.可用标志寄存器存放执行指令得到的各种标志信息
B.可通过指令直接访问标志寄存器并修改其值
C.条件转移指令根据标志寄存器中的标志位确定PC的值
D.不需像通用寄存器那样对标志寄存器进行编号
标志寄存器（程序状态字寄存器 PSW）的核心功能就是存储指令执行后产生的各种标志位，比如进位 / 借位标志 CF、零标志 ZF、溢出标志 OF 等，A 正确

标志寄存器的标志位不能通过指令直接访问和修改，而是由 CPU 在执行算术 / 逻辑运算等指令时，根据运算结果自动设置的。虽然部分指令（如 CLC、STC）可以修改个别标志位，但不存在直接读写整个标志寄存器的通用指令，因此 B 错误，本题选 B

条件转移指令（如 jg、jle）正是通过读取标志寄存器中的对应标志位，来判断是否满足转移条件，从而修改程序计数器 PC 的值，实现程序分支，C 正确

通用寄存器需要编号（如 R0~R7、EAX~EDX）来供指令寻址，而标志寄存器是 CPU 内部的专用寄存器，不需要编号，D 正确

假设 R[ax]=FFE8H，R[bx]=7FE6H，执行指令 "add ax,bx" 后，寄存器的内容和各标志的变化为 ( )。

A.R[ax]=7FCEH, OF=1, SF=0, CF=0, ZF=0
B.R[bx]=7FCEH, OF=1, SF=0, CF=0, ZF=0
C.R[ax]=7FCEH, OF=0, SF=0, CF=1, ZF=0
D.R[bx]=7FCEH, OF=0, SF=0, CF=1, ZF=0
指令 add ax,bx 的作用是 R[ax] + R[bx] → ax，这里是补码相加，R[ax] + R[bx] = FFE8H + 7FE6H = (1)7FCDH，最高位有进位，所以 Cout = 1，R[ax] = 7FCDH（丢弃最高位的进位）

因为 R[ax]=FFE8H 是负数，而 R[bx]=7FE6H 是正数，负数 + 正数不可能溢出，所以 OF = 0，R[ax] + R[bx] 的结果是 7FCDH 不等于 0，所以 ZF = 0，结果是正数，所以 SF = 0

因为做加法，所以 Cin = 0，因此进位/借位标志 CF = Cin ^ Cout = 0 ^ 1 = 1

因此，R[ax] = 7FCDH，OF = 0、ZF = 0、SF = 0、CF = 1，本题选 C

注意：无论是无符号数还是有符号数，都以二进制代码形式无差别地存放在计算机内。即便两个有符号数相加，也会导致 CF 的变动，只是 CF 值对有符号数运算是没有意义的。同理，两个无符号数相加，也会导致 OF 和 SF 的变动，只是 OF 值和 SF 值仅对有符号数运算有意义

很明显，机器数 FFE8H - 机器数 7FE6H 是够减的，不需要借位，因此 CF = 0

因此，R[bx] = 8002H，OF = 0、ZF = 0、SF = 1、CF = 0，本题选 B

  2. OF = Cout ^ Cn-1 （Cn-1 是次高位进位）
