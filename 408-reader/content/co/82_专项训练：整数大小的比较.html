CPU 中执行算术运算（加减乘除等）和逻辑运算（与、或、非、异或等）的最基本部件是 ALU（算术逻辑单元，Arithmetic Logic Unit），本题选 D

ALU 是运算器的核心，专门负责完成各类算术与逻辑操作。多路选择器、移位器、加法器都是 ALU 内部或运算流程中的组成单元，但不能独立完成完整的算术和逻辑运算

A 多路选择器：用于数据通路的选择，不参与运算本身
B 移位器：仅负责二进制位的移位操作，是 ALU 的子功能模块，不是完整运算部件
C 加法器：仅能完成加法运算，无法实现逻辑运算或其他复杂算术运算

⑤ 无符号整数一般用来表示什么信息？

①  无符号数 x = 68 = 64 + 4 = 2^6 + 2^2 = 0100 0100H = 44H，y = 80 = 64 + 16 = 2^6 + 2^4 = 0101 0000H = 50H

所以，寄存器 A 和寄存器 B 中的内容分别是 44H 和 50H


② x + y = 44H + 50H = 94H，那么寄存器 C 中的内容就是 94H，结果在 8 位无符号编码表示范围（00H ~ FFH）内，因此没有溢出，CF = 0，所以结果是正确的

因为结果不是 0，所以 ZF = 0，同时因为做加法，所以加法器的 Cin = 0，而 CF = Cin ^ Cout = 0，所以 Cout = 0

③ x - y = 44H - 50H = F4H，所以寄存器 D 中的内容是 F4H，因为无符号数 F4H 大于减数 44H，因此运算结果是错误的

很明显 x - y 不够减（x 的值小于 y 的值），需要借位，那么 CF = 1，因为做减法，所以加法器的 Cin = 1，而 CF = Cin ^ Cout = 1，那么 Cout = 0

因为结果不是 0，所以 ZF = 0

④ 在加法器进行加法时，如果 Cout = 1 的话，说明两个无符号数相加最高位有进位，从而使得两数相加结果发生溢出

在加法器中进行无符号整数减法运算时，若加法器最高位进位 Cout = 1，则表示被减数大于减数（即够减），反之被减数小于减数（即不够减）


假设两个 n 位无符号数 A 和 B，A 减去 B 实际上等于 A 加上对 B 求反再加 1：A - B = A + (~B + 1) = A + (2^n - B)

  • 当 A ≥ B：A + (2^n - B) = 2^n + (A - B)，式子自带 2^n，一定会产生向外进位，即 Cout=1，剩下低 n 位就是正确差值  A‑B

  • 当 A < B：A + (2^n - B) = 2^n - (B - A)，肯定是小于 2^n，因此不会产生进位，即 Cout=0，此时必须向高位借位


因此，在无符号数相加时，此时 Cin = 0，那么 CF = Cout；在无符号减法时，此时 Cin = 1，那么 CF = ~Cout


就是说不管是做加法还是做减法，CF = Cin ^ Cout

记住两个公式：
  1. CF = Cout ^ Cin（Cout 是最高位进位，而 Cin 是最低位的初始进位，如果做加法，那么 Cin = 0，如果做减法，Cin = 1）
  2. OF = Cout ^ Cn-1 （Cn-1 是次高位进位）

在上面加法器中，输入 X 是 R1 寄存器中的二进制（即 FFFF FFFFH），输入 Y 是 R2 寄存器中的二进制（即 FFFF FFF0H）


加法器计算时，将减法会转化成加法，X - Y = X + (-Y 的补码)，而 -Y 的补码等于对 Y 取反加 1，所以 Cin = 1，然后对 Y 进行取反得到 0000 000FH 送入到加法器和 X 做加法


即计算：FFFF FFFFH + 0000 000FH + 1 = FFFF FFFFH + 0000 0010H = 0000 000FH，最高位进位 Cout = 1，次高位进位 Cn-1 = 1


所以 CF = Cout ^ Cin = 1 ^ 1 = 0，OF = Cout ^ Cn-1 = 1 ^ 1 = 0，因此选 A
