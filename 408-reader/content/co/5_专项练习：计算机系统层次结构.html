以下是有关计算机中指令和数据存放位置的叙述，其中正确的是(   )。

B.指令和数据任何时候都存放在内存

A 错误：指令和数据在程序运行时都存放在内存中，外存（如硬盘、U 盘）用于长期存储，不直接参与 CPU 执行


B 错误：程序未启动时，指令和数据存放在外存；启动后才被加载到内存，并非 “任何时候都在内存”


C 错误：CPU 执行时必须访问内存中的指令和数据，外存速度太慢，无法直接参与运行


D 正确：程序启动（运行）时，操作系统会将其指令和数据从外存加载到内存，供 CPU 读取执行，本题选 D

本题从另一个角度来给计算机系统进行分层

计算机是一个硬软件组成的综合体。因为面对的应用范围越来越广，所以必须有复杂的系统软件和硬件的支持

由于软/硬件的设计者和使用者从不同的角度、用不同的语言来对待同一个计算机系统，因此他们看到的计算机系统的属性对计算机系统提出的要求也就各不相同

计算机系统的多级层次结构的作用，就是针对上述情况，根据从各种角度所看到的机器之间的有机联系，来分清彼此之间的界面，明确各自的功能，以便构成合理、高效的计算机系统


关于计算机系统层次结构的分层方式，目前尚无统一的标准，这里采用如下图所示的层次结构：



第 1 级是微程序机器层，这是一个实在的硬件层，它由机器硬件直接执行微指令

第 2 级是传统机器语言层，它也是一个实际的机器层，由微程序解释机器指令系统

第 3 级是操作系统层，它由操作系统程序实现。操作系统程序是由机器指令和广义指令组成的，这些广义指令是为了扩展机器功能而设置的，是由操作系统定义和解释的软件指令，所以这一层也称混合层

第 4 级是汇编语言层，这一层由汇编程序支持和执行，借此可编写汇编语言源程序

第 5 级是高级语言层，它是面向用户的，是为方便用户编写应用程序而设置的，该层由各种高级语言编译程序支持和执行


因此，本题选 C


在高级语言层之上，还可以有应用程序层，它由解决实际问题的处理程序组成，如文字处理软件、多媒体处理软件和办公自动化软件等

没有配备软件的纯硬件系统称裸机。第 3 层～第 5 层称为虚拟机，简单来说就是软件实现的机器


虚拟机器只对该层的观察者存在，这里的分层和计算机网络的分层类似，对于某层的观察者来说，只能通过该层的语言来了解和使用计算机，而不必关心下层是如何工作的，层次之间的关系紧密，下层是上层的基础，上层是下层的扩展


以下有关程序编写和执行方面的叙述中，错误的是(   )。

A.可用高级语言和低级语言编写出功能等价的程序
B.高级语言和汇编语言源程序都不能在机器上直接执行
C.编译程序员必须了解机器结构和指令系统
D.汇编语言是一种与机器结构无关的编程语言
高级语言（如 C、Java）和低级语言（汇编、机器语言）都能实现等价功能，只是开发效率、可读性、执行效率不同，因此 A 描述正确

机器语言（二进制指令）可直接被 CPU 执行；高级语言和汇编语言必须先编译 / 汇编成机器语言，才能在机器上运行，因此 B 描述正确

对于 C，编译程序员是开发或者维护编译器的程序员，因为编译器是系统软件，所以编译程序员属于系统程序员，而编译器的作用是把高级语言代码（C/C++、Java、Go 等）翻译成机器能直接执行的机器语言（二进制指令）

每种 CPU（x86、ARM、RISC-V 等）都有专属的指令集、寄存器、寻址方式、指令格式，因此，编译程序员必须了解指令系统

编译程序员必须了解机器结构：
  • CPU 流水线、超标量、乱序执行机制；
  • 缓存层次（L1/L2/L3）、内存访问延迟；
  • 指令的执行周期、依赖关系

如果编译程序员不懂这些，就不能将高级语言程序翻译成性能很好的机器语言程序了


所以，选项 C 编译程序员必须了解机器结构和指令系统描述正确

汇编语言是面向机器的低级语言，汇编语言与机器指令一一对应，与机器结构紧密相关，不同 CPU（如 x86、ARM）的汇编指令集不通用，并非与机器结构无关，因此选项 D 描述错误，本题选 D

关于编译程序和解释程序，下列说法中错误的是 ( )。

A.编译程序和解释程序的作用都是将高级语言程序转换成机器语言程序
B.编译程序编译时间较长，运行速度较快
C.解释程序方法较简单，运行速度也较快
D.解释程序将源程序翻译成机器语言，并且翻译一条以后，立即执行这条语句
A 正确：编译程序和解释程序的核心作用都是将高级语言源程序转换为机器可执行的指令（编译生成目标程序，解释逐行执行）

B 正确：编译程序需先完成全程序的翻译（耗时），生成的目标程序可直接执行，运行速度快；解释程序逐行翻译，无需预编译，启动快但运行效率低（因为每次执行一行代码，都需要先解释成机器指令，然后再执行）

C 错误：解释程序方法简单，但运行速度较慢（每次执行都要重新翻译），并非 “运行速度也较快”，因此，本题选 C

D 正确：解释程序的工作方式是逐行翻译、立即执行，翻译一条执行一条，不生成独立的目标文件

最后，来比较下编译器和解释器：


编译执行的优点是执行速度快，因为程序一次性编译成机器指令，机器只要不断地执行机器指令就可以，但是解释执行就不一样，它需要边解释边执行，执行速度慢

编译执行的缺点是开发周期比较长，每次开发完都有编译，等你以后工作了，你会发现，如果编译一个大的项目，需要很长的时间

而解释执行开发周期就短了，代码写完了就可以运行，就可以看看有没有 bug，相对来说开发效率高点

在主流的编程语言中，C、C++、Go 语言等都是编译执行的，而 Python、JavaScript 语言等都是解释执行的，也有两种执行方式都有的，比如 Java，就包括了编译执行和解释执行两种方式

I 机器语言：由二进制指令（0/1）组成，可被 CPU 直接识别和执行，无需翻译

II 汇编语言：用助记符（如 MOV、ADD、SUB）代替二进制指令，是机器语言的符号化表示，需经汇编器翻译成机器语言才能执行

III 高级语言（如 C、Java）：接近自然语言，需编译 / 解释为机器语言才能执行，不是助记符编写

IV 操作系统原语：是操作系统提供的底层操作，不是独立编程语言

V 正则语言：用于字符串匹配，不是计算机可直接执行的指令语言

所以，可以在计算机中直接执行的语言是机器语言，用助记符编写的语言是汇编语言，本题选 C

ISA 定义了一台计算机可以执行的所有指令的集合，每条指令规定了计算机执行什么操作，所处理的操作数所存放的位置以及操作数的类型等

ISA 规定的内容包括指令格式、指令操作类型，指令的操作数类型、寻址方式和可访问地址空间大小，程序可访问的寄存器个数、位数和编号，控制寄存器的定义，I/O 空间的编址方式，中断结构，机器工作状态的定义和切换，输入/输出结构和数据传送方式，存储保护方式等

A 正确：指令的操作码与寻址方式是 ISA 的核心内容，定义了 CPU 能执行的操作和数据访问方式


B 正确：通用寄存器的数量与编号是 ISA 定义的，是程序员可见的硬件资源


C 错误：ALU 的具体电路实现方式属于微体系结构（硬件实现细节），不在 ISA 的定义范畴内，本题选 C


D 正确：存储器的寻址空间与数据格式是 ISA 的重要组成部分，决定了程序如何访问内存

关于微体系结构的叙述，错误的是（ ）

A. 微体系结构是 ISA 的硬件实现方案
B. 流水线、超标量等技术属于微体系结构范畴
C. 微体系结构的设计不影响程序的执行效率
D. 不同厂商可基于同一 ISA 设计不同微体系结构的 CPU
A 正确：微体系结构是 ISA（指令集体系结构）的硬件实现方案，决定 CPU 如何执行指令

B 正确：流水线、超标量、缓存、乱序执行等都属于微体系结构的设计范畴

C 错误：微体系结构的设计直接影响程序的执行效率（如流水线级数、缓存大小、指令并行度等都会显著改变运行速度），因此，本题选 C


D 正确：同一 ISA（如 x86、ARMv8）可由不同厂商设计出不同微体系结构的 CPU，保证软件兼容

下列关于 ISA 与微体系结构关系的说法，正确的是（ ）

A. ISA 与微体系结构一一对应，不可分离
B. 微体系结构的改变会导致 ISA 的重新定义
C. ISA 是软件与硬件的接口，微体系结构是硬件内部实现
D. 程序员编写程序时需同时关注 ISA 与微体系结构
A 错误：ISA 与微体系结构并非一一对应，同一 ISA 可对应多种微体系结构（如 x86 架构有不同代的 CPU 实现）

B 错误：微体系结构的改变不会导致 ISA 的重新定义，微体系结构是 ISA 的硬件实现，修改实现方式不改变接口规范

相反，如果 ISA 改变的话，那么微体系结构必然改变，如果 ISA 变了（比如新增指令、改了寄存器数量、换了寻址方式），原有的微体系结构就无法正确实现新的 ISA 规范，必须重新设计微体系结构来适配新 ISA

C 正确：ISA 是软件与硬件的接口（程序员可见），微体系结构是硬件内部实现（程序员不可见）

D 错误：程序员编写程序时只需关注 ISA，无需关心微体系结构的具体实现，因此，本题选 D

总结下，ISA 和微体系结构的核心区别是：
  • ISA 是定规则/能力（软件可见），回答 "计算机能做什么？" 的问题
  • 微体系结构定实现/方案（软件不可见），回答 "计算机怎么做？" 的问题

ISA 定义指令格式 / 寻址方式、寄存器规格、存储器编址 / 数据格式；微结构体系则包含流水线执行阶段、缓存设计、乱序执行技术等硬件实现细节

同一 ISA 可对应多种微体系结构实现，微体系结构是 ISA 的硬件实现方案，对程序员是不可见的，ISA 是软/硬件的接口，对程序员是可见的

下列属于微体系结构设计内容的是（）


I：规定寄存器的功能与访问方式

II：设计指令的流水线执行阶段

III：选用 CMOS 工艺制作 CPU 的物理晶圆

IV：定义指令的操作类型与格式

V：设计 ALU 部件

A.I、II、III
B.II、V
C.III、V
D.II、III、V

I 错误：规定寄存器的功能与访问方式属于ISA（指令集体系结构），是程序员可见的接口定义，不是微体系结构设计内容


II 正确：设计指令的流水线执行阶段（取指、译码、执行、访存、写回）是微体系结构的核心设计内容，决定指令的执行效率


III 错误：选用 CMOS 工艺制作 CPU 的物理晶圆属于集成电路制造 / 物理实现，不属于微体系结构设计范畴


IV 错误：定义指令的操作类型与格式属于ISA，是指令集的规范定义，不是微体系结构


V 正确：设计 ALU 部件（算术逻辑单元）的结构、功能、实现方式是微体系结构的重要组成部分


因此，本题 II 和 V 属于微体系结构的内容，本题选 B

II：汇编语言程序
III：硬件描述语言程序

计算机硬件能直接执行的只有机器语言程序，机器语言程序的每一条机器指令是采用二进制编码

【2022 第 20 题】将高级语言源程序转换为可执行目标文件的主要过程是 ( )。

A.预处理→编译→汇编→链接
B.预处理→汇编→编译→链接
C.预处理→编译→链接→汇编
D.预处理→汇编→链接→编译
以下是将高级语言程序转换为可执行目标文件的四个过程

预处理阶段：这个阶段根据字符 # 开头的命令，修改原始的 C 程序，比如 hello.c 第一行是 #include<stdio.h> 命令，那么读取系统头文件 stdio.h 的内容，并把它直接插入程序文本中，结果就得到了另一个 C 程序

编译阶段：这个阶段将 hello.i 中的程序翻译成对应的汇编语言程序

汇编阶段：这个阶段将 hello.s 中的汇编程序翻译成对应的机器语言程序

链接阶段：这部分是由链接程序来实现，将多个目标文件和库文件组合成一个可执行文件


这里很容易将编译和汇编这两个阶段的顺序弄反了，我们要知道的是汇编程序是离机器语言最近的，汇编程序中的每一条汇编指令是和机器指令一一对应的，如果得到了汇编程序，就可以直接将每条汇编指令翻译成对应的机器指令，因此再高级程序翻译成机器语言时，一般先将其编译成汇编程序，然后再将汇编程序汇编成机器语言程序

【2016 第 12 题】将高级语言源程序转换为机器级目标代码文件的程序是（ ）

A.汇编程序
B.链接程序
C.编译程序
D.解释程序
将高级语言源程序转换为机器级程序只有两种方式，一个是通过编译程序转换，一个是通过解释程序转换


编译程序，它将高级语言源程序一次全部翻译成机器级目标代码，并放在一个可执行文件中，每次执行程序时，只要执行可执行文件，因此，只要源程序不变，就无须重新编译

解释程序，它将高级语言中源程序的一条语句翻译成对应的机器指令，并立即执行，然后翻译下一条源程序语句并执行，直至所有源程序语句全部被翻译并执行完。所以解释程序的执行过程是翻译一句执行一句，不会生成可执行的机器级目标代码文件


如果你不理解编译程序和解释程序的区别，请复习视频：程序的编译执行过程，从 11 分 10 秒开始

汇编程序也是一种语言翻译程序，它把汇编语言源程序翻译为机器语言程序。汇编语言是一种面向机器的低级语言，是机器语言的符号表示，与机器语言一一对应

链接程序并不是翻译程序，它的作用是将多个目标文件和库文件组合成一个可执行文件，这个概念属于操作系统，目前你可能还不理解，没关系，我们将在操作系统课程中详细讲解
