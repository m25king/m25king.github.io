前面学习的无符号编码只能表示非负整数，而很多应用还是希望能表示负数，能表示负数的编码有补码、原码、反码和移码
不过最常见的有符号数编码就是补码，我们先来介绍补码

补码编码

假设机器字长是 n，看下图：

你看无符号编码中，所有的位都是取正权的，而补码编码将二进制串的最高有效位位取负权，其他的位还是取正权，最高有效位 xn-1 也称为符号位，它的 "权重" 为 -2n-1，是无符号编码中权重（2n-1）的负数
符号位被设置为 1 时，表示值为负整数，而当符号位为 0 时，值为非负数，这样，就是用补码编码来表示了有符号整数
一个 n 位的补码，当其最高有效位是 1，其他位都是 0 的时候，就是它能表示的最小值，其整数值就是 -2n-1；当其最高有效位是 0，其他位都是 1 的时候，就是它能表示的最大值，其整数值就是 2n-1 - 1
比如长度为 8 的补码，能表示的有符号整数范围是 -27 ~ 27 - 1（即 -128 ~ 127）
补码编码也是唯一的，即：一个长度为 n 的补码编码（即长度为 n 的二进制串）都可以表示为 -2n-1 ~  2n-1 - 1 之间的一个唯一的整数，反过来，在  -2n-1 ~  2n-1 - 1 之间的每一个整数都可以编码为一个唯一的长度为 n 的补码编码

从上表可以得出以下 2 个结论：
① 同一个二进制串，如果采用无符号编码，就可以将其解释成无符号数，如果采用补码编码的话，就可以将其解释成有符号数，即一个相同的二进制串具体要表示什么数值，取决于对这个二进制串的编码方式
② 如果二进制串最高位是 0 的话，那么有符号数和无符号数是相同的（比如上面的 0000 ~ 0111）；当最高位为 1 的时候，补码编码则表示负数。所以补码的范围是不对称的（最小值的绝对值 = 最大值的绝对值 + 1），因为 0 是非负数，也就意味着能表示的正数数比负数少 1 个
③ 一个负数的补码等于这个负数的绝对值对应无符号编码进行取反再加 1，比如 -3 的绝对值是 3，其对应的无符号编码是 0011，将其取反得到 1100，然后再加 1，得到 -3 的补码 1101；再比如 -8 的绝对值是 8，其对应的无符号编码是 1000，将其取反得到 0111，然后再加 1，得到 -8 的补码 1000
使用补码编码的一个最大作用就是：使得计算机系统，可以将复杂的减法转换为加法
假设现在计算机要求 2 - 6，可以将 2 的补码 0010，加上 -6 的补码 1010，得到 1100，而这个补码表示 -4，就是说 2 - 6 = -4
这里如果不理解的话，可以看视频【什么是补码以及为什么需要补码？】，其实不理解的话，不去看视频也可以，不用理解，记住结论即可：补码的符号可以参与运算，从而使得复杂的减法转换为加法
结论：
  • 当你拿到一个 n 位补码时，可以通过上面补码的公式，计算得到这个补码表示的有符号整数
  • 当你拿到一个有符号数时，可以先得到这个有符号数的绝对值的无符号编码，然后将这个无符号编码取反加 1，就可以得到这个有符号数的补码

UMAXw 表示 w 位无符号数编码可以表示的最大无符号数，当然是全 1 的时候，表示的无符号数最大，比如 16 位字长的话，最大无符号数是 0xFFFF

-1 的补码编码是全 1，假设 8 位字长，-1 的绝对值对应的无符号数编码是 0000 0001，对齐取反得到 1111 1110，再加 1，就得到 -1 的 8 位补码 1111 1111（十六进制 0xFF）
而对于 0，不管是无符号数编码还是补码编码，其编码都是全 0

根据这个公式，可以得出，n 位原码编码能表示的最小值，它的符号位为 1，剩下 n - 1 位的数值位也全是 1，也就是负的最大值，就是最小值了，等于 -(2n-1 - 1)，最大值是符号位是 0，数值位全为 1，也就是正的最大值，就是最大值了，等于 2n-1 - 1
所以 n 位原码编码可以表示有符号整数的范围是 -(2n-1 - 1) ~ 2n-1 - 1
原码有两个缺陷：
  • 在原码中，0 的表示不唯一，符号位是 1，数值位是 0，表示负 0，符号位是 0 数值位是 0，表示 +0，这样的话，浪费一个编码，而且给使用带来不便
  • 更重要的是，原码加减运算规则复杂

原码也有两个优点：
  • ① 和真值之间的转换很简单，其数值位就是真值的绝对值，比如原码编码 1011，它的真值就是 -011（即 -3），你看原码编码和真值的绝对值一样
  • ② 用原码实现乘除运算比较简便，这也是为什么浮点数编码中的尾数使用原码来表示的原因
机器数：通常将数值数据在计算机内部编码表示的数称为机器数，机器数中只有 0 和 1 两种符号
机器数真正的值（即原来带正负号的数），称为机器数的真值
比如，-10 （即 -1010B）用 8 位补码表示为：-10 的绝对值的无符号数编码 0000 1010，将其取反加 1，得到 -10 的补码 1111 0110，此时，我们说补码编码 1111 0110 是真值 -10 的机器数

总结

现代计算机中有符号整数一般都采用补码表示，这个是因为：
  • ① 与原码和反码相比，数 0 的补码表示形式唯一
  • ② 与原码相比，补码可以用加法实现减法运算，且符号位可以和数值位一起参加运算
  • ③ 与原码和反码相比，补码比原码和反码多表示一个最小负数，因为原码和反码都需要 2 个编码来分别表示 +0 和 -0
  • ④ 与反码相比，补码加法不需要通过循环进位来调整结果
如何理解上面的第 ④ 点呢？
反码加法：若最高位产生进位，需要将这个进位循环加到最低位（循环进位），否则结果错误
比如，使用反码计算 (-2) + (−5)，看下图：
首先最右边第一位的 1 + 0 = 1，然后第二位的 0 + 1 = 1，然后第三位的 1 + 0 = 1，最后第四位的 1 + 1 = 0，还需要进一位，如果不考虑最高位的进位的话，那么结果是 0111，这个是 7 的反码，结果是不对
对于反码相加，需要将最高为的进位循环加到最低位，即 0111 + 1 = 1000，这就是 -7 的反码，结果对了（这里的反码加法在计网课程中还会用到）
而补码加法：直接丢弃最高位的进位即可，无需额外调整，运算更高效、硬件实现更简洁

补码和原码的转换

给你一个有符号数，你可以这样得到它的 n 位补码：首先得到这个有符号数绝对值的 n 位无符号编码，然后对这个无符号编码取反加 1，就可以得到这个有符号数的补码
给你一个有符号数，你可以这样得到它的 n 位原码：首先得到这个有符号数绝对值的 n 位无符号编码，然后判断：
  • 如果有符号数是正数，那么将无符号编码最高位设置为 0 就是对应原码
  • 如果有符号数是负数，那么将无符号编码最高位设置为 1 就是对应原码
现在如果在原码和补码之间进行转换的话，方法是这样的：原码（补码）的符号位不变，数值位取反，再加 1，就可以得到对应的补码（原码）
