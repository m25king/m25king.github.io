我们利用这个题来分清楚向量中断、中断向量、中断向量表、向量地址、中断类型号这些概念

向量中断是指一种识别中断源的技术或方式。识别中断源的目的就是要找到中断源对应的中断服务程序的入口地址，即获得向量地址。采用向量中断进行中断源识别的做法是，采用某种硬件排队线路 (如菊花链、并行判优)，对所有未被屏蔽的中断请求进行排队，选出优先级最高的中断源，然后对其编码，得到该中断源的编号 (有些书中称其为向量地址)，通过总线将其取到 CPU 中，转换成向量地址，从而从中断向量表中取出中断服务程序人口地址，或直接跳转到中断服务程序。还有一种中断源识别方式是用程序 (称为中断查询程序) 进行识别的软件方法


中断向量：每个中断源都有对应的处理程序，称这个处理程序为中断服务程序，其入口地址称为中断向量


中断向量表：所有中断 (包括异常) 的中断服务程序入口地址构成一个表，这个表称为中断向量表。也有的机器把中断服务程序入口的跳转指令构成一个表，这个表称为中断向量跳转表


向量地址：中断向量表或中断向量跳转表中每个表项所在的地址称为向量地址，所以说中断向量地址是中断服务程序入口地址的地址，本题选 C


中断类型号：中断向量表或中断向量跳转表中每个表项所在的表项索引值称为中断类型号

软盘每次中断传输 16 位（即 2B），其数据传输率为 50kB/s，所以每秒中断次数 = 50kB/s / 2B = 25k

【2022 第 21 题】下列关于中断 I/O 方式的叙述中，不正确的是 ( )。

A.适用于键盘、针式打印机等字符型设备
B.外设和主机之间的数据传送通过软件完成
C.外设准备数据的时间应小于中断处理时间
D.外设为某进程准备数据时 CPU 可运行其他进程

对于键盘和鼠标，因为随机性很强，也就是数据随时都可能产生，也可能很长时间不产生，所以这一类外设，一般采用中断 I/O 方式，当鼠标和键盘产生数据时，给 CPU 发送一个中断信号，通知 CPU 来读取数据，这种 I/O 方式很高效


对于打印机，因为打印数据是一个非常低速的过程，也就是说打印机是一个低速 I/O 设备，当打印机打印数据时，CPU 可以同时执行很多的指令，因此为了让 CPU 和打印机并行工作，可以采用中断 I/O 方式，当打印机打印完了一个数据，就通知 CPU，将下一个需要打印的数据送到打印机接口，然后打印机打印数据的同时， CPU 就可以执行其他的指令，这样提高 CPU 的时间利用率


因此中断 I/O 方式适用于键盘、针式打印机等字符型设备，选项 A 描述正确


若采用中断 I/O 方式，当外设准备好数据后，向 CPU 发出中断请求，CPU 暂时中止正在运行的程序，转去运行中断服务程序，由中断服务程序完成数据的传送，这里外设和主机之间的数据传送通过软件（中断服务程序）完成，因此选项 B 描述正确


若外设准备数据的时间小于中断处理时间，则可能导致数据丢失，以输入设备为例，设备为程序 A 准备的数据会先写入设备控制器的数据缓冲寄存器，缓冲寄存器每写满一次，就会向 CPU 发出一次中断请求，CPU 响应并处理中断的过程，就是将数据缓冲寄存器中的数据 "取走" 的过程，若外设准备数据的时间小于中断处理时间，则可能导致外设往数据缓冲寄存器写入数据的速度快于 CPU 从数据缓冲寄存器取走数据的速度，从而导致数据缓冲寄存器的数据被覆盖，进而导致数据丢失，所以 C 错误，选 C


若采用中断 I/O 方式，当程序 A 需要读取磁盘的数据时，向磁盘发送读取数据的请求，然后磁盘会准备数据，这时这个程序 A 应该要被阻塞，也就是 CPU 不执行程序 A 了，因为你这个程序 A 要的数据还没到，这时 CPU 就可以去执行其他的程序，比如执行程序 B 了，当磁盘准备好了程序 A 需要的数据，会给 CPU 发送中断信号，通知 CPU 去读取磁盘中的数据，数据读完后，可以继续执行程序 A 了，因为它要的数据已经准备好了


因此当外设为某进程准备数据时，可令该进程阻塞，然后 CPU 运行其他进程，D 描述正确，这个选项设计到了操作系统中的进程调度相关的概念，在这里你只需要有个印象就行，我们将在操作系统详细讲解

【2021 第 22 题】下列是关于多重中断系统中 CPU 响应中断的叙述，其中错误的是 (  )。

A.仅在用户态 (执行用户程序) 下，CPU 才能检测和响应中断
B.CPU 只有在检测到中断请求信号后，才会进入中断响应周期

不管是执行操作系统程序（内核态下），还是执行用户程序（用户态下），CPU 都需要检测和响应中断，如果执行操作系统程序时，不能检测和响应中断的话，那么你的电脑就会很卡了，因为执行操作系统程序时，都不会响应你的键盘和鼠标发起的中断，也就不会接受键盘和鼠标发出的数据了，因此选项 A 描述错误，选 A

在多重中断中，CPU 只有在检测到中断请求信号后 (中断处理优先级更低的中断请求信号是检测不到的、会屏蔽掉的)，才会进入中断响应周期；进入中断响应周期时，说明此时 CPU 一定处于中断允许状态，否则无法响应该中断

如果所有中断源都被屏蔽 (说明该中断处理优先级最高)，则 CPU 不会检测到任何中断请求信号，相反，若 CPU 检测到中断请求信号，则一定存在未被屏蔽的中断源请求信号
