多模块存储器所以能高速进行读/写，是因为(  )。

A.采用了高速元器件
B.各模块有独立的读写电路
C.采用了信息预读技术
D.模块内各单元地址连续
多模块存储器（如交叉存储器）能高速读写的根本原因，是将主存划分为多个独立的存储模块，每个模块都配备了独立的地址寄存器、数据寄存器和读写控制电路


这使得：

  • 多个模块可以并行或重叠地执行读写操作，而不是等待前一个操作完成
  • 例如在连续地址访问时，CPU 可以向不同模块交替发送请求，实现流水线式的高速数据传输


本题选 B



已知单个存储体的存储周期为 110ns，总线传输周期为 10ns，采用低位交叉编址的多模块存储器时，存储体数应 ( )

A.小于 11
B.等于 11
C.大于 11
D.大于或等于 11
在采用低位交叉编址的 n 体多模块存储器中，每个体的存储周期 T 和总线传输周期 τ 必须满足的关系是 T ≤ nτ

这样主要是为了保证启动某个存储体后，经 nτ 的时间（即 1 个存储周期）后，能再次启动该存储器体时，这个存储体的上次存取操作必须已完成

本题的 T = 110ns，τ = 10ns，所以，n ≥ 110/10 = 11，本题选 D

一个四体并行低位交叉存储器，每个模块的容量是 64K×32 位，存取周期为 200ns，总线周期为 50ns，在下述说法中，( ) 是正确的。

A.在 200ns 内，存储器能向 CPU 提供 256 位二进制信息
B.在 200ns 内，存储器能向 CPU 提供 128 位二进制信息
C.在 50ns 内，每个模块能向 CPU 提供 32 位二进制信息
D.以上都不对
低位交叉存储器采用流水线技术，可以在一个存取周期内连续访问 4 个模块，32 位 × 4=128 位。本题答案为 B

注：本题若作为计算题来考虑，从第一个字的读/写请求发出，到第 4 个字读/写结束，共需要 T + (4 - 1) τ = 200ns + 3 * 50ns = 350ns

T 是存储体的存储周期，τ 是总线传输周期

但这里考查的是整体工作性能，可从以下角度理解：如果从上面的四体存储器连续读出 m 个字，需要的时间是 T + (m - 1)τ，那么平均每个字的存取时间是 (T + (m - 1)τ) / m = T/m + τ + τ/m，而实际工作时，m 是非常大的，那么平均每个字的存储时间就非常接近 τ 了，可以认为每个总线传输时间 τ 能给 CPU 提供一个字


即每隔 T/4 可以读出一个字，那么在 200ns 内，存储器能向 CPU 提供 32 位 × 4=128  位二进制信息

A.2×10^8bit/s
B.3.2×10^8bit/s
C.2×10^7bit/s
D.3.2×10^7bit/s
存储字长是 16 位，那么存储总线的数据线宽度是 16 位，而每个体的存储单元也是 16 位，因此，该低位交叉存储器采用轮流启动

存储周期 T = 200ns，总线传输周期 τ = 50ns，那么该低位交叉 4 体存储器连续读出 m 个字需要的时间是 T + (m - 1)τ，那么读取 1 个字的平均时间是 (T + (m - 1)τ) / m = T/m + τ + τ/m

本题求的是存储器读取的平均速度，所以，假设 m 非常的大，那么此时读取 1 个字的平均时间就非常接近于 τ 了

因此，在流水线情况下，无论连续多少个字，其平均速度都是一样的，即一个总线传输周期就可以传输一个字，因此，平均速度为 16bit/50ns = 3.2×10^8bit/s，本题选 B

如果是轮流启动的话，存储器总线的数据线宽度等于一个体的存储单元（即 16 位），这个时候：
  • 存储器每隔 T/4 可以向 CPU 提供 16 位是数据，那么每隔 T = 400ns = 0.4μs 内，可以向 CPU 提供 16 位 * 4 = 64 位的数据
  • 每个存储体每个一个存储周期 T = 400ns = 0.4μs，可以向 CPU 提供 16 位的数据


如果是同时启动的话，存储器总线的数据线宽度等于 4 个体的存储单元之和，即 16 位 * 4 = 64 位，这个时候：

  • 存储器每隔 T = 400ns = 0.4μs 内，可以向 CPU 提供 16 位 * 4 = 64 位的数据
  • 每个存储体每个一个存储周期 T = 400ns = 0.4μs，可以向 CPU 提供 16 位的数据


因此 C 正确

【2017 第 13 题】某计算机主存按字节编址，由 4 个 64M×8 位的 DRAM 芯片采用交叉编址方式构成，并与宽度为 32 位的存储器总线相连，主存每次最多读写 32 位数据。若 double 型变量 x 的主存地址为 804001AH，则读取 x 需要的存储周期数是（ ）

A.1
B.2
C.3
D.4
题目给的是 4 个 DRAM 芯片采用交叉编址方式构成的主存，其实就是 4 体交叉编址多模块存储器，只不过每个模块是一个 DRAM 芯片

每个 DRAM 芯片容量是 64M × 8 位，因此每个 DRAM 每个存储周期可以读写 8 位数据，而存储器总线是 32 位 = 8 位 × 4，所以 CPU 在一个存储周期内可以同时读写 4 个 DRAM 芯片（即同时启动），也就是在一个存储周期可以读写 32 位数据

而 double 型变量 x 占 8 字节，64 位，它的主存地址是 804001AH，在访问多模块存储器时，这个地址被分成两个字段，分别是高位的模块内地址和低位的模块号

因为有 4 个存储模块，所以用主存地址的低 2 位来表示主存地址所在的模块号，而 double 型变量 x 的地址 804001AH 的最低 2 位是 10B，因此 double 变量 x 的起始字节位于 2 号模块（模块号从 0 开始），因为 double 占 8 个字节，因此这个 double 变量是这样存储的（下图红色部分的 8 个字节）：


所以，同时启动下，CPU 需要 3 个存储周期，才可以读完 double 变量 x：
  • 第一个存储周期，CPU 读取 2 号模块的第 1 字节、3 号模块的第 2 字节
  • 第二个存储周期，CPU 同时读取 0、1、2、3 号模块的 4 个字节
  • 第三个存储周期，CPU 同时读取 0 号、1 号模块中的 2 个字节

同时启动的话，每个存储周期，CPU 都会读取 0、1、2、3 号模块中中相同位置的 8 位数据，也就是 32 位数据

如果是轮流启动，需要 11/4 个存储周期就可以读完上面 8 个字节的数据，首先第 1 个存储周期读取第 1 个字节，然后每隔 T/4 存储周期，就读取一个字节，总共是 1 + 7/4 = 11/4 个存储周期

所以，选 C

【2022 第 17 题】某内存条包含 8 个 8192×8192×8 位的 DRAM 芯片，按字节编址，支持突发 (burst) 传送方式，对应存储器总线宽度为 64 位，每个 DRAM 芯片内有一个行缓冲区 (row buffer)。下列关于该内存条的叙述中，不正确的是 (  )。

A.内存条的容量为 512 MB
B.采用多模块交叉编址方式
C.芯片的地址引脚为 26 位
D.芯片内行缓冲有 8192×8 位
内存条的容量等于所有 DRAM 芯片容量之和，即 8×8192×8192×8 位 = 512MB，内存条的容量为 512MB，因此 A 正确

一个 DRAM 芯片的存储容量是 8192×8192×8 位，那么每个 DRAM 存储芯片只能传输 8 位的数据，而内存条的存储器总线是 64 位，也就是说要求内存条一次性传输 64 位数据，所以，只有 8 个 DRAM 芯片并行传输，才可以一次性传输 8 × 8 位 = 64 位的数据，而要使的多模块存储器所有模块可以并行传输的话，只能是采用交叉编址的多模块了，因此 B 正确


内存条一次性传输 64 位数据必须是连续的，因为按字节编址，所以这 8B 对应的 8 个地址必须是连续的


如果采用连续编址的话，8 个连续的地址肯定是位于同一个芯片中，这样在同一个存储周期内就不能一次性传输 64 位数据，而是一次性传输 8 位数据了


对于选项 C，说的是单个 DRAM 芯片的地址引脚数，单个 DRAM 芯片的存储容量是 8192×8192×8 位，按字节编址（也就是一个字节 8 位对应一个地址），那么地址的数量是 8192 × 8192，行地址位数是 13，列地址位数是 13（2^13 = 8192），不过 DRAM 采用地址线复用技术，因此单个 DRAM 芯片地址引脚的数量是 13，因此选项 C 错误

因为 DRAM 芯片内行数是 8192，那么一行的大小是 8192×8bit，所以 DRAM 芯片内行缓冲大小就是一行的大小，即 8192×8bit，所以 D 正确
