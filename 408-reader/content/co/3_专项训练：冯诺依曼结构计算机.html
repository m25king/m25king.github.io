【2009 第 11 题】冯·诺依曼计算机中指令和数据均以二进制形式存放在存储器中，CPU 区分它们的依据是（ ）

A.指令操作码的译码结果
B.指令和数据的寻址方式
C.指令周期的不同阶段
D.指令和数据所在的存储单元
对于 A，指令译码的结果就是很多的控制信号，根据控制信号是不能区分存储器中的指令和数据的

对于 B，指令的寻址方式主要有两种
  1. 寄存器间接寻址：PC 寄存器中的内容是指令的有效主存地址，根据 PC 寄存器的地址就可以找到指令
  2. 相对寻址：在执行转移指令时，需要将 (PC) + 偏移量得到指令在主存的地址


很明显，计算机也可以使用寄存器间接寻址和相对寻址来寻址数据，所以不能根据寻址方式来区分指令和数据


对于 C，首先指令周期是指 CPU 每取出并执行一条指令所需的全部时间，包括两个阶段：
  1. 取指阶段完成取指令和分析指令的操作，又称取指周期
  2. 执行阶段完成执行指令的操作，又称执行周期

在取指阶段，从主存中取出的就是指令，而在执行阶段，要去访问主存的话，那么肯定是访问数据，而不是指令，所以可以根据指令周期的不同阶段来区分指令和数据，所以选 C

对于 D，指令和数据都是以二进制形式存放在存储器中的存储单元，也就是说所有的存储单元可以存放数据，也可以存储指令，因此不能根据指令和数据所在的存储单元区分指令和数据

对于指令周期，你要是不理解的话，请复习视频：单总线 CPU 的指令取指阶段 和 单总线 CPU 的指令执行阶段

本题考察的是冯诺依曼计算机的特点

冯 · 诺依曼结构的基本思想主要包括以下五个方面：
  • ①：计算机由运算器、控制器、存储器、输入设备和输出设备 5 个基本部件组成
  • ②：指令和数据以同等地位存储在存储器中，形式上没有区别，但计算机应能区分它们

本题选 C


冯·诺依曼计算机工作方式的基本特点是 (  )。

A.程序一边被输入计算机一边被执行
B.程序直接从磁盘读到 CPU 执行
C.按地址访问指令并自动按序执行程序
D.程序自动执行而数据手工输入
冯・诺依曼计算机采用 “存储程序”工作方式，“存储程序” 的基本思想是：将事先编制好的程序和原始数据送入主存储器后才能执行，一旦程序被启动执行，就无须操作人员的干预，计算机会自动逐条执行指令，直至程序执行结束

A：错误。程序和数据需先存入内存，CPU 再从内存读取执行，而非边输入边执行

B：错误。程序需先存入主存储器，CPU 从主存储器取指执行，而非直接从磁盘读取

C：正确。按地址访问指令并自动按序执行，是冯・诺依曼体系的核心特征，本题选 C

D：错误。程序和数据均需预先存入存储器，而非自动执行时才输入数据

CPU 包含：

  • 通用寄存器组 (General Purpose Registerset，GPRs)，通用寄存器组由若干通用寄存器组成，用于临时存放数据、地址等，提高运算效率，每个通用寄存器有一个编号，通过指令可以指定哪个编号的寄存器中的数据作为 ALU 运算的操作数

(  ) 可以区分存储单元中存放的是指令还是数据。

A.控制器
B.运算器
C.用户
D.输入输出设备
指令和数据在计算机内部都是用二进制表示的，因而都是 0、1 序列，在形式上没有差别

在指令和数据取到 CPU 之前，它们都存放在存储器中，CPU 必须能够区分读出的是指令还是数据，如果是指令，CPU 会把指令的操作码送到指令译码器进行译码，而把指令的地址码送到相应的地方进行处理；如果是数据，则送到寄存器或运算器

那么，CPU 如何识别读出的是指令还是数据呢？实际上，CPU 并不是把信息从主存读出后，靠某种判断方法来识别信息是数据还是指令。而是在读出之前就知道将要读的信息是数据还是指令了

执行指令的过程分为取指令、指令译码、取操作数、运算、送结果等。所以，在取指令阶段，总是根据程序计数器  (PC) 的值去取指令，所以取来的一定是指令；取操作数阶段取来的一定是数据


因此，控制器通过指令周期区分：取指阶段从内存取的是指令，执行阶段取的是数据；同时通过地址来源（PC 指向指令地址，指令地址码指向数据地址）来识别，所以本题选 A
