在主存和 CPU 之间增加 Cache 的目的是(   )。

A.增加内存容量
B.提高内存可靠性
C.加快信息访问速度

Cache（高速缓存）是位于 CPU 与主存之间的高速小容量存储器，它的核心作用是缓解 CPU 与主存之间的速度差异

CPU 运算速度远快于主存访问速度，通过将 CPU 近期频繁访问的数据和指令暂存于 Cache 中，可让 CPU 直接从高速的 Cache 中读取数据，从而显著加快整体信息访问速度，本题选 C

选项 B 错误：Cache 的引入与提升内存可靠性无关

A 和 D 错误，无论 Cache 容量做得多大，都无法增加主存的物理容量。其原因如下：

① 首先 Cache 和主存在物理上相互独立：Cache 是 CPU 内部或紧邻 CPU 的高速 SRAM 存储单元；而主存是独立的 DRAM 内存条 / 内存颗粒

② 再者两者地址空间完全隔离，程序访问的内存地址是直接指向主存的，Cache 只是 CPU 内部的透明缓存层：对程序员 / 操作系统而言，可见的内存容量就是主存容量；Cache 不参与地址空间的编址，不会出现在系统的 “内存总量” 统计里

③ 两者功能定位不同：主存负责持久存储运行中的程序和数据（断电后数据丢失，但属于程序运行时的 “工作内存”）；Cache负责临时缓存 CPU 近期高频访问的数据，是为了提速，不是为了扩容

以下 (   ) 情况能很好地发挥Cache 的作用。

A.程序中不含有过多的I/O操作
B.程序的大小不超过实际的内存容量
C.程序具有较好的访问局部性
D.程序的指令间相关度不高
Cache 的工作原理依赖于程序的局部性原理，主要分为：
  • 时间局部性：近期被访问的数据，在短期内很可能会被再次访问
  • 空间局部性：当前被访问的数据，其相邻地址的数据也很可能会被访问


当程序具备良好的局部性时，CPU 频繁访问的数据和指令会被预取并暂存到 Cache 中，能大幅提升 Cache 命中率，从而高效发挥其加速作用


因此，本题选 C


选项 A：I/O 操作多少与 Cache 作用发挥无直接关联，I/O 操作主要涉及外设与内存的数据交互


选项 B：程序大小是否超过内存容量影响的是是否会发生内存和磁盘的交换（这个是 OS 的内容，在 OS 会详细讲解），与 Cache 的性能发挥无关


选项 D：指令间相关度低可能会导致分支预测失效、流水线停顿，但这并不会提升 Cache 的作用，反而可能降低整体执行效率

假定 CPU 通过存储器总线读取数据的过程为：发送地址和读命令需 1 个时钟周期，存储器准备一个数据需 8 个时钟周期，总线上每传送 1 个数据需 1 个时钟周期。若主存和 Cache 之间交换的主存块大小为 64B，存取宽度和总线宽度都为 4B，则 Cache 的一次缺失损失至少是 (   ) 个时钟周期。

首先，你得明白 Cache 的一次缺失损失是指从主存读入一个主存块到 Cache 的时间

本题并没有明确说使用突发传输，所以，你只能老老实实的按照非突发传输的方式来计算

CPU 从主存读取一个数据需要的时间 = 发送地址和读命令的 1 个时钟 + 准备一个数据需 8 个时钟 + 总线上每传送 1 个数据需 1 个时钟 = 10 个时钟，即每个总线事务需要 10 个时钟周期

因为存取宽度和总线宽度都为 4B，所以一个数据的大小就是 4B

现在 CPU 需要从主存传输一个主存块，也就是 64B，那也就是说需要传输 64B / 4B = 16 个数据，需要 16 个总线时序，因此从主存读入一个主存块到 Cache 的时间是 16 × 10 时钟 = 160 时钟周期，本题选 D

扩展，如果现在将存取宽度和总线宽度设置为 8B 的话，那么 Cache 的一次缺失损失又是多少呢？

一次缺失损失需要从主存读出一个主存块（64B），每个总线事务读取 8B，因此，需要 64B/8B=8 个总线事务。每个总线事务所用时间为 1+8+1=10 个时钟周期，总共需要 80 个时钟周期


可以看到，增加数据线宽度，可以减少 Cache 损失缺失

假定用作 Cache 的 SRAM 的存取时间为 2ns，用作主存的 SDRAM 的存取时间为 40ns。为使存储系统的平均存取时间达到 3ns，则 Cache 命中率应达到 ( ) 左右。

CPU 在 cache - 主存层次的平均访问时间为：Ta = p × Tc + (1 - p) × (Tm + Tc) = Tc + (1 - p) × Tm

其中：
  • cache 命中时，CPU 在 cache 中直接存取信息，所有的时间开销就是访问 cache 的时间 Tc，称为命中时间
  • 把从主存读入一个主存块到 cache 的时间 Tm 称为缺失损失
  • p 是 Cache 命中率

在本题中，Tc = 2ns，Tm = 40ns，平均存取时间 Ta = 3ns，代入上面公式 Ta = Tc + (1 - p) × Tm，得到：3ns = 2ns + (1 - p) × 40ns，得到 p = 1 - 0.025 = 0.975

所以Cache 命中率应达到 97.5% 左右。本题选 C
