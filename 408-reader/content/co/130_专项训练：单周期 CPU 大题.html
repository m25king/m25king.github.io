请分别描述下列指令的执行路径以及所有控制信号的值：

① R 型指令：将寄存器 Rs 和 Rt 的内容进行运算，并将结果写到 Rd 寄存器

② 立即数运算指令（上面的 ori 和 addiu 指令）：对 16 位立即数进行符号扩展或零扩展，然后和 Rs 的内容进行运算，最终把 ALU 的运算结果送目的寄存器 Rt 中

③ lw 指令：M[R[Rs] + SEXT(imm16)] → R[Rt]，其中 SEXT 是符号扩展的意思

④ sw 指令： R[Rt] → M[R[Rs] + SEXT(imm16)]

① R 型指令，将寄存器 Rs 和 Rt 的内容进行运算，并将结果写到 Rd 寄存器，指令执行过程如下图，黑色粗线描述的是执行路径：寄存器堆（Rs，Rt） → busA，busB → ALU → Rd（busW）


控制信号的取值分析如下
  • Branch=Jump=0：因为不是分支指令和无条件跳转指令
  • RegDst=1：因为 R-型指令的目的寄存器为 Rd
  • ALUSrc=0：保证选择 busB 作为 ALU 的 B 口操作数
  • ALUctr=add/sub/subu/sht/sltu：5 条 R-型指令的操作各不相同，因而对应 5 种类型
  • MemtoReg=0：保证选择 ALU 输出送到目的寄存器
  • RegWR=1：保证在下个时钟到来时，在不发生溢出的情况下（Overflow = 0）结果被写到目的寄存器，发生溢出的话，则不写目的寄存器
  • Memwr=0：保证在下个时钟到来时，不会有信息写到数据存储器
  • ExtOp=x：因为 ALUSrc = 0，所以扩展器的输出不会影响执行结果，故 ExtOp 取 0（零扩展） 或 1（符号扩展） 都无所谓


② 立即数运算指令，对 16 位立即数进行符号扩展或零扩展，然后和 Rs 的内容进行运算，最终把 ALU 的运算结果送目的寄存器 Rt 中，指令执行过程如下图，黑色粗线描述的是执行路径：寄存器堆（Rs） → busA，扩展器(imm16) → ALU → Rt（busW）


对于目标指令中的 I-型运算指令 ori 和 addiu，不难看出各控制信号的取值如下：
  • Branch=Jump=0：因为不是分支指令和无条件跳转指令
  • RegDst=0：因为目的寄存器为 Rt
  • ALUSrc=1：保证选择立即数 imm16 扩展后作为 ALU 的 B 口操作数
  • ALUctr=or/addu (ori 指令为or，addiu 指令为 addu)
  • MemtoReg=0：保证选择 ALU 输出送到目的寄存器
  • RegWr=1：保证在下个时钟到来时，在不发生溢出的情况下（Overflow = 0）结果被写到目的寄存器，因为此时 ALUctr = or/addu，所以不需要判断溢出的，即 Overflow 肯定是等于 0 的
  • MemWr=0：保证在下个时钟到来时，不会有信息写到数据存储器
  • ExtOp=0/1：执行 ori 指令时为 0，逻辑计算需要进行零扩展；执行 addiu 指令为 1，算术计算进行符号扩展，注意，addiu 虽然是将寄存器的值和立即数进行无符号加法，但是对于立即数还是需要做符号扩展，而不是零扩展，前面我们说过，有符号加法和无符号加法除了要不要判断溢出这点不同，其他的都是相同的

③ lw 指令，M[R[Rs] + SEXT(imm16)] → R[Rt]，其中 SEXT 是符号扩展的意思，指令执行过程如下图，黑色粗线描述的是执行路径：寄存器堆（Rs） → busA，扩展器(imm16) → ALU（addu） → 数据存储器 → Rt（busW）


对于 lw 指令，不难看出各控制信号的取值如下：
  • Branch=Jump=0：因为不是分支指令和无条件跳转指令
  • RegDst=0：因为目的寄存器为 Rt
  • ALUSrc=1：保证选择 imm16 扩展后作为 ALU 的 B 口操作数
  • ALUctr=addu (对内存地址进行 addu，即不进行溢出判断，Overflow = 0)
  • MemtoReg=1：保证从数据存储器中读出的数据送到目的寄存器
  • RegWr=1：保证在下个时钟到来时，在不发生溢出的情况下（Overflow = 0）结果被写到目的寄存器
  • MemWr=0：保证在下个时钟到来时，不会有信息写到数据存储器
  • ExtOp=1，对 16 位补码偏移量进行符号扩展


④ sw 指令： R[Rt] → M[R[Rs] + SEXT(imm16)]，其中 SEXT 是符号扩展的意思，指令执行过程如下图，黑色粗线描述的是执行路径：寄存器堆（Rs，Rt） → busA，扩展器(imm16) ，busB→ ALU（addu），busB → 数据存储器



对于 sw 指令，不难看出各控制信号的取值如下：
  • Branch=Jump=0：因为不是分支指令和无条件跳转指令
  • RegDst=x：因为不需要写目的寄存器，所以 RegDst 可以为任意值
  • ALUSrc=1：保证选择 imm16 扩展后作为 ALU 的 B 口操作数
  • ALUctr=addu (对内存地址进行 addu，即不进行溢出判断，Overflow = 0)
  • MemtoReg=x：因为不需要写目的寄存器，所以 MemtoReg 可以为任意值
  • RegWr=0：保证在下个时钟到来时，不会有信息写到寄存器堆
  • MemWr=1：保证在下个时钟到来时，将 busB 总线上的数据写到数据存储器
  • ExtOp=1，对 16 位补码偏移量进行符号扩展
