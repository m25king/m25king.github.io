下列关于机器字长的定义，最准确的是（ ）

A. CPU 地址总线的宽度
B. CPU 数据总线的宽度
C. CPU 一次能处理的二进制数据位数
D. 主存储器的存储单元位数
地址总线宽度决定了 CPU 可寻址的内存空间大小，与机器字长无关，A 错误

数据总线宽度是 CPU 与内存一次传输的数据位数，它通常与机器字长相等，但不是机器字长的定义本身，只是外在表现，B 错误

对于 C，CPU 一次能处理的二进制数据位数，这是机器字长最本质、最准确的定义。它直接决定了通用寄存器的位数、ALU 的运算位数，是 CPU 处理能力的核心指标，本题选 C


存储单元位数是内存中的参数，与 CPU 的处理能力无必然联系，D 错误

若某 CPU 的机器字长为 32 位，则其通用寄存器的位数至少为（ ）

A. 16 位
B. 32 位
C. 64 位
D. 128 位
通用寄存器是 CPU 暂存数据的核心部件，其位数必须与机器字长一致，才能保证 CPU 一次可完整处理一个字长的数据。因此 32 位机器字长的 CPU，通用寄存器位数至少为 32 位

对比 16 位与 32 位机器字长的 CPU，下列说法错误的是（ ）

A. 32 位 CPU 可寻址的物理地址空间更大
B. 32 位 CPU 一次可处理的整数运算位数更多
C. 16 位 CPU 的指令集设计更复杂
D. 32 位 CPU 的通用寄存器位数更多
对于 A（32 位 CPU 可寻址的物理地址空间更大）是正确的，一般来说，32 位 CPU 通常支持更宽的地址总线，可寻址空间为 2^32 字节（约 4GB），远大于 16 位 CPU 的 2^16字节（约 64KB）

对于 B（32 位 CPU 一次可处理的整数运算位数更多）是正确的，机器字长直接决定 ALU 运算位数，32 位 CPU 一次可处理 32 位整数，16 位 CPU 仅能处理 16 位

对于 C（16 位 CPU 的指令集设计更复杂）是错误，机器字长越长，CPU 可支持更丰富的寻址方式、数据类型和指令功能，因此 32 位 CPU 的指令集设计更复杂，16 位 CPU 受硬件限制，指令集更精简，本题选 C

对于 D（32 位 CPU 的通用寄存器位数更多）是正确的，通用寄存器位数与机器字长一致，因此 32 位 CPU 的寄存器位数为 32 位，多于 16 位 CPU 的 16 位
