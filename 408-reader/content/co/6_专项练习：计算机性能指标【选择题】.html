Ⅰ 描述错误，实际应用程序的测试结果不能全面代表计算机性能。计算机性能受 CPU、内存、硬盘、显卡、系统架构等多硬件因素，以及操作系统、编译器、算法等软件因素影响，单一应用程序仅能反映特定场景下的性能，无法覆盖所有工作负载（如科学计算、图形渲染、数据库处理等）

II 描述正确，系列机的核心特性就是指令系统向后兼容。即新推出的系列机型号，能兼容运行旧型号的程序，保证软件的可移植性和延续性，这是系列机设计的关键原则

系列机是指同一厂家生产的、指令系统基本相同、体系结构兼容，但在性能、价格、配置上有差异的一系列计算机

核心特点：向后兼容—— 新机型能运行旧机型的软件，旧软件不用修改就能在新机器上跑，保护用户软件投资

比如 Intel x86 系列处理器，系列构成：从早期的 8086、80286，到后来的 386、486、Pentium，再到现在的酷睿 i3/i5/i7/i9、至强系列

兼容核心：x86 指令集向后兼容
  • 几十年前用 8086 写的 DOS 程序，现在的酷睿 i9 电脑依然能运行（通过兼容模式）
  • 你在 i5 电脑上装的 Windows、软件，换到同代 i7 或更新的 i9 上，直接就能用，不用重装或重写

该如何选择呢？这里会用到一个基本思想，就是加速经常性事件，也就是对应经常发生的事件，我们一般会选择给它加速

以下给出了改善计算机性能的 4 种措施：

① 用更快的处理器来替换原来的慢速处理器；

② 增加同类处理器个数，使得不同的处理器同时执行程序；

③ 优化编译生成的代码使得程序执行的总时钟周期数减少；

④ 减少指令执行过程中访问内存的时间

① 更换更快的处理器，因为总执行时间 = 总时钟周期数 × 时钟周期。更快的处理器意味着时钟频率加快了，即每个时钟周期更短了，故总执行时间变短了。因此，采用更快的处理器可缩短程序响应时间

② 增加同类处理器个数（并行执行），若程序支持多线程 / 多进程，多个处理器可并行执行不同任务段，总耗时显著降低

即使程序串行，多核也可通过操作系统调度提升并发效率，间接缩短执行时间，如果只有 1 个处理器，要执行 3 个程序的话，那么程序需要轮流执行，但是如果有 3 个处理器的话，那么可以每个处理器同时执行 1 个程序，很明显，多个处理器可以减少程序执行时间

③ 优化编译代码，减少总时钟周期数，编译优化可消除冗余指令、简化指令序列、提升指令流水线效率，程序执行的总时钟周期数减少，在相同处理器下耗时更短

④ 减少指令执行的内存访问时间，内存访问是 CPU 执行的主要瓶颈之一，减少访存延迟 / 等待时间（可以通过提升 Cache 命中率等来实现），可大幅提升指令执行效率，缩短程序总执行时间

因此，①②③④ 全部措施都能缩短特定程序的执行时间，本题选 D

CPU 主频：指 CPU 的时钟脉冲频率（单位 Hz），是 CPU 时钟周期的倒数，描述时钟的快慢，而非 “执行指令的频率”，A 的前半句描述错误、C 的前半句描述错误

核心定义速记

  • 主频：时钟频率（Hz），决定时钟周期长短
  • CPI：1 条指令平均用多少个时钟周期
  • MIPS：每秒执行多少百万条指令（整数性能）
  • MFLOPS：每秒执行多少百万次浮点运算（浮点性能）

计算机中，CPU 的 CPI 与下列 ( ) 因素无关。

A.时钟频率
B.系统结构
C.指令集
D.计算机组织
CPI（Clock Cycles Per Instruction）是执行一条指令平均需要的时钟周期数，它由指令集、系统结构、计算机组织等决定，与时钟频率（主频）无关

A 时钟频率：仅决定单个时钟周期的时长（周期 = 1 / 主频），不改变执行一条指令需要多少个周期，因此与 CPI 无关，本题选 A

B 系统结构：如流水线深度、超标量、Cache 层次等，会直接影响 CPI
  • 流水线深度：流水线越合理，指令重叠执行，CPI 越接近 1；流水线冲突（数据冒险、控制冒险）会让 CPI 上升
  • 超标量 / 超流水线：能同时发射多条指令，CPI 可小于 1（平均一条指令不到 1 周期）
  • Cache 层次与命中率：Cache 命中，访存周期少；不命中，要等内存，CPI 大幅上升
  • 分支预测：预测准，分支延迟少，CPI 低；预测错，要冲刷流水线，CPI 高


一句话：系统结构决定 "指令能不能高效并行、少等资源"，直接影响 CPI


C 指令集：指令复杂度、寻址方式、是否有复杂指令等，会改变 CPI
  • CISC（复杂指令集）：一条指令做很多事（如一条指令完成数组拷贝），单条指令周期多，CPI 高；但总指令数少
  • RISC（精简指令集）：指令简单、规整，单条指令周期少（常 1 周期），CPI 低；但总指令数多
  • 寻址方式：复杂寻址（如间接寻址、变址寻址）要多周期计算地址，CPI 上升；简单寻址（寄存器直接寻址）CPI 低
  • 指令类型：乘法 / 除法 / 浮点指令周期多，CPI 高；加减 / 逻辑指令周期少，CPI 低


一句话：指令集决定 “一条指令要做多少事、要多少周期”，是 CPI 的源头


D 计算机组织：ALU、总线、控制器设计等，会影响指令执行的周期数
  • ALU 位数与速度：32 位 / 64 位 ALU 一次完成运算，CPI 低；8 位 ALU 要多次运算，CPI 高
  • 控制器设计：硬布线控制器速度快，CPI 低；微程序控制器要读微指令，CPI 高
  • 总线宽度与带宽：宽总线一次传更多数据，访存 / 传数周期少，CPI 低；窄总线要多次传输，CPI 高
  • 寄存器数量：寄存器多，数据不用频繁访存，CPI 低；寄存器少，频繁 load/store，CPI 高
  • 功能单元并行：多个 ALU / 浮点单元可并行执行，CPI 降低；单功能单元只能串行，CPI 高


一句话：计算机组织决定 “硬件能不能快速完成指令的每一步”，直接影响单条指令的周期数

下列有关计算机性能指标 MIPS 的描述中，错误的是（ ）

A.MIPS 是指平均每秒执行的百万条指令数
B.MIPS 越大说明机器性能一定越好
C.用 MIPS 对不同机器进行性能比较不太客观
D.MIPS 反映的是机器执行定点指令的速度
A 正确：MIPS = Million Instructions Per Second，即每秒执行的百万条指令数

B 错误：MIPS 仅衡量整数指令的执行速率，不能直接反映机器性能好坏
  • 不同指令集（如 CISC 与 RISC）的指令复杂度不同，MIPS 高不代表实际程序运行快
  • 例如：CISC 机器单条指令功能强，MIPS 低但可能完成任务更快；RISC 机器 MIPS 高，但总指令数多，实际耗时不一定短


因此，本题选 B


C 正确：MIPS 依赖指令集和 CPI，不同机器间用 MIPS 比较性能不客观

D 正确：MIPS 反映的是定点指令（整数指令）的执行速度，不反映浮点性能

计算机性能指标包括以下几个


时钟周期：计算机执行一条指令的过程被分成若干个步骤来完成，每一步都要有相应的控制信号进行控制，这些控制信号何时发出，作用时间多长，都要有相应的定时信号进行同步。因此，计算机必须能够产生同步的时钟定时信号，也就是 CPU 的主脉冲信号，其宽度称为时钟周期


CPU 主频（或者称为时钟频率）：就是 CPU 时钟周期的倒数，表示 1 秒内有多少个时钟周期数


CPI（Cycles Per Instruction）：表示执行一条指令需要的时钟周期数


IPC（Instructions Per Cycle）：表示每周期执行的指令数，也就是每个时钟周期执行多少条指令（这个在课上没有讲，是因为在袁春风计组教材中也没有出现过，不过这个指标很好理解）


IPS（Instructions Per Second）：表示平均每秒执行多少条指令，MIPS（Million Instrcutions Per Second），表示平均每秒执行多少百万条指令


FLOPS（Floation-point Operations Per Second）：平均每秒执行多少次浮点运算操作，MFLOPS (Million FLOPS)，即每秒执行多少百万 (10^6) 次浮点运算


在计算机 M1 和计算机 M2 上分别运行功能完全相同的高级语言程序，程序在 M1 和 M2 上的平均 CPI 相等，则对于该类程序而言 ( )。

A.M1 和 M2 执行速度相等
B.M1 和 M2 中主频高的计算机执行速度快
C.M1 和 M2 中主频低的计算机执行速度快
D.无法确定哪台机器的执行速度快

CPU 执行时间 = 指令条数 × CPI × 时钟周期大小，程序在 M1和 M2 上的平均 CPI 相等，但影响 CPU 执行时间的因素还有指令条数和时钟周期的大小


因为不同计算机使用的 ISA 不同，所以相同的高级语言程序在不同计算机上编译生成的机器指令条数可能不同，因此无法确定哪台机器执行该类程序的速度快，因此，本题选 D

假定处理器 P1 的时钟频率是 1.5GHz，其对应 CPI 为 2，如果一个程序执行时间为 10s，那么执行该程序的时钟周期和指令数分别是（ ）

A. 15G，7.5G
B. 30G，15G
C. 7.5G，30G
D. 15G，30G
程序执行时间 10s = 该程序总的时钟周期数 / 时钟频率，所以该程序总的时钟周期数 = 10s * 1.5GHz = 15G

因为该程序总的时钟周期数 = 该程序总的指令条数 * CPI，所以该程序总的指令条数 = 该程序总的时钟周期数 / CPI = 15G / 2 = 7.5G，因此，本题选 A

假设某个程序执行的时间为 100s，其中 80s 的时间用于乘法运算，以下说法正确的是（ ）

A. 可通过改进乘法运算部件，将程序的运算速度提高 5 倍
B. 可通过改进乘法运算部件，将程序运行时间降低为 10s
C.不可能通过改进乘法运算部件，将程序的运算速度提高 5 倍
D. 不可能通过改进乘法运算部件，将程序的运算速度提高 3 倍
本题考察阿姆达尔定律，该定律的基本思想是，对系统中某个硬件部分，或者软件中的某部分进行更新所带来的系统性能改进程度，取决于该硬件部件或软件部分被使用的频率或其执行时间占总执行时间的比例

阿姆达尔定律定义了增强或加速部分部件而获得的整体性能的改进程度，它有两种表示形式：
  • 形式 ①：改进后的执行时间 = 改进部分执行时间 ÷ 改进部分的改进倍数 + 未改进部分执行时间
  • 形式 ②：整体改进倍数=1 / (改进部分执行时间比例 ÷ 改进部分的改进倍数 + 未改进部分执行时间比例)


对于本题【某个程序执行的时间为 100s，其中 80s 的时间用于乘法运算】，现在要改进乘法部件，那么未改进部分的执行时间是 100s - 80s = 20s，因此，根据形式 ①，可以确定的是改进后的执行时间肯定是大于 20s 的，因此选项 B 错误


因为未改进部分的执行时间是 20s，其占比是 20s/100s = 0.2，改进部分执行时间比例是 80s/100s = 0.8，那么根据上面的形式 ②：

  • 整体改进倍数=1 / (0.8 ÷ 改进部分的改进倍数 + 0.2)


因为改进部分的改进倍数不可能是 0，所以可以得到整体改进倍数肯定是小于 5 的，因此不可能通过改进乘法运算部件，将程序的运算速度提高 5 倍，本题选 C，那么选项 A 错误



很明显，整体改进倍数肯定是可以小于 5 的，因此 D 错误

假定某程序 P 由一个 100 条指令构成的循环组成，该循环共执行 50 次，在某系统 S 中执行程序 P 花了 20000 个时钟周期，则系统 S 在执行程序 P 时的 CPI 是多少（ ）

A.3
B.4
C.5
D.6
某程序 P 由一个 100 条指令构成的循环组成，该循环共执行 50 次，那么一共执行了 100 * 50 = 5000 条指令

执行这 5000 条指令花了 20000 个时钟周期，则系统 S 在执行程序 P 时的 CPI = 20000 / 5000 = 4

因此，本题选 B

假设某机器 M 的时钟频率为 2GHz，用户程序 P 在 M 上的指令条数为 1×10⁹，其 CPI 为 1.5，若在机器 M 上从程序 P 开始启动到执行结束所需的时间是 2s，则程序 P 的用户 CPU 时间占用的百分比是多少？（ ）

A.40%
B.37.5%
C.38%
D.37%

在机器 M 上从程序 P 开始启动到执行结束所需的时间是 2s，这个 2s 的时间包括用户 CPU 时间和其他时间


这个其他时间可能包括 CPU 执行操作系统程序的时间和等待 I/O 的时间


现在要求的是用户 CPU 时间的占比，所谓用户 CPU 时间其实就是 CPU 执行用户程序 P 指令的时间


CPU 执行时间 = 指令总条数 * CPI * 时钟周期 = 指令总条数 * CPI / 时钟频率 = 1 * 10^9 * 1.5 / (2 * 10^9Hz) = 0.75s


那么程序 P 的 CPU 执行时间在 2s 内占用的百分比是 0.75 / 2 * 100% = 37.5%，本题选 B

不过在这个题目中，是求一个程序的 CPI，因此要计算平均 CPI，其平均 CPI = 50% * 2 + 20% * 3 + 10% * 4 + 20% * 5 = 1 + 0.6 + 0.4 + 1 = 3，那么每秒执行的指令数是：主频 / 平均 CPI = 1.2G / 3 = 0.4G

【2014 第 12 题】程序 P 在机器 M 上的执行时间是 20 秒，编译优化后，P 执行的指令数减少到原来的 70%，而 CPI 增加到原来的 1.2 倍，则 P 在 M 上的执行时间是（ ）

A.8.4 秒
B.11.7 秒
C.14 秒
D.16.8 秒

执行时间 = 程序总指令数 * CPI * 时钟周期，假设优化前的程序总指令数等于 n，CPI 等于 cpi，时钟周期是 c，那么 n * cpi * c = 20s，而优化后的程序总指令数是 70% * n，也就是 0.7n，CPI 等于 1.2cpi，时钟周期不变还是 c，所以优化后的执行时间是 0.7n * 1.2cpi * c = (0.7 * 1.2) * (n * cpi * c) = 0.84 * 20s = 16.8s，因此选 D

【2023 第 12 题】若机器 M 的主频为 1.5Ghz，在 M 上执行程序 P 的指令条数为 5×10⁵，P 的平均 CPI 为 1.2，则 P 在 M 上的指令执行速度和用户 CPU 时间分别为 ( )。

B.0.8GIPS，0.4μs
C.1.25GIPS，0.4ms
D.1.25GIPS，0.4μs

题目第一问要求的是 GIPS，我们知道 IPS 表示每秒执行的指令数，MIPS 表示每秒执行多少百万条指令，MIPS = IPS / (10^6)，而 1G = 10^3M，因此 GIPS = MIPS / (10^3)，所以 GIPS = IPS / (10^9)


因此程序 P 的 CPI 等于 1.2，也就是说执行一条指令需要 1.2 个时钟周期，一个时钟周期的时间是 1.2 / 1.5GHz，也就是说，执行一条指令需要的时间是 1.2 / 1.5GHz，那么每秒可以执行的指令数等于 1 / (1.2 / 1.5GHz) = 1.5GHz / 1.2 = 1.25 G，那么 GIPS = 1.25 G / (10^9) = 1.25 （1G = 10^9）


CPU 执行时间 = 程序总指令数 * 平均 CPI * 时钟周期 = (程序总指令数 * 平均 CPI) / 主频 = (5 * 10^5 * 1.2) / 1.5 GHz = (5 * 10^5 * 1.2) / (1.5 * 10^9 Hz) = 4 * 10^-4 s = 0.4 * 10^-3 s = 0.4ms
