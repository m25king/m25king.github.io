在一个半导体存储器（比如主存储器）中，一般由多个半导体 RAM 芯片组成，所以，我们先来看半导体 RAM 芯片的内部原理

半导体 RAM 具有体积小、存取速度快等优点，因而适合作为内部存储器使用，比如可以用于组成高速缓存和主存储器

按工艺不同，可将半导体 RAM 分为双极型 RAM 和 MOS 型 RAM 两大类，现在用的多的还是 MOS 型 RAM，  MOS 型 RAM 又分为静态 RAM（Static RAM，SRAM）和动态 RAM（Dynamic RAM，DRAM）

半导体 RAM 芯片结构

接下来，我们分别再看 SRAM 芯片和 DRAM 芯片之前，先来看下半导体 RAM 芯片的内部结构，一般都是采用二维译码结构，一个半导体 RAM 芯片由存储体、输入输出（I/O）电路、地址译码和控制电路组成，看下图：

① 存储体，由若干个存储阵列组成，上图的存储体由 8 个 64 × 64 位的存储阵列组成，当给定一个地址，就会同时选中每个存储阵列中相同行相同列的那个存储元，被选中的 8 个存储元同时被读出或写入

也就是说一个地址对应着 8 位，那么上图存储器芯片的存储单元就是 8 位（也可以说存储字长是 8 位），存储体就是存储单元的集合，上图就有 64 × 64 = 4096 个存储单元，这里的每个存储单元都有对应的地址，即每个字节（8 位）都有唯一的一个地址，这种编址方式，我们就称为按字节编址，所以说，按字节编址的话，存储单元就是 8 位（1 个字节）

② 地址译码器，用来将地址转换为译码输出线上的高电平，以便驱动相应的读写电路，这里采用的是二维译码方式，将一个地址拆分成行地址和列地址分别进行译码，因此适用于容量较大的存储器

③ 驱动器，在二维译码结构中，一条行地址方向上的选择线要控制在其上的各个存储单元的字选择线，所以负载较大，因此需要再译码器输出后加驱动器

如何理解呢？

上面的存储体有 64 × 64 个存储字，对吧，当行地址经过行地址译码器译码后，会选中所有的存储阵列的对应的相同的行，在一行中有 64 个存储字，也就是 64 个存储单元，每个存储字都有一条对应的字选择线，也就是有 64 条字选择线，那么一条行地址方向上的选择线要控制这 64 条字选择线，所以说，一条行地址方向上的选择线要控制在其上的各个存储单元的字选择线

而当列地址经过列地址译码器译码后，其对应的列选择线只要在指定行中的 64 个存储字中选择一个存储字即可，相对来说，其负载比较小，所以在列地址方向上不需要驱动器

④ 输入输出（I/O）电路，用于控制被选中的存储单元的读出或写入，具有放大信息的作用

⑤ 片选控制信号 CS，单个存储芯片容量太小（比如上面的存储芯片的容量就是 64 × 64 × 8 位 = 4KB），肯定满足不了计算机对存储器容量的要求，因此需将一定数量的存储芯片按特定方式连接成一个完整的存储器，当访问某个存储单元时，必须 "选中" 该存储单元所在的存储芯片，而其他存储芯片不被 "选中"

对于片选控制信号 CS，我们在稍后的主存储器扩展中还会详细说明

⑥ 读/写控制信号 WE，根据 CPU 给出的是读命令还是写命令，控制被选中的存储单元进行读或写

看存储芯片的结构，接下来，我们来学习静态 RAM（即 SRAM）芯片和动态 RAM（即 DRAM）芯片，这两种芯片的内部结构差不多，就是上面的介绍的这种二维译码结构，它俩不同的地方就是存储元的电路结构不同而已，也就是存储 1 位二进制位的电路结构不同

SRAM 存储芯片

SRAM 芯片中的存储元使用 6 个 MOS 管来存储 1 位二进制位，如下图：

上图中的 T1 ~ T6 就是 6 个 MOS 管，若 T2 导通，则 T1 一定截止，A 点为高电平，B 点为低电平，表示存储的是二进制 1；反之（当 T1 导通时）则表示存储的是二进制 0

对于上面的电路如果你看懂没关系的，只要知道这个 6 管电路结构就是存储 1 个二进制位的即可

这个电路天生具备双稳态特性， 其存储的二进制数据在供电持续的情况下，会一直保持稳定状态，无需外部电路周期性地刷新（Refresh）就能维持数据，所以，我们将它称为静态 RAM
