条件码

除了整数寄存器，CPU 还维护着一组单个位的条件码寄存器，它们描述了 CPU 最近执行的算术或逻辑指令的结果，可以检测这些位来执行条件分支指令，看下图：

条件码寄存器也称为标志寄存器，或者称为程序状态字寄存器，最常用的条件码（标志位）有：CF（进位标志）、ZF（零标志）、SF（符号标志），OF（溢出标志），当执行 add、sub 等指令时，都会产生这些标志位，根据这些标志位就可以判断两个整数的大小，根据两个整数的大小就可以执行不同的跳转指令
add、sub 指令执行时，不但会产生标志位（修改标志寄存器），还会改变其他寄存器的值，而 cmp 指令只会设置条件码（标志位）而不会改变任何其他寄存器，比如指令 cmp S1, S2 是根据 S1 - S2 的结果来设置条件码，除了只设置条件码而不更新目的寄存器之外，cmp 指令和 sub 指令的行为是一样的

if 条件语句的实现

上面我们学习了通过算术逻辑运算指令和 cmp 指令可以修改条件码，那条件码如何被读取呢？在 X86-64 中，可以通过跳转指令（或称为分支指令）来访问标志寄存器中的条件码，然后根据条件码来决定程序的跳转，来看一段 C 程序及其对应的 x86 汇编代码：
第 ① 条就是比较指令 cmp rdi, rsi ，作用就是将 rdi 的 x 和 rsi 的 y 做有符号减法，不需要减法的结果，只要减法过程中产生的 ZF、SF、CF、OF 这些标志信息，当执行完减法后，这些标志信息会存放在标志寄存器中；接下来第 ② 条跳转指令 jge .L2，它取读取符号标志 SF 和溢出标志 OF，然后判断 ~(SF ^ OF) = 1 的话，则说明 rdi 的 x 大于等于 rsi 的 y，如果 x >= y 的话，就跳转到 .L2 执行，即执行 else 代码块（jge 是 jump if great equal 的缩写，大于等于跳转指令），否则也就是 x < y，那么就顺序执行 jge 下面的指令，即执行 if 代码块
jge .L2 中的 .L2 本质上就是一个内存地址（即 jge 跳转目的指令的内存地址），上面使用标签 .L2 书写可读性强一点，再来看上面程序代码的机器指令（经过汇编和链接后）：

第 (1) 条指令 cmp rdi, rsi 的内存地址是 0x00000000004004ed（为了方便，这里省去前面的 0，写成 0x4004ed），指令的机器编码是 0x4839f7（占 3 个字节），所以第 (2) 条指令 jge 400501 的内存地址是上一条指令的内存地址 0x4004ed + 上一条指令的大小 3 字节 = 0x4004f0，这条指令的机器代码是 0x7d0f（占 2 个字节），可以看到 jge 的跳转目的地址是 0x400501（也就是上面的第 (7) 条指令的内存地址），你再看上面的 jge 指令的后面还有 <absdiff_se+0x14> 它意思就是 jge 的跳转目的地址等于函数第一条指令的地址 0x4004ed + 0x14 = 0x400501，这就是 jge 后面的跳转目的地址了
接下来，我们来看下 jge 400501 <absdiff_se+0x14> 的机器代码就是 2 个字节 0x7d0f，其中 0x7d 是指令 jge 的操作码，那么这个 0x0f 是什么呢？直接给答案，这个 0x0f 就是跳转目的指令的地址（第 (7) 条指令的内存地址 0x400501）与紧跟在 jge 指令后面那条指令的地址（第 (3) 条指令的内存地址 0x4004f2）的差，即 0x400501 - 0x4004f2 = 0x0f，可以看出

跳转指令的跳转目的地址采用 PC 相对偏移量进行编码（而且偏移量是一个 8 位的补码，其范围是 -128 ~ 127，就是说可以往前跳也可以往后跳），当执行上面的jge 指令时，PC 中的内存地址是当前正在执行指令jge 的内存地址 0x4004f0，其跳转目的地址= PC + 当前执行指令的长度 + 偏移量 = 0x4004f0 + 2 + 0x0f = 0x400501


注意：对于上面的 jge 指令，在内存中保存的是机器指令代码 0x7d0f，而汇编指令  jge 400501 <absdiff_se+0x14>  是反汇编器将机器指令代码 0x7d0f 反汇编得到的，汇编指令时给人看到，其可读性高，我们一看到  jge 400501 <absdiff_se+0x14> 就知道跳转目的地址是 0x400501，而机器指令代码是给机器 CPU 执行的，CPU 需要通过 PC + 偏移量，才可以计算出跳转目的地址

再来看下上面 if 语句块中的第一条指令 add QWORD PTR [rip + 0x200b46], 0x1，就是将内存地址为 [rip + 0x200b46] 位置的双字加上 1，结果写到内存地址为 [rip + 0x200b46] 位置上，这个指令实际上就是执行 lt_cnt++ 语句，而 lt_cnt 是一个全局变量，它所在的内存地址是 [rip + 0x200b46]，这里的 rip 就是 PC，当执行这些add 指令时，rip 中的内存地址 0x4004f2，所以lt_cnt 在内存中的地址 = rip + 当前执行指令 add 的长度 + 偏移量 = 0x4004f2 + 8 + 0x200b46 = 0x601040，这里其实也是采用了相对寻址方式（即操作数的有效内存地址 = PC + 偏移量），这里使用相对寻址方式来寻址数据

上面的跳转指令的跳转条件都可以根据下面两点来推导的：

① 对于有符号比较 A - B，你只需要记住 ZF = 1 的话，那么 A = B；如果 ZF = 0 并且 SF ^ OF = 0 的话，那么 A > B；如果 ZF = 0 并且 SF ^ OF = 1 的话，那么 A < B

② 对于无符号比较 A - B，你只需要记住 ZF = 1 的话，那么 A = B；如果 ZF = 0 并且 CF = 0（够减），那么 A > B；如果 ZF = 0 并且 CF = 1（不够减），那么 A < B

test 指令

除了 add、sub 和 cmp 会修改条件码之外，逻辑运算指令也会修改上面的条件码，比如：按位与 and 指令的结果为 0，则 ZF 被置为 1；否则，ZF 被置为 0。根据按位与 and 指令结果的最高位设置，若最高位为 1，则 SF 为 1；否则，SF 为 0
