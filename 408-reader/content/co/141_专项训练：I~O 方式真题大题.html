【09-43】(8 分) 某计算机的 CPU 主频为 500MHz，CPI 为 5 (即执行每条指令平均需 5 个时钟周期)。假定某外设的数据传输率为 0.5MB/s，采用中断方式与主机进行数据传送，以 32 位为传输单位，对应的中断服务程序包含 18 条指令，中断服务的其他开销相当于 2 条指令的执行时间。请回答下列问题，要求给出计算过程。


1) 在中断方式下，CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少?

2) 当该外设的数据传输率达到 5MB/s 时，改用 DMA 方式传送数据。假定每次 DMA 传送块大小为 5000B, 且 DMA 预处理和后处理的总开销为 500 个时钟周期，则 CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少 (假设 DMA 与 CPU 之间没有访存冲突)?

首先，请注意审题，题目要求你给出计算过程，那么就需要把计算过程写出来

因为 CPU 的时钟周期是固定的，而这种类型的题目是求时间占比，所以，可以直接用时钟周期作为单位来表示中断、DMA 耗费 CPU 的时间，没必要去求中断、DMA 真实耗费 CPU 的时间

题目在计算中断耗费 CPU 的时间时，用的是 CPI，中断包括中断响应和中断处理两个阶段，这两个阶段都需要 CPU 的参与，题目说中断服务程序包含 18 条指令，那么 CPU 执行这 18 条的中断服务程序指令，需要的时钟周期数就是 18 × CPI = 18 × 5

题目又说中断服务的其他开销相当于 2 条指令的执行时间，其实就是说中断响应的时间的是 2 × CPI = 2 × 5，因此一次中断耗费 CPU 的时钟周期数就是 (18 + 2) × 5

另外，外设每秒传输 0.5MB 数据时，每次中断传输 32 位（4B）数据，那么每秒发生 0.5MB / 4B = 125000 次中断，如果发生的中断次数少于 125000 的话，就会丢失数据

在这里，实际上题目默认这个外设在一直工作，一直以 0.5MB/s 的速度产生数据，每次准备好 32 位数据，就会给 CPU 发送一个中断，通知 CPU 来读取数据

同样，对于 DMA 传输也是一样，外设每秒传输 5MB 数据，每次 DMA 传输 5000B 数据，那么每秒需要发生 5MB / 5000B = 1000 次 DMA 传输，如果每秒 DMA 传输次数少于 1000 次，就会丢失数据

如果，我们这样计算外设 D 将 1000 个字符送到 I/O 端口花费的时钟周期数： 1000 * 0.5ms * 50MHz = 25000000 （传输 1000 个字符，每传输 1 个字符需要 0.5ms，而每秒的时钟周期数是 50M）

那么，在计算 CPU 执行中断服务程序的时间时，前 999 个中断处理的时间只要计算前 15 条指令的执行时间（因为从 16 条指令到 20 条指令的执行时间，已经算在上面的字符送到 I/O 端口时间内了），但是最后 1 个中断，其中断处理时间是整个 20 条指令的执行时间（因为最后一个中断处理程序不需要启动外设 D）

因此，前 999 个中断服务的时钟周期数 = 999 × (中断响应时钟周期数 + 中断服务程序前 15 条指令的执行时钟周期数) = 999 × (10 + 15 × 4) （这里的 4 就是 CPI）；最后一个中断服务的时钟周期数 = 中断响应时钟周期数 + 整个中断服务程序执行时钟周期数 = 10 + 20 × 4

所以 CPU 完成从 D 中读取 1000 个字符，总共需要的时钟周期数是 25000000 + 999 × (10 + 15 × 4) + (10 + 20 × 4) = 25070020

CPU 在整个读取 D 中 1000 个字符的过程中，每次中断的中断响应和执行中断服务程序，都需要 CPU 的时间，所以 CPU 耗费的时钟周期数 = 1000 × (10 + 20 × 4) = 90000

【2022 第 44 题】(8 分) 假设某磁盘驱动器中有 4 个双面盘片，每个盘面有 20000 个磁道，每个磁道有 500 个扇区，每个扇区可记录 512 字节的数据，盘片转速为 7200 RPM(转/分)，平均寻道时间为 5ms。请回答下列问题。

1) 每个扇区包含数据及其地址信息，地址信息分为 3 个字段。这 3 个字段的名称各是什么？对于该磁盘，各字段至少占多少位？

2) 一个扇区的平均访问时间约为多少？

3) 若采用周期挪用 DMA 方式进行磁盘与主机之间的数据传送，磁盘控制器中的数据缓冲区大小为 64 位，则在一个扇区读写过程中，DMA 控制器向 CPU 发送了多少次总线请求？若 CPU 检测到 DMA 控制器的总线请求信号时也需要访问主存，则 DMA 控制器是否可以获得总线使用权？为什么？


（1）3 个字段的名称是磁头号（也可以称为盘面号）、磁道号（也可以称为柱面号）、扇区号；

由于每个盘面有 20000 个磁道，因此该磁盘共有 20000 个磁道，磁道号字段至少占 ⌈log₂20000⌉=15 位；由于该磁盘共有 4 个盘片，每个盘片有 2 个盘面，因此磁头号字段至少占 log₂(4×2) = 3 位；由于每个磁道有 500 个扇区，因此扇区号字段至少占 ⌈log₂500⌉ = 9 位

（2）记住公式：一个扇区的平均访问时间 = 平均寻道时间 + 平均旋转等待时间 + 一个扇区的数据传输时间

一般，平均寻道时间题目会给出，这里是 5ms

平均旋转等待时间等于盘片旋转一周需要的时间的一半，盘片转速为 7200 RPM，那么转一圈的时间是 60s / 7200 = 1/120 s，那么平均旋转等待时间是 1/240 s ≈ 4.167ms

计算一个扇区数据传输时间有两种方式：
  1. 一种就是我们在视频 【磁盘的平均存取时间】中讲解的，一个扇区数据传输时间 = 一个扇区的容量大小 / 数据传输率
  2. 另一种就是这题中用到的，一个扇区数据传输时间 = 旋转一圈需要的时间 / 一个磁道的扇区数；就是一个扇区划过磁头下方所需要的时间


在这一题中，并没有告诉你数据传输率，所以用第二种方式来计算个扇区数据传输时间，转一圈的时间是 60s / 7200 = 1/120 s，每个磁道有 500 个扇区，所以一个扇区的传输时间是 1 / (120 × 500) s ≈ 0.017ms

所以，一个扇区的平均访问时间 = 平均寻道时间 + 平均旋转等待时间 + 一个扇区的数据传输时间 = 5ms + 4.167ms + 0.017ms ≈ 9.18ms

（3）因为磁盘控制器中的数据缓冲区大小是 64 位（8 字节），每次数据缓冲区满了数据，就需要发起一次 DMA 传输，那么读写一个大小为 512 字节的扇区，需要 DMA 传输 512B / 8B = 64 次，每次 DMA 传输都要向 CPU 发起总线请求，所以 DMA 控制器向 CPU 发送 64 次总线请求

这里采用的是周期挪用 DMA 方式，会发生三种情况：
  1. 当 DMA 申请总线控制权时，CPU 已经在使用存储器总线访问主存，这时 DMA 需要等待，等待 CPU 使用存储器总线事务结束，然后 DMA 才可以拿到总线控制权
  2. 当 DMA 申请总线控制权时，CPU 没有访存，那么 DMA 直接拿到总线控制权
  3. 当 DMA 申请总线控制权时，CPU 刚好也要访问主存，那么 DMA 控制器可以优先获得总线使用权。因为一旦磁盘开始读写，就必须按时完成数据传送，否则数据缓冲区中的数据会发生丢失（因此 DMA 获取总线控制权访问主存的优先级高于 CPU）
