CPU 和主存储器通过北桥芯片和 I/O 总线相连，然后在 I/O 总线上挂了外部设备的接口（比如上图的 USB 接口、以太网卡、磁盘控制器等），这些 I/O 接口通过通信总线和外部设备连接


因此，正确的顺序是这样的：CPU和主存 → I/O总线 → I/O接口(外设控制器) → 通信总线(电缆) → 外设，本题选 A

以下有关 I/O 接口功能和结构的叙述中，错误的是(   )。

A.I/O 接口就是像显卡或网卡之类的一种外设控制逻辑
B.CPU 可以向 I/O 接口传送用来对设备进行控制的命令
C.CPU 可以从 I/O 接口取状态信息，以了解接口和外设的状态
D.I/O 接口中主机侧数据宽度与设备侧数据宽度总是一样

A 正确：I/O 接口是主机与外设之间的控制逻辑电路，显卡、网卡等设备的核心控制部分都属于 I/O 接口的范畴


B 正确：CPU 可以通过 I/O 接口向设备发送控制命令（如读、写、复位等），实现对外设的控制


C 正确：I/O 接口会保存设备的状态信息（如忙 / 闲、是否出错），CPU 可以读取这些状态，判断设备是否就绪或是否发生故障


D 错误：I/O 接口的一个核心功能就是数据缓冲与宽度匹配。主机侧数据宽度通常是 CPU 的字长（如 32/64 位），而设备侧宽度可能是 8 位、16 位等，接口会通过串并转换、缓冲等方式完成不同宽度数据的传输，两者并不总是相同的，本题选 D

II：I/O 过程中错误与状态检测
II：I/O 操作的控制与定时
IV：与主机和外设通信

A.I 和 IV
B.I、III 和 IV
C.I、II 和 IV
D.I、II、III 和 IV

I/O 接口会完成串并转换、数据宽度匹配等工作，解决主机与外设数据格式不一致的问题，I 正确


I/O 接口会记录外设的状态（如忙 / 闲、出错），供 CPU 查询，同时进行错误校验，II 正确


I/O 接口接收 CPU 的控制命令，协调主机与外设之间的时序差异，控制数据传输过程，III 正确


I/O 接口是主机与外设之间的桥梁，负责数据、控制信号和状态信号的双向传输，IV 正确

以下有关 I/O 端口的叙述中，错误的是(   )。

A.I/O 接口中程序可访问的寄存器被称为 I/O 端口
B.I/O 接口中有命令端口、状态端口和数据端口
C.I/O 端口可以和主存统一编号，也可以单独编号
D.I/O 接口中命令端口和状态端口不能共用同一个
A 正确：I/O 端口就是 I/O 接口中可以被 CPU 直接访问的寄存器，用于数据、控制和状态信息的交互，比如下图的数据缓冲寄存器、设备状态寄存器、命令/控制寄存器都是 I/O 端口


B 正确：I/O 接口通常包含三类端口：
  • 数据端口：用于传输设备和主机之间的数据
  • 命令 / 控制端口：CPU 向设备发送控制指令
  • 状态端口：CPU 读取设备的当前状态


C 正确：I/O 端口的编址方式有两种：
  • 统一编址（存储器映射 I/O）：端口地址和主存地址在同一个地址空间，CPU 用访存指令访问端口
  • 独立编址（I/O 映射）：端口地址单独编号，CPU 用专门的 I/O 指令（如 IN/OUT）访问端口

D 错误：命令端口和状态端口可以共用同一个端口地址。CPU 对该端口执行写操作时，数据会被写入命令寄存器；执行读操作时，读取的是状态寄存器的值。这种方式可以节省端口地址资源，是很常见的设计，本题选 D


从功能上来说，状态寄存器和控制/命令寄存器在传送方向上是相反的，而且 CPU 对它们的访问在时间上一般是错开的，因此有的 I/O 接口中将它们合二为一；CPU 在给控制器发送命令时，肯定之前已经知道了接口或者设备的状态了，如果接口或者设备状态是忙的话，那么 CPU 也不能给接口发送命令了

以下有关统一编址方式的描述中，错误的是(   )。

A.I/O 端口地址和主存地址一定不重号
B.CPU 通过执行访存指令来访问 I/O 端口
C.根据指令类型可区分访问主存还是访问 I/O 端口
D.可利用主存的存储保护措施对 I/O 端口进行存储保护

A 正确：统一编址方式下，I/O 端口地址和主存地址共享同一个地址空间，为了避免冲突，两者的地址一定不重号


B 正确：统一编址的核心特点就是 CPU 不需要专门的 I/O 指令，直接使用访存指令（如LOAD/STORE）就可以访问 I/O 端口


C 错误：在统一编址方式下，访问主存和访问 I/O 端口使用的是同一类访存指令，无法通过指令类型来区分两者，只能通过地址范围来判断。只有独立编址方式下，才会通过不同的指令（访存指令 vs IN/OUT 指令）来区分，本题选 C


D 正确：由于 I/O 端口和主存地址在同一空间，因此可以直接复用主存的存储保护措施（如地址越界检查、访问权限控制）来保护 I/O 端口（这里涉及到了操作系统内存管理相关的内容）

下列关于 I/O 端口和接口的说法中，正确的是 ( )。

A.按照不同的数据传送格式，可将接口分为同步传送接口和异步传送接口
B.在统一编址方式下，存储单元和 I/O 设备是靠不同的地址线来区分的
C.在独立编址方式下，存储单元和 I/O 设备是靠不同的地址线来区分的
D.在独立编址方式下，CPU 需要设置专门的输入/输出指令访问端口
A 错误：接口按数据传送格式分为并行接口和串行接口；按传送定时方式才分为同步传送接口和异步传送接口。选项混淆了分类标准

B 错误：统一编址（存储器映射 I/O）下，存储单元和 I/O 设备是靠地址范围来区分的，而不是不同的地址线。地址线是共用的，只是分配的地址空间不同

C 错误：在独立编址方式下，存储单元和 I/O 设备的地址线是完全共用的，区分两者的关键是控制信号，而不是地址线，访问内存时，CPU 会发出 MEMR/MEMW（存储器读 / 写）控制信号；访问 I/O 端口时，CPU 会发出 IOR/IOW（I/O 读 / 写）控制信号，也就是说，同样的地址值，配合不同的控制信号，CPU 就能区分是访问内存还是访问 I/O 设备


D 正确：独立编址方式下，I/O 端口有独立的地址空间，CPU 需要使用专门的输入 / 输出指令（如 x86 的 IN/OUT）来访问端口，这是它和统一编址的核心区别之一

I/O 的编址方式采用统一编址方式时，进行输入/输出的操作的指令是 ( )。

A.控制指令
B.访存指令
C.输入/输出指令
D.都不对

统一编址（存储器映射 I/O）的核心特点是：I/O 端口地址和主存地址共享同一个地址空间，CPU不需要专门的 I/O 指令，直接使用访存指令（如LOAD/STORE）就可以访问 I/O 端口，B 正确，本题选 B


输入 / 输出指令，这是独立编址（I/O 映射）方式下使用的指令，比如 x86 的 IN/OUT 指令，和统一编址无关

下列关于 I/O 指令的说法中，错误的是 ( )。

A.I/O 指令是 CPU 系统指令的一部分
B.I/O 指令是机器指令的一类
C.I/O 指令反映 CPU 和 I/O 设备交换信息的特点
D.I/O 指令的格式和通用指令的格式相同

A 正确：I/O 指令是 CPU 系统指令集的一部分，用于实现输入 / 输出功能，是系统级指令


B 正确：I/O 指令属于机器指令的一类，是 CPU 可以直接执行的指令，例如 x86-64 指令系统的 IN和 OUT 指令


C 正确：I/O 指令的设计就是为了支持 CPU 和 I/O 设备之间的信息交换，反映了这种交互的特点


D 错误：I/O 指令的格式和通用指令（如算术运算、访存指令）不相同。以 x86 为例，IN AL, DX 指令的格式和普通的 ADD AX, BX 等指令格式差异很大，因为它需要专门的端口地址字段来指定 I/O 设备，本题选 D


在内存地址空间与接口地址空间统一编址的计算机中，不需要的指令是 ( )。

A.数据传送类 (如 MOV 指令)
B.算术、逻辑运算类 (如 ADD、SUB、AND 和 OR 指令)
C.输入/输出类 (如 IN 和 OUT 指令)
D.程序控制类 (如条件转移指令和子程序调用指令)

统一编址方式把 I/O 端口当作存储器的单元进行地址分配，CPU 不需要设置专门的 I/O 指令 (即输入/输出类指令)，用统一的访存指令就可以访问 I/O 端口。本题选 C

在统一编址的情况下，就 I/O 设备而言，其对应的 I/O 地址不可取的是 ( )。

A.要求固定在地址高端
B.要求固定在地址低端
C.要求相对固定在地址的某部分
D.可以随意在地址的任何地方

在统一编址（存储器映射 I/O）方式下，I/O 设备的端口地址与主存地址共享同一个地址空间，为了避免与主存地址冲突，I/O 地址不能随意分布在地址空间的任何地方，必须有固定的规划：


A 地址高端：常见做法，把地址空间的高端部分分配给 I/O 设备，不影响主存使用


B 地址低端：也可以，部分系统会把低端地址分配给 I/O（如早期 PC 的 BIOS 数据区）


C 地址的某部分：核心原则，I/O 地址必须在地址空间中划分出固定的区域，不能和主存地址重叠


D 随意在任何地方：不可取，如果 I/O 地址可以随意分布，就会和主存地址冲突，导致 CPU 无法区分访问的是内存还是 I/O 设备

【2014 第 21 题】下列有关 I/O 接口的叙述中，错误的是（ ）

A.状态端口和控制端口可以合用同一个寄存器
B.I/O 接口中 CPU 可访问的寄存器称为 I/O 端口
C.采用独立编址方式时，I/O 端口地址和主存地址可能相同
D.采用统一编址方式时，CPU 不能用访存指令访问 I/O 端口
首先，你得明白 I/O 端口和 I/O 接口的区别，如下图：

I/O 接口是 I/O 设备和主机通信的桥梁，而 I/O 端口就是 I/O 接口中的寄存器，比如上图中，打印机和磁盘都有对应的 I/O 接口，在 I/O 接口中，都有 3 个寄存器，因此上图有 2 个 I/O 接口，每个 I/O 接口有 3 个 I/O 端口，CPU 可以直接访问这些 I/O 端口

因此，I/O 接口中 CPU 可访问的寄存器称为 I/O 端口，选项 B 描述正确

从功能上来说，状态寄存器和控制寄存器在传送方向上是相反的，而且 CPU 对它们的访问在时间上一般是错开的，比如，CPU 在给控制器发送命令时，肯定之前已经知道了接口或者设备的状态了，如果接口或者设备状态是忙的话，那么 CPU 也不能给接口发送命令了，因此有的 I/O 接口中将它们合二为一，因此选项 A 描述正确

对 I/O 端口，采用独立编址方式时，I/O 端口地址和主存地址位于不同的地址空间，因此I/O 端口地址和主存地址可能相同，所以选项 C 描述正确

对 I/O 端口，采用统一编址方式时，I/O 端口地址和主存地址统一使用相同的地址空间，那么 CPU 如何访问主存，那么 CPU 就可以如何访问 I/O 端口，因此采用统一编址方式时，CPU 就可以用访存指令访问 I/O 端口，选项 D 描述错误，选 D
