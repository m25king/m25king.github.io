第一条指令就是将 result 的值 1 放到 eax 寄存器，然后直接执行循环体，先执行一个乘法操作 imul rax, rdi，这里的 rax 寄存器一开始存储的是 result 对应的 1，它和 eax 是同一个寄存器，只不过 eax 是 rax 的低 32 位而已，再执行一个减法操作 sub rdi, 1，再来判断循环条件，执行比较指令 cmp rdi, 1，就是比较 n 和 1 的值，如果 n 大于 1，就跳转 .L5 继续执行循环体，jg 指令看的是 SF、OF 和 ZF 这三个标志位（jg 是 jump if great 的缩写，大于就跳转指令，判断 ~(SF ^ OF) & ~ZF 是否等于 1）
do while 对应的汇编代码格式可以看成是这样的：先执行循环体，然后再判断，确定要不要继续执行循环体，所以循环体至少会被执行一次

while 循环

根据不同的优化级别，while 循环可以翻译成两种不同形式的汇编代码格式，下面是在优化级别为 -Og 下得到的：

首先第一条指令 mov eax,1 将 result 的初始值 1 放到 eax 中，然后第二条指令 jmp .L2 无条件的跳转到 cmp rdi, 1 指令，比较 n 和 1，然后跳转指令 jg .L3 判断如果 n 大于 1，则跳转到循环体对应的指令，先执行乘法，再执行减法，然后再进行比较 n 和 1，如果 n 大于 1 的话，则又去执行循环体，否则的话，直接退出循环体
这个汇编代码格式就是这样的：一上来一条无条件跳转到循环条件判断，然后判断要不要执行循环体，要的话则跳到 loop 执行循环体
再来看在优化级别为 O1 的情况下，上面求 n 阶乘的代码对应的汇编代码：

一上来就通过指令 cmp rdi, 1 比较 n 和 1，然后执行 jle .L4 指令，判断如果 n <= 1 的话，直接跳转到 .L4 返回值为 1 的 result，函数结束（ jle：jump less equal 的缩写，小于等于就跳转指令，判断 (SF ^ OF) | ZF = 1），否则的话执行第三条 mov eax, 1 指令，将 result 的初始值 1 放到 eax 中，然后执行循环体中的乘法和减法两条指令，接下来再通过 cmp rdi, 1 比较 n 和 1，然后执行 jne .L3 指令，判断如果 n != 1 则跳转到 .L3 继续执行循环体（jne：jump not equal 的缩写，不等于就跳转指令，判断 ~ZF = 1），如如果 n == 1 的话，则退出循环体，返回函数
这种 while 循环的汇编代码格式是这样的：先进行判断，如果不符合循环条件，直接不执行循环体，否则，先执行一次循环体，然后再次判断条件，决定是否要执行循环体

for 循环语句

任何的 for 循环代码，都是可以翻译成对应的 while 循环的，所以，在 x86-64 中，for 循环的汇编代码都翻译成 while 循环对应的两种汇编代码格式，具体翻译成哪一种 while 汇编代码格式，取决于编译优化等级了，比如下面使用 for 循环求 n 的阶乘：

再来看这段 for 代码，求一个数组中所有元素之和，数组 arr 基地址放在 rdi 寄存器，参数 n 放在 esi 寄存器中，优化级别为 -O1，其对应的汇编格式是先进行判断，如果不符合循环条件，直接不执行循环体，否则，先执行一次循环体，然后再次判断条件，决定是否要执行循环体：

其对应的汇编代码如下图，一上来使用 test esi, esi 判断 n 的值是不是小于等于 0，我们知道，test 指令通过将 esi 的值和 esi 的值取与（and），来设置 ZF 用于表示结果是不是 0、SF 用于标志结果是正数还是负数、OF 恒为 0，也就是不会溢出
接下来使用 jle 指令判断 (SF ^ OF) | ZF = 1 来确定 n 是不是小于等于 0，首先 OF 恒为 0，如果 SF 等于 1，也就是 esi 的值是负数，那么 SF 和 OF 异或结果是 1，说明 esi 的值小于 0，如果 SF 的值是 0 的话，再看 ZF，如果 ZF 等于 0 的话，说明 esi 的值等于 0；如果 n <= 0 的话，则不用执行循环体，直接跳转到 0x400508 处的指令 mov eax, 0x0，然后执行 ret，就是函数返回，返回结果 0 放在 eax 寄存器

如果 n > 0 的话，就可以执行循环体了，不过先执行第三条指令将 i 的初始值 0 放到 edx 寄存器，第四条指令将 res 的初始值 0 放到 eax 寄存器，接下来开始执行循环体 res += arr[i]，对应上图第 (5) 条指令 add eax, DWORD PTR [rdi + rdx * 4]，先计算 arr[i] 的内存地址 = 数组 arr 基地址 + i * 每个元素大小 = rdi + rdx * 4（i 变量存放在 eax 中，也就是 rdx 中，因为 eax 是 rdx 的低 32 位），然后将 arr[i] 的值累加到 eax （即 res 变量）上，接下来第 (6) 条指令完成 i++
循环体执行完成后，执行第 (7) 条指令 cmp esi, edx 比较 esi 中的值 n 和 edx 中的值 i 的大小，第 (8) 条指令 jg 0x4004fb 判断 n > i 的话，则跳转到执行内存地址为 0x4004fb 的指令（上图第 5 条指令），即执行循环体，否则 n <= i 的话，则直接返回，结果放在 eax 寄存器中
