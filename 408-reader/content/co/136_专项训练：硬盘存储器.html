若磁盘的转速提高一倍，则 ( )。

A.平均寻道时间减少一半
B.存取速度也提高一倍
C.平均旋转延迟时间减少一半
D.不影响磁盘传输速率

平均寻道时间是磁头移动到目标磁道的时间，和磁盘转速无关，只与磁头的机械移动速度有关，A 错误


存取速度受寻道时间、旋转延迟、传输时间共同影响，转速提高只能减少旋转延迟，无法让整体存取速度直接翻倍，B 错误


最大旋转时间（以秒为单位）= (1 / RMP) × (60s / 1min)，那么平均旋转时间就是最大旋转时间的一半，平均旋转时间和转速 RMP 成反比，转速提高一倍，平均旋转延迟就会减少一半，C 正确，本题选 C


磁盘数据传输率 = 一个磁道的容量 / 盘面旋转一圈的时间，= （磁道扇区数 * 扇区大小）/ （(1 / 磁盘旋转速度) * 60s），因此磁盘传输速率（单位时间读取的数据量）和转速成正比，转速提高一倍，传输速率也会提高一倍，D 错误



假定一个磁盘的转速为 7200RPM (转/分)，磁盘的平均寻道时间为 20ms，平均数据传输率为 1MB/s，不考虑排队等待时间，那么读一个 512B 的扇区的平均存取时间大约为 (   )。

A.14.7ms
B.18.8ms
C.24.7ms
D.28.8ms

平均旋转时间 = 60s / (7200 * 2) = 1s / 240 ≈ 4.17ms


一个扇区的传输时间 = 扇区大小 / 平均数据传输率 = 512B / 1MB/s = 512s / 1000000 = 0.512ms


所以，平均存取时间 = 平均寻道时间 + 平均旋转时间 + 一个扇区的传输时间 ≈ 20ms + 4.17ms + 0.512ms ≈ 24.7ms，本题选 C

某磁盘盘面共有 200 个磁道，盘面总存储容量为 60MB，磁盘旋转一周的时间为 25ms，每个磁道有 8 个扇区，各扇区之间有一间隙，磁头通过每个间隙需 1.25ms。则磁盘接口所需的最大传输速率是 ( )。

A.10MB/s
B.60MB/s
C.83.3MB/s
D.20MB/s

每个磁道的容量 = 60MB / 200 = 0.3MB，读一个磁道数据的时间等于磁盘旋转一周的时间减去通过扇区间隙的总时间 (每个磁道有 8 个间隙)，即 25ms - 1.25ms × 8 = 15ms，数据传输速率 = 0.3MB / 15ms = 20MB/s。本题选 D

下列关于固态硬盘 (SSD) 的说法中，错误的是 ( )。

A.基于闪存的存储技术
B.随机读/写性能明显高于磁盘
C.随机写比较慢
D.读/写速度快，常用作主存
固态硬盘基于闪存技术，没有机械部件，随机读/写不需要机械操作，因此速度明显高于磁盘，A 和 B 正确

SSD 写入前需要先擦除旧数据（擦除以块为单位，写入以页为单位），因此随机写入速度通常比读取慢很多，C 正确

SSD 读写速度远快于机械硬盘，但远低于主存（内存）的速度，且不具备断电数据易失性、随机访问延迟低等主存的关键特性，因此不能用作主存，通常作为外存使用，D 错误，本题选 D

下列关于固态硬盘的说法中，正确的是 ( )。

A.固态硬盘的写速度比较慢，性能甚至弱于机械硬盘
B.相比机械硬盘，固态硬盘优势主要体现在连续存取的速度
C.静态磨损均衡算法通常比动态磨损均衡算法的表现更优秀
D.写入时，静态磨损均衡算法每次选择使用长期存放数据而很少擦写的存储块
固态硬盘（SSD）的读写速度整体远快于机械硬盘（HDD），即使是随机写入性能，也普遍优于常规机械硬盘，A 错误

SSD 的最大优势体现在随机存取速度（没有机械寻道和旋转延迟），而不是连续存取速度；高端机械硬盘的连续读写速度也能达到较高水平（机械磁盘连续读的话，其寻道时间和旋转时间很少的），和入门级 SSD 差距不大，B 错误


为了弥补 SSD 的寿命缺陷，引入磨损均衡，这个功能是在硬盘控制器实现的，磨损均衡分为两种，一种是动态磨损均衡：写入数据时，自动选择较新的闪存块，老的闪存块先歇一歇；另一种是更先进的静态磨损均衡，就算没有数据写入，SSD 也会检测并自动进行数据分配，让老的闪存块承担无须写数据的存储任务，同时让新的闪存块腾出空间，平常的写操作在较新的闪存块中进行，这样的话，各个闪存块的寿命损耗就差不多了


可以看出，静态磨损均衡算法通常比动态磨损均衡算法的表现更优秀，C 正确，D 错误，本题选 C

【2013 第 20 题】下列选项中，用于提高 RAID 可靠性的措施有（ ）
I：磁盘镜像
II：条带化
III：奇偶校验
IV：增加 Cache 机制

A.仅 I，II
B.仅 I，III
C.仅I，III 和 IV
D.仅 III 和 IV
注意审题：题目问的是提高 RAID 的可靠性，所谓可靠性就是数据会不会丢失，丢失后能不能找回来

磁盘镜像：将一个磁盘块的数据存放在一个磁盘上的同时，将其冗余存储在另一个磁盘中，当一个磁盘坏了，可以用另一个磁盘中的数据，这提高了 RAID 的可靠性，比如磁盘 RAID 1 就采用了磁盘镜像技术

条带化：是一种将数据均匀分布在多个磁盘上的技术，就是把数据分割成小块并分别存储在不同磁盘的相同位置，可以提高 RAID 的存储容量和读写性能（RAID 0 就是用了条带化技术），但是不能提高 RAID 的可靠性，因为数据分割成小块并分别存储在不同磁盘，如果某个磁盘坏了，那么存放在这个磁盘上的数据就丢失了

奇偶校验：当一个数据块坏了，可以通过奇偶检验恢复出这个坏的数据块，因此可以提高 RAID 的可靠性，比如 RAID 5

增加 Cache 机制：读写数据，都是先读写 Cache，未命中，就读写 RAID 磁盘，可以提高 RAID 的读写性能，但是，如果没有采用镜像技术的话，也不能提高 RAID 的可靠性

所以说，可以提供 RAID 可靠性的有磁盘镜像和奇偶检验，其他两个不能提高可靠性，因此选 B

【2013 第 21 题】某磁盘的转速为 10000 rpm，平均寻道时间是 6ms，磁盘传输速率是 20MB/s，磁盘控制器延迟为 0.2ms，读取一个 4KB 的扇区所需的平均时间约为（ ）

A.9ms
B.9.4ms
C.12ms
D.12.4ms

记住公式：平均存取时间 =  平均寻道时间 + 平均旋转等待时间 + 数据传输时间 + 磁盘控制器延迟（这题还有一个磁盘控制器延迟）


一般平均寻道时间题目会告诉你，这里是 6ms


而平均旋转等待时间等于旋转一周需要的时间的一半，磁盘转速是 10000rpm，旋转一周需要的时间 = (1 / RPM) * (60s / 1min) = 60s / 10000 = 6ms，所以平均旋转等待时间 = 3ms


数据传输时间 = 需要传输的数据大小 / 数据传输率 = 4KB / (20MB/s) = (4 × 10^3) / (20 × 10^6) = 0.2ms


所以平均存取时间 =  平均寻道时间 + 平均旋转等待时间 + 数据传输时间 + 磁盘控制器延迟 = 6ms + 3ms + 0.2ms + 0.2ms = 9.4ms，选 B

【2015 第 20 题】若磁盘转速为 7200rpm，平均寻道时间为 8ms，每个磁道包含 1000 个扇区，则访问一个扇区的平均存取时间大约是（ ）

A.8.1ms
B.12.2ms
C.16.3ms
D.20.5ms
记住公式：平均存取时间 =  平均寻道时间 + 平均旋转等待时间 + 数据传输时间

一般平均寻道时间题目会告诉你，这里是 8ms

而平均旋转等待时间等于旋转一周需要的时间的一半，磁盘转速是 7200rpm，旋转一周需要的时间 = (1 / RPM) * (60s / 1min) = 60s / 7200 ≈ 8.3333ms，所以平均旋转等待时间 ≈ 4.17ms

磁盘寻转一圈需要的时间是 60s / 7200，而一圈（即每个磁道）有 1000 个扇区，所以传输一个扇区的时间是 (60s / 7200) / 1000 ≈ 0.008ms

所以平均存取时间 =  平均寻道时间 + 平均旋转等待时间 + 数据传输时间 + 磁盘控制器延迟 = 8ms + 4.17ms + 0.008ms ≈ 12.2ms，选 B


从这里，可以看出，计算一个扇区数据传输时间有两种方式：

  1. 一种就是我们在视频 【磁盘的平均存取时间】中讲解的，一个扇区数据传输时间 = 一个扇区的容量大小 / 数据传输率

  2. 另一种就是这题中用到的，一个扇区数据传输时间 = 旋转一圈需要的时间 / 一个磁道的扇区数；就是一个扇区划过磁头下方所需要的时间

具体要用哪一种方式，就看题目要求，题目如果告诉你数据传输率，那么一般使用第一种方法，否则使用第二种方式
