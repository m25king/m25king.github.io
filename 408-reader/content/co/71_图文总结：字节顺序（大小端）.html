计算机中许多类型数据由多个字节组成，比如 int 和 float 类型变量占 4 字节，double 类型变量占 8 字节
对于这种多字节变量都被存储为连续的字节序列，现在的机器基本都采用按字节编址（一个字节一个地址），那么多字节变量的地址就是字节序列中最小的那个地址
比如，一个类型为 int 的变量 x 的地址为 0x100，也就是说地址表达式 &x 的值为 0x100，那么 x 的 4 个字节被存储在内存的 0x100、0x101、0x102 和 0x103 的位置上
现在假设变量 x 的十六进制值是 0x01234567，包含了 4 个字节，分别是 0x01、0x23、0x45、0x67，其中最左边的字节 0x01 是最高有效字节（Most Significant Byte，MSB），最右边的字节 0x67 是最低有效字节（Least Significant Byte，LSB）
根据各字节在连续存储单元中排列顺序的不同，有两种字节顺序：大端（big endian）和小端（little endian），看下图：

大端方式将数据的最高有效字节 MSB 存放在低地址单元中，即数据的地址就是 MSB 所在的地址，比如变量 x 的最高有效字节是 0x01，它的地址是低地址 0x100，这个地址也是变量 x 的地址
小端方式将数据的最低有效字节 LSB 存放在低地址单元中，即数据的地址就是 LSB 所在的地址，比如变量 x 的最低有效字节是 0x67，它的地址是低地址 0x100，这个地址也是变量 x 的地址
具体是用大端序存储还是小端序存储，这个要看，不同的机器有不同的存储方式
比如 IBM 360/370、Motorola 68000、MIPS、SPARC、HP PA 等机器都采用大端方式；Intel 80x86、DEC VAX 等都采用小端方式
而且这两种方式没有好坏之分，取决于设计系统的人员选择而已，如果非要比较它俩的优缺点

请问，这台机器采用大端序还是小端序来存储数据的？
因为 12345 = 8192 + 4096 + 32 + 16 + 8 + 1 = 2^13 + 2^12 + 2^5 + 2^4 + 2^3 + 2^0，因此 x 的 32 位补码是 0000 0000 0000 0000 0011 0000 0011 1001 = 00003039H
可以看到，其最低有效字节 39H 存储在低地址 8000H 上，所以，这台机器采用的是小端序

因此浮点数 x 的单精度浮点编码是 0100 0110 0100 0000 1110 0100 0000 0000 = 4640e400H
可以看到，最高有效字节 46H 存储在低地址 8000H 上，所以，这台机器采用大端序存储数据
