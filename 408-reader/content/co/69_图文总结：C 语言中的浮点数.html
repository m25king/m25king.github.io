在 C 语言中，有 float 和 double 两种不同浮点数类型，分别对应着 IEEE 754 的单精度浮点数格式，和双精度浮点数格式
接下来，我们主要关心 int、float、double 之间的强制类型转换
① int 转换为 float 时，int 是 32 位，采用补码表示，它能表示的数据范围是 -2^31 到 2^31 - 1，而 float 也是 32 位，采用单精度浮点数表示，它能表示的范围比 int 型表示范围大很多
所以 int 转 float 时是不会溢出，所谓溢出就是要表示的数据大小超过了表示范围，你看不管是哪个 int 的值，都不会超过 float 的表示范围，所以 int 转 float 时，不会溢出，但是有可能有数据被舍入

但是 float 的精度没有 int 高，这里说的精度就是指有效位数，int 的有效位数是 31 位，而 float 的有效位数只有 24 位
思考一个问题：一个十进制的 int 整数，具体多少位时，转换成 float 时会发生数据舍入呢？
因为 float 类型的尾数有效位是 24 位（包括 1 位隐藏位 1），因此一个十进制的 int 整数对应 32 位补码的有效位如果超过了 24 位的话，转换成 float 时就会发生数据舍入
而一个 24 位有效位的 int 整数，可以表示的最大整数是 2^25 - 1，这个最大整数对应 7 位的十进制数（log10(2^25 - 1) = 7.525），因此，当 int 十进制整数超过 7 位的话，转换成 float 类型时就会发生数据舍入

① i == (int) (float) i; 因为 int 可以表示 32 位的有效数据，而 float 只有 24 位有效的尾数，因此 int 的精度比 float 要高，所以当 i 转换为 float 后再到 int 时，有效位数可能丢失，所以 false

④ f == (float) (double) f;  double 比 float 有更大的精度和范围，当 f 转为 double 后再到 float 时数值不变。因此为 true
