总线结构的核心优势是共享传输线路，多个设备共用一组总线，因此减少了信息传输线的条数，硬件更简洁、扩展更方便


A 错误：总线结构不减少信息传输量，只是共享线路


B 错误：总线共享会带来竞争，不一定提高传输速度（甚至可能因等待降低速度）


C 正确：共用总线减少信号线数量，是总线结构的关键优点，本题选 C


D 错误：总线通常是分时复用，同一时刻只能一个主设备使用，降低了并行性

C.可同时向总线发送数据，并同时从总线接收数据
D.可同时向总线发送数据，但只能分时从总线接收数据

总线的主要缺点是它可能产生通信瓶颈，因为当多个部件与总线相连时，如果出现了两个或两个以上部件同时向总线发送信息时，势必会导致信号冲突，使得传输无效


所以在两个或两个以上部件同时向总线发送信息之前，需要进行总线仲裁，仲裁逻辑按照一定的优先级顺序确定哪个部件可以使用总线，只有获得总线的控制权的部件，才可以开始和从设备通信


这样就可以保证，在某一时刻，只允许有一个部件向总线发送信息，不过，在总线上多个部件可以同时从总线上接收相同的信息


因此，系统总线采用分时复用机制，同一时刻总线上只能有一个设备发送数据（避免冲突），但多个设备可以同时从总线上接收数据，本题选 B



在总线上，同一时刻 ( )。

A.只能有一个主设备控制总线传输操作
B.只能有一个从设备控制总线传输操作
C.只能有一个主设备和一个从设备控制总线传输操作
D.可以有多个主设备控制总线传输操作

总线采用分时复用机制，同一时刻只能有一个主设备控制总线并发起传输操作，避免多个主设备同时驱动总线导致信号冲突；从设备只能被动响应，不具备控制总线的能力

地址总线仅传输地址，告诉系统 "要访问的是哪个内存单元 / 外设接口中的哪个寄存器"，但无法决定该设备是否响应、何时响应，这个必须靠控制总线的信号来 “激活” 该设备，让它参与传输

主存通过 ( ) 来识别信息是地址还是数据

A.总线的类型
B.存储器数据寄存器 (MDR)
C.存储器地址寄存器 (MAR)
D.控制单元 (CU)
主存通过总线的类型（地址总线、数据总线、控制总线）来区分信息是地址还是数据：
  • 地址总线：传输的是主存单元或 I/O 设备的地址信息，主存据此定位存储单元
  • 数据总线：传输的是存储单元中的数据 / 指令信息，主存据此进行读写操作
  • 控制总线：配合地址 / 数据总线，传递读 / 写等控制信号，辅助主存识别操作类型

B 选项（MDR）：存储器数据寄存器，仅暂存数据，它只是被动接收数据总线传来的数据，本身没有 “识别” 能力


C 选项（MAR）：存储器地址寄存器，仅暂存地址，它只是被动接收地址总线传来的地址，本身没有 “识别” 能力


CPU 要读主存某单元：先通过地址总线发地址 → 主存识别是地址 → 把地址存入 MAR；再通过控制总线发 "读命令" → 主存从对应单元取数据 → 通过数据总线发数据 → 主存识别是数据 → 把数据存入 MDR


整个过程中，总线类型完成 "识别"，MAR/MDR 只是 "存结果"


D 选项（CU）：控制单元，是 CPU 的部件，不直接参与主存对地址 / 数据的识别

你看主存间接寻址访问操作数的话，需要访问内存两次，第一次是将指令中的地址码（0x12345678）通过地址总线传输给主存，然后主存将地址为 0x12345678 对应的存储单元中的操作数的有效地址（0x12345558）通过数据总线传送给 CPU


地址总线是用于 CPU 选择主存单元地址和 I/O 端口地址的单向总线，不能回传（即不能从主存传输到 CPU），所以从主存中传输地址或者数据给 CPU 的话，只能是通过数据总线了


所以，主存间址寻址第一次访问内存所得到的信息（即操作数的有效内存地址）经系统总线的数据线传送到 CPU，本题选 A


当 CPU 拿到操作数的有效内存地址 0x12345558 后，会通过地址总线，将这个内存地址 0x12345558 传送到主存，然后主存将地址为 0x12345558 对应的存储单元中的操作数通过数据总线传送给 CPU，这个是第二次访问内存

控制总线的核心是传输控制信号、时序信号、状态 / 响应信号，不传输地址信息

I 错误：存储器和 I/O 设备的地址码由地址总线传输，不属于控制总线

II 正确：所有存储器和 I/O 设备的时序信号与控制信号（如读 / 写、片选、时钟等），是控制总线的核心内容

III 正确：来自 I/O 设备和存储器的响应信号（如就绪、忙、中断、应答等），通过控制总线反向传输给 CPU

本题选 B

控制线用来控制对数据线和地址线的访问和使用


由于数据线、地址线都是被挂在总线上的所有部件共享的，如何使各部件能在不同时刻占有总线使用权，需依靠控制线来完成，因此控制线是用来发出各种控制信号的传输线

通常对任一控制线而言，它的传输是单向的。例如，存储器读/写命令或 I/O 设备读/写命令都是由 CPU 发出的


但对于控制线总体来说，又可认为是双向的。例如，当某设备准备就绪时，便向 CPU 发中断请求；当某部件 (如 DMA 接口) 需获得总线使用权时，也向 CPU 发出总线请求

此外，控制线还起到监视各部件状态的作用。例如，查询该设备是处于“忙”还是“闲”，是否出错等。因此对 CPU 而言，控制信号既有输出，又有输入
常见的控制信号如下：
  • 时钟：用来同步各种操作
  • 复位：初始化所有部件
  • 总线请求：表示某部件需获得总线使用权
  • 总线允许：表示需要获得总线使用权的部件已获得了控制权
  • 中断请求：表示某部件提出中断请求
  • 中断响应：表示中断请求已被接收
  • 存储器写：将数据总线上的数据写至存储器的指定地址单元内
  • 存储器读：将指定存储单元中的数据读到数据总线上
  • I/O读：从指定的I/O端口将数据读到数据总线上
  • I/O写：将数据总线上的数据输出到指定的I/O端口内
  • 传输响应：表示数据已被接收，或已将数据送至数据总线上

总线复用方式可以( )

A.更快地传递信息和数据

总线复用（分时复用）的核心是用同一组总线线路，在不同时间段传输不同类型的信息（地址、数据、控制），从而减少总线中信号线的数量，降低硬件成本与复杂度


A 错误：复用是分时传输，速度不会更快，反而可能因分时略有延迟


B 错误：复用是分时传送，同一时刻只能传一种信息，不能同时传地址和数据


C 正确：复用减少了物理信号线数量，是其主要优势，本题选 C


D 错误：复用不直接增加总线功能，可靠性也并非其核心目标
