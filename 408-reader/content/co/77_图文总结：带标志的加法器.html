看下图 8 位加法器内部电路图，在做加减法运算过程中，会产生一些标志：

①  零标志 ZF，用于表示加减法的结果是否是 0，可以对所有的本位和进行或非，就可以得到零标志的值，如果 ZF = 1，表示结果为 0，这个零标志可以用于比较两个数的大小，可以将两个数进行相减，比如 A - B ，如果零标志位 ZF = 1 的话，那就说明 A 是等于 B 的
② 符号标志 SF，他其实就是结果和 F 的最高位，如果 SF = 0 表示结果是正数，如果 SF = 1，表示结果是负数，很明显，对于无符号位数的加减，这个符号标志没有任何意义，所以符号标志只在有符号数加减时才有意义
③ 进位/借位标志 CF，表示无符号数加减运算时的借/进位，加法时，若 CF = 1 则表示无符号加法溢出；减法时，若 CF = 1 则表示有借位，即不够减，CF = Cin ^ Cout（稍后来解释）
④ 溢出标志 OF，表示带符号整数加减运算时是否溢出，如果 OF = 1 表示带符号整数加减运算时结果发生了溢出，OF 等于符号位产生的进位 Cout 和最高数值位产生的进位 Cn-1 的异或值（即 OF = Cn ^ Cn-1）（稍后来解释）
接下来，我们分别详细介绍 CF 和 OF 两个标志

进位/借位标志 CF

要彻底理解 CF 标志，我们需要先理解无符号加法溢出，考虑两个 w 位的非负整数 x 和 y，它们的范围都是在 0 ~ 2^w - 1，那么 x + y 的范围就是 0 ~ 2^(w+1) - 2，表示这个和可能需要 w + 1 位
假设无符号整数 x 和 y 使用 4 位表示，那么它们的取值范围就是 0 ~ 15，x + y 的和的范围就是 0 ~ 30，而要表示 30 这个无符号整数的话，需要 5 位
比如现在 x = 9、y = 12，其 4 位无符号编码分别是 1001 和 1100，x + y = 21，其无符号编码是 10101，但是现在机器字长是 4 位，那么就需要丢弃最高位，得到 x + y = 0101 = 5，很明显结果不对，这种情况就是发生溢出
而通过 CF 标志就可以检测出无符号加法是否发生了溢出，当进行无符号加法时，如果 CF = 1 ，说明发生了溢出，看下图：
上面 4 位无符号加法，13 + 11 = 8，很明显发生溢出，此时，最高位有进位 Cout = 1，因为是做加法，所以 Cin = 0，此时的 CF 值就是 1，表明无符号加法发生溢出，也就是说，如果做加法时（Cin = 0），最高位又产生了进位（Cout = 1），那么 CF = 1，即 CF = Cin ^ Cout
再比如上面的 5 + 3 = 8，没有发生溢出，此时做加法（Cin = 0），但是最高位没有进位（Cout = 0），那么 CF = Cin ^ Cout = 0，即没有发生溢出
理解了通过进位 CF 标志可以判断无符号加法是否溢出后，再来理解通过借位 CF 标志可以判断无符号减法是否够减，比如来看 4 位无符号减法：3 - 8

3 的无符号编码 0011 输入 X 端，8 的无符号编码 1000 输入 Y 端，因为做减法，所以控制信号 Sub = 1，低位进位 Cin 也是等于 1，对于 Y 输入端，选择 Y 的取反（即 0111）送到加法器，X 和 Y' 做加法后得到结果 F = 1011，最高位进位 Cout = 0，此时 CF = Cin ^ Cout = 1 ^ 0 = 1，说明需要借位（即不够减），得到的结果 1011 解释成无符号整数的话就是 11，即 3 - 8 = 11，很明显不对，就是因为不够减
其实，我们从两个无符号编码就可以看出是否够减，上面的是 0011 - 1000，很明显是不够减的，因此 CF 肯定等于 1
再来看无符号减法 8 - 3：

8 的无符号编码 1000 输入 X 端，3 的无符号编码 0011 输入 Y 端，因为做减法，所以控制信号 Sub = 1，低位进位 Cin 也是等于 1，对于 Y 输入端，选择 Y 的取反（即 1100）送到加法器，X 和 Y' 做加法后得到结果 F = 0101，最高位进位 Cout = 1，此时 CF = Cin ^ Cout = 1 ^ 1 = 0，说明不需要借位（即够减），得到的结果 0101 解释成无符号整数的话就是 5，即 8 - 3 = 5，这个结果是对的
其实，我们从两个无符号编码就可以看出是否够减，上面的是 1000 - 0011，很明显是够减的，因此 CF 肯定等于 0
总结：进位/借位标志 CF = Cin ^ Cout，如果是无符号加法的话，用于判断是否有进位（即是否溢出），如果 CF = 1 表示有进位（即有溢出），CF = 0，表示无进位（无溢出）；如果是无符号减法的话，用于判断是否需要借位（即是否够减），如果 CF = 1 的话，表示需要借位（即不够减），CF = 0 表示不需要借位（即够减）

溢出标志 OF

对于无符号加法溢出的判断可以使用 CF 标志，而对于有符号加减运算的溢出判断要用到溢出标志 OF，溢出标志 OF = 1 表示有符号整数运算时结果发生了溢出，OF 等于符号位产生的进位 Cout 和最高数值位产生的进位 Cn-1 的异或值（即 OF = Cn ^ Cn-1）
要理解 OF 标志，我们需要先理解补码加减法溢出问题，假设两个 w 位补码表示的整数 x 和 y，它们的取值范围是 -2^(w-1) ~ 2^(w - 1) - 1，那么：
  • 如果 x + y ≥ 2^(w - 1)，那么发生正溢出，此时需要 w + 1 位表示 x + y，所以会丢弃最高位（即最高位溢出）
  • 如果 -2^(w-1) ≤ x + y ≤ 2^(w - 1) - 1，那么正常，不会溢出
  • 如果 x + y < -2^(w - 1)，那么发生负溢出，此时需要 w + 1 位表示 x + y，所以会丢弃最高位（即最高位溢出）
比如现在进行 4 位补码的加减法，4 位补码可以表示的整数范围是 -8 ~ 7，如果加减的结果超过了这个范围，则溢出，先来看 -7 - 6 ，如果我们人类来算的话，其结果就是 -13，小于 -8，所以负溢出，而 -13 = -16 + 2 + 1，所以 -13 的补码编码是 10011（需要 5 位补码表示），丢弃最高位的 1，得到 0011，即 -7 - 6 = 3，再来看下面的加法器计算 -7 - 6 的步骤：

-7 的补码 1001 输入 X 端，6 的补码 0110 输入 Y 端，因为做减法，所以控制信号 Sub = 1，低位进位 Cin 也是等于 1，对于 Y 输入端，选择 Y 的取反（即 1001）送到加法器，X 和 Y' 做加法后得到结果 F = 0011，最高位进位 Cout = 1，此时 OF = C3 ^ Cout = 0 ^ 1 = 1，表示溢出了，这里的 C3 就是第 3 位（即最高数值位）相加的进位
再来看加法器计算 -3 - 5 的步骤：

-3 的补码 1101 输入 X 端，5 的补码 0101 输入 Y 端，因为做减法，所以控制信号 Sub = 1，低位进位 Cin 也是等于 1，对于 Y 输入端，选择 Y 的取反（即 1010）送到加法器，X 和 Y' 做加法后得到结果 F = 1000，最高位进位 Cout = 1，此时 OF = C3 ^ Cout = 1 ^ 1 = 0，表示未溢出了，结果 1000 是 -8 的补码表示，这里 -3 - 5 = -8 结果正确，没有溢出
再来看 3 + 6 和 3 + 4，加法很简单，只需要将其补码相加：

对于 3 + 6，人类计算的话，其值是 9 > 7，发生了正溢出，加法器计算的话，首先 Cin = 0，然后 3 和 6 的补码直接送到加法器中，得到结果 F = 1001，最高符号位进位 Cout = 0，此时 OF = C3 ^ Cout = 0 ^ 1 = 1，表示溢出了
对于 3 + 4，人类计算的话，其值是 7 = 7，没有发生溢出，加法器计算的话，首先 Cin = 0，然后 3 和 4 的补码直接送到加法器中，得到结果 F = 0111，最高符号位进位 Cout = 0，此时 OF = C3 ^ Cout = 0 ^ 0 = 0，表示未溢出
总结：假设 n 位补码进行加减，其溢出标识 OF = 最高数值位的进位异或符号位的进位的 = Cn-1 ^ Cout = Cn-1 ^ Cn；当 OF = 1 表示补码加减运算发生溢出，当 OF = 0 表示补码加减运算未发生溢出

CF 和 OF

从上面看，对于无符号数运算的话，SF 和 OF 都是没有意义的，因为无符号数是没有符号位的，其次我们不能通过 OF 标志来判断无符号数运算是否溢出；对于带符号整数运算（补码运算），CF 没有意义，我们不能通过 CF 标志来判断补码运算是否溢出
不过，我们需要注意的是，在加法器中，不管是执行一次无符号加减运算，还是执行一次补码加减运算，都会通过下面的硬件计算产生 ZF、SF、CF 和 OF 这 4 个标志信息：

带标志的加法器

到现在为止，零标志、符号标志、进位借位标志、溢出标志都已经讲完了，我们可以讲加法器看成一个黑盒：

它有两个输入 X 和 Y，为了使用加法实现减法，需要用一个反相器和二路选择器，同时控制器输出是减法还是加法的控制信号，同时作为 Cin 输入到加法器中
加法器的输出出了和结果、高位进位之外，还会输出四个标志，零标志 ZF、符号标志 SF、进位借位标志 CF 以及溢出标志 OF
这些标志信息一般暂存在标记寄存器中，这个标志寄存器也可以称为程序状态字寄存器，简称 PSW，也可以称为条件码寄存器，之所以称为条件码寄存器，是因为可以使用这些标志信息作为条件，来判断两个整数的大小，我们稍后再说这个
