分层的多总线结构

下图是单总线结构的示意，它是将CPU、主存、I/O 设备 (通过 I/O 接口) 都挂在一组总线上，允许 I/O 设备之间、I/O 设备与 CPU 之间或 I/O 设备与主存之间直接交换信息

优点：结构简单，成本低，易于接入新的设备。缺点：带宽低、负载重，多个部件只能争用唯一的总线，且不支持并发传送操作

但是，当设备越来越多的时候，我们需要分层的多总线结构

总线分层的原则：速度差异较大的设备模块使用不同速度的总线，而速度相近的设备模块使用同一类总线，而且速度越快的设备越接近 CPU 处理器

所以，我们把主存储器通过存储器总线直接和 CPU 相连，而速度比较慢的 I/O 设备挂在第二层的 I/O 总线上，这样就得到了双总线结构，如下图：

图中通道是一个具有特殊功能的处理器，CPU 将一部分功能下放给通道，使其对 I/O 设备具有统一管理的功能，以完成外部设备与主存储器之间的数据传送，其系统的吞吐能力可以相当大。这种结构大多用于大、中型计算机系统

下图是三总线结构的示意图：

上图中主存总线用于 CPU 与主存之间的传输；I/O 总线供 CPU 与各类 I/O 设备之间传递信息；DMA 总线用于高速 I/O 设备 (磁盘、磁带等) 与主存之间直接交换信息

在三总线结构中，任一时刻只能使用一种总线。主存总线与 DMA 总线不能同时对主存进行存取，I/O 总线只有在 CPU 执行 I/O 指令时才能用到

如果主存总线和 DMA 总线同时对主存进行存取的话，那么主存控制器需要根据特定的策略来判断由谁先访问主存

我们在计组第七章的【IO 方式之 DMA 控制方式】中有详细讲三种策略：

① 停止 CPU 访问主存

② 周期挪用

③ DMA 和 CPU 交替访问

还可以将 I/O 总线再次分成高速 I/O 总线和低速 I/O 总线，高速 I/O 设备离 CPU 近，而低速 I/O 设备离 CPU 远一点，如下图：

这样可以提供整个计算机系统的效率，计算机系统一般都采用这种分层的总线结构

传统的总线结构

下图是传统的计算机总线结构：

可以看到，速度越慢的设备离 CPU 越远，在上图中有 5 条总线，每条总线都有总线控制器，分别是：

  • 处理器总线，有自己的总线控制器

  • 存储器总线，主存控制器中有总线控制器的功能

  • PCI 总线 x0，HOST 桥 x 中包含了这条总线的总线控制器功能

  • PCI 总线 x1，PCI 桥 x01 中包含了这条总线的总线控制器功能

  • ISA 总线，PCI-to-ISA 桥中包含了这条总线的总线控制器功能

这 5 条总线都是属于同步并行总线

上图中的桥的作用不单单包含了总线控制器的功能，还包含了缓冲的功能，比如处理器总线的速度比 PCI 总线的速度快很多，当 CPU 通过处理器总线发给 PCI 设备 01 时，数据需要先在 HOST 桥 x 中进行缓存，因为 PCI 总线 x0 的速度跟不上处理器总线传输数据的速度

接下来，我们来看一个实际总线结构的例子，在早期的 Intel x86 处理机系统中，连接 CPU 的处理器总线被称为前端总线，然后有一个北桥芯片和前端总线相连，看下图：

在北桥芯片中，主要就是三部分，显卡、主存控制器、以及一个或者多个 HOST 主桥，显示器通过 HDMI 接口和显卡连接，主存控制器通过存储器总线和主存储器连接

而 HOST 主桥推出 PCI 总线，和南桥芯片连接，南桥芯片中集成了各种 I/O 设备的接口，比如 USB 控制器、以太网卡、硬盘控制器等，当然还可以通过 PCI 桥进行扩展

现代的总线结构

上面传统的计算机系统是三芯片结构的（处理器芯片 + 北桥芯片 + 南桥芯片），而现代的计算机系统结构将北桥芯片功能集成到处理器芯片中，这样主板上的芯片组不再是传统的三芯片结构，而是双芯片结构（处理器芯片 + PCH 芯片）

看下图是现代 Intel x86 计算机系统的总线结构：

在上面的计算机系统中，有两个芯片，分别是处理器集成芯片和 PCH（Platform Controller Hub） 芯片，PCH 芯片除了包含原来南桥芯片中的 I/O 控制器集线器的功能外，还包含了以前北桥芯片中的图形显示控制单元等功能

上图中的 CPU 内部的 QPI/UPI 总线是一种点对点、同步并行传输，并且是全双工的总线

存储器总线和 PCI 总线是同步并行总线

USB 总线不是纯同步串行总线，是异步为核心、3.x 后高速段混合同步的串行总线，行业内通常将 USB 归为异步串行总线（核心特征主导分类）  

PCIe 总线（也就是 PCI-Express 总线）是异步串行总线，并且也是点对点的全双工通信
