计算机内部的带符号整数大多用补码表示，以下是一些关于补码特点的叙述：

① 零的表示是唯一的

② 符号位可以和数值部分一起参加运算

③ 和其真值的对应关系简单、直观

④ 减法可用加法来实现

以上叙述中，(  ) 是补码表示的特点

A.①和②
B.①和③
C.①、②和③
D.①、②和④

现代计算机中有符号整数一般都采用补码表示，这个是因为：

  • ① 与原码和反码相比，数 0 的补码表示形式唯一

  • ② 与原码相比，补码可以用加法实现减法运算，且符号位可以和数值位一起参加运算

  • ③ 与原码和反码相比，补码比原码和反码多表示一个最小负数，因为原码和反码都需要 2 个编码来分别表示 +0 和 -0

  • ④ 与反码相比，补码加法不需要通过循环进位来调整结果


因此，题目的 ①、② 和 ④ 正确，本题选 D，题目的 ③ 是原码的特点

【2015 第 13 题】由 3 个 "1" 和 5 个 "0" 组成的 8 位二进制补码，能表示的最小整数是（ ）

A.-126
B.-125
C.-32
D.-3

对于补码的定义，一定一定要牢牢记住：

你看，要想使得补码表示的整数最小，那么最高位肯定是 1，也就是负数，剩下的 1 越往低位放，那么补码的值就越小


3 个 1，5 个 0 的话，能表示的最小的补码是 1000 0011，也就是 -2^7 + 0 + 0 + 0 + 0 + 0 + 2^1 + 2^0 = -128 + 2 + 1 = -125，因此选 C


从这里也可以得出一个结论，如果补码最高位是 1 的话，那么剩下的数值位越大的话，补码表示的整数值越大，如果剩下的数值位越小的话，补码表示的整数值越小

【2021 第 13 题】已知带符号整数用补码表示，变量 x，y，z 的机器数分别为 FFFDH，FFDFH，7FFCH，下列结论中，正确的是 (  )

A.若 x, y 和 z 为无符号整数，则 z<x<y
B.若 x, y 和 z 为无符号整数，则 x<y<z
C.若 x, y 和 z 为带符号整数，则 x<y<z
D.若 x, y 和 z 为带符号整数，则 y<x<z
对于补码的定义，一定一定要牢牢记住：


如果最高位是 0 的话，那就是正数，最高位是 1 的话，那就是负数，正数肯定大于负数，因此 z = 7FFCH 是最大的

对于负数，数值位越大，那么补码对应的整数也就越大，因此 x > y，因为 x 的数值位是 7FFDH，y 的数值位是 7FDFH，很明显 7FFDH > 7FDFH

所以 z > x > y，选 D
扩展：如果你想将 FFFDH 和 FFDFH 转换成对应的十进制的话，那么可以使用【符号扩展后的补码二进制和符号扩展前的补码二进制对应的十进制是相等的】这个结论来简化计算

比如 FFFDH，对应的二进制是 1111 1111 1111 1101，将前面连续的 13 个符号位 1 省略，得到 101，然后使用补码公式计算出其十进制 = -2^2 + 1 = -3


再比如 FFDFH，对应的二进制是 1111 1111 1101 1111，将前面连续的 9 个符号位 1 省略，得到 101 1111，然后使用补码公式计算出其十进制 = -2^6 + 2^4 + 2^3 + 2^2 + 2^1 + 1 = -2^6 + 2^5 - 1 = -64 + 32 - 1 = -33

那么，8190 = 8192 - 2 = 10 0000 0000 0000 - 1 - 1 = 01 1111 1111 1111 - 1 = 01 1111 1111 1110
