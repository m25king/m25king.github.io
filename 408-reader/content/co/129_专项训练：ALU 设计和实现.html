下图是某机器的 32 位的 ALU 部件的具体实现，ALU 的输入为两个 32 位操作数 A 和 B，其中，核心部件是加法器，加法器的输出除两个数的和 Add-Result 以外，还有进位标志 Add-carry（其实就是 Cout）、零标志 Zero（即 ZF）、溢出标志 Add-Overflow（即 OF）和符号标志 Add-Sign（即 SF）：


在操作控制端 ALUctr 的控制下，在 ALU 中执行加、减、按位或、带符号整数比较小于置 1 和无符号数比较小于置 1 等运算，Result 作为 ALU 运算的结果被输出，同时，零标志 Zero 和溢出标志 Overflow 也被作为 ALU 的结果标志输出，请回答下面的问题：

（1） ALU 所在机器的机器字长是多少位？

（2）上图中的 ①、② 以及 ③ 分别是什么部件？分别有什么作用？

（3）假设寄存器 $4 中的机器数是 1111111AH，寄存器 $5 中的机器数是 FFFFF888H，现在执行有符号（补码）加法指令（需判断溢出） add $2, $4, $5，即 R[$4] + R[$5] → $2，那么上面 ALU 中的 SUBctr、OPctr、OVctr 以及 SIGctr 的信号值是多少？ALU 的输出 Result、Zero 以及 Overflow 的值又是多少呢？

（4）假设寄存器 $4 中的机器数是 1111111AH，寄存器 $5 中的机器数是 FFFFF888H，现在执行无符号加法指令（不需判断溢出） addu $2, $4, $5，即 R[$4] + R[$5] → $2，那么上面 ALU 中的 SUBctr、OPctr、OVctr 以及 SIGctr 的信号值是多少？ALU 的输出 Result、Zero 以及 Overflow 的值又是多少呢？

（5）假设寄存器 $4 中的机器数是 3456789AH，寄存器 $5 中的机器数是 FFFFF888H，现在执行有符号整数比较小于置 1 指令（不需判断溢出） slt $2, $4, $5，即 if (R[$4] < R[$5]) 1 → $2 else 0 → $2，那么上面 ALU 中的 SUBctr、OPctr、OVctr 以及 SIGctr 的信号值是多少？ALU 的输出 Result、Zero 以及 Overflow 的值又是多少呢？

（1）一般而言 ALU 的位数等于机器字长，因为 ALU 是 32 位的，所以本机的机器字长是 32 位



（2）① 是异或门，将 Cin 和最高位进位 Cout 进行异或，可以求出进位/借位标志 CF 的值，根据这个 CF 值可以判断两个无符号整数的大小

② 是异或门，将溢出标志 Add-Overfow 和符号标志 Add-Sign 进行异或（即 OF ^ SF），根据这个异或结果可以判断两个有符号整数的大小

③ 是与门，将溢出标志 Add-Overflow 和 OVctr 取与的目的是为了能控制要不要进行溢出判断，如果不需要进行溢出判断的话，那么 OVctr = 0 即可，这样不管 溢出标志 Add-Overflow 的值是多少，ALU 的溢出标志 Overflow 都是 0，即不进行溢出判断

如果需要进行溢出判断的话，那么将 OVctr 设置位 1，这样 ALU 的溢出标志 Overflow 就等于加法器的溢出标志，如果 Add-Overflow = 1 的话，那么就需要进行溢出处理了


（3）执行有符号（补码）加法指令（需判断溢出） add $2, $4, $5，因为是加法，所以 SUBctr = 0；因为 ALU 输出的是 Add-Result，所以 OPctr = 00、SIGctr = 任意值；因为需要判断溢出，所以 OVctr = 1


R[$4] + R[$5] = 1111111AH + FFFFF888H = 111109A2H，即 Result 的值是 111109A2H，因为结果不是 0，所以零标志 Zero = 0，这里是正数 + 负数 = 正数，所以肯定不会溢出，那么加法器的溢出标志 Add-Overflow = 0，ALU 的溢出标志 Overflow = 0


（4）执行无符号加法指令（不需判断溢出） addu $2, $4, $5，因为是加法，所以 SUBctr = 0；因为 ALU 输出的是 Add-Result，所以 OPctr = 00、SIGctr = 任意值；因为不需要判断溢出，所以 OVctr = 0，那么 ALU 的溢出标志 Overflow = 0


R[$4] + R[$5] = 1111111AH + FFFFF888H = 111109A2H，即 Result 的值是 111109A2H，因为结果不是 0，所以零标志 Zero = 0


看到了吗？有符号加法 add 和无符号加法 addu 的输出结果是一模一样的（主要因为加法器实现两者的原理是一样的），这两个指令只有是否判断溢出这点是不同的，有符号加法判断溢出，无符号加法不判断溢出，


（5）执行有符号整数比较小于置 1 指令（不需判断溢出） slt $2, $4, $5，因为是需要做减法（将 R[$4] - R[$5]），所以 SUBctr = 01；因为 ALU 输出的是 0 或者 1，所以 OPctr = 10；因为是做有符号整数判断大小，所以 SIGctr = 1；因为不需要判断溢出，所以 OVctr = 0，那么  ALU 输出 Overflow = 0


R[$4] - R[$5] = 3456789AH - FFFFF888H = 3456789AH + 00000777H + 1 = 34568012H，这个是正数，所以 SF = 0，OF = Cout ^ C31 = 0 ^ 0 = 0，因为 SF ^ OF = 0 ^ 0 = 0，所以 R[$4] > R[$5]，所以需要输出 0，即 ALU 的输出 Result = 0，因为 R[$4] - R[$5] 不等于 0，所以 Zero = 0


这里我们也可以通过看符号位就知道 R[$4] > R[$5]，因为 R[$4] 是正数，而 R[$5] 是负数，所以 R[$4] > R[$5]
