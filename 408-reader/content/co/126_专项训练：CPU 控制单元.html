下列有关指令和微指令之间关系的描述中，正确的是 (   )。

我们先明确指令、微指令、微程序三者的层级关系：
  • 机器指令（指令）：程序员可见的指令，是 CPU 执行的基本单位（如 ADD R1, R2）
  • 微程序：由多条微指令组成的一段程序，对应一条机器指令的功能
  • 微指令：由多个微命令组成，是控制 CPU 内部数据通路的最小操作单位，存储在控制存储器（CM）中


A 错误：一条机器指令的功能需要多条微指令（一个微程序）来实现，不可能由一条微指令完成


B 正确：这是微程序控制器的核心定义：一条机器指令对应一段微程序，CPU 执行机器指令时，就是在执行对应的微程序，本题选 B


C 错误：完全颠倒了层级关系，微指令是机器指令的底层实现，不是反过来


D 错误：微程序由微指令组成，一条微指令是微程序的一个步骤，不是由微程序实现微指令

组合逻辑控制器（硬布线控制器）的微操作控制信号，由指令操作码、时序信号（节拍 / 时钟）、状态条件码（PSW 中的标志位，如零标志、进位标志） 共同决定

A.微程序
B.微指令

一条指令的功能是通过一系列的微操作完成的，比如执行 ADD 指令时，分为取指阶段和执行阶段，在取指阶段有 6 个微操作在 3 个时钟周期内完成取指功能，在执行阶段，有 3 个微操作在 3 个时钟周期内完成加法功能

每个微操作在相应的控制信号的控制下执行，比如微操作将 PC 中的地址送到 MAR 中，对应的控制信号是 PCOut = 1 和 MARWr = 1，而微操作给主存储器发送读命令，其控制信号就是 Read = 1


每一个微操作都在相应的控制信号的控制下执行，这里的每个控制信号，我们称为一个微命令，比如上图的 PCOut 就是一个微命令，MARWr 也是一个微命令。而微程序是一个微指令序列，一条微指令包含若干个微命令，在微程序控制单元中，一条机器指令的功能由一个微程序完成

因此，控制部件向执行部件发出的某个控制信号称为微命令，本题选 D

下列关于微命令的描述中，正确的是 ( ) 。

A.同一 CPU 周期中，可以同时出现的微命令叫相容性微命令
B.同一 CPU 周期中，可以同时出现的微命令叫互斥性微命令
C.在执行过程中可能会引起总线冲突的微命令叫互斥性微命令
D.同一 CPU 周期中，不允许同时出现的微命令叫相容性微命令
相容性微命令：在同一个 CPU 周期（节拍）内，可以同时、并行发出的微命令，它们之间不会发生冲突（例如 “寄存器输出” 和 “ALU 输入” 可以同时进行）

互斥性微命令：在同一个 CPU 周期内，不能同时发出的微命令，否则会引发硬件冲突（例如 “总线读” 和 “总线写” 不能同时执行，“ALU 加法” 和 “ALU 减法” 也不能同时进行）


A 正确：完全符合相容性微命令的定义，本题选 A；B 错误：可同时出现的是相容性，不是互斥性


C 错误：互斥性微命令的本质是同一周期不能同时出现，而非仅 “可能引起总线冲突”，总线冲突只是互斥的一种表现，不是定义本身


D 错误：不允许同时出现的是互斥性，不是相容性

字段直接编码法将微指令分成若干个字段，每个字段包含若干个微命令，把互斥微命令组合在同一个字段，相容微命令组合在不同的字段，对每一个字段内的微命令进行编码

题目中规定微指令共有 33 个微命令，构成 5 个互斥类，分别包含 7、3、12、5 和 6 个微命令

有 5 个互斥类，所以微指令分成 5 个字段

因为第一个互斥类包括 7 个微命令，所以第一个字段，需要编码 7 + 1 = 8 个微命令（加 1，是因为还需要额外编码一个不发微命令的情况），因此需要 3 位即可（2^3 = 8）

第二个字段，需要编码 3 + 1 = 4 个微命令，因此需要 2 位即可（2^2 = 4）

第三个字段，需要编码 12 + 1 = 13 个微命令，因此需要 4 位即可（2^3 < 13 < 2^4）

第四个字段，需要编码 5 + 1 = 6 个微命令，因此需要 3 位即可（2^2 < 6 < 2^3）

第五个字段，需要编码 6 + 1 = 7 个微命令，因此需要 3 位即可（2^2 < 7 < 2^3）

C.8
D.9

题目问微指令中下地址字段的位数，其实就是问要寻址所有的微指令，需要多少位，比如下图控存中的 12 条微指令的存储情况：

要表示 12 条微指令，就需要 4 位，因为 2^3 < 12 < 2^4，所以每条微指令的微地址是 4 位，那么下址表示的是下一条微指令的地址，肯定也是 4 位了


题目说计算机共有 32 条指令，各个指令对应的微程序平均为 4 条，则 32 条指令对应的微指令数一共是 32 × 4 = 128 条，而公共微指令还有 2 条，所以整个系统中微指令的条数一共为 128 + 2 = 130 条，所以需要 log₂130 = 8 位才能寻址到 130 条微指令（2^7 < 130 < 2^8），或者说需要 8 位才可以表示 130 条微指令，答案选 C

【2017 第 18 题】下列关于主存储器 (MM) 和控制存储器 (CS) 的叙述中，错误的是（ ）

A.MM 在 CPU 外，CS 在 CPU 内
B.MM 按地址访问，CS 按内容访问
C.MM 存储指令和数据，CS 存储微指令
D.MM 用 RAM 和 ROM 实现，CS 用 ROM 实现
主存储器 (MM) 在 CPU 外，存储指令和数据，由 RAM 和 ROM 实现，按地址访问存储单元

控制存储器 (CS) 用来存放实现指令系统的所有微指令，是一种只读型存储器（ROM），机器运行时只读不写，在 CPU 的控制器内，控存按照微指令的地址访问，所以 B 错误


可以稍微总结下，微程序控制器执行微指令的过程和 CPU 执行机器指令的过程非常的类似，以下是微程序控制器的内部结构：


其中控制存储器（CS）就和主存储器一样，不过控存存储的是只读微指令，所以控存一般是 ROM，而主存储器除了存储只读机器指令，还会存储内容可以变化的数据，所以主存一般由 ROM 和 RAM 组成（注意哈，并不是说机器指令存放在 ROM 中哈，ROM 主要用于存放一些只读不改变的数据），控存和主存都是根据地址取出指令的


在微程序控制器中的 μPC 就和 CPU 中的 PC 一样，μPC 用于暂存下一条要执行的微指令的地址，PC 用于暂存下一条要执行的机器指令的地址


在微程序控制器中的 μIR 就和 CPU 中的 IR 一样，μIR 用于暂存正在执行的微指令，IR 用于暂存下一条要执行的机器指令
