多体模块结构的存储器采用交叉编址后，可以在不改变每个模块存储周期的前提下，提高存储器的带宽
假设有一个连续编址的四模块存储器，每个模块的存储字长是 8 位，存储周期 T = 200ns，假设数据总线宽度也是 8 位，总线传输周期 τ = 50ns，如下图：
那么这个四模块存储器的带宽是多少呢？
我们知道，存储器带宽表示单位时间内存储器存取的信息量

对于连续编址的四模块存储器，每个存储周期 T 可以读出 1 个字，那么读出 1 个字的花费的时间是 200ns，那么这个存储器的带宽 = 8 位 / 200ns = 40Mb/s
注意，这里求的是存储器的带宽，在读取每个存储字的时候，不需要考虑将数据从存储器经过数据总线传输到 CPU 的时间，也就是不用考虑总线传输周期这个时间，只要考虑存储器从收到地址，到对应存储字存放到存储器芯片中的缓冲中的这段时间（就是存储周期）即可
就是说，存储器带宽是存储器的性能指标，和总线是没有关系的，存储器带宽为 40Mb/s 的意思就是单位时间（1 s）内，这个存储器可以存取 40Mb 的数据到存储器芯片的数据缓冲中
现在假设上面的四模块存储器采用低位交叉编址，如下图：
那么这个四模块存储器的带宽又是多少呢？我们先求出连续读出地址 0 ~ 3 这 4 个存储字的时间
因为采用低位交叉编址，所以，可以采用流水线的方式来读取连续的 4 个字，如下图：
因为求的是存储器带宽，所以读取连续 4 个字需要的时间，应该是从存储器收到第一个存储字的地址的时刻开始（即上图的时刻 0），此时开始启动模块 M0，M0 需要经过一个存储周期，才可以读出第一个存储字
在 M0 准备数据的时候，CPU 可以将第 2 个数据的地址发送给存储器，此时存储器同时启动模块 M1，M1 也需要经过一个存储周期，才可以读出第二个存储字
在 M0、M1 准备数据的时候，CPU 可以将第 3 个数据的地址发送给存储器，此时存储器同时启动模块 M2，M2 也需要经过一个存储周期，才可以读出第三个存储字
在 M0、M1、M2 准备数据的时候，CPU 可以将第 4 个数据的地址发送给存储器，此时存储器同时启动模块 M3，M3 也需要经过一个存储周期，才可以读出第四个存储字

当时间来到 t0（也就是 1 个存储周期），此时 M0 中的数据已经放到存储芯片的数据缓冲中，可以通过总线送到 CPU，总线将 M0 的数据送到 CPU 的同时，M1、M2、M3 都在准备数据，因为总线和存储器是两个不同的部件，所以可以并行工作
当经过一个总线传输周期 τ 后，M0 的数据传送到 CPU
在时刻 t1 传送完第一个字，此时刚好 M1 准备好第二个字，开始通过总线传输第二个字
在时刻 t2 传送完第二个字，此时刚好 M2 准备好第三个字，开始通过总线传输第三个字
在时刻 t3 传送完第三个字，此时刚好 M3 准备好第四个字，开始通过总线传输第四个字
注意，我们要求的是存储器带宽，所以总线传送第四个字的总线传输周期 τ 不能算，也就是说，存储器读出连续的 4 个字的时间是从时刻 0 到时刻 t3，花费的时间是 T + 3τ = 200ns + 3 * 50ns = 350ns
那么存储器带宽 = 4 * 8 位 / 350ns = (32 * 10^9 位) / 350s = 91.43Mb/s，这个是大于上面的连续编址四体存储器带宽（40Mb/s）的
所以说，多体模块结构的存储器采用交叉编址后，可以在不改变每个模块存储周期的前提下，提高存储器的带宽
如果现在要从低位交叉编址四体存储器中，读出以下连续的 8 个存储字（地址 0 ~ 地址 7），需要的时间又是多少呢？

看下面时间图：

在时刻 t6 读完连续的 8 个存储字（地址 0 ~ 地址 7） ，花费的时间是 T + 7τ
从上图可以看到，在时刻 t0 的时候，刚好模块 M0 准备好第 1 个字，然后总线开始传输第 1 个字，而 M0 又再次启动，准备第 5 个字，对吧，在这里的话 T 刚好等于 4τ

实际上，在低位交叉编址的 n 体存储器中，当采用流水线方式存取时，应满足 T = nτ，这是为什么呢？
这样主要是为了保证启动某个存储体后，经 nτ 的时间（即 1 个存储周期）后，能再次启动该存储器体时，这个存储体的上次存取操作必须已完成，看下图读出连续的 9 个字的时间图：
比如上图中，在时刻 0 启动 M0，然后在时刻 t0 时刻 M0 准备好数据，此时才可以重新启动 M0 读取第 5 个字，对吧
接下来再经过一个存储周期，来到 t4 时刻，M0 准备好第 5 个字，此时才可以重新启动 M0 读取第 9 个字，对吧
而在 t0 ~ t4 之间，在 M0 准备数据的同时，也需要将前 4 个字依次通过总线传输给 CPU，可以看到 T = 4τ
那么 T 就不可以大于 nτ？不可以小于 nτ 吗？
T 不可以大于 nτ，看下面四体存储器 T > 4τ 的时间图：

这样是不行的，你看在时刻 0 启动了 M0，M0 正在准备第 1 个字，然后在时刻 t0 又启动 M0 想读取第 5 个字
就是说，在时刻 t0 和 t1 之间，CPU 要同时访问 M0 两次，这肯定是不行的，对吧，如果一个存储体正在准备数据（还没完成操作），那么就不能再次启动，对吧
T 可以小于 nτ，看下面四体存储器 T < 4τ 的时间图：
可以看到，在时刻 0 启动了 M0，M0 正在准备第 1 个字，然后在时刻 t0 准备好第 1 个字，通过总线送到 CPU，现在还没有启动 M0，直到时刻 t4 才开始启动 M0 读取第 5 个字
这是可以的，对于存储器 M0，再次启动该存储器体时（在时刻 t4），这个存储体的上次存取操作已经在时刻 t0 就完成了
但是这种情况下，流水线中有浪费时间，比如在上图的 t0 ~ t4 时刻是可以启动 M0 的，而这段时间 M0 是空闲的，这样会影响存储器的带宽
而在 T = nτ 时，是不会浪费时间的，比如下图的四体存储器，T = 4τ：

在时刻 t0 ，M0 读取第 1 个字的操作结束，就立马启动 M0 来读取第 5 个字，不会浪费时间
所以，一般情况下，对于 n 体存储器，每个存储体的存储周期 T = nτ，τ 是总线传输周期，就是从主存储器传送一个存储字到 CPU 需要的时间
这种低位交叉 n 体存储器采用的是轮流启动方式启动 n 个存储体，如果每个存储体一次读写的位数（即一个存储字）正好等于存储器总线的数据位数，就采用轮流启动方式，如下图：

对于低位交叉 n 体存储器，采用轮流启动的话，那么每隔 1/n 的存储周期（即 T/n）就会启动一个存储体，如下 4 体存储器：

因为 T = 4τ，所以，上图是每隔一个  τ（也就是 T/4）就会启动一个存储体，在第一个存储周期之后，每隔 T/4 就可以读出一个字，就是说在第一个存储周期之后，每个存储周期都可以读出连续的 4 个字，这样大大的提高了存储器带宽
如果从上面的四体存储器连续读出 m 个字，需要的时间是 T + (m - 1)τ，那么平均每个字的存取时间是 (T + (m - 1)τ) / m = T/m + τ + τ/m，而实际工作时，m 是非常大的，那么平均每个字的存储时间就非常接近 τ 了，可以认为每个总线传输时间 τ 能给 CPU 提供一个字
即每隔 T/4 可以读出一个字，此时的存储器的带宽 = 8 位 / (T/4) = 32 位 / T = 32 位 / 200ns = 160Mb/s，这个也是上面低位交叉 4 体存储器的最大带宽了
如果所有存储模块一次并行读写的总位数正好等于存储器总线中数据位数，则可用同时启动方式
例如，对于图的低位交叉 4 体存储器：
每个存储模块（一个存储模块可以是一个 DRAM 芯片）提供 8 位数据，4 个 DRAM 芯片一共提供 32 位数据，其位数正好等于存储器总线的数据线的位数
因此，可同时启动 4 个芯片进行并行读写，同时读写 32 位数据，即一个存储周期 T 可以读取 32 位数据，所以这个存储器的带宽是 32 位 / T = 32 位 / 200ns = 160Mb/s，和轮流启动方式的四体存储器的最大带宽是一样的
不过，轮流启动方式的话，如果考虑第一个存储周期的话，其存储器带宽要小一点的（这就是轮流启动和同时启动的区别）
比如轮路启动方式连续读取 32 位（即 4 个字）需要的时间是 T + (4 - 1) * τ = 200ns + 3 * 50ns = 350ns，其存储器带宽 = 32 位 / 350ns = 91.43Mb/s < 160Mb/s
需要注意的是，同时启动的话，每个存储周期必须是同时启动并读取所有的存储体，即使此时某个存储体中没有你需要的数据，也需要启动该存储体，如下图：

假设一个数据占 4 个字节（上图的红色部分），其首地址是 6，此时如果 CPU 给出地址 6，要求读取这 4 个字节的话，在同时启动方式下，需要 2 个存储周期：
  • 第 1 个存储周期，同时启动 4 个存储体，分别读取地址 4、5、6、7 的字节给到 CPU，不过 CPU 会丢弃掉地址 4、5 对应的字节，而保留地址 6 和 7 的字节
  • 第 2 个存周期，再次同时启动 4 个存储体，分别读取地址 8、9、10、11 的字节给到 CPU，不过 CPU 会丢弃掉地址 10、11 对应的字节，然后将地址 6、7、8、9 四个字节拼起来
如果是轮流启动读取上面的 4 个字节的话，首先 CPU 给出地址 6，直接启动 M2，然后 CPU 给出地址 7，再启动 M3，然后 CPU 给出地址 8，再启动 M0，然后 CPU 给出地址 9，再启动 M2，那么，在 1 个存储周期内就可以读出这 4 个字节
现代计算机中由于在 CPU 和主存之间设置有高速缓存（cache），因而通常 CPU 是对一个主存块中的连续单元进行访问，DMA 传送也是将一块连续主存单元与高速设备进行数据交换
因此，对主存的访问通常都是读写一块连续的主存单元。对于连续一块信息的读写，采用低位交叉编址的多模块存储器，通过轮流或并行访问多个存储模块，可以显著提高访存速度
