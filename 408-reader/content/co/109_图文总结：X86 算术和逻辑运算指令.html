一元和二元操作

上图第二组的操作是一元操作，只有一个操作数，既是源又是目的，这个操作数可以是一个寄存器，也可以是一个内存位置，比如：
  • 指令 inc rax 就是将 rax 寄存器的值加 1，结果再写到 rax 寄存器
  • 指令 inc  WORD PTR [rbp - 25] 就是将内存地址为 R[rbp] - 25 的字加 1，结果写到内存地址为 R[rbp] - 25 的字中
上图第三组是二元操作，其中第一个操作数既是源又是目的，第二个操作数是源，这种语法让我们想起 C 语言中的赋值运算符，例如 x -= y
对于二元操作，第二个操作数可以是立即数、寄存器或是主存地址，而第一个操作数可以是寄存器或是主存地址，注意，当第一个操作数为主存地址时，CPU 必须从主存读出第一个操作数，执行操作后，再把结果写回主存
所以，根据源地址和目的地址的类型不同组合，二元操作指令可以产生五种组合：
  1. 寄存器 + 寄存器 → 寄存器：指令 add eax, edi 就是将 eax 中的值加上 edi 中的值，结果写到 eax 中
  2. 寄存器 + 立即数 → 寄存器：指令 add rsp, 8 就是将 rsp 中的值和 8 相加，结果写到 rsp 中
  3. 寄存器 + 主存地址 → 寄存器：指令 add esi, WORD PTR [rdi + 12] 就是将 esi 中的值加上内存地址为 [rdi + 12] 的一个字数据，结果写到 esi 寄存器中
  4. 主存地址 + 寄存器 → 主存地址：指令 add WORD PTR [rdi + 12], esi,  就是将内存地址为 [rdi + 12] 的一个字数据加上 esi 中的值，结果写到内存地址为 [rdi + 12] 的字中
  5. 主存地址 + 立即数 → 主存地址：指令 add WORD PTR [rdi + 12], 10,  就是将内存地址为 [rdi + 12] 的一个字数据加上 10 值，结果写到内存地址为 [rdi + 12] 的字中

左移指令有两个名字 sal 和 shl，两者效果一样，都是高位丢弃低位补 0。右移指令不同，SAR 执行算术右移（低位丢弃，高位补符号位），而 SHR 执行逻辑右移（低位丢弃，高位补 0）
移位操作的移位量可以是一个立即数，也可以是一个寄存器（寄存器中存放了移位量），目的操作数 D 可以是一个寄存器或是一个主存地址

乘除法指令

对于乘法指令 imul 有两种不同的格式，上面二元操作中的 imul D, S 是一种，就是将操作数 D 和操作数 S 相乘，结果写到 D 中，这里的 D 可以是寄存器或是内存地址，S 可以是立即数、寄存器或是内存地址
X86-64 还提供了两条不同的单操作数乘法指令，一个是无符号数乘法指令 mul S，另一个是补码乘法指令 imul S；我们知道两个 64 位有符号或无符号整数相乘得到的乘积需要 128 位来表示，指令 mul S 和 imul S 都要求一个乘数必须存放在 rax 寄存器中，而另一个作为指令的源操作数给出（就是 S），然后乘积存放在寄存器 rdx（高 64 位）和 rax（低 64 位）中，因此：
  • 有符号乘法指令 imul S 的作用是 S × R[rax] → R[rdx]:R[rax]
  • 无符号乘法指令 mul S 的作用是 S × R[rax] → R[rdx]:R[rax]

再来看除法指令，包括有符号除法指令 idiv S 和无符号除法指令 div S，在做除法时，需要将 64 位的被除数扩展到 128 位，如果是有符号除法的话，需要对被除数进行符号扩展，如果是无符号除法，需要对被除数进行零扩展
除法指令将寄存器 rdx（高 64 位）和 rax（低 64 位）中的 128 位作为被除数，而除数作为指令的操作数给出（就是 S），指令将商存储在寄存器 rax 中，将余数存储在寄存器 rdx 中，即：
  • 有符号除法 idiv S 的作用是：R[rdx]:R[rax] mod S → R[rdx]，R[rdx]:R[rax] ÷ S → R[rax]
  • 无符号除法 div S 的作用是：R[rdx]:R[rax] mod S → R[rdx]，R[rdx]:R[rax] ÷ S → R[rax]
上面说的是 64 位数除以 64 位数，如果是 32 位数除以 32 位数的话，那么 eax 存放被除数的低 32 位，edx 存放被除数的高 32 位，商存储在寄存器 eax 中，将余数存储在寄存器 edx 中看下图除法的电路实现：
