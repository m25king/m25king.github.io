【09-12】一个 C 语言程序在一台 32 位机器上运行。程序中定义了三个变量 x、y 和 z，其中 x 和 z 为 int 型，y 为 short 型。当 x=127, y=-9 时，执行赋值语句 z=x+y 后，x、y 和 z 的值分别是（ ）

A.x=0000007FH, y=FFF9H, z=00000076H
B.x=0000007FH, y=FFF9H, z=FFFF0076H
C.x=0000007FH, y=FFF7H, z=FFFF0076H
D.x=0000007FH, y=FFF7H, z=00000076H

再 C 语言中，int 和 short 都是属于有符号整数，采用补码编码


127 = 2^7 - 1 = 1000 0000B - 1 = 111 1111B，因为 x = 127，且 x 是 int 类型，其符号位是 0，占 4 个字节，因此 x 的二进制是 00000000 00000000 00000000 01111111B，对应的十六进制是 0000007FH


y 是 short 类型，占 2 个字节，因为 y = -9 = -16 + 4 + 2 + 1 = -2^4 + 2^2 + 2^1 + 2^0，所以 -9 的补码 1 0111，符号扩展到 16 位就是 1111 1111 1111 0111B，对应的十六进制是 FFF7H


执行 z = x + y 时，由于 x 是 int 型，y 为 short 型，需将短整型的 y 转换成长整型，因为 short 是补码编码，因此这里需要进行符号扩展，由于 y 的符号位为 1, 故在 y 的前面添加 16 个 1，即可将 y 转换为 int 型，其十六进制形式为 FFFFFFF7H


最后执行加法，即 0000007FH + FFFFFFF7H = 00000076H,  其中最高位的进位 1 自然丢弃。 本题选 D

因为 x 的补码是 1111 0100，x*2 表示将 x 算术左移一位（高位丢弃，低位补 0），得到 1110 1000，因为高位丢弃的是 1，和算术左移后的高位 1 相同，所以没有溢出

因为 y 的补码是 1011 0000，y/2 表示将 y 算术右移一位（低位丢弃，高位补符号位），得到 1101 1000，低位丢弃的是 0，所以精度也没有损失

101 1111B 就是通过符号扩展得到 1111 1111 1111 1111 1111 1111 1101 1111B 的，而符号扩展之前和扩展之后表示的值是一样的


对于补码 0000 0041H，因为是正数，所以直接转换成十进制 4 × 16 + 1 = 65


既然补码的直接相减和转加法计算结果一样，那么要求 x - y，就可以直接将 FFFF FFDFH - 0000 0041H = FFFF FF9EH（最低位 F - 1 = E，第二位 D = 4 = 9，剩下的都是 F - 0 = F）


不过注意，这是我们人类的做法，而机器硬件不是采用直接减，而是用上面将减法变成加法的方法来实现，效果是一样的


所以 x = -33，y = 65，x - y 的机器数是 FFFF FF9EH，本题选 C

  2. OF = Cout ^ Cn-1 （Cn-1 是次高位进位）


本题中的 x 和 y 都是 int 型，采用 32 位补码表示，x = 10 对应的补码是 00000000 00000000 00000000 00001010B，y = -20 对应的补码是 11111111 11111111 11111111 11101100B，现在是求 x - y 的 CF 和 OF

所以 CF = Cout ^ Cin = 0 ^ 1 = 1，OF = Cout ^ Cn-1 = 0 ^ 0 = 0，因此，选 B
