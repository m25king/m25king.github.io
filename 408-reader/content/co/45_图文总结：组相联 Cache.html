基本思想

前面我们介绍的直接映射和全相联映射，它们的优缺点刚好相反，接下来我们要介绍的组相联映射则是结合了前两种方式的优点
在组相联映射中，也是将主存地址分成三个字段，只不多 Cache 行号变成了 Cache 组号：

组相联映射的基本思想是：将 Cache 所有的行分成 2^c 个大小相等的组，每组有多个 Cache 行，每个主存块被映射到 Cache 固定的组中的任意一行，也就是说主存块与 Cache 组采用直接映射，而在 Cache 组内，主存块和 Cache 行采用全相联映射的方式
来看一个组相联映射的 Cache：

Cache 总共有 8 行，分成 4 组，每组有 2 行
比如 CPU 访问这个主存地址：

Cache 组号也称为组索引，一个意思
其主存块号是 6（高 5 位的 00110），然后根据主存块号的低 2 位确定主存块对应的 Cache 组号，之所以是 2 位，是因为这里有 4 组，4 = 2^2，所以 2 位足够表示 4 个组
这里的组号是 2，也就是说，6 号主存块应该装入 2 号 Cache 组，很明显，这一步映射就是直接映射，至于这个主存块映射到这一组的哪一个 Cache 行，这个随意，假设这里映射到第 1 行，有效位设置为 1，并且将主存块号的高 3 位（001）作为标记，如下图：

这里因为每个 Cache 组中有两个 Cache 行，所以称为二路组相联，如果每个 Cache 组有 4 个 Cache 行，那么就是四路组相联，每个 Cache 组有多少个 Cache 行，就是多少路组相联

CPU 访存过程

接下来，我们来看一个二路组相联映射的电路实现，并看看在组相联映射下的访存过程，看下图：

这是一个二路组相联映射的 Cache，它有 6 组，每组有两个 Cache 行，这里为了演示方便，将一组内的两个 Cache 行放到水平方向，要访问的主存地址，被分成标记、Cache 组号和块内地址三个字段
访问主存的步骤如下：
  • ①  根据 Cache 组号直接定位找到 Cache 组
  • ② 将对应 Cache 组中每个行的标记与主存地址的标记进行比较
  • ③  再将比较结果和有效位 V 相与，将所有行的相与结果再一次进行取或，意思是若有一路比较相等且有效位是 1 ，则输出 1，表示命中 Cache，并且选中这一路 Cache 行中的主存块
  • ④ 当取与的结果是 1，就是说命中这一行，那么这一行的主存块的数据会通过这个三态门，如果取与结果是 0 的话，对应的行的主存块数据是不会通过这个三态门的
  • ⑤ 最后一步，如果命中，则选择 Cache 中的数据，否则选择到主存中读取一个主存块到 Cache 行中
从这里我们可以看出，在二路组相联的电路实现中，需要 2 个比较器，如果是 四路组相联的话，就需要 4 个比较器，就是说多少路组相联，就需要多少个比较器，比较器的位数等于标记的位数
总结：
  • 直接映射只需要 1 个比较器
  • 组相联映射，每组多少个 Cache 行，就有多少个比较器
  • 全相联映射，有多少 Cache 行，就有多少比较器
比较器的位数都是等于标记的位数

例子

再来看一个具体的组相联的 Cache 例子
假定主存和 Cache 之间采用 2 路组相联映射，块大小为 512B，按字节编址。Cache 数据区容量为 8KB，主存地址空间为 1MB，请问：主存地址如何划分？说明 CPU 对主存单元 0240CH 的访问过程
按字节编址，块大小为 512B，因此块内地址位数是 9 位（2^9 = 512）
主存地址空间为 1MB，因此主存被划分成 1MB / 512B = 2048 个主存块，那么需要 11 位表示主存块号（因为 2^11 = 2048）
Cache 数据区容量是 8KB，Cache 行大小等于主存块大小 512B，所以，Cache 总行数 = 8K / 512B = 16，2 路组相联，那么每组有 2 个 Cache 行，所以 Cache 总组数 = 16 / 2 = 8，那么主存块号的低 3 位可以表示 Cache 组号（2^3 = 8），因此，主存地址划分如下图：

主存地址 0240CH 展开为二进制数为 0000 0010 0100 0000 1100，所以主存地址划分为：

访问 0240CH 单元的过程如下，首先根据地址中间 3 位 010，找到 Cache 的 2 号组，将标记 0000 0010 与 2 号组中两个 Cache 行的标记同时进行比较
  • 若有一个相等且有效位为 1，则命中。此时，根据低 9 位块内地址从对应行中取出单元内容送 CPU
  • 若都不相等或有一个相等但有效位为 0，则不命中。此时，将 0240CH 单元所在的主存块（块号是 0000 0010 010，即 18 号主存块）复制到 Cache 2 号组的任意一个空闲行中，并置有效位为 1，置标记为 0000 0010

3 种映射方式比较

组相联映射方式结合了直接映射和全相联映射的优点
当 Cache 的组数为 1 时，变为全相联映射；当每组只有一个 Cache 行时，则变为直接映射
组相联映射的冲突概率比直接映射低，由于只有组内各行采用全相联映射，所以比较器的位数和个数都比全相联映射少，易于实现，查找速度也快得多
对于一个主存块来说，3 种映射方式下对应 Cache 行的个数不同
直接映射是唯一映射，每个主存块只有一个固定行与之对应；全相联映射是任意映射，每个行都可对应；N 路组相联映射有 N 行对应
这种特性可用“关联度”来度量，即关联度指一个主存块映射到 Cache 中时可能存放的位置个数
因此，直接映射的关联度最低，为 1；全相联映射的关联度最高，为 Cache 的总行数；N 路组相联映射的关联度居中，为 N
当 Cache 大小、主存块大小一定时，关联度和命中率、命中时间、标记所占额外开销等有如下关系
① 关联度越低，命中率越低。因此直接映射命中率最低，全相联映射命中率最高
② 关联度越低，判断是否命中的开销越小，命中时间越短。因此，直接映射的命中时间最短，全相联映射的命中时间最长

③  关联度越低，标记所占额外空间开销越少。因此，直接映射额外空间开销最少，全相联映射额外空间开销最大
