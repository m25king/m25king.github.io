接下来，我们开始学习浮点数编码，不过在学习浮点数编码前，我们先来学习两个前置内容：移码编码和浮点数

移码编码

移码编码规则是：将真值加上一个偏置常数（bias），对于 n 位移码，其偏置常数一般是 2n-1，（这个偏置常数不一定就是 2n-1，还可能是其他的值，要看清题目）
之所以叫移码，是因为每个有符号整数都加上 2n-1，相当于每个整数都往大的方向移动了 ，使得每个移码都是正数：
  • [x]移 = 2n-1 + x，其中 x 是真值，n 是机器字长（也是寄存器的位数）
因为移码是 n 位，没有符号位数值位之分，所以移码的大小是从 0 到 2n - 1，然后将对应的移码减去 2n-1 就得到了真值 x 的范围是 -2n-1 到 2n-1 - 1之间

定点数和浮点数

数据有整数和小数之分，在小数中是包含小数点的，因此要使的计算机能够处理日常使用的数值整数，就必须要解决小数点的表示问题
通常计算机通过约定小数点的位置来实现，小数点位置约定在固定位置的数称为定点数，小数点位置约定为可浮动的数称为浮点数

对于 n 位定点小数的补码，其能表示的最大值是 0.11...1（小数点后面有 n - 1 个 1）= 1 - 2-(n-1)
能表示的最小值是 1.00...0（小数点后面有 n - 1 个 0）= -1，所以 n 位定点小数补码取值范围是 -1 ~ 1 - 2-(n-1)

看下图：

比如上图的 13/64 = 13 * 2^(-6)，这个是可以使用二进制精确表示的，因为分母是 64 = 2^6，因此小数的位数就是 6 位，然后分子 13 = 8 + 4 + 1 = 2^3 + 2^2 + 2^0，那么 13 的二进制位是 1101，那么 13/64 = 0.001101（6 位小数，在 13 的二进制位 1101 之前加上 2 个 0，就是这个小数了）
再比如数字 1/5 可以使用十进制的小数 0.20 精确表示，但是，我们并不能使用二进制小数来精确表示 1/5，因为我们不能将 1/5 写成 x * 2^y 这个形式
