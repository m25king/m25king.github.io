前面我们说，存储芯片字扩展时，同一个时刻只能选中一个芯片工作，工作是串行模式的，而在多模块存储器中，同一时刻可以选中多个模块同时工作，这样可以让 CPU 并行的访问存储器，从而提高存储器的带宽
存储器带宽：表示单位时间内存储器存取的信息量，单位可以用【字/秒】、【字节/秒】或者【位/秒】来表示
如果一个单模块存储器的存储周期是 500ns，每个存储周期可访问 16 位（即存储字长是 16 位），那么这个单模块存储器带宽 = (1 / 500ns) * 16 位 = (1 / (500 * 10^-9 s)) * 16 位 = 32M 位/秒 = 32Mb/s（1 M = 10^6）
存储周期也可以称为存取周期
那么，如何理解多模块存储器中的 "模块" 呢？
来看一个例子，假设现在 CPU 要连续访问 23、56、88、109 这 4 个地址对应的存储单元
在早期，内存是一整块，地址线、数据线和控制线全都共用一套，每次只能读写一个地址对应的存储单元，CPU 连续读取好几个数据时，必须等前一次读完，才能读下一个
那么 CPU 先访问 23 地址对应存储单元，拿到对应的数据后，然后再将 56 这个地址发送给内存，再读取 56 地址所在的存储单元数据，然后再依次去读取 88、109 地址所在的存储单元数据
这就好比只有一个窗口的银行，所有人排队一个一个办业务，很慢 ，而多模块就是开多个窗口，同时办理业务
这里的每个模块就是一套相对独立的存储芯片阵列，有自己的地址译码、读写控制、数据缓冲，可以和其他模块同时工作（并行），同时，每个模块的存储周期和存储容量都是一样的
在多模块存储器中，CPU 连续读取的几个数据，可以位于不同的模块中，那么 CPU 可以采用流水线的方式读取这些数据
假设地址 23 位于模块 A，地址 56 位于模块 B，地址 88 位于模块 C，地址 109 位于模块 D，现在 CPU 要连续访问 23、56、88、109 这 4 个地址对应的存储单元，那么：
  • CPU 首先将地址 23 发送给主存的模块 A
  • 在模块 A 准备数据的期间，CPU 可以将下一个地址 56 发送给主存的模块 B
  • 在模块 A 和模块 B 准备数据的期间，CPU 可以将下一个地址 88 发送给主存的模块 C
  • 在模块 A、B 和 C 准备数据的期间，CPU 可以将下一个地址 109 发送给主存的模块 D
  • 模块 A 准备好数据，将数据传输给 CPU
  • 模块 B 准备好数据，将数据传输给 CPU
  • 模块 C 准备好数据，将数据传输给 CPU
  • 模块 D 准备好数据，将数据传输给 CPU
可以看到，各个模块都是并行的同时工作（准备数据），相比于早期的内存，其带宽肯定高很多
那么在多模块主存储器中，每个模块的地址是怎么安排的？多模块主存储器有两种编址方式，分别是连续编址和交叉编址

连续编址方式


在连续编址的多模块主存储器中，主存地址的高位表示模块号（或体号），低位表示模块内地址（或体内地址），因此，也称为按高位地址划分方式，地址在模块内连续

下图是连续编址方式示意图，存储器共有 4 个模块 M0～M3，每个模块有 n 个单元，模块 Mi 的地址范围为 i * n～（i+1) * n - 1
连续编址方式下，总是把低位的体内地址送到由高位体号所确定的模块内进行地址译码。上图中数据因按体内地址顺序存放 (一个体存满后，再存入下一个体)，故又有顺序存储之称
按这种编址方式，只要合理调动，使不同的请求源同时访问不同的体，便可实现并行工作。例如，当一个体正与 CPU 交换信息时，另一个体可同时与外部设备（比如 DMA 控制器）进行直接存储器访问，实现两个体并行工作
假设主存储器包含 4 个存储体（M0、M1、M2 和 M3），每个存储体的存储单元都是 8 位，主存地址是 12 位， 如下图：

这里假设：
  • τ 表示总线传输周期，也就是存储器总线传送一次地址或者传送一次数据的时间
  • T 表示主存储器的存储周期，即主存收到地址到数据放在主存内部中的缓冲中的这一段时间
当主存将数据放到缓冲中后，然后存储器总线需要经过一个总线传输周期 τ 将这个数据传送给 CPU
CPU 首先将地址 0 发送给主存的存储体 M0（需要的时间为 τ），M0 需要一个存储周期（即 T）才可以读出对应的存储单元
在 M0 准备数据的期间，CPU 将地址 1027 发送给主存的 M1（需要的时间为 τ），同样，M1 需要一个存储周期（即 T）才可以读出对应的存储单元
在 M0、M1 准备数据的期间，CPU 将地址 3069 发送给主存的 M2（需要的时间为 τ），同样，M2 需要一个存储周期（即 T）才可以读出对应的存储单元
在 M0、M1、M2 准备数据的期间，CPU 将地址 3072 发送给主存的 M3（需要的时间为 τ），同样，M3 需要一个存储周期（即 T）才可以读出对应的存储单元
接下来，到达上图的时刻 t0，M0 经过一个存储周期，读取地址 0 对应的存储单元数据，送到数据总线上，然后数据总线经过时间 τ 将数据传输到 CPU 中
到达上图的时刻 t1，M1 经过一个存储周期，读取地址 1027 对应的存储单元数据，送到数据总线上，然后数据总线经过时间 τ 将数据传输到 CPU 中
到达上图的时刻 t2，M2 经过一个存储周期，读取地址 3069 对应的存储单元数据，送到数据总线上，然后数据总线经过时间 τ 将数据传输到 CPU 中
到达上图的时刻 t3，M3 经过一个存储周期，读取地址 3072 对应的存储单元数据，送到数据总线上，然后数据总线经过时间 τ 将数据传输到 CPU 中
上面是 CPU 连续访问 4 个不相邻的地址的情况，而在实际情况中，CPU 经常需要连续访问相邻地址的存储块，比如一个 int 类型的变量，就保存在相邻的 4 个字节的存储块中
再比如，CPU 和主存之间一般是以主存块为单位进行传输，因为 CPU 和主存之间有一个 Cache，当 Cache 缺失时，会将对应的主存块一起加载到对应 Cache 行中，一个主存块就包含了很多个相邻的地址（即连续的地址）

CPU 首先将地址 0 发送给主存的 M0，然后经过一个存储周期 T，来到上图的时刻 t0，再将数据传输到 CPU 的同时，CPU 可以将下一个地址 1 发送给主存的 M0
M0 经过一个存储周期 T，来到上图的时刻 t1，再将数据传输到 CPU 的同时，CPU 可以将下一个地址 2 发送给主存的 M1
M0 经过一个存储周期 T，来到上图的时刻 t2，再将数据传输到 CPU 的同时，CPU 可以将下一个地址 3 发送给主存的 M0
M0 经过一个存储周期 T，来到上图的时刻 t3，将数据传输到 CPU
很明显，在这种连续编址的多模块主存储器中顺序访问的话，要等一个存储单元访问完了，再去访问下一个存储单元，这个主存储器的带宽就低了
而且，对于连续编址的多模块主存储器，当访问一个连续主存块时，总是先在一个模块内访问，等到该模块全部单元访问完才转到下一个模块访问，因而这种情况下不能提高存储器的带宽

交叉编址方式

为了提高在访问连续主存块时的吞吐率，我们可以使用交叉编址的方式对多模块存储器进行编址

在交叉编址的多模块存储器中，主存地址的低位表示模块 (体) 号，高位表示模块 (体) 内地址，因此，也称按低位地址划分方式

每个模块按 "模 m" 交叉方式编址。假定有 m 个模块 (体)，每个模块有 n 个单元，则第 i (i = 0～m-1) 模块中的地址为 i，i+m，i+2m，…，i+(n-1)*m

一般模块数 m 取 2 的方幂，这样硬件电路比较简单。但有的机器为了减少存储器冲突，采用质数个模块，如我国的银河计算机就取 m 为 31，其硬件实现比较复杂

下图是模 4 (即 m=4) 交叉编址方式存储器示意图

在交叉编址方式下，总是把高位的体内地址送到由低位体号所确定的模块内进行译码

CPU 要连续访问相邻的 4 个地址 0、1、2 和 3，在交叉编址中，这 4 个地址分别位于 M0、M1、M2 和 M3 中，那么就可以采用流水线的方式来访问主存储器，如下图：

首先 CPU 发送地址 0 到主存的 M0（花费时间 τ），M0 需要一个存储周期（即 T）才可以读出对应的存储单元

在 M0、M1 准备数据的同时，CPU 将地址 2 发送到 M2（花费时间 τ），M2 需要一个存储周期（即 T）才可以读出对应的存储单元

在 M0、M1、M2 准备数据的同时，CPU 将地址 3 发送到 M3（花费时间 τ），M3 需要一个存储周期（即 T）才可以读出对应的存储单元

到达上图的时刻 t1，M1 经过一个存储周期，读取地址 1 对应的存储单元数据，送到数据总线上，然后数据总线经过时间 τ 将数据传输到 CPU 中

到达上图的时刻 t2，M2 经过一个存储周期，读取地址 2 对应的存储单元数据，送到数据总线上，然后数据总线经过时间 τ 将数据传输到 CPU 中
