我们先来看下面递归求阶乘的函数，现在假设 main 函数调用 rfact(4)，首先第一条和第二条指令完成比较 n <= 1，根据结果跳转，因为 4 > 1，所以跳转到 $L8 执行：
在 $L8 中的开始段中，第 ① 条指令创建一个大小为 32 字节的 rfact(4) 的栈帧，第 ② 条指令保存 main 函数的返回地址到当前栈帧，第 ③ 条指令保存 $16 这个保存寄存器的值到当前栈帧（这是因为接下来要用到 $16 保存寄存器），在 rfact(4) 的本体段中，先通过 move 指令将 $4 寄存器中的 n 的值 4 放到 $16 这个保存寄存器中（这是因为在递归调用 rfact(n - 1) 后还会用到 n 的值），接下来使用指令 addiu $4, $4, -1 将 n - 1 的值放到 $4 寄存器中，然后调用 rfact(n - 1)，也就是调用 rfact(3)
递归调用执行 rfact(3)，同样比较 n <= 1，因为 3 > 1，所以跳转到 $L8 执行，在 $L8 中的开始段中，第 ① 条指令创建一个大小为 32 字节的 rfact(3) 的栈帧，第 ② 条指令保存 rfact(4) 函数的返回地址到当前栈帧，第 ③ 条指令保存 $16 这个保存寄存器的值到当前栈帧，因为 $16 中保存的是执行 rfact(4) 时的 n 的值（即 4），所以把 n = 4 的值保存到当前栈帧，再通过 move 指令将 $4 寄存器中的 n 的值 3 放到 $16 这个保存寄存器中，接下来使用指令 addiu $4, $4, -1 将 n - 1 的值放到 $4 寄存器中，然后调用 rfact(n - 1)，也就是调用 rfact(2)
递归调用执行 rfact(2)，同样比较 n <= 1，因为 2 > 1，所以跳转到 $L8 执行，在 $L8 中的开始段中，第 ① 条指令创建一个大小为 32 字节的 rfact(2) 的栈帧，第 ② 条指令保存 rfact(3) 函数的返回地址到当前栈帧，第 ③ 条指令保存 $16 这个保存寄存器的值到当前栈帧，因为 $16 中保存的是执行 rfact(3) 时的 n 的值（即 3），所以把 n = 3 的值保存到当前栈帧，再通过 move 指令将 $4 寄存器中的 n 的值 2 放到 $16 这个保存寄存器中，接下来使用指令 addiu $4, $4, -1 将 n - 1 的值放到 $4 寄存器中，调用 rfact(n - 1)，也就是调用 rfact(1)
递归调用执行 rfact(1)，同样比较 n <= 1，因为 1 == 1，所以执行最上面的第 3 条指令 li $2, 1，就是将 1 放到 $2 寄存器，其实就是执行 result = 1，然后执行 jr $31，此时 $31 寄存器中保存的是 rfact(2) 函数的返回地址，所以，跳转执行 rfact(2) 中的 jal rfact 这条指令的下一条指令 mult $2, $16，因为 $16 中保存的是 rfact(2) 中的 n 的值（即 2），因此执行 1 * 2 = 2，乘积结果最终通过 mflo $2 放到 $2 寄存器，这里其实就是执行 result = 2 * rfact(1)

执行完 rfact(2) 的本体段后，开始执行 rfact(2) 的结尾段，第 ① 条指令将 rfact(3) 函数的返回地址恢复到 $31 寄存器，第 ② 条指令将 n 的值 3 恢复到 $16 寄存器中，第 ③ 条指令释放当前 rfact(2) 栈帧，第 ④ 条指令返回到 rfact(3) 函数的调用函数指令 jal rfact 的下一条指令  mult $2, $16，因为 $16 中保存的是 rfact(3) 中的 n 的值（即 3），因此执行 2 * 3 = 6，乘积结果最终通过 mflo $2 放到 $2 寄存器，这里其实就是执行 result = 3 * rfact(2)
执行完 rfact(3) 的本体段后，开始执行 rfact(3) 的结尾段，第 ① 条指令将 rfact(4) 函数的返回地址恢复到 $31 寄存器，第 ② 条指令将 n 的值 4 恢复到 $16 寄存器中，第 ③ 条指令释放当前 rfact(3) 栈帧，第 ④ 条指令返回到 rfact(4) 函数的调用函数指令 jal rfact 的下一条指令  mult $2, $16，因为 $16 中保存的是 rfact(4) 中的 n 的值（即 4），因此执行 6 * 4 = 24，乘积结果最终通过 mflo $2 放到 $2 寄存器，这里其实就是执行 result = 4 * rfact(3)
执行完 rfact(4) 的本体段后，开始执行 rfact(4) 的结尾段，第 ① 条指令将 main 函数的返回地址恢复到 $31 寄存器，第 ② 条指令恢复 $16 寄存器的值，第 ③ 条指令释放当前 rfact(4) 栈帧，第 ④ 条指令返回到 main 函数的调用函数指令 jal rfact 的下一条指令中，至此 rfact(4) 执行完成，结果放在 $2 寄存器中（值是 24）
从上面可以看到汇编代码使用 $16 寄存器保存参数 n，先把 $16 已有的值保存到栈内存，随后在返回前恢复该值。根据栈的使用特性（先进后出）和寄存器保存规则，可以保证当递归调用 rfact(n - 1) 返回时，（1）该次调用的结果会保存在 $2 寄存器中，（2）参数 n 的值仍然在 $16 寄存器中，把这两个值相乘就能得到最终结果
从上面的例子我们也可以看到，递归调用一个函数本身与调用其他函数时一样的。栈规则提供了一种机制，每次函数调用都有它自己私有的状态信息（保存的返回地址和被调用者保存寄存器的值）存储空间。栈分配和释放的规则很自然地就与函数调用 - 返回的顺序匹配
