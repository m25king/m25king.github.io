机器字长的定义就是 CPU 中定点运算数据通路的宽度，也就是一次能处理的二进制数据的位数，A 正确


CPU 中通用寄存器、程序计数器等核心寄存器的位数，通常和机器字长保持一致，因此机器字长和寄存器位数直接相关，B 正确


机器字长直接决定了计算机能表示的数值范围（字长越长，可表示的数的范围越大）和运算精度（字长越长，有效数字位数越多，精度越高），C 正确


机器字长越长，CPU 内部的运算器、寄存器、数据总线等硬件的设计复杂度和成本都会显著提升，会直接影响计算机硬件的造价，D 错误，本题选 D



假定两种浮点数表示格式的位数都是 32 位，但格式 1 的阶码长、尾数短，而格式 2 的阶码短、尾数长，其他所有规定都相同，则它们可表示的数的精度和范围为 (   )。

A.两者可表示的数的范围和精度均相同
B.格式 1 可表示的数的范围更小，但精度更高
C.格式 2 可表示的数的范围更小，但精度更高
D.格式 1 可表示的数的范围更大，且精度更高

在浮点数编码中：


  • 阶码：决定了浮点数可表示的数值范围，阶码位数越长，能表示的指数范围越大，数值范围就越大

  • 尾数：决定了浮点数的表示精度，尾数位数越长，有效数字位数越多，精度就越高


因此：


  • 格式 1：阶码长、尾数短 → 阶码位数多 → 可表示的数值范围更大；尾数位数少 → 精度更低

  • 格式 2：阶码短、尾数长 → 阶码位数少 → 可表示的数值范围更小；尾数位数多 → 精度更高

【2010 第 14 题】假定变量 i、f 和 d 的数据类型分别为 int、float 和 double (int 用补码表示，float 和 double 分别用 IEEE754 单精度和双精度浮点数格式表示), 已 i=785， f=1.5678e3， d=1.5e100。若在 32 位机器中执行下列关系表达式，则结果为 “真” 的是（ ）

I. i==(int)(float)i        

II. f==(float)(int)f

III. f==(float)(double)f       

IV. (d+f)-d=f


A.仅 I 和 II
B.仅 I 和 III
C.仅 II 和 III
D.仅 III 和 IV

 int i = 785， float f = 1.5678e3 = 1.5678 × 10^3， double d = 1.5e100 = 1.5 × 10^100


从 int 到 float 到 double 表示范围是越来越大；但是 int 可以表示 31 位有效的二进制位数，而 float 的有效二进制位数是 24 位（包括隐藏位），double 的有效二进制位数是 53 位（包括隐藏位），因此从 float 到 int 到 double 表示的精度越来越高


在这里，稍微解释下有效二进制位数，比如 int a = 10 = 0000 0000 0000 0000 0000 0000 0000 1010B，那么它的有效二进制位数就是 1010 这四位，再比如 int a = 2^31 - 1 = 0111 1111 1111 1111 1111 1111 1111 1111B，那么它的有效二进制位数就是最后的 31 个 1


如果将这 31 个 1 （2^31 - 1）转换成 float 类型的话，就会损失精度，因为 float 的尾数最高是 24 位，也就是 float 的有效二进制位数是 24，那么将 31 个 1 转成 float 型，就会舍掉 7 个二进制 1，使得精度损失了


对于 I：i == (int)(float) i，因为 i = 785，其有效二进制位数不会超过 24 位，所以将 i 转成 float 类型的话，不会出现精度损失，因此将 i 转换成 float 可以精确表示，然后在转回到 int，也不会出现溢出和精度损失，所以这个选项是 "真"


对于 II：f == (float)(int)f，因为 f 有小数，将其转成 int 整型时，会将小数截断舍掉，所以这个选项不是 "真"


对于 III：f == (float)(double)f，因为 double 的精度比 float 高，表示范围也比 float 大，所以 f 转成 double 可以精确表示，然后再将其转回到 float 的话，也不会损失精度，所以这一项是 "真"


对于 IV：(d + f) - d = f，在做 d + f 的时候，需要先对阶，也就是将 f 的阶向 100 看齐，那么 1.5678 × 10^3 = 0.0...05678 × 10^100，这个尾数小数点后面有 96 个 0，而 double 的有效位只有 52 位，因此会将 52 位后面的二进制都舍掉，所以对接后的 f 的尾数变成 0 了，那么 d + f = d 了，所以 (d + f) - d = 0 而不是等于 f，所以这一项不是 "真"


所以，本题 I 和 III 正确，选 B
