每推出新一代 DRAM 芯片，地址线至少增 1 根，则容量至少提高到原来的 (  ) 倍。

A.2

DRAM 芯片采用二维地址译码，它的地址分为行地址和列地址，我们假设行地址位数是 r，列地址位数是 c，其地址数量是 2^(r + c)

然后 DRAM 芯片采用行列地址引脚复用技术，DRAM 芯片的地址引脚数是 r 和 c 的最大值（即 max(r, c)），那么 DRAM 芯片的地址线的数量也是等于 max(r, c)

现在增加 1 根地址线，也就是增加 1 个地址引脚，那么，行地址位数和列地址位数都可以增加 1 位，即行地址位数是 r + 1，列地址位数是 c + 1，此时地址总数是 2^(r+1+c+1) = 4 * 2^(r + c)

就是说，地址的数量是没有增加地址线之前的 4 倍，因为存储单元没有变，所以，存储容量提高到了原来的 4 倍，本题选 B

DRAM 芯片的存储元电路结构非常的简单，就是由一个 MOS 管 T 和一个电容 Cs 组成，如下图：

当电容 Cs 上存储有大量电荷时表示二进制 1，没有电荷时表示 0

当从这个存储元读出二进制时，Cs 上电荷会放电，电位下降，因此是破坏性读出，读后应有重写操作，称为 "再生"

由于 MOS 管电容 Cs 上存储的电荷会缓慢放电，超过一定时间，就会丢失信息。因此必须定时对 Cs 充电，这一过程称为刷新


因此 DRAM 芯片组成的存储器需要定时对 DRAM 芯片刷新


存储器刷新时主存控制器只给各 DRAM 芯片送行地址和 RAS 信号，芯片中某一行的所有存储元被选中并进行读操作，每次读后再生，即某存储元读出是 0 则充分放电，读出是 1 则进行充电

因此，DRAM 芯片是按行为单位进行刷新的，看下图一个 4M × 4bit 的存储器芯片：


因为 DRAM 芯片的行列地址均分，所以容量 4M × 4bit = 2048×2048×4bit，即有 2048 行，所以只要 2048 次刷新操作就可将整个存储器刷新一遍，因此，本题选 B

由于刷新按行进行，所以无须进行列寻址。芯片内部有一个行地址生成器（也称刷新计数器），由它自动生成刷新行地址，因而刷新计数器的位数与行地址位数相同

行地址缓冲器和刷新计数器通过一个多路选择器（MUX）将选择的行地址输出到行译码器，用于控制是进行刷新操作，还是正常访问主存操作

集中刷新是在规定的一个刷新周期内，对全部存储元集中一段时间逐行进行刷新，如下图


因为是集中对整个芯片进行以行为单位进行刷新，所以刷新期间（即上图的 128 个周期 64μs）内，整个存储器都不能进行正常的读写操作，这里的 64μs，也称为死时间

因此，集中刷新是存在死时间的

分散刷新是指对每行存储单元的刷新分散到每个存储周期内完成，如下图：


分散刷新则是把存储周期 tC 分成两段，前半段 tM 用来正常接收 CPU 发送过来的地址，正常读写数据，后半段 tR 则用来刷新，因此，每个存储周期都可以正常读写数据，所以不存在死时间，本题选 B

异步刷新是前两种方式的结合，它既可以缩短死时间，又充分利用最大刷新间隔，如下图：

在 15.6μs 内只有最后的一个存储周期用于刷新某一行，其他的存储周期用于读写操作，这样刷新一行只停止一个存储周期，对于每行来说，刷新间隔时间仍为 2ms，而死时间缩短为 0.5μs

因此，异步刷新也是存在死时间的

动态半导体存储器（DRAM）的 “动态” 指的是电容电荷会随时间泄漏，并非指存储内容会自动变化。如果不进行刷新，内容会因漏电而丢失，而非主动改变，因此 I 错误

对于 II，这就是刷新（Refresh）操作。由于 DRAM 电容的漏电特性，必须定期（如每 64ms）对所有行进行读出并重新写入，以恢复电荷，防止数据丢失，因此 II 正确

刷新过程中的读并不是把信息读入 CPU，重写也不是从 CPU 向主存存入信息，它只是把信息读出，通过一个刷新放大器后又重新存回存储单元，而刷新放大器是集成在 RAM 上的。因此，这里只进行了一次访存，也就是占用一个存取周期，IV 正确，III 错误

本题 II 和 IV 是正确的，选 C

DRAM 刷新操作按行进行，每次刷新一整行的所有存储单元，A 正确

DRAM 存储单元靠电容电荷存储数据，电容漏电会导致电荷流失，刷新的本质就是对电容重新充电，以恢复原有电荷水平，防止数据丢失，B 正确

DRAM 是破坏性读出，每次读操作都会使电容电荷减少。刷新操作模拟一次 “读” 操作：将行数据读出、放大后再写回，但数据不输出到外部总线，以此完成对整行的刷新，C 正确

DRAM 的刷新操作会占用存储周期，在刷新期间，被刷新的行无法响应 CPU 的访存请求，会对 CPU 的访存造成一定的阻塞或延迟影响。虽然现代 DRAM 通过优化刷新策略（如分散刷新、异步刷新）来降低影响，但并不能做到 "完全不影响"，D 错误

我们可以把上面的读出时间和写入时间称为存储器的存取时间（或者称为访问时间），是指启动一次存储器操作（读或写）到完成该操作所需的全部时间

而上面的读周期和写周期可以称为存储器的存储周期（或者称为存取周期），是指存储器进行连续两次独立的存储器操作（如连续两次读操作，或者连续两次写操作）所需的最小间隔时间

本题选 C


在 DRAM 芯片组成的主存储器中，其存储周期大于存取时间，因为连续两次存储器操作之间需要进行额外的预充电的内部操作；而 SRAM 存储器中，其存储周期一般就是等于存取时间的

若某存储器存储周期为 250ns，每次读出 16 位，该存储器的数据传输速率是 ( )。

A.4×106B/s
B.16MB/s
C.8×106B/s
D.8×220B/s
数据传输速率（也称为带宽），存储器带宽，它表示单位时间内存储器存取的信息量，单位可以用字/秒、字节/秒或者位/秒来表示

每个存储周期读出 16bit=2B，因此数据传输速率为 2B÷(250×10^-9)s，即 8×10^6 B/s，本题选 C

【2010 第 16 题】下列有关 RAM 和 ROM 的叙述中，正确的是（ ）
I. RAM 是易失性存储器，ROM 是非易失性存储器
II. RAM 和 ROM 都采用随机存取方式进行信息访问
III. RAM 和 ROM 都可用作 Cache
IV. RAM 和 ROM 都需要进行刷新

A.仅 I 和 II
B.仅 II 和 III
C.仅 I、II 和 IV
D.仅 II、III 和 IV
ROM 是 Read Only Memory 的缩写，意思就是只读存储器，而 RAM 是 Random Access Memory 的缩写，意思是随机存取存储器

ROM 在正常工作下，只能读出数据，不过为了适应不同的场景，现在的 ROM 也可以写入数据，比如可擦除可编程只读存储器（EPROM）、电擦除电改写只读存储器（EEPROM）等都可以写入数据；而 RAM 既可以读出数据，也可以写入数据，因此 ROM 经常存储那些不经常改变的系统数据，而 RAM 用于存储软件程序产生的会改变的中间数据

RAM 是易失性存储器，一旦断电，数据就会丢失，而 ROM 是非易失性存储器，即使切断电源，存储在 ROM 中的数据也不会丢失，因此选项 I 描述正确

不管是 ROM 还是 RAM，在读写数据的时候，不管数据是存储在哪一个存储单元，只要给出数据所在存储单元的地址，都可以在很短的时间内访问到数据，也就是说访问数据的时间和数据所在的地址无关，因此 ROM 和 RAM 都是随机存取方式的存储器，所以说，采用随机存取方式的存储器并不一定是随机存取存储器（RAM），因此选项 II 描述正确

RAM 又分为 SRAM 和 DRAM，SRAM 是静态 RAM（即 Static RAM），DRAM 是动态 RAM（即 Dynamic RAM）

SRAM 的存储元电路（存储 1 个二进制位的电路）是六个 MOS 管组成，下图的 T1 ~ T6 都是 MOS 管：



SRAM 存储元电路的状态是静态的，只要不改变电源状态或受到外部干扰，数据就会一直保持不变，所以被称为静态随机存取存储器

而 DRAM 存储元电路是由一个 MOS 管 T 和一个电容 Cs 组成，如下图：



为了保持数据的正确性，需要每隔一定的时间对电容进行充电刷新，以补充泄漏的电荷，维持数据的存储状态。这种需要动态刷新来保持数据的特性，使得它被称为动态随机存取存储器

接下来，比较下 SRAM 和 DRAM 的各自特点

① SRAM 用的 MOS 管比较多，占硅片面积大，因此集成度低；而 DRAM 所用 MOS 管少，占硅片面积小，因此集成度高

② SRAM 即使存储元不工作，也有电流流过，功耗大；而 DRAM 存储元不工作，就没有电流流过，因此功耗小

③ SRAM 只要有电源，可保持状态不变，无需刷新，也不会因为读操作而使状态发生改变，读写速度非常快；而 DRAM 会发生漏电，必须定时刷新，读操作后会使得状态变化，需要读后再生，读写速度相对 SRAM 要慢

④ SRAM 价格比较昂贵，适合做高速小容量存储器，比如 CPU 中的高速缓冲 Cache，而 DRAM 价格比较便宜，适合做慢速大容量存储器，比如主存储器一般就是用 DRAM 实现

从上面的比较，可以看出 SRAM 适合用作 Cache， Cache 必须要支持快速的读写速度，而 ROM 虽然可以写，但是写的速度太慢，因此 ROM 不适合作 Cache 用，所以选项 III 描述错误

DRAM 需要进行刷新，而 ROM 是不需要进行刷新的，因此选项 IV 描述错误

所以本题选择 A

【2018 第 17 题】假定 DRAM 芯片中存储阵列的行数为 r、列数为 c，对于一个 2K×1 位的 DRAM 芯片，为保证其地址引脚数最少，并尽量减少刷新开销，则 r、c 的取值分别是（ ）

A.2048、1
B.64、32
C.32、64
D.1、2048
首先，我们知道 DRAM 芯片采用地址线复用技术，行地址和列地址分开，分别通过相同的地址线送到各自的译码器中，因此，要使的地址引脚数最少，那么就需要使得行地址和列地址的位数相差不大，也就是说，存储阵列中的行数 r 和列数 c 不要相差太大

举个例子：假设地址的总位数是 20 位，如果行地址是 15 位，列地址是 5 位的话，采用地址线复用的话，那么必须要有 15 根地址线，因为这样才可以用这 15 根地址线传送 15 位的行地址和 5 位的列地址；假设行地址是 10 位，列地址也是 10 位的话，采用地址线复用的话，那么只需要 10 根地址线即可，因为既可以使用这 10 根地址线传送 10 位的行地址，也可以传送 10 位的列地址，这种情况下的行地址和列地址的位数相差为 0，也是最节省地址线的情况（地址引脚数最少）

因为 DRAM 芯片容量是 2K × 1 位，因此 r × c = 2K = 2048，显然，四个选项都符合这个公式，但是可以首先排除掉 A 和 D，因为它们的 r 和 c 相差太大

对于 A，r = 2048 = 2^11，c = 1 = 2^0，那么行地址位数是 11 位，列地址位数是 0，因此地址引脚数取行地址位数和列地址位数最大值，也就是 11

对于 D，r = 1 = 2^0，c = 2048 = 2^11，同样，地址引脚数也是 11

对于 B 和 C 的话，地址引脚数取行地址位数和列地址位数最大值，那就是 6，因为 2^6 = 64

其次，为了减小刷新开销，而 DRAM 一般是按行刷新的，所以应选行数 c 的值较少的，所以答案为 C
