原码一位乘法

用原码实现乘法运算时，符号位与数值位分开计算，因此，原码乘法运算分为两步
  1. 确定乘积的符号位。由两个乘数的符号异或得到
  2. 计算乘积的数值位。乘积的数值部分为两个乘数的数值部分之积
对于第二步，其实就是计算 2 个无符号数乘积，这里有个很重要的概念，就是部分积 P，看下图：

每将乘数 Y 的一位乘以被乘数得到 X × Yi 后，就将该结果与前面所得到的结果累加，得到 Pi，称之为部分积，每次求部分积 Pi+1 时，都是将上一次的部分积 Pi 和 X × Yi 相加后右移一位
部分积的初始值 P0 = 0，无符号数乘法过程就是循环的计算 P1、P2、P3、P4 的过程，每次求部分积 Pi 的过程是这样的：
  1. 取乘数的最低位 Yi 判断
  2. 若 Yi 是 1 ，则将上一次计算得到的部分积 Pi 和 X 相加；若 Yi 为 0 ，则什么都不做
  3. 右移一位，产生本次部分积 Pi+1
部分积 Pi 和 X 进行无符号数相加，可能会产生进位，因而需要有一个专门的进位位 C。整个迭代过程从乘数最低位 Y0 和 P0=0 开始，经过 n 次“判断一加法一右移”循环，直到求出 Pn 为止。Pn 就是最终的乘积

上图实现两个 32 位无符号数乘法的电路逻辑结构图，两个 32 位无符号数乘积的结果是 64 位
被乘数寄存器 X 用于存放被乘数；乘积寄存器 P 开始时设置为初始部分积 P0 = 0，结束时存放的是 64 位乘积的高 32 位；乘数寄存器 Y 开始时存放乘数，结束时存放的是 64 位乘积的低 32 位
进位触发器 C 保存 ALU 做加法时的进位（即 Cout）；控制逻辑中的计数器初始值是 32，每循环一次，计数器减 1，当计数器为 0 时，乘法运算结束
ALU 时乘法器核心部件，在控制逻辑的控制下，对乘积寄存器 P 和被乘数寄存器 X 的内容进行加运算，在写使能控制下运算结果被送回乘积寄存器 P，进位位存放在 C 中，原码一位乘法流程如下图：
每次循环都要对进位位 C、乘积寄存器 P 的最低位和乘数寄存器 Y 实现同步右移，此时进位位 C 移入到寄存器 P 的最高位，寄存器 P 的最低位移出到寄存器 Y 的最高位，寄存器 Y 的最低位移出，0 移入进位位 C 中（其实就是相当于对进位位 C、乘积寄存器 P 和乘数寄存器 Y 整体进行逻辑右移一位）
从乘数寄存器 Y 的最低位 Y0 开始，逐次把乘数的各个数为 Yi 移到寄存器 Y 的最低位上，因此，寄存器 Y 的最低位被送到控制逻辑以决定被乘数是否需要加到部分积上
假定每次循环在一个时钟周期内完成，则 n 位乘法需要用 n 个时钟周期来完成

补码一位乘法

A.D.Booth 提出了一种补码相乘算法，可以将符号位与数值位合在一起参与运算，直接得出用补码表示的乘积，且正数和负数同等对待。这种算法被称为布斯 (Booth) 乘法
补码一位乘法的逻辑结构图和无符号数乘法电路的逻辑结构图非常类似，只是部分控制逻辑不同，下图是实现 32 位补码一位乘法的电路图：

补码一位乘法的运算规则如下：
  1. 乘数最低位增加一位辅助位 Y-1 = 0
  2. 根据 Yi-1Yi 的值，决定是加 X 的补码，还是减 X 的补码，还是 +0
    1. 如果 Yi-1Yi = 00 或者 11 时，则 [Pi+1] 补 = [Pi+1 + 0] 补
    2. 如果 Yi-1Yi = 01 时，则 [Pi+1] 补 = [Pi+1 - X] 补
    3. 如果 Yi-1Yi = 10 时，则 [Pi+1] 补 = [Pi+1 + X] 补
  3. 每次加减后，对 P 和 Y 整体算术右移一位，得到部分积 Pi+1
  4. 重复第 2 步和第 3 步 32 次，P 和 Y 中存储的就是补码乘法的结果，即 [X × Y] 补

两位乘法的基本思想

不管是原码一位乘法还是补码一位乘法，每一轮只看乘数寄存器中一个位，每次也只右移一位，所以使用这种电路实现的乘法，称为一位乘法，这种速度比较慢
如果对乘数的每两位取值情况进行判断，使每步求出对应于该两位的部分积，则可将乘法速度提高一倍，这种方法被称为两位乘法

对于补码两位乘法也是一样，两位两位的判断和右移

阵列乘法器

乘法器是处理器中进行数据处理的关键部件，大约 1/3 是乘法运算，因此，有必要实现高速乘法运算
前面介绍的原码两位乘法和补码两位乘法，通过一次判断两位乘数来提高乘法速度。同理，可以采用一次判断更多位乘数的乘法，但是多位乘法运算的控制复杂度呈几何级数增长，实现难度很大
随着大规模集成电路技术的飞速发展，出现了采用硬件叠加或流水处理的快速乘法器件，比如阵列乘法器，下图就是使用组合逻辑线路构成的一个 4 位无符号数 × 4 位无符号数阵列乘法器（被乘数 X=X1X2X3X4，乘数 Y=Y1Y2Y3Y4）：

上图中的每个正方形框框就是一个模块，一个模块内部包含了一个与门和一个全加器，与门用于计算 Xi × Yi 的结果，而全加器用于累加部分积，而且 Yi 会送到对应行中的所有模块中，Xi 会送到对应斜列中的所有模块中，这样每一行中被乘数 X 与乘数的某一位 Yi 相乘，产生一组部分积
比如第一行将被乘数 X 和乘数的最低位 Y4 相乘，得到一组部分积，然后将部分积传递到第二行中；在第二行中奖被乘数 X 和乘数的次低位 Y3 相乘，其结果再和第一行的部分积相加，就得到新的部分积送到第三行中；在第三行中奖被乘数 X 和乘数的低位 Y2 相乘，其结果再和第二行的部分积相加，就得到新的部分积送到第四行中；在第四行中奖被乘数 X 和乘数的低位 Y1 相乘，其结果再和第三行的部分积相加，最终就得到最终的结果 P7P6P5P4P3P2P1
上图是基于行波进位加法器的阵列乘法器，采用串行进位，你看上面的模块的全加器不仅依赖上一行的部分积，而且还依赖相同行的前一个模块的进位，这种乘法阵列运算速度比较慢，为了加快运算速度，可以改进优化上面的阵列乘法器，使得在同一行中的模块不依赖前一个模块的进位，就是可以使得前一行的进位和和同时送到下一行中，这样可以提高阵列乘法器的速度
阵列乘法器结构规范，标准化程度高，有利于布局布线，适合用超大规模集成电路实现，且能获得较高的运算速度，其乘法速度仅取决于逻辑门和加法器的传输延迟
对于阵列乘法器了解这么多就可以了，使用阵列乘法器实现的乘法，可以在 1 个时钟周期内完成一次乘法操作，而我们前面讲的使用这种 ALU + 移位的方式实现的乘法，如果是实现 32 位乘法计算的话，至少需要 32 个时钟周期，每个时钟周期，都需要右移一位，然后再做加法
