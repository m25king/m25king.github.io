时钟周期（节拍）：主频的倒数，是计算机中最小的时间单位，一个指令周期通常包含多个时钟周期

机器周期（CPU 周期）：完成一个基本操作（如取指、间址、执行、中断）所需的时间，一个指令周期通常包含多个机器周期

扩展：指令执行过程中的每个操作步骤都有先后顺序，为了使计算机能正确执行指令，CPU 必须按正确的时序产生操作控制信号。由于不同指令对应的操作序列长短不一，序列中各操作执行时间也不相同，因此，需要考虑用怎样的时序方式来控制

早期计算机通常采用机器周期、节拍和脉冲三级时序对数据通路操作进行定时控制。一个指令周期可分为取指令、读操作数、执行并写结果等多个基本工作周期，称为机器周期

一个机器周期内要进行若干步操作。例如，存储器读机器周期有送主存地址、发送读写命令、检测数据有无准备好、取数据等步骤。因此，有必要将一个机器周期再划分成若干节拍，每个动作在一个节拍内完成。为了产生操作控制信号并使某些操作能在一拍时间内配合工作，常在一个节拍内再设置一个或多个工作脉冲


现代计算机中，已不再采用三级时序系统，机器周期的概念已逐渐消失。整个数据通路中的定时信号就是时钟信号，一个时钟周期就是一个节拍

【2009 第 11 题】冯·诺依曼计算机中指令和数据均以二进制形式存放在存储器中，CPU 区分它们的依据是（ ）

对于 A，指令译码的结果就是很多的控制信号，根据控制信号是不能区分存储器中的指令和数据的

对于 B，指令的寻址方式主要有两种
  1. 寄存器间接寻址：PC 寄存器中的内容是指令的有效主存地址，根据 PC 寄存器的地址就可以找到指令
  2. 相对寻址：在执行转移指令时，需要将 (PC) + 偏移量得到指令在主存的地址


很明显，计算机也可以使用寄存器间接寻址和相对寻址来寻址数据，所以不能根据寻址方式来区分指令和数据


对于 C，首先指令周期是指 CPU 每取出并执行一条指令所需的全部时间，包括两个阶段：
  1. 取指阶段完成取指令和分析指令的操作，又称取指周期
  2. 执行阶段完成执行指令的操作，又称执行周期

在取指阶段，从主存中取出的就是指令，而在执行阶段，要去访问主存的话，那么肯定是访问数据，而不是指令，所以可以根据指令周期的不同阶段来区分指令和数据，所以选 C

对于 D，指令和数据都是以二进制形式存放在存储器中的存储单元，也就是说所有的存储单元可以存放数据，也可以存储指令，因此不能根据指令和数据所在的存储单元区分指令和数据

组合逻辑电路在任何时刻的输出信号的稳定值，仅仅与该时刻的输入信号有关，而与该时刻以前的输入信号无关，这种组合逻辑电路一般用于数据处理，所以在 CPU 内部，组合逻辑电路也称为操作元件

所以算术逻辑部件 (ALU) 和 多路选择器 (MUX) 都属于组合逻辑元件，因此选 D

时序电路在任何时刻的输出稳态值，不仅与该时刻的输入信号有关，而且与该时刻以前的输入信号也有关，这种电路具有存储功能，可以保存某一时刻的数据状态，所以也可以称为状态元件

程序计数器 (PC) 和 通用寄存器组 (GPRs) 都属于状态元件

【2024 第 13 题】通常情况下，将汇编语言程序中实现特定功能的指令序列定义成一条伪指令 (pseudo instruction)。下列选项中，CPU 能理解并直接执行的是 (  )。
I：伪指令
II：微指令
III：机器指令
IV：汇编指令

A.仅 I，IV
B.仅 II，III
C.仅 III，IV
D.仅 I，III，IV

对于 I，伪指令不是真正的指令，并没有与之对应的机器码，因此不会被 CPU 执行


对于伪指令，我们在将 MIPS 指令系统的视频 MIPS 中的寄存器寻址 的 15:32 开始，有讲 move 这个伪指令，他并不是真的指令，它实际上是由 addu 指令来实现的，伪指令的作用是提高汇编程序的可读性，我们在视频 printf 函数调用的机器级表示 讲了 MIPS 中的另一个伪指令 li


对于 II，微指令是微程序控制器可以执行的指令，而微程序控制器是属于 CPU 内部的部件，因此，微指令是 CPU 能理解并直接执行


对于 III，机器指令是 CPU 能理解并直接执行


对于 IV，汇编指令是汇编语言中的指令，它们使用助记符来表示机器指令的功能。汇编指令本身并不是 CPU 能直接执行的，它们需要被汇编器转换成机器指令后才能被 CPU 执行，因此汇编指令不能被 CPU 理解并直接执行


所以微指令和机器指令都是可以被 CPU 直接执行的，选 B

【2021 第 17 题】下列寄存器中，汇编语言程序员可见的是 (  )。
I：指令寄存器
II：微指令寄存器
III：基址寄存器
IV：标志/状态寄存器

A.仅 I，II
B.仅 I，IV
C.仅 II，IV
D.仅 III，IV
判断一个寄存器是不是程序员可见，只要看能不能使用汇编指令去操作访问这个寄存器

通用寄存器组很明显是汇编程序员可见的，我们可以通过指令访问通用寄存器组中的寄存器，比如 MIPS 中，add $4,$5,$6 中的 4、5、6 号寄存器都属于通用寄存器

基址寄存器：在 MIPS 中的 sp 寄存器就是一个基址寄存器，用于存放栈顶元素的地址，在汇编程序中，可以使用 lw 或者 sw 指令来操作 sp 这个基址寄存器，比如 lw $3, 24($sp)，因此基址寄存器也是汇编程序员可见的

程序计数器 PC ：我们可以通过转移指令来设置 PC 寄存器的值，比如 j 0x12345678，这条指令就可以设置 PC 的值，因此程序计数器 PC 也是汇编程序员可见的

标志/状态寄存器：在 X86 中，就可以通过 cmp 指令来设置标志寄存器中的标志，然后转移跳转指令 jle 等，则是根据标志寄存器中相应的标志值来决定是否跳转，所以标志/状态寄存器也是程序员可见的

而 MAR、MDR、IR 是 CPU 的内部工作寄存器，对汇编程序员不可见。微指令寄存器属于微程序控制器的组成部分，它是硬件设计者的任务，对汇编程序员是透明的 (即不可见的)

综上所述，III 和 IV 是程序员可见的寄存器，选 D
