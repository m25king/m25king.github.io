有些情况下可能不知道所访问信息的地址，只知道要访问信息的内容特征，此时，只能按内容检索到存储位置进行读写。这种存储器称为按内容访问存储器（Content Addressed Memory，CAM）或相联存储器（Associative Memory，AM)


因此，本题选 B


比如相联存储器存储了学生信息，如下图：


比如现在要查找总分是 600 分的学生信息，那么此时就需要用 600 和上面所有的学生记录的总分字段进行比较查找，找到总分等于 600 分的学生，很明显，这里不是按数据地址来查找，而是按照内容访问存储器，这就是相联存储器

相联存储器的原理在 CPU Cache 中得到了应用，例如，在 Cache 中将主存块的标记同时与每个缓存行的标记字段进行比较，就可以判断出该主存块是否命中

不过，CPU Cache 的底层存储介质是 SRAM，属于静态随机存取存储器，严格符合随机存取存储器的定义，是 RAM 的一种

Cache 的相联寻址（全相联 / 组相联） 是主存地址到 Cache 地址的映射 / 查找策略，并非存储介质的存取方式，与随机存取不冲突

比如，在一个 Cache 组中，按照 Tag 标记查找，就属于相联寻址，是按照内容查找，这里的内容就是 Tag 标记

相联寻址 + 随机存取的组合，是 Cache 在速度和硬件复杂度之间的最优折中，也是现代 CPU Cache 的标准设计

总结：CPU Cache 是「用相联寻址策略的随机存取存储器」，核心属性是 RAM，相联寻址是其附加的地址匹配逻辑  

磁盘属于 ( ) 类型的存储器。

A.随机存储器 (RAM)
B.只读存储器 (ROM)
C.顺序存取存储器 (SAM)
D.直接存取存储器 (DAM)

按存取方式来分，存储器可以分成随机存储、顺序存取、直接存取和按内容存取几类

随机存取存储器 (Random Access Memory，RAM) 的特点是按地址访问存储单元，因为每个地址译码时间相同，所以，在不考虑芯片内部缓冲的前提下，每个单元的访问时间是一个常数，与地址无关。半导体存储器属于随机存取存储器，可用作 CPU Cache 和主存储器

顺序存取存储器 (Sequential Access Memory，SAM) 的特点是信息按顺序存放和读出，其存取时间取决于信息存放位置，如果信息在存储器中的存放位置不同，那么对这个信息的读/写时间也不同

磁带存储器就是一种顺序存取存储器，其存储容量大，但存取速度慢，不论信息处在存储器的哪个位置上，读/写时必须从磁带的起始端开始按顺序寻找

直接存取存储器 (Direct Access Memory，DAM) 的存取方式兼有随机访问和顺序访问的特点。首先可直接选取所需信息所在区域，然后按顺序方式存取

直接存储存储器的存取数据分为直接定位 + 连续存取两个阶段，比如磁盘存储器，磁盘存取一个数据块的过程，就分为直接定位 + 连续存取两个阶段，首先根据磁盘地址，通过磁头进行寻道和旋转找到数据块的起始扇区，然后在同一个磁道上连续存取这个数据块，这就是直接存取


因此，本题选 D

无论数据快在磁道 1 还是磁道 1000，都可通过磁头移动直接定位，无需遍历中间的磁道 / 扇区—— 这是磁盘属于直接存取、而非顺序存取的本质区别

随机存取是 "无差别存取"（任何位置数据的存取时间几乎相同），而直接存取是 "有定位的存取"（定位有延迟，传输无延迟），磁盘因存在位置相关的机械定位延迟，无法达到随机存取的标准，因此属于直接存取，而非随机存取 


上述 3 类存储器都是按所需信息的地址来访问，但有些情况下可能不知道所访问信息的地址，只知道要访问信息的内容特征，此时，只能按内容检索到存储位置进行读写。这种存储器称为按内容访问存储器（Content Addressed Memory，CAM）或相联存储器（Associative Memory，AM)


ROM 是只读存储器，通常只能读取，而不能随机写入，很明显，磁盘是可以写入，因此磁盘不属于 ROM

存储器有 3 个主要性能指标：速度、容量和每位价格 (简称位价，就是存储一个二进制位的成本)，一般来说，速度越快，位价就越高；容量越大，位价就越低，而且容量越大，速度必越低

某一种元件制造的存储器很难同时满足大容量、高速度和低成本的要求。比如双极型半导体存储器的存取速度快，但是难以构成大容量存储器。而大容量、低成本的磁表面存储器的存取速度又远低于半导体存储器，并且难以实现随机存取

因此，计算机把各种不同容量和不同存取速度的存储器按一定的结构有机地组织在一起，形成层次化的存储器体系结构，下图是存储系统层次结构示意图：

程序和数据按不同的层次存放在各级存储器中，整个存储系统在速度、容量和价格等方面具有较好的综合性能指标


所以，本题选 B

计算机的存储系统是一个分层的、完整的体系，如下图：



按速度从快到慢、容量从小到大依次包含：

  1. 寄存器：位于 CPU 内部，速度最快，用于暂存当前运算数据
  2. Cache（高速缓存）：位于 CPU 与主存之间，用于缓存 CPU 频繁访问的数据与指令，缓解速度差
  3. 主存储器（内存）：包含 RAM 和 ROM，是程序运行的直接载体
  4. 外存储器（辅存）：如硬盘、U 盘等，用于永久保存数据和程序


因此，本题选 D


在下列几种存储器中，CPU 不能直接访问的是 ( )。

A.硬盘
B.内存
C.Cache
D.寄存器
CPU 只能直接访问物理上与它直接相连、并通过地址总线寻址的存储器

对于寄存器，它直接集成在 CPU 内部，是 CPU 可直接访问的最快存储单元

对于 Cache，位于 CPU 与主存之间，由硬件自动管理，CPU 可直接读写

对于内存/主存，通过系统总线与 CPU 连接，是程序运行的直接载体，CPU 可直接访问

对于硬盘这种辅存，属于外部存储，需要先将数据加载到内存中，CPU 才能通过访问内存间接使用硬盘数据，CPU 无法直接寻址或读写硬盘，因此，本题选 A


如何理解 CPU 不能直接访问辅存？
我们知道 CPU 可以通过 IN 和 OUT 指令来访问外设，那么肯定也可以访问磁盘哈，对吧，那这不就是 CPU 直接访问辅存了？
这样理解是不对的，看下图：

在 CPU 中，OUT 0x3349, eax 这条指令，执行的是将 CPU 中的 eax 寄存器中的数据写到磁盘控制器（磁盘 I/O 接口）中的数据寄存器中的，也就是说 IN/OUT 指令用于 CPU 直接访问 I/O 接口中的寄存器（即 I/O 端口），而不是直接访问磁盘的，所以，IN 和 OUT 指令也不是直接访问辅存的
如果 CPU 要访问辅存（磁盘）中的数据块的话，那么只能通过 DMA 控制器将磁盘中的数据块先传输到主存储器中，然后 CPU 再从主存中访问对应的数据，因此，CPU 不能直接访问辅存，辅存只能与主存交换信息

可以看到内存（即上图的主存储器）必须由 RAM 和 ROM 组成，因此，本题选 C


怎么理解呢？


首先，内存必须是可以随机读和随机写的，因此，内存必须由 RAM 组成，这个很好理解，对吧


然后题目说了操作系统是保存在硬盘中的，实际上就是这样的，比如你的电脑的 windows 操作系统就是保存在 C 盘中的


但是电脑启动时，CPU 是无法直接读取硬盘中的数据的，也就是说，如果系统没有启动引导的程序，CPU 是不能将硬盘中的操作系统加载到内存中的


这个时候，就需要用到 ROM，在 ROM 中固化了 BIOS/UEFI 固件，负责开机自检（POST）并将硬盘中的操作系统内核加载到 RAM 中


对于开机启动的流程，我们将在操作系统中详细学习


所以说，计算机的内存储器必须同时包含 RAM 和 ROM，二者功能互补，ROM 负责启动引导，RAM 负责系统运行，是计算机内存的标准配置
