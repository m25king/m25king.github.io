DMA 方式的数据交换不是由 CPU 执行一段程序来完成，而是在 (   ) 之间建立一条逻辑上的直接数据通路，由 DMA 控制器来实现的。

A.CPU 与主存之间
B.外设与主存之间
C.外设与 CPU 之间
D.外设与外设之间

DMA（直接存储器访问）的核心思想，就是在外设和主存之间建立一条直接的数据通路，绕过 CPU，由 DMA 控制器直接控制数据传输，本题选 B

以下关于 DMA 控制器和 CPU 关系的叙述中，错误的是(   )。

A.DMA 控制器和 CPU 都可以作为总线的主控设备
B.DMA 控制器和 CPU 都要使用总线时，CPU 优先级更高
C.CPU 可通过执行 I/O 指令来访问 DMA 控制器中的 I/O 端口
D.CPU 可通过执行 I/O 指令来启动进行 DMA 传送的设备

A 正确：DMA 控制器和 CPU 都可以作为总线的主控设备。DMA 控制器在进行数据传输时，会接管总线控制权，成为总线主设备


B 错误：当 DMA 控制器和 CPU 同时请求使用总线时，DMA 控制器的优先级更高。这是因为外设的数据传输有时间限制（比如磁盘数据必须在规定时间内完成读写，否则数据会丢失），CPU 必须为 DMA 让道，本题选 B


C 正确：CPU 可以通过执行 I/O 指令（如 IN/OUT）来访问 DMA 控制器中的寄存器端口，设置传输参数


D 正确：CPU 通过执行 I/O 指令来设置 DMA 控制器，从而启动外设进行 DMA 传输

以下是有关对 DMA 方式的叙述：① DMA 控制器向 CPU 请求的是总线使用权；② DMA 方式可用于键盘和鼠标器的数据输入；③ DMA 方式下整个 I/O 过程完全不需要 CPU 介入；④ DMA 方式需要用中断处理进行辅助操作，以上叙述中，错误的是(   )。

A.仅①和②
B.仅②和③
C.仅②和④
D.仅③和④
DMA 控制器需要获得总线控制权，才能直接控制外设与主存的数据传输，因此它会向 CPU 发出总线请求，① 正确，看下图：


其中上图第 ③ 步就是向主存控制器申请存储器总线的控制权，注意，现代的计算机主存控制器一般是位于 CPU 中的，所以，我们也可以说 DMA 控制器向 CPU 申请存储器总线的控制权


DMA 适用于高速、大量数据传输的场景，比如磁盘、网卡。键盘和鼠标属于低速字符设备，数据量很小，用中断方式更高效，不需要 DMA，② 错误


DMA 传输前，CPU 需要执行指令来初始化 DMA 控制器（设置源地址、目的地址、传输长度）；传输结束后，CPU 需要响应中断进行后续处理。因此，DMA 并非完全不需要 CPU 介入，③ 错误


DMA 传输结束后，DMA 控制器会向 CPU 发 DMA 结束中断信号，通知 CPU 数据传输完成，④ 正确


因此 ② 和 ③ 错误，本题选 B

以下 (   ) 情况出现时，会引起 CPU 自动查询有无中断请求，进而可能进入中断响应周期。

A.一条指令执行结束
B.一次 I/O 操作结束
C.一次中断处理结束
D.一次 DMA 操作结束

CPU 只会在一条指令执行结束时，才会自动查询有无中断请求，并判断是否进入中断响应周期，本题选 A


I/O 操作本身不会触发 CPU 查询中断，I/O 设备需要主动发出中断请求，CPU 才会处理


中断处理结束时，CPU 会恢复现场并返回原程序，此时不会主动查询中断请求


DMA 操作结束会发出 DMA 结束中断请求，但 CPU 并不会因此自动查询，还是要等到下一条指令结束时才会处理

下列有关磁盘存储器读/写操作的叙述中，错误的是 ( )。

A.最小读/写单位可以是一个扇区
B.采用直接存储器存取 DMA 方式进行输入/输出
C.按批处理方式进行一个数据块的读/写
D.磁盘存储器可与 CPU 交换盘面上的存储信息

A 正确：磁盘的最小读写单位是扇区（通常 512B 或 4KB），不能直接读写单个字节


B 正确：磁盘属于高速外设，为了高效传输数据，通常采用 DMA 方式与主存交换数据


C 正确：磁盘按数据块（扇区 / 簇）为单位进行批量读写


D 错误：磁盘不能直接和 CPU 交换数据，必须先通过 DMA 方式将数据读入主存，再由 CPU 访问主存中的数据。磁盘控制器与 CPU 之间仅传递控制信号，不直接传输存储信息

以下 I/O 控制方式中，主要由硬件而不是软件实现数据传送的方式是(  )

A.程序查询方式
B.中断方式
C.DMA方式
D.无条件程序控制方式

A 程序查询方式：完全由 CPU 执行指令来轮询设备状态、传输数据，是纯软件实现


B 中断方式：CPU 响应中断后，仍需执行中断服务程序（软件）来完成数据传输，硬件仅用于触发中断


C DMA 方式：数据传输由 DMA 控制器硬件直接控制，在外设和主存之间建立数据通路，CPU 仅需在传输前后进行初始化和收尾操作，数据传输过程完全由硬件实现，本题选 C


D 无条件程序控制方式：CPU 直接执行 I/O 指令进行数据传输，也是纯软件实现

周期挪用方式常用于 (   ) 方式的输入/输出控制中。

A.DMA
B.中断
C.程序查询
D.通道
周期挪用的核心思想是 DMA 控制器在不影响 CPU 正常运行的前提下，挪用 CPU 的总线周期来完成一次数据传输。它是 DMA 传输的典型控制方式之一，本题选 A

中断方式下，数据传输由 CPU 执行中断服务程序完成，不需要通过挪用总线周期来传输数据

程序查询方式下，CPU 主动轮询设备状态并执行 I/O 指令，没有周期挪用的概念

通道是一种更高级的 I/O 控制方式，本身是独立的处理器，不需要挪用 CPU 周期（这个我们在操作系统中还会详细讲解）

采用周期挪用方式进行数据传送时，每传送一个数据要占用一个(   )的时间。

A.指令周期
B.机器周期
C.时钟周期
D.存储周期
周期挪用是 DMA 的一种工作方式，它的核心是：DMA 控制器在不影响 CPU 正常运行的前提下，挪用一次存储器访问周期，完成一个数据的传输

D 存储周期：存储器完成一次读或写操作所需的时间，正好对应 DMA 传输一个数据的时间，本题选 D

【2013 第 22 题】下列关于中断 I/O 方式和 DMA 方式比较的叙述中，错误的是（ ）

A.中断 I/O 方式请求的是 CPU 处理时间，DMA 方式请求的是总线使用权
B.中断响应发生在一条指令执行结束后，DMA 响应发生在一个总线事务完成后
C.中断 I/O 方式下数据传送通过软件完成，DMA 方式下数据传送由硬件完成
D.中断 I/O 方式适用于所有外部设备，DMA 方式仅适用于快速外部设备
在中断 I/O 方式下，I/O 设备给 CPU 发送中断信号，然后 CPU 响应中断，并且执行相应中断服务程序，不管是中断响应还是中断处理，都需要 CPU 的参与，因此中断 I/O 方式请求的是 CPU 处理时间

在 DMA 方式下，DMA 控制器需要控制使用 I/O 总线和存储器总线传输设备和主存之间的数据，在数据传输的过程中，不需要 CPU 的参与，所以，DMA 方式请求的是总线使用权，因此 A 描述正确

CPU 响应中断的三个条件：
  1. 至少有一个中断请求
  2. 当前指令执行完成
  3. CPU 处于开中断

因此，中断响应发生在一条指令执行结束后；因为 DMA 请求的是总线使用权，所以，只有在一个总线事务完成后，才会去响应 DMA 的请求，因此 B 描述正确

中断 I/O 方式下数据传送通过中断服务程序（即软件）完成的，而 DMA 方式下，由 DMA 控制器直接控制总线传输数据，所以 DMA 方式下数据传送由硬件完成，C 描述正确

中断 I/O 方式可以用于一些低速的外部设备（比如鼠标、键盘、打印机等），但是不能适用于高速的外部设备，比如磁盘，而 DMA 一般适用于快速外部设备，所以 D 描述错误，选 D

【2019 第 22 题】下列关于 DMA 方式的叙述中，正确的是（ ）
I：DMA 传送前由设备驱动程序设置传送参数
II：数据传送前由 DMA 控制器请求总线使用权
III：数据传送由 DMA 控制器直接控制总线完成
IV：DMA 传送结束后的处理由中断服务程序完成

A.仅 I，II
B.仅 I，III，IV
C.仅 II，III，IV
D.I，II，III，IV
DMA 的数据传送过程分为预处理、数据传送和后处理 3 个阶段

预处理阶段需要设置一些初始化传送参数，比如主存起始地址、数据交换的个数等，这些参数是有设备的驱动程序设置的，所以 I 正确

数据传送的时候，DMA 接口向 CPU 申请总线控制权，拿到总线控制权后，DMA 控制器直接控制总线完成数据传输，所以 II、III 都正确

当数据传送完毕，DMA 接口向 CPU 发起中断信号，由中断服务程序完成 DMA 的后处理阶段，所以 IV 正确

因此，本题选 D

【2023 第 22 题】下列关于 I/O 控制方式的叙述中，错误的是 ( )。

A.查询方式下，通过 CPU 执行查询程序进行 I/O 操作
B.中断方式下，通过 CPU 执行中断服务程序进行 I/O 操作

在查询方式下，CPU 执行查询程序不断地对设备进行查询，如果设备准备好数据，就读取设备的数据，如果设备还没准备好，或者设备忙的话，那么 CPU 等待（或者不断地对设备进行查询），因此，查询方式下，通过 CPU 执行查询程序进行 I/O 操作，A 描述正确

中断方式下，设备准备好数据的话，给 CPU 发送中断信号，然后由中断服务程序来读取设备的数据，所以说，中断方式下，通过 CPU 执行中断服务程序进行 I/O 操作，B 描述正确

DMA 方式下，设备的数据是用硬件 DMA 控制器控制总线传输的，数据传送时，不需要 CPU 的参与，因此，DMA 方式下，不是通过 CPU 执行 DMA 传送程序进行 I/O 操作，所以 C 描述错误，选 C

DMA 使用于高速设备，比如 SSD、网络适配器等高速设备，D 描述正确

DMA 的作用是实现外设数据和主存数据的直接交换，所以 DMA 控制器控制的数据传输通路位于设备接口和主存之间，所以选 C


注意，DMA 传输数据时，分为预处理、数据传输和后处理三个阶段，其中在数据传输的过程不需要 CPU 的参与


不过，DMA 传输前的预处理和传输后的后处理阶段还是需要 CPU 参与的，预处理通常由设备驱动程序来完成，后处理通常由中断处理程序来完成


预处理阶段的数据交换主要发生在 CPU 和 DMA 控制器之间（将参数从 CPU 中送到 DMA 接口中的寄存器），不过题目问的是数据传输的通路
