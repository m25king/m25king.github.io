0 号寄存器（$0）

编号为 0 的 zero 寄存器，它的值恒为 0，之所以设置一个恒为 0 的 0 号寄存器，是因为常数 0 是经常被使用的，将经常使用的常数 0 放在 0 号寄存器中，可以提升指令执行速度，因为指令从寄存器取出 0，总比从主存中取出 0 要快很多
这个 0 号寄存器还可以简化指令集，在程序执行的时候，经常需要将一个寄存器中的值复制到另一个寄存器中，这个通过 addu 指令就可以实现，比如：

不过，在看 mips 汇编指令的时候，你可能会看到上面 move $2, $4 指令，它的作用就是将 4 号寄存器的值传送到 2 号寄存器，在 mips 中，是不存在 move 指令，它是一条伪指令，它实际上还是通过加 0 号寄存器来实现，之所以使用 move 伪指令，是为了提高汇编程序的可读性
