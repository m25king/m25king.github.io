看下面的描述：

I：若寄存器内容为 1000 0000，若它等于 -0，则为原码表示

II：若寄存器内容为 1111 1111，若它等于 127，则为移码表示

III：若寄存器内容为 1111 1111，若它等于 -1，则为补码表示

IV：若寄存器内容为 0000 0000，若它等于 -128，则为移码表示

其中描述正确的是（ ）

A.I
B.I、II
C.I、II、III
D.I、II、III、IV

若寄存器内容为 1000 0000，采用原码表示的话，其值是 -0，I 描述正确


若寄存器内容为 1111 1111，采用移码表示的话，其偏置值是 2^7，那么它的值 = 1111 1111 - 2^7 = 2^8 - 1 - 2^7 = 256 - 1 - 128 = 127，II 描述正确


对于 n 位移码，如果没有明确说明它的偏置值的话，那么偏置值一般就是取 2^(n-1)


若寄存器内容为 1111 1111，采用补码表示的话，那么它的值就是 -2^0 = -1，III 正确


若寄存器内容为 0000 0000，采用移码表示的话，其偏置值是 2^7，那么它的值 = 0000 0000 - 2^7 = 0 - 2^7 = -128，IV 描述正确


所以本题选 D

A.相同位数的补码和移码表示具有相同的表数范围
B.零的补码和移码表示相同
C.同一个数的补码和移码表示，其数值部分相同，而符号相反
D.一般用移码表示浮点数的阶，而补码表示定点整数
相同位数的补码和移码，表数范围完全一致（例如 n 位补码 / 移码，范围均为−2^(n−1) ∼ 2^(n−1) − 1），A 正确

零的补码和移码表示不同。以 4 位编码为例：
  • 0 的补码是 0000
  • 0 的移码是 1000（移码是在真值基础上加上偏置常数 2^(n - 1)，4 位移码的偏置常数是 2^3）


B 错误，本题选 B

同一个数的补码和移码，数值部分（尾数）相同，仅符号位相反（移码符号位与补码符号位取反），C 正确

在计算机体系结构中，移码常用于表示浮点数的阶码（便于比较大小），补码则常用于表示定点整数（便于加减运算），D 正确

下列为 8 位移码机器数 [x]移，求 [-x]移 时，( ) 将会发生溢出。

A.11111111
B.00000000
C.10000000
D.01111111
对于 8 位移码能表示的数值范围是 -2^7 ~ 2^7 - 1（即 -128 ~ 127），其偏置值是 2^7 = 128

对于 A，x = 11111111 - 2^7 = 255 - 128 = 127，那么 -x = -127，在 8 位移码表示的范围内，因此求 [-x]移 时，不会发生溢出

对于 B，x = 00000000 - 2^7 = 0 - 128 = -128，那么 -x = 128，超过了 8 位移码能表示的最大值 127，所以求 [-x]移 时，会发生溢出，本题选 B


对于 C，x = 10000000 - 2^7 = 128 - 128 = 0，那么 -x = 0，在 8 位移码表示的范围内，因此求 [-x]移 时，不会发生溢出


对于 D，x = 01111111- 2^7 = 127 - 128 = -1，那么 -x = 1，在 8 位移码表示的范围内，因此求 [-x]移 时，不会发生溢出

一个 8 位的二进制整数由 2 个 "0" 和 6 个 "1" 组成

若采用移码表示，二进制越大，能表示的数值越大，因此，能表示的最大值的二进制移码是 1111 1100，能表示的最小值的二进制移码是 0011 1111

对于，采用移码表示，偏置值为 127，因此：
  • 表示的最大值 = 1111 1100 - 127 = 1111 1111 - 0000 0011 - 127 = 255 - 3 - 127 = 125
  • 表示的最小值 = 0011 1111 - 127 = 2^6 - 1 - 127 = -64，因此 A 正确，本题选 A
