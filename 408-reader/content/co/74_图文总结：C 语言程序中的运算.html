加、减、乘、除等算术运算是高级语言必须提供的基本运算。C 语言中除算术运算外，还有这几类基本运算：按位、逻辑、移位、位扩展和位截断等运算
对于位扩展和位截断，在前面已经学习过了，接下来主要就是来看下按位、逻辑、移位这 3 种运算，对于加、减、乘、除等算术运算稍后再看

按位运算

C 语言中按位运算包括：按位与运算（&）、按位或运算（|）、按位取反运算（~）、按位异或运算（^）

对于按位与运算，操作数有一个为 0，那么结果是 0，操作数都是 1 时，结果才是 1
对于按位或运算，操作数有一个为 1，那么结果是 1，操作数都是 0 时，结果才是 0
对于按位取反运算，0 取反得到 1，1 取反得到 0
对于按位异或运算，操作数相同，结果是 0，操作数不同，结果是 1

再来看一个例子，假设机器字长是 32 位，变量 x = 0x87654321
现在要求将 x 的最低有效字节设置成全 1，其他的字节保持不变
按位或运算的特点：不管是 0 还是 1，只要和 1 取或的话，就得到 1；不管是 0 还是 1，只要和 0 取或的话，就得到本身
因此，我们可以将 x 和 0xFF 按位取或，即 x | 0xFF = 0x87654321 | 0x000000FF = 0x876543FF（最低有效字节设置成全 1，其他的字节保持不变）

现在要求除了 x 的最低有效字节外，其他的位都取反，最低有效字节保持不变
按位异或运算的特点：不管是 0 还是 1，只要和 1 取异或的话，就得到相反的二进制（相当于取反）；不管是 0 还是 1，只要和 0 取异或的话，就得到本身
因此，我们可以将 x 和 ~0xFF 按位取异或，即 x | ~0xFF = 0x87654321 | 0xFFFFFF00 = 0x789ABC21（除了 x 的最低有效字节外，其他的位都取反，最低有效字节保持不变），看下图：

你看，低 8 位和全 0 取异或，得到本身；高 24 位和全 1 取异或，相当于取反了，这就是按位异或的特点

逻辑运算

C 语言中的逻辑运算包括或运算（||）、与运算（&&）、非运算（!），这个和按位运算的功能完全不同，逻辑运算是非数值计算，即操作数只有两个逻辑值：True 和 False，通常用非 0 表示 True，0 表示 False，看下图：

对非零数值 0x41 取非，得到 False（结果 0），对零 0x00 取非，得到 True（结果 1），两个非零数值 0x69 和 0x55 取与运算得到 True（结果 1）
逻辑运算符 && 和 || 与它们对应的位级运算 & 和 | 之间另一个重要的区别是，如果对第一个参数求值就能确定表达式的结果，那么逻辑运算符就不会对第二个参数求值（这就是短路求值特性）。比如：
表达式 a && 5/a 将不会造成被零除，当 a = 0 的话，&& 前面的结果就是 False 了，不管 && 的后面结果是啥，都不影响整个表达式的结果是 False，因此，此时不会执行 5/a，也就不会出现除零异常
表达式 p&&p++ 也不会导致间接引用空指针，当 p = NULL （即 p = 0）的话，整个表达式就是 False，不会执行 p++，也就不会导致间接引用空指针

移位运算

移位运算包括逻辑移位和算术移位，逻辑移位不需要考虑符号位，一般对无符号整数进行移位称为逻辑移位，而算术移位需要考虑符号位，一般对有符号数进行移位的称为算术移位

对于移位运算，在硬件层面上，可以使用带移位功能的寄存器来实现，这种寄存器称为移位寄存器（也可以简称移位器）
