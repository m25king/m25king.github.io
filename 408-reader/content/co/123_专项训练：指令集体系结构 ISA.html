在计算机系统中，描述系统运行状态的部件是(   )。

A.程序计数器
B.累加器
C.通用寄存器
D.程序状态字寄存器
A 程序计数器 (PC)：用于存放下一条要执行的指令的地址，仅跟踪指令执行的位置，不描述系统整体运行状态，不符合题意

B 累加器 (ACC)：用于暂存算术 / 逻辑运算的操作数或中间结果，属于运算器的工作寄存器，不存储系统状态信息，不符合题意

C 通用寄存器：用于存放数据、地址等临时信息，供指令灵活寻址使用，不承担描述系统运行状态的功能，不符合题意

D 程序状态字寄存器 (PSW，也叫标志寄存器)：专门用于存放系统运行状态和指令执行结果的标志信息（如运算溢出、进位、中断允许、特权级等），是描述系统运行状态的核心部件，本题选 D

下列有关 RISC 特征的描述中，错误的是 (  ) 

A.指令格式规整，寻址方式少
B.采用硬连线控制和指令流水线
C.配置的通用寄存器数目不多
D.运算类指令的操作数不访存
RISC 指令格式规整（通常固定长度），且为了简化硬件，寻址方式少（常用简单寻址为主），A 正确

RISC 内部采用硬连线控制（组合逻辑），而非微程序控制；同时支持指令流水线高效执行。B 正确

RISC 为了减少访问内存的延迟、提升流水线效率，配置的通用寄存器数目通常很多（而非不多）。C 错误，本题选 C

RISC 的定义核心就是指令种类少、格式简单、寻址方式简单，运算类指令大多在寄存器之间操作，不会访问主存，D 正确

通常将在部件之间进行数据传送的指令称为传送指令。以下有关各类传送指令功能的叙述中，错误的是 (   )。

A.出栈/入栈指令 (push/pop) 完成 CPU 和栈顶之间的数据传送
B.访存指令 (load/store) 完成 CPU 和存储单元之间的数据传送
C.I/O指令 (in/out) 完成 CPU 和 I/O 端口之间的数据传送
D.寄存器传送指令 (move) 完成 CPU 和寄存器之间的数据传送
入栈指令push将 CPU 寄存器的数据压入栈顶，出栈指令pop将栈顶数据弹出到 CPU 寄存器，完成 CPU 与栈顶（内存的栈区）的数据传送，A 正确

load（取数）指令将存储单元的数据加载到 CPU 寄存器，store（存数）指令将 CPU 寄存器的数据写入存储单元，完成 CPU 与主存之间的数据传送，B 正确

in 指令将 I/O 端口的数据读入 CPU，out 指令将 CPU 的数据输出到 I/O 端口，完成 CPU 与外设端口之间的数据传送，C 正确

寄存器传送指令 move（如 MOV R1, R2）的功能是在 CPU 内部的通用寄存器之间传送数据，而不是 CPU 和寄存器之间。寄存器本身就是 CPU 的组成部分，D 错误，本题选 D

下列关于指令集体系结构和指令系统的说法中，错误的是 ( )。

A.指令集体系结构位于计算机软/硬件的交界面上
B.指令集体系结构是指低级语言程序员所看到的概念结构和功能特性
C.任何程序运行前都要先转换为机器语言程序
D.指令系统和机器语言是无关的
指令集体系结构（ISA）是计算机硬件和软件之间的接口，位于软硬件的交界面上，硬件实现 ISA，软件基于 ISA 开发，A 正确

ISA 是低级语言（汇编语言、机器语言）程序员可见的计算机概念结构和功能特性，包括指令格式、寻址方式、寄存器等，B 正确

计算机硬件只能直接执行机器语言（二进制指令），因此任何高级语言、汇编语言编写的程序，运行前都必须通过编译 / 汇编转换为机器语言程序，C 正确

指令系统就是机器语言的集合，机器语言是指令系统的二进制编码形式，二者一一对应、紧密相关，因此 D 错误，本题选 D

下列有关指令集体系结构 (ISA) 的叙述中，错误的是 ( )。

A.ISA 规定了执行每条指令时所包含的控制信号
B.ISA 规定了指令获取操作数的方式，即寻址方式
C.ISA 规定了所有指令的集合，包括指令格式和操作类型
D.ISA 规定了程序可访问的寄存器个数、存储空间大小、编址方式和大端/小端方式

执行每条指令时的控制信号，是 CPU 内部微体系结构（硬件实现层）的内容，由硬件设计者决定，不属于 ISA 的定义范围。ISA 只规定 “指令做什么”，不规定 “硬件怎么发控制信号实现它”，因此 A 错误，本题选 A

下列关于 RISC 的叙述中，正确的是 ( )。

A.RISC 机一定采用流水技术
B.采用流水技术的机器一定是 RISC 机
C.RISC 机的兼容性优于 CISC 机
D.CPU 配备很少的通用寄存器

RISC（精简指令集计算机）的核心设计目标就是高效执行，其指令格式规整、长度固定、寻址方式简单，天然适配指令流水线技术，因此 RISC 机一定采用流水技术来提升执行效率，A 正确，本题选 A


流水技术不是 RISC 的专利，现代 CISC（复杂指令集计算机，如 x86）处理器也会采用流水线（甚至超标量流水线）来提升性能，B 错误


CISC 机（如 x86）拥有庞大的指令集和长期的软件生态，兼容性远优于 RISC 机；RISC 架构（如早期 ARM）需要重新开发软件生态，兼容性较差，C 错误


RISC 机为了减少访存、提升流水线效率，会配备大量通用寄存器（Load/Store 架构，运算在寄存器间完成），D 错误

下列描述中，不符合 RISC 指令系统特点的是 ( )。

A.指令长度固定，指令种类少
B.寻址方式种类尽量减少，指令功能尽可能强
C.增加寄存器的数目，以尽量减少访存次数
D.选取使用频率最高的一些简单指令，以及很有用但不复杂的指令

A、C 和 D 都是 RISC 的特点。对于 B，寻址方式种类尽量减少是 RISC 的特点，而增强指令的功能则是 CISC 的特点。RISC 指令功能简单，复杂指令的功能由简单指令的组合来实现

下列关于 RISC 和 CISC 的说法中，不正确的是 ( )。

A.RISC 指令格式种类少，寻址方式少，指令长度固定，更容易用硬布线电路实现
B.CISC 指令功能强大，寻址方式多，便于汇编程序员编程
C.CISC 指令格式种类多，所以更有利于编译优化
D.RISC 多数指令能够在一个时钟周期内完成，特别适合流水线工作

RISC 的核心特征就是指令格式规整、种类少，寻址方式简单，指令长度固定，这种设计天然适配硬布线（硬连线）控制电路，A 正确


CISC（复杂指令集）的指令功能强大、寻址方式丰富，能直接用单条指令完成复杂操作，降低了汇编编程的难度，便于程序员使用，B 正确


编译优化依赖规整、统一的指令格式。CISC 指令格式种类多、长度可变、寻址方式复杂，会大幅增加编译器的设计难度，不利于编译优化；而 RISC 才是更有利于编译优化的架构，C 错误，本题选 C


RISC 指令功能简单，绝大多数指令可以在一个时钟周期内完成，完美适配指令流水线技术，能极大提升 CPU 执行效率，D 正确

I：指令字格式和指令类型
II：CPU 的时钟周期
III：通用寄存器个数和位数
IV：加法器的进位方式

A.仅 I，II
B.仅 I，III
C.仅 II，IV
D.仅 I，III，IV

指令字格式和指令类型、通用寄存器个数和位数都由 ISA 规定


两个 CPU 可以有不同的时钟周期，但指令集可以相同，因此 CPU 的时钟周期不由 ISA 规定，而是由 CPU 设计制造者规定。同样，加法器的进位方式涉及电路设计，也不由指令集规定，而是由 CPU 设计制造者规定


因此选项 I 和 III 正确，选 C

【2010 第 18 题】下列寄存器中，汇编语言程序员可见的是（ ）

A.存储器地址寄存器(MAR)
B.程序计数器(PC)
C.存储器数据寄存器(MDR)
D.指令寄存器(IR)

首先必须明白 "汇编语言程序员可见" 的含义，即汇编语言程序员通过汇编程序可以对某个寄存器进行访问


比如在 MIPS 中的通用寄存器就是汇编语言程序员可见的，指令 add $2, $4, $5 就可以直接访问 2、4、5 号通用寄存器


汇编程序员可以通过指定待执行指令的地址来设置 PC 的值，如转移指令（jump 0x1234568）、子程序调用指令等都可以直接设置 PC 寄存器的值，因此 PC 是汇编程序员可见的寄存器，选 B


而 IR、MAR、MDR 是 CPU 的内部工作寄存器，程序员无法直接获取和设置它们的值，也无法直接对它们进行其他操作，所以对程序员不可见
