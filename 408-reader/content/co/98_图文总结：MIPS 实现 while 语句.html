第一个指令 li 是将 result 的值初始化为 1，放在 2 号寄存器；接下来先执行一轮循环，这个是 do while 的特点，第二个指令 mult 将 result 和 n 相乘，乘积放在 Lo 寄存器；第三个指令 mflo 将乘积结果放在 2 号寄存器，相当于将乘积结果赋值给 result；第四个指令 addiu 将 n 减去 1，结果赋值给 n；第五个指令 slt 判断循环条件，如果 n 小于 2，则将 R[$3] 设置为 1，如果 n 大于等于 2 的话，那么 R[$3] 设置为 0；第六个指令 beq 判断如果  R[$3] == 0，说明 n 大于等于 2，也就是 n 大于 1，所以跳转到循环体的第一条指令 mult

while 循环结构

看下面代码，求 n 的阶乘，根据不同的优化级别，while 循环可以翻译成不同形式的汇编代码格式，下面是在优化级别为 -Og 下得到的：

第一条指令 li 将 result 的值初始化为 1，放在 2 号寄存器中；第二条指令 b 无条件跳转到 L2 代码块的第一条指令 slt，判断循环条件，如果 n < 2 的话，将 R[$3] 设置为 1，如果 n >= 2，则将 R[$3] 设置为 0；下一条指令 beq 判断 R[$3] == 0 的话，说明 n >= 2，那么就跳转到 L3 代码块第一条指令 mult，开始执行 while 循环体，先执行乘法，然后再执行 n = n - 1
然后再来执行指令 slt 判断循环条件，如果 n < 2 的话，将 R[$3] 设置为 1，如果 n >= 2，则将 R[$3] 设置为 0；下一条指令 beq 判断 R[$3] == 0 的话，说明 n >= 2，那么就跳转到 L3 代码块第一条指令 mult，开始执行循环体，如果 R[$3] != 0，则不跳转，跳出循环体，执行 beq 下面的 nop 指令和返回函数指令 jr
这里将 while 循环代码翻译成这种汇编代码格式：一上来进行无条件跳转到判断循环条件的代码块，然后决定是跳转循环体，还是结束循环体，等循环体执行完后，再次进入判断条件
接下里，来看，对于相同的 while 代码，在 -O1 的优化级别下，翻译成下面的汇编代码，一上来就执行 slt 判断循环条件，如果 n < 2 的话，则 R[$2] 设置为 1，否则设置 R[$2] 为 0，下一条指令 bne 判断如果 R[$2] == 0 的话，那么说明 n < 2，就跳转到 L4 代码块结束循环体，否则的话，往下执行循环体

在执行循环体之前，先执行指令 li $3, 1 循环条件中的常量 1 放到 3 号寄存器，这个后面比较会用到，再将初始化 result 为 1，然后执行指令 mult $2, $4 将 result 和 n 相乘，结果放在 Lo，接下来，开始执行循环体：
  1. 先执行 mflo $2，将乘积赋值给 result
  2. 再执行 n = n - 1
  3. 最后执行指令 mult $2, $4 将 result 和 n 相乘，结果放在 Lo
接下来执行 bne $4, $3, $L6，判断 R[$4] != R[$3]，即判断 n != 1 的话，则跳转到循环体，开始执行循环体的 3 条指令，如果 n == 1 的话，则结束循环，执行 jr 指令返回函数
这种 while 循环的汇编代码格式，就是先进行判断，如果不符合循环条件，直接不执行循环体，否则，先执行一次循环体，然后再次判断条件，决定是否要执行循环体
对于 while 的这两种汇编格式，第一种一上来就是一个无条件跳转到循环条件判断，然么每一轮循环都测试下循环条件，符合就执行循环体：

第二种，一上来是先判断循环条件，不符合的话，直接结束，如果符合的话，则往下执行循环体，然后判断循环条件，第二种方式，可以优化循环条件的判断逻辑，至于如何做到优化的，我们可以不去追究了，能看懂这两种 while 汇编代码就可以了
