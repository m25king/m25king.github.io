算术逻辑部件（Arithmetic Logic Unit，ALU）是一种能进行多种算术运算与逻辑运算的组合逻辑电路，我们通常使用下面的符号表示 ALU：

上图是一个 32 位的 ALU，输入端 X 和 Y 和 32 位的通用寄存器连接，支持 7 种不同的运算，因此 ALUctr 控制信号需要 3 位，ALU 的核心部件是带标志加法器，下图是上面的 ALU 的内部电路实现：

上图控制单元要让 ALU 做有符号减法操作（sub），两个减数的补码分别输入到 X 和 Y 端，然后控制单元将 sub 的控制信号 ALUctr = 011 送到 ALU 中，ALU 控制信号生成部件根据 011 生成 SUBctr = 1（做减法）、OPctr = 00（控制 MUX2 输出加法器的结果）、OVctr = 1（需要判断是否溢出）、SIGctr 随意（不需要得到比较的结果）
因为做减法，所以加法器的输入 Cin = 1，然后 SUBctr = 1 经过位扩展扩展到 32 个 1，然后和输入 Y 进行异或，对输入 Y 进行取反，然后和 X 都送到加法器，得到 add result，并且会产生 OF 标志信息，add result 通过 MUX2 选择器送到 ALU 的输出 result 中，OF 标志信息通过一个逻辑与门送到 ALU 的输出 OF，这样就完成了 sub 操作
再来看控制单元要让 ALU 做逻辑或操作（or），两个操作数分别从 X 和 Y 输入：

控制单元将 or 的控制信号 ALUctr = 100 送到 ALU 中，ALU 控制信号生成部件根据 100 生成 SUBctr 随意（不用加法器）、OPctr = 01（控制 MUX2 输出或门阵列的结果）、OVctr 随意（不用加法器）、SIGctr 随意（不需要得到比较的结果）
输入 X 和输出 Y 经过或门阵列，得到 X or Y 的结果通过 MUX2 多路选择器输出到 ALU 的输出 result
再来看控制单元要让 ALU 做无符号比较操作（sltu、set less than unsigned，就是无符号比较，小于的话则输出 1），两个无符号数分别从 X 和 Y 输入：

控制单元将 sltu 的控制信号 ALUctr = 101 送到 ALU 中，ALU 控制信号生成部件根据 101 生成 SUBctr = 1（需要做减法 X - Y）、OPctr = 10（控制 MUX2 输出 MUX3 的输出结果）、OVctr 随意（不需要考虑溢出）、SIGctr =0（使用 CF 来判断无符号数 X 和 Y 的比较大小）
因为做减法，所以加法器的输入 Cin = 1，然后 SUBctr = 1 经过位扩展扩展到 32 个 1，然后和输入 Y 进行异或，对输入 Y 进行取反，然后和 X 都送到加法器，得到 CF 标志信息，CF 经过 MUX1 送达 MUX3，作为 MUX3 的选择信号，如果 CF = 1 表示不够减，说明 X < Y，那么从 MUX3 选择 1 再通过 MUX2 输出到 ALU 的输出 result 中，如果 CF = 0 表示够减，那么输出 0
对于 ALU 我们接下来会经常用到，比如实现乘法时需要用到 ALU，实现浮点数的加减运算时也需要用到 ALU
