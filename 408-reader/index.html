GitHub Pages 使用说明

  1. 在 iPad Safari 中打开公开网址，无需登录。
  2. 点左上角菜单，或从屏幕左边缘向右滑，打开可侧拉的资料目录。
  3. 通过“资料阅读 / 题库答题”切换合集；题库只用于本地导入 408 做题本。
  4. 使用顶部的上一篇、下一篇和“单独打开”按钮连续阅读。

这是包含 279 篇 HTML 的公开学习页面。仅供个人学习整理，资料版权归原作者，请勿用于商业用途。原页面中的图片、视频和公式脚本仍来自资料网站。

阅读器会在当前浏览器里记住最后打开的文章、访问记录和滚动位置。若内嵌页面显示异常，可点右上角“单独打开”。

可在 Safari 的分享菜单中选择“添加到主屏幕”，以后像 App 一样打开。
